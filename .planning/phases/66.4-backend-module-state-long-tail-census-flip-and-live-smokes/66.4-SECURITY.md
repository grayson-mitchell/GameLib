## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| developer change -> CI ratchet / census | conversions and the census test decide what passes | source text, shard JSON, sanctioned counts |
| checker -> operator process table / spawned sidecar | `meta/sidecarExitCheck.ts` reads ps output; eof mode spawns a child | pids, command lines, an isolated profile |
| environment -> path derivation | `GAMELIB_APP_ROOT`, `APPDATA`, `XDG_*`, `SNAP_REAL_HOME`, `GAMELIB_SHELL_EXE` select dirs and binaries | filesystem paths, bundled-binary locations |
| frontend RPC -> store backend / store write channels | `storeNew` / `storeSet` / `storeDelete` names reach the path resolver | store names, user JSON |
| frontend -> engine switch, fallback install, launch | user actions start bottle, runtime and game processes | appIds, launch requests |
| Steam refresh token -> keyring / dev vault | token store holds the authenticated Steam session | credentials (sensitive) |
| GOG / Epic / Amazon CLIs, HLTB -> credential caches | session credentials read and cached in memory | credentials (sensitive) |
| Valve CDN / CM, runner payloads, remote catalogs -> disk | downloaded manifests, chunks, binaries, fix profiles | untrusted remote content |
| Rust shell / renderer -> sidecar dispatch | every inbound frame crosses `validateInbound` | RPC payloads |
| stdin EOF / quit -> in-flight work, outbound HTTP | quit must stop referenced work | process lifetime |
| filesystem watcher, OS power management | external writes trigger refreshes; wake locks held | events, power state |
| `gamelib://` protocol URLs / .lnk -> launch | external links trigger launches | app names, runners (untrusted) |
| install directory -> icon scan | arbitrary user-writable tree | filesystem metadata |
| user config dir -> heroic→GameLib rename at boot | moves a whole user data directory | user settings and library |
| test -> HKCU registry / Explorer (opt-in probe) | throwaway protocol key in the operator's real session | registry keys |
| operator machine -> UAT files | evidence copied into committed files | log lines, registry values |
