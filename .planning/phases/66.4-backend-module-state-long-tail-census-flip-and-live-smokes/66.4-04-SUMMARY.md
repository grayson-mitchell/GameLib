# Phase 66.4 Plan 04: Per-boot StoreRoot Summary

Every persistent store now takes its directory, shared file cells and renderer-push channel from one `StoreRoot` built by the 'stores' boot step from `ctx.paths.userData`; `storeChangeNotifier.ts`, the `fileStore` cell registry and the two long-tail store modules are gone from the census.

## Commit
- 502b49d82: refactor(66.4-04): per-boot StoreRoot for every store, notifier and file cells (one commit: the three plan tasks change one contract and the tree does not typecheck between them)

## StoreRoot contract
`createStoreRoot({ userData })` returns `{ userData, cells, changes }`. `cells.cellFor(fullPath, create)` is the former `cellRegistry` (D-14 same-path sharing kept, per root). `changes` is the former notifier + `suppressDepth`: `notify` is a no-op until `bind(push)`, a throwing push never propagates, `invalidate(name)` replaces `notifyStoreInvalidated`, `withSuppressed(fn)` restores depth after a throw. WR-11 containment is the same resolve+relative check, now reading `root.userData` (store_backend and fileStore); `../../evil` still throws (tested in storeRoot.test.ts and cache.test.ts).

## New families
`createStores` now returns 18 families: `engine.noticeStore` (CacheStore `steam_engine_notices`, name unchanged) and `systemInfo.{deviceNameCache,vendorNameCache}` (`pci_ids_device`/`pci_ids_vendor`, unchanged). `lazyNoticeStore` and its `require` are deleted; the 'engine-state' step reads `stores.engine.noticeStore`. pci_ids lookups take `PciIdCaches`; `SystemInfoDeps` gains `stores: Pick<Stores,'systemInfo'>`; `ClearCacheDeps` gains `systemInfo`.

## Cascade edits (call-site only)
utils.ts (clearCache reads `systemInfo`), utils/systeminfo/index.ts + gpu/index.ts + gpu/pci_ids.ts, launcher.ts (stores gains `systemInfo`, passed to getSystemInfo), sidecar/clipboardFlowRegistration.ts and settingsFlowRegistration.ts (deps gain `stores`/`systemInfo`), sidecar/runnerAuthFlowRegistration.ts and storeManagers/legendary/user.ts (stores Pick gains `systemInfo`), sidecar/handlers.ts (passes `storeRoot`, `stores` to clipboard), sidecar/storeWriteHandlers.ts (applyStoreWrite(registry, root, ...), root bind, `{registry, root}` latch), services/types.ts (`Stores.engine/systemInfo`, `BootServices.storeRoot`).
