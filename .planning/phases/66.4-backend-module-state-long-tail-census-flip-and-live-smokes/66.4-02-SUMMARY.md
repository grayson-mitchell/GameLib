# Phase 66.4 Plan 02: Sidecar exit/orphan checker Summary

A report-only checker that snapshots the sidecar process tree, measures exit latency after quit/EOF, and reports surviving or reparented descendants; decision logic is pinned by 7 fixture tests (T1-T7).

## Commits
- 7181d08ba: pure logic and tests
- 88fa52d69: CLI driver and package script

## Thresholds
- eof: PASS up to 2000 ms, WARN above 2000, FAIL above 5000 or any survivor.
- live: PASS up to 1500 ms, WARN above 1500 (shell_state.rs shutdown_child SIGKILL grace is 2000 ms), FAIL above 5000 ms or any descendant alive/reparented 5000 ms after the shell is gone.
- Empty/unparseable ps, missing sidecar pid, or unobserved exit is INVALID (exit code 2); FAIL exits 1; PASS/WARN exit 0.

## Measured eof latency
`pnpm smoke:exit-check -- --mode eof` against a fresh `pnpm build:sidecar`: PASS, latencyMs 41, no survivors. This is far below the ~0.7 s the plan cited, so the 2000 ms warn line has wide margin on an empty profile; the real-profile live arm is where slow exit would show.

## Operator command (plan 22)
Start `pnpm tauri:dev`, then in another terminal: `pnpm smoke:exit-check` (live), and press Cmd+Q when prompted (30 s window). Live mode matches the dev sidecar (`build/main/sidecar.js`) and the packaged `gamelib-sidecar` externalBin.
