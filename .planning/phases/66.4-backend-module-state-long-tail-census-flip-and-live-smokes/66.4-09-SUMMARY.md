# Phase 66.4 Plan 09: Steam depot and library-poll long tail Summary

The Steam install pipeline's appinfo order tap, CDN schema cache, shared-redist lock table and tmp sequence, Rust depot job registry, install poll registry (plus bridge-finalized set and notice sequence), restart-hold bookkeeping and uninstall poll registry are now closure fields of factories bundled in a boot-built SteamInstallRuntime.

## Commit
One code commit (`a5f9d24cb`) for both tasks: the tree does not typecheck between them once ManagerDeps, the depot opts types and the shared test helpers change (as in 66.4-04 to 08).

## Runtime contract
`createSteamInstallRuntime()` builds the install poll state first, then the restart hold over it. Construction allocates empty maps, sets, a WeakMap and counters only: no I/O, timer or handle (tested: zero fake timers after construction). Consumers:
- depot pipeline: `opts.installRuntime` (a `DepotRuntime` Pick) on DownloadSteamDepotsOpts and DownloadSharedRedistOpts; `fetchAppInfo` / `fetchDlcInfos` take the appinfo order tap; Rust install / secondary / sharedRedist jobs take `installRuntime.depotJobs` through `RunDepotJobHooks.registry` and `SharedRedistJobArgs.registry`
- sidecar: `registerDepotHostFlows({ ipc, depotJobs })` looks jobs up and dispatches events on the boot's registry
- library: `deps.steamInstallRuntime.polls` (installPolling, installPollOnce, installStop, resume, refresh, index, gameUninstall, gameInstallBridge), `.restartHold` (installPollOnce, refresh, resume, index), `.uninstallPolls` (uninstallPolling); GameDetailsDeps carries `polls` for `isDelegatedInstallPolling`
- The RunningAppID poller (`steam-running-poll` step) is untouched; pollState's three sites are install poll state only

## Step position
`'steam-install-runtime'` sits directly after `'steam-bridge-runtime'` and before `'winetricks-queue'` / `'store-managers'`. BootServices.steamInstallRuntime, ManagerDeps.steamInstallRuntime, `CreateStoreManagersDeps`, `managerDepsFromServices`, requireServices and the store-managers step carry it. bootstrap.test pins 33 fields.
