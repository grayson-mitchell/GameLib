## Build

Run on the Windows 11 machine (Steam installed, signed in), in PowerShell. This is the same flow the 2026-11-11 9p6/a9g gates used:
`pnpm tauri:dev` runs the preflight, `pnpm build:sidecar`, then `tauri dev`.

Prerequisites (as for the earlier gates): Git, Node 22, pnpm, Rust toolchain (MSVC), and the Tauri prerequisites (WebView2).

1. Get the phase head. The 66.4 commits must be pushed to `origin/main` first (as of writing, local main is 173 commits ahead of origin).

   ```powershell
   cd <your GameLib checkout>
   git fetch origin
   git checkout main
   git pull --ff-only origin main
   git log --oneline -1   # expect the phase head, or later; the 66.4-23 UAT commit is the newest 66.4 commit
   pnpm install --frozen-lockfile
   ```

2. Quit any installed GameLib (system tray too). `tauri:dev` refuses to start when a foreign `gamelib-shell.exe` is running.
3. Launch the dev app, then confirm the sidecar bundle is fresh:

   ```powershell
   pnpm tauri:dev
   # in a second PowerShell window:
   (Get-Item build\main\sidecar.js).LastWriteTime   # must be after your pull
   ```

4. The log is `%LOCALAPPDATA%\GameLib\logs\gamelib.log`. Config and library data live under `%APPDATA%\GameLib`.

Exit check: `pnpm smoke:exit-check` is NOT part of this UAT. meta/sidecarExitCheck.ts reads `ps -axo pid,ppid,pgid` and has no win32 branch, so it does not run on Windows; the sidecar exit contract was measured on macOS in 66.4-22. Do not run it here.

Not re-run: 5fw spawn-path items (D-66.4-06).
