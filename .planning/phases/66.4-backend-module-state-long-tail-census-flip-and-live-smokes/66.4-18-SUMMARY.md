# Phase 66.4 Plan 18: Store versioning, dialog acks, misc runtime and the last stateless path readers Summary

Store versioning, read-only tracking and migration chains are now fields of the per-boot StoreRoot, the dialog display-ack table and notification-denial flag are owned by their host services, a new misc runtime holds the metadata push / Mac arch prompt chain / CheapShark cache, and the last six files reading `constants/paths` read an AppPaths slice instead.

## Commits
- 0d41378c3: refactor(66.4-18): store versioning, read-only tracking and migration chains as per-root StoreRoot state
- 0a64cde32: refactor(66.4-18): dialog acks, notification denial, misc runtime and the last stateless path importers

## What changed
- `createStoreVersioning({ migrations, readOnly })` (engine.ts), `createReadOnlyStores({ sinks? })` (readOnlyStores.ts, `flush` replaces `flushReadOnlyStores`) and `createMigrations({ overrides? })` (storeMigrations/index.ts) replace the module state. `createStoreRoot` builds all three; `readOnlySinks` and `migrationOverrides` are its options.
- The `readOnly`/`list` API, the four `storeVersioning/*File.ts` helpers, config/game_config settings migration, engine marker, Mac Steam owed marker and shared-redist ledger all take the root's `versioning`. App-shell `frontendReady` flushes `deps.readOnly` (the root's tracker).
- `Dialogs.displayAcks`: engine dialogs, Steam launch notices, bridge invite picker and the `dialogDisplayed` handler use it. `createNotifications` reports a permission denial to `onFailed` once per instance; `notify()` lost its flag.
- `miscRuntime.ts`: `metadataOverrides` (createMetadataOverrides, warn-once per instance when built with no notifier), `macArchPrompts` (createMacArchPromptChain), `storeMap` (createStoreMapCache). New boot step `'misc-runtime'` directly after `'app-runtime'`; BootServices gains `miscRuntime` (42 fields).
- Paths: `createGlobalConfig` / `createGameConfigs` take `paths`; `setGameOverrides` takes `paths.userData`; `LegendaryGlobalConfigFolderMigration` takes `userHome`; shortcuts take `heroicIconFolder`/`userHome`. None of the six imports `constants/paths`.
