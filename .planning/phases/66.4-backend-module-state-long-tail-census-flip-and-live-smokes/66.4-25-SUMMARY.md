# Phase 66.4 Plan 25: Windows proof of the G-66.4-W2 shortcut fix Summary

Proved the 66.4-24 Windows shortcut fix on real Windows in two layers: a Windows-only jest file that reads the real writer's .lnk back and dispatches it against a throwaway protocol (with an unquoted negative control that shows the probe can see the defect), and a live operator double-click of real Desktop shortcuts that is recorded as UAT item 7 (pass), resolving G-66.4-W2.

## What was done

### Task 1: real Windows .lnk readback and opt-in dispatch probe (commit 14fb16a92)

`src/backend/shortcuts/__tests__/windowsShortcut.win32.test.ts`, skipped off Windows so ubuntu CI never runs it.

- Describe A (every Windows jest run, no registry, nothing opened): the real `writeWindowsShortcut` .lnk on disk reads back with TargetPath `explorer.exe`, Arguments the URL wrapped in double quotes, IconLocation the icon path plus `,0`.
- Describe B (`GAMELIB_LNK_DISPATCH_PROBE=1`): registers `HKCU:\Software\Classes\gamelibprobe<8 hex>`, opens the .lnk through ShellExecute, polls a hit file, closes any Explorer window the probe opened, and removes the key in `afterAll`, asserting absence. The quoted .lnk must hit the handler with no `file:` window; the pre-fix unquoted .lnk must not, and a control hit fails the suite with a message that the probe can no longer tell quoted from unquoted.

## Deviations from Plan

### Auto-fixed Issues (both inside the new test file, Task 1)

**1. [Rule 1 - Bug] PowerShell 5.1 serialised Get-Content strings as PSObjects**
- **Found during:** Task 1 (first live run of the probe)
- **Issue:** `ConvertTo-Json` in Windows PowerShell 5.1 emitted `Get-Content` results as PSObject property bags rather than plain strings, so the hit lines were unparseable.
- **Fix:** cast each line to `[string]` before serialising.
- **Files modified:** src/backend/shortcuts/__tests__/windowsShortcut.win32.test.ts
- **Commit:** 14fb16a92

**2. [Rule 1 - Bug] tsc `noUncheckedIndexedAccess` on `out.hits[0]`**
- **Found during:** Task 1 (`pnpm codecheck`)
- **Fix:** `out.hits[0] ?? ''`.
- **Files modified:** src/backend/shortcuts/__tests__/windowsShortcut.win32.test.ts
- **Commit:** 14fb16a92
