# Phase 66.4 Plan 24: Windows shortcut dispatch and icon Summary

**Windows .lnk shortcuts now hand explorer.exe the gamelib:// URL as one double-quoted argument (inner quotes percent-encoded) and carry the game's own exe as their icon, found by a bounded install-dir scan when the store record has none.**

## Accomplishments

- **Dispatch (G-66.4-W2 defect 1).** `buildShortcutEnv` wraps the URL in double quotes and replaces any inner `"` with `%22`; `args` follow the closing quote; the non-URL arm is untouched. The win32 arm builds its launch URL with `encodeURIComponent` on `app_name` and `runner`, mirroring `generateMacOsApp`. Threat T-66.4-76 is covered by a test where a hostile `app_name` (`x" /root,C:\ &x`) still yields exactly two quote characters.
- **Icon (defect 2).** New `windowsShortcutIcon.ts` exports one function, `resolveWindowsShortcutIcon`. The scan is breadth-first, at most 3 directory levels and 20,000 entries, skips symlinks and junctions, swallows per-directory errors. Candidates rank by name match (tier 0 exact, tier 1 contained, tier 2 other), then shallower, then larger, then relative path. Helper exes are excluded by regex. Only an existing `.exe`/`.ico`/`.dll` is returned. `shortcuts.ts` replaced its win32 icon block with a call to it and logs the source.
- **Tests.** 22 resolver cases built from the nine measured Steam layouts plus depth, symlink, store-exe and fallback cases; 5 new `buildShortcutEnv`/`addShortcuts` dispatch cases; 3 new `addShortcuts` icon cases. Six shortcut suites: 90 tests passing on this Windows host.

Shortcuts written before this fix keep the old target and icon; re-adding a shortcut rewrites the .lnk.

## Deviations from Plan

**1. [Rule 1 - Bug] Helper exclusion exempts an exact name match**
- **Found during:** Task 2 design
- **Issue:** The plan's helper regex over the relative path would drop a game whose own exe name contains a helper word (e.g. `CrashBandicoot.exe` matches `crash`), giving it the shell icon.
- **Fix:** A tier-0 candidate (name equals install dir or title) is never excluded. Covered by a Crash Bandicoot case.
- **Files modified:** `windowsShortcutIcon.ts`, `windowsShortcutIcon.test.ts`
- **Commit:** `d46639af5`

**2. [Rule 1 - Bug] Absolute store executable is not re-joined**
- **Found during:** Task 2
- **Issue:** "Join with install path" would turn an absolute store executable into a path that cannot exist.
- **Fix:** An absolute `storeExecutable` is used as given.
- **Commit:** `d46639af5`

**Total deviations:** 2 auto-fixed (both Rule 1, both narrowing, no scope change).
