## Non-vacuity — what was done to avoid a green check that proves nothing

**1. The `onKeyDown` chain was traced to the DOM, not to the call site.** A grep for `onKeyDown`
finds it in `PathSelectionBox/index.tsx:184` and as a type declaration at
`TextInputWithIconField/index.tsx:17` — and **nowhere in `TextInputField`**. Taken at face value
that reads like a broken chain. It is not: the prop reaches the real `<input>` by double spread —
`TextInputWithIconField:24,28` spreads `...props` into `TextInputField`, which collects
`...inputProps` at `:30` and spreads them onto `<input>` at `:65`. **A named-prop grep would have
returned a false negative here**, which is worth recording for the next reader.

**2. The jest suite was mutation-tested in three independent directions.** A suite that passes
against broken code proves nothing, so each guard was disabled in turn and the suite re-run:

| Mutation | Result |
| --- | --- |
| G2 disabled (`false && enterCommittedRef.current === next`) | **1 failed**, 7 passed |
| G1 disabled (`false && next === path`) | **1 failed**, 7 passed |
| Auto-repeat guard weakened (`e.repeat` dropped) | **2 failed**, 6 passed |

Each mutation failed a *different, correctly-named* test. Source restored by `cp` (never
`git checkout` — that fires the post-checkout hook and `download-helper-binaries` throws) and
confirmed byte-identical by shasum `c43c6fd9faa8092af7796131e96382e5ba7c9ce3`.

**3. The layout claim was measured, not eyeballed.** REQ-34.17-03's "does not shift the surrounding
layout" was asserted from screenshots during execution and was **false**. It is now measured by
decoding frames captured from one fixed rectangle: all five states land on y=132.

**4. i18n placement checked in both directions:** `pathSelectionBox` appears in
`public/locales/en/gamelib.json` and **zero times** in `translation.json`.

**5. Full regression run:** `npx jest --selectProjects Frontend` → **126 suites, 2059 tests, all
passing**. Note `--selectProjects` is case-sensitive and `Frontend` is the real display name; a
lowercase value matches nothing and exits 0.
