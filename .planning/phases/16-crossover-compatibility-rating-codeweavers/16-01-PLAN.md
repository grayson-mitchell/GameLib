<objective>
Create the CodeWeavers backend lookup service that, given a game title, fetches
`GET https://www.codeweavers.com/compatibility/crossover/{slug}` with a desktop
browser User-Agent, detects hit vs miss by page CONTENT (parseable `VideoGame`
JSON-LD `aggregateRating` vs a soft-404 page titled "404 Not Found"), and returns
a numeric `ratingValue` + `ratingCount` (D-01, D-03, D-05). Implements the D-04
slugify fixes (drop apostrophes, normalize roman numerals, one fallback slug) and
the D-09 miss/error contract (soft-404 → cacheable EMPTY marker object; fetch error
→ null so it retries).

Purpose: This is the data source for the whole phase. Plans 02 (orchestrator) and
03 (frontend row) depend on the exported `getInfoFromCodeweavers` and the new
`CodeweaversInfo` / `WikiInfo.codeweavers` types this plan defines.
Output: `codeweavers/` backend module (utils + constants + tests) and the extended
type model in `common/types.ts`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| game title → outbound URL | User/library-controlled title is slugified and appended to a fixed CodeWeavers path |
| codeweavers.com → parser | Untrusted third-party HTML/JSON-LD is parsed and cached |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16-01 | Tampering/Info-Disclosure (SSRF/path-traversal) | slugify → URL in codeweavers/utils.ts | mitigate | slugify emits only `[a-z0-9-]` (collapses `/ . : ..` to `-`, trims); slug appended to constant `BASE_URL` so host + path prefix are fixed — a crafted title cannot redirect the request to another host or escape the `/compatibility/crossover/` path |
| T-16-02 | Denial of Service | extractVideoGameJsonLd / axios fetch | mitigate | `maxContentLength` cap on the axios call bounds response size; `ldJsonRegEx` is non-greedy (`[\s\S]*?`) so no catastrophic backtracking; `JSON.parse` wrapped in try/catch |
| T-16-03 | Tampering (cache poisoning) | getInfoFromCodeweavers return contract | mitigate | A fetch error or JSON.parse throw funnels to the catch → `return null` (retryable), so a transient CDN challenge / malformed page is never cached as a false miss; only a content-classified soft-404 caches the EMPTY marker (D-09) |
| T-16-04 | Information Disclosure | outbound lookup to codeweavers.com | accept | Only the public game title (already displayed) leaves the app; no PII/credentials; on-demand + cached reference-style lookups honor CodeWeavers `use=reference` signal (SC-02). No mitigation needed beyond polite caching |
| T-16-SC | Tampering (supply chain) | npm installs | accept | N/A — no new dependencies; axios/electron-store already present and vetted. No Package Legitimacy Gate required |
</threat_model>
