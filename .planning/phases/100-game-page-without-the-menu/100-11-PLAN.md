<objective>
Close the shell half of gap 2 in 100-VERIFICATION.md (review finding CR-02). `moveInstall`,
`changeInstallPath` and `steamRemoveAllCopies` are not on the shell's `LONG_RUNNING_CHANNELS`, so
under Tauri a Move longer than 60 s rejects while the sidecar keeps copying. Since Phase 100 the
Location row catches that rejection and shows "Move failed" with a Retry for a move that is still
running. This plan adds the three channels to the list with the list's per-entry rationale style,
pins each with an explicit `timeout_for(...) == None` assertion, and extends the TS mirror gate.

Purpose: an inline failure is only honest if the transport waits for the backend's answer (D-12,
D-18). The renderer half (Retry gating, a hand-off for a timeout that still reaches it) is plan
100-13.
Output: three new list entries and one Rust pin test in `src-tauri/src/main.rs`; three new mirror
entries and member tests in `src/backend/__tests__/longRunningChannels.test.ts`.

Rust shutdown convention (Skill gamelib-conventions, confirmed while planning): this plan adds no
spawn, task, timer, socket or exit work. It only adds strings to a const that `timeout_for`
consults. A pending exempt invoke is still released when the sidecar's stdout ends
(`drain_pending_invokes`), and the sidecar's process group is still reaped in the children stage
of `handle_exit` within `ExitBudget::DEFAULT`.

Spec-less probe fallback skipped: phase has no requirement IDs to probe (visible skip).
</objective>
