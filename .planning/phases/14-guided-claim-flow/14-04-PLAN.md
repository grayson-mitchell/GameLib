<objective>
Build the HumbleClaimWizard — a single stateful React component passed as the `message` of showDialogModal — that carries the C1 warning, the reveal action, the post-reveal key display + activation link-out, and the mark-redeemed confirmation, plus the C2 redirect and all failure states.

Purpose: This is the one controlled surface the entire claim UX flows through (D-65). It must make reveal impossible without an explicit danger-confirm (HCLAIM-01), copy+open the Steam registerkey page (HCLAIM-03), and offer only a link-out for non-Steam keys (HCLAIM-05). It owns its own step/loading/error state internally so no state leaks into the caller.
Output: The wizard component + scoped CSS (semantic tokens only) + a component test covering the non-Steam branch, the no-reveal-without-confirm invariant, and the C2 redirect.
</objective>
