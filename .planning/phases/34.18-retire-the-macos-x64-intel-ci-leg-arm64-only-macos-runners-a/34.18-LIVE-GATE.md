## `T-34.18-30` hazard — read this before running anything

During this gate, `git checkout -- <path>` fires `.husky/post-checkout`, whose
`pnpm download-helper-binaries` step can, at that arbitrary moment, either throw on a
half-restored `meta/runnersOnedirDigests.json` or (once §2 has pinned real digests) kick off a
full runner re-download you did not ask for. **This is an acceptance criterion in §3, not
advice**: every backup in this document is taken with `cp`, every restore is done with `cp`, and
every restore is verified with `shasum -a 256` against the backup's own recorded hash. Never
`git checkout -- <path>`, never `git stash`, never `git reset` — this repository also has a
concurrent session active in the same tree, and any of those three commands can strand it
(project standing lesson: `executor-git-stash-strands-concurrent-session`).
