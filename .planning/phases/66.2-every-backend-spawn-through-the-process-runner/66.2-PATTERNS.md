## Pattern Assignments

### Shared recipe 1: `run` with timeout + non-zero-exit handling (replaces `exec`/`execFile` rejection)

**Analog:** the injected `spawnAsync` (`src/backend/spawnAsync.ts:78-113`) and `commandRunner.ts:514-560`. Core rule: `run` resolves on non-zero/timeout/abort, so every converted `try { await exec… } catch { missing }` needs an explicit `ok(result)`.

Copy (RESEARCH Pattern 1/2, `66.2-RESEARCH.md:231-249`, consistent with `spawnAsync.ts`):
```typescript
const r = await deps.runner.run('/usr/bin/pgrep', ['-x', 'steam_osx'], {
  env: profile.childEnv(), replaceEnv: true, stdin: '', timeoutMs
})
if (r.timedOut) throw new Error(`pgrep timed out after ${timeoutMs} ms`)
if (r.code === 0) return true
if (r.code === 1) return false
throw new Error(`pgrep exited ${r.code}`)
```
Shell-string -> argv (e.g. `which`, `rsync --version`, `mdfind`): one helper per module:
```typescript
const ok = (r: RunResult) => !r.timedOut && !r.aborted && r.code === 0
const present = await deps.runner.run('which', [dependency], { env: envs, replaceEnv: true, timeoutMs: 5_000 })
  .then(ok, () => false)            // spawn error (ENOENT) rejects -> "missing"
```
`mdfind kMDItemCFBundleIdentifier = "*.wine"` -> keep the three-word argv `['kMDItemCFBundleIdentifier','=','*.wine']` (CONTEXT).

Spawn-error mapping (Pattern 2): `rejection -> failure`, `timedOut -> failure`, `code !== 0 -> failure or a domain meaning`. `steamClientProcess.ts`: map rejection to the existing `'ERR'` code, `timedOut` to non-zero, so `listSteamClientPids` keeps returning `undefined` on failure and `[]` on pgrep exit 1.

**Timeout opt-out** (only where the old code had no cap, e.g. winetricks installs, tar): copy `commandRunner.ts:527-531`:
```typescript
timeout: { none: true, reason: 'store CLI downloads and installs run for as long as the transfer takes; the user cancels through the abort controller or killTracked' },
```
`reason` must be non-empty (`TypeError` otherwise).

### Shared recipe 2: `stdin: ''` and `replaceEnv: true`

**Source of truth:** RESEARCH Pitfall 1, 5 (`66.2-RESEARCH.md:294-312`); live precedent `commandRunner.ts:514-518`, `helperSpawn.ts:346-352`.

## Shared Patterns

### Factory, narrow deps, no default args
**Source:** `spawnAsync.ts:67` (`createSpawnAsync(deps: { runner: ProcessRunner })`), `process/runner.ts` `createProcessRunner(deps)`.
**Apply to:** every converted module with 3+ dep-taking functions or closure state; narrow `{ runner }` / `{ runner, clock }`, never whole `AppContext`, never `getContext()`/module-level runner. Replace `defaultEngineDecisionDeps()`, `defaultMacSteamOfflineDeps()`, `defaultRunTool`, `defaultRunCodesign`, `defaultRunUnzip`, `defaultDeps()`.

### Exit contract
**Source:** `process/runner.ts` (unrefs child, pipes, clock timers), CLAUDE.md convention 3.
**Apply to:** boot-adjacent probes (`checkRosettaInstall`, `getCometVersion`, `genericSpawnWrapper`, `searchForExecutableOnPath`, `listSteamClientPids`, `restoreMacSteamOnlineIfOwed`, `startRunningPoll`). Every `run` bounded; timers on `ctx.clock`; verify `pnpm build:sidecar && pnpm smoke:sidecar` (smoke misses slow exit; pair with unit assertions).

### Fake-HOME
**Source:** `testUtils/fakeHomeProfile.ts`, `fakeHomeIsolation.test.ts`.
**Apply to:** production probes (`createFakeHomeProfile().childEnv()` + `replaceEnv: true`) and any real-child test. Re-run `pnpm jest src/backend/__tests__/fakeHomeIsolation` after any plan that deletes or rewrites a spawn site.

### Kill signal and cancel semantics
**Source:** `spawnAsync.ts:1-18` contract. Timeout = SIGKILL (was SIGTERM in `genericSpawnWrapper`/`timeout` option); abort resolves `aborted: true` (never `AbortError`); legacy `utils.spawnAsync` never took a signal, so no cancel semantics need preserving for `moveOn*`/`extractTarFile`. Treat `killedByUs`/signal exits as cancellation, not failure (`commandRunner.ts` ~545-560).

### Verify/format
Every task `<verify>`: `npx prettier --file-info <path>` then `npx prettier --check <exact paths>` (never `.`); omit with a stated reason if all paths are prettier-ignored. Also `pnpm codecheck` when types change, `pnpm boundaries`, `pnpm lint`.
