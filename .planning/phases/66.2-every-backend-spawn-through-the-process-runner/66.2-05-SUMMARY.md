# Phase 66.2 Plan 05: Leaf utility spawners on the runner Summary

`os/path`, `os/processes`, `helperBinaries` and `utils/macArch` no longer import `child_process`; the four childProcess census entries are gone. System Information and disk-info probes (C-04) and the mac-arch probes run through `runner.run`, each bounded.

## Commits

- ede363ff7 Task 1: os/path pure PATH scan
- 91f3fbf81 Task 2: System Information, disk-info and comet probes on the runner
- 9debf1d27 Task 3: macArch probes async on the runner; steam library and recovery callers

## Decisions

- **os/path discretion choice:** no child at all. `which`/`where` is a PATH lookup, so `findExecutableOnPath(executable, env, platform, cwd)` is an `fs.statSync` + `X_OK` scan (win32: PATHEXT, cwd first). `searchForExecutableOnPath`/`hasExecutable` keep their signatures, so no 28-call-site cascade. First match only (old `where.exe` could return several joined lines). The sync helper is exported for plan 07's default wine.
- **SIGTERM -> SIGKILL:** the probe timeout kill is now the runner's SIGKILL (the old `spawn({timeout})` sent SIGTERM).
- `genericSpawnWrapper` passes `replaceEnv: true` when `options.env` is given (old spawn replaced the env), and `stdin: ''`.
- `getCometVersion`: spawn rejection or `timedOut` -> `'invalid'`; non-zero exit still returns trimmed stdout (unchanged).
- `machOArchsOfAsync`: each probe 5 000 ms; spawn error, timeout or non-zero falls to the next probe; both failing -> `[]`, never rejects. Empty lipo output also falls back to `file`.
- `getPageSize` (macOS memory): empty stdout (timed-out probe) now falls back to 4096 instead of 0.
- No boot step calls `getSystemInfo`/`getDiskInfo` (`bootstrap.ts:1236` records that the dump is lazy, A-CR-1); verified by grep.

## Cascade edits

- `ProbeDeps = { runner: Pick<ProcessRunner,'run'> }` exported from `os/processes`; every probe in `systeminfo/*` and `filesystem/*` takes it first; `getSystemInfo` deps and `getDiskInfo(deps, path)` carry it.
- `launcher.ts`, `clipboardFlowRegistration.ts`, `settingsFlowRegistration.ts`: pass `runner`. `shellFilesFlowRegistration.ts`: `getDiskInfo(deps, path)`.
- `runnerMiscFlowRegistration.ts` (not in the plan's file list): `getCometVersion({ runner: deps.runner })`.
- `MacArchRecoveryDeps` gains `runner`; `verifyMacArchGroundTruth` awaits `machOArchsOfAsync(deps, ...)`.
- Tests: new `os/path`, `os/processes`, `helperBinaries` (comet) and `systeminfo/__tests__/probes.test.ts` on scripted runners; `filesystem` tests rewritten; `shellFilesFlows.test.ts` scripts `df` for `checkDiskSpace`; `macArch.test.ts`, `library.macArch.test.ts`, `macArchKnownFixRouting.test.ts` drop their `child_process` mocks (library test uses a `probe` fn behind a runner adapter).
- Shards: `utils.json` (3 childProcess entries removed, macArch.test 5->4), `storeManagers.steam.macArch.json` (26->25, 34->33). `macArch.json`, `__tests__.json`, `sidecar-tests-flows-*` needed no change (measured counts unchanged).
