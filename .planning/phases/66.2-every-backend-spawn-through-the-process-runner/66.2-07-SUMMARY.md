# Phase 66.2 Plan 07: Wine discovery on the runner Summary

`compatibility_layers.ts`, `config.ts` and `downloader/utilities.ts` no longer import `child_process`; `compatibility_layers` no longer imports `execAsync`. The only `execAsync` user left outside `utils.ts` itself is `tools/index.ts` (plan 08).

## Commit

- dc76bb496: all three tasks in one commit (the changes interleave through shared deps types, so they could not be split cleanly).

## What changed

- The seven shell strings are argv `runner.run` calls: `mdfind ['kMDItemCFBundleIdentifier','=','*.wine']`, `['kMDItemCFBundleIdentifier','=','com.codeweavers.CrossOver']`, `['wine64']`, and `run(wineBin, ['--version'])` (no shell, so a path with a single quote works). Timeouts: mdfind 10 000 ms, `--version` 5 000 ms. A local `ok(r)` maps timedOut/aborted/non-zero to the old exec rejection; wineskin/system GPTK keep their catch-and-log path, mdfind failure yields an empty set.
- `getDefaultWine` is gone: `getDefaultWineBinary()` (sync PATH scan via `findExecutableOnPath`) and the version naming moved into async `getLinuxWineSet({ runner }, scanCustom)`.
- `config.ts`: `isFlatpakSteamInstalled(roots)` fs check of `/var/lib/flatpak` and `~/.local/share/flatpak` replaces `flatpak info`; `getAlternativeWine`/`getMacOsWineSet` take `{ runner }` per call.
- `getFolderSize({ runner }, folder)` is async on `run('du', ...)`, 60 000 ms; failure now returns 0 (the old code returned NaN) with a warning.

## Decisions / notes

- **D-66.2-03 deferral:** `GlobalConfig.globalInstance` and every other static stay; no runner is bound into GlobalConfig. Removal belongs to 66.3.
- **D-66.2-01 accepted cost:** on a fresh Linux profile the persisted default `wineVersion.name` is the binary name (`wine`) until the wine list is read.
- Tests: no new `jest.mock`; mac-only cases in `compatibility_layers.test.ts` run on macOS hosts only (`describe.skip` elsewhere) to keep the shard at 1.
- Shards: `utils.compat` (childProcess entry removed), `_root.config` (childProcess removed), `wine` (utilities.ts removed). `__tests__.config`, `engine`, `storeManagers.steam.wine` measured unchanged.
