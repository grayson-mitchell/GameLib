| Boundary | Description |
|----------|-------------|
| renderer URL -> shell.openExternal -> /usr/bin/open | untrusted URL becomes an argv entry of a detached child |
| game title / paths -> PowerShell script | user-influenced strings reach a script interpreter |
| registry values -> filesystem paths | REG_EXPAND_SZ values are expanded and used as directories |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-66.2-13 | Tampering | openExternal background arm | mitigate | runner.openDetached passes the URL as one argv entry to /usr/bin/open (no shell); shouldOpenInBackground gate unchanged |
| T-66.2-14 | Tampering | windowsShortcut | mitigate | script stays the fixed WRITE_SHORTCUT_SCRIPT on stdin; user values travel only through buildShortcutEnv env vars, as today; argv fixed |
| T-66.2-15 | Denial of service | nativeImage runSync | mitigate | runSync requires timeoutMs 15 000 and a reason; blocks at most 15 s as before |
| T-66.2-16 | Elevation (policy) | transport seam | mitigate | runner methods passed from ctx.runner at the one boot step; no module-level runner holder added |
| T-66.2-17 | Information disclosure | reg.exe probe | accept | reads only the current user's shell-folder values, same as before |
</threat_model>
