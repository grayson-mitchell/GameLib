# Phase 66.2 Security

## Trust Boundaries

| Boundary | Description |
|---|---|
| developer PR -> CI gate | a change can edit both code and the baseline JSON in one PR |
| source text -> AST counter | the counter decides what "zero child_process" means |
| backend module -> ProcessRunner | every spawn crosses the injected runner; only `src/backend/process/runner.ts` may import `child_process` |
| user/config values -> child argv/env | paths, URLs and tool names reach children as argv entries or env vars, never shell strings |
