## Sampling Rate

- **After every task commit:** touched suites (`pnpm jest <paths> --maxWorkers=2`); `node meta/backendDiCeilings.cjs --shard <shard>` for each shard edited; `npx prettier --check <exact paths>` (after `--file-info`); `pnpm codecheck` when types change.
- **After every plan wave:** `pnpm jest src/backend --maxWorkers=2`, `pnpm backend-di-ceilings`, `pnpm boundaries`, `pnpm lint`, `pnpm find-deadcode`, `pnpm steam-line-ceiling` (Steam waves), `pnpm planning-gates`, `pnpm build:sidecar && pnpm smoke:sidecar`.
- **Before `/gsd-verify-work`:** all of the above green except the baseline. The live macOS smoke is 66.3 (D-17).
- **Max feedback latency:** ~60 s per task.
