## Decisions

- `ElectronStubTransport` gained `openDetached` and `runSync`; `bootstrap.ts` supplies them from `ctx.runner` at the existing `transport` boot step. `platformApi.nativeImage` is `createNativeImage({ runSync })` over the already-counted `transport` variable; it throws `platformApi transport not bound` if used before binding. No new module state.
- nativeImage stays synchronous on `runSync`, with the stated reason (mirrors Electron's sync NativeImage API; both production callers chain it synchronously). A non-zero exit, timeout or spawn error throws a named `[platformApi] nativeImage: sips failed` error; `getSize` returns 0x0 on failure as before.
- `knownFolders.windowsFolderCache` and `clearKnownFolderCache` are deleted (D-15 module-state conversion, knownFolders moduleState 1 to 0): both consumers are user-initiated, one `reg.exe` query per action.
- `pathShim.getPath('desktop'|'documents')` on win32 now returns the homedir fallback (sync cannot await). The registry folder is read by the async callers.
- Windows `.lnk` result mapping: rejection, `timedOut`, and non-zero/missing `.lnk` each map to `{ ok: false, error }`; never rejects.
