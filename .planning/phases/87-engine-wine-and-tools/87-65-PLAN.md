<objective>
Make Stop end a non-Steam game that runs on CrossOver in its own bottle (87-59 finding F3, Stop half; user decision 4).

Purpose: in 87-59, Stop on Trash Goblin (Epic, CrossOver) killed legendary's tracked child but left the game running:
`shutdownWine` ran `wineserver -k` with `WINEPREFIX` set to the stored `winePrefix` (the shared default prefix), because
the CrossOver launch overlay keeps the stored prefix and names the bottle only in `wineCrossoverBottle`
(`utils.ts:964`, `launch/settings.rs`). Stop worked on the built-in engine and on every Steam bridge title. The engine
already has a guarded, capped bottle wineserver kill reachable from TS (`killBottleWineServerWith`, op
`engine_bottle_kill_wineserver`, a gamelib-proc helper spawn with `WINEPREFIX` = the bottle's directory), so the fix routes
the CrossOver case to it; no new Rust op and no new shim.
Output: the routing in `shutdownWine`, its tests, the schedule importer row.
</objective>
