normal end at `:441-444` stops it without clearing `deps.power.displayId`, so the blocker id leaks across launches. The page
state cleared on remount, so the stuck flag was the page's own `playClicked` latch, not the store's status.
Output: the backend fix and the renderer fix, each with tests at the layer of the hole.
</objective>
