## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| game process (Wine) → helper TCP 127.0.0.1 | version strings and handle ints from untrusted game code cross into the native helper |
| helper → signed-in Mac Steam client | forwarded calls act with the user's real Steam session |
| helper stderr → gamelib.log | logged strings originate in game-controlled input |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-52-01 | Tampering | generated in-string decode for pchVersion | medium | mitigate | existing bounded decode (len <= WIRE_IN_STRING_MAX_BYTES 4096 and offset+4+len <= argLen, T-51-24) reused unchanged for every SteamClient GetISteam* case |
| T-52-02 | Spoofing | forwarded GetISteam* | high | mitigate | shim returns a proxy only on native presence; never the x64 null object (text-pin test); no locally fabricated ISteamClient answer exists anywhere on this path |
| T-52-03 | Elevation of Privilege | identity-only helper mode | medium | mitigate | GetISteamUserStats/RemoteStorage/GameServerStats dispatch cases refuse under g_bd_identity_only, mirroring T-51-25 (test pin) |
| T-52-04 | Information Disclosure | FWD log lines | medium | mitigate | log only interface/method names, sanitized version strings and int/presence results; no CSteamID/uint64 values; sanitizer bounds length and strips control chars (prevents log-line injection) |
| T-52-05 | Denial of Service | game-issued BReleaseSteamPipe/ReleaseUser/BShutdownIfAllPipesClosed reaching the native client | low | accept | the helper's own InitFlat pipe is never handed out (shim SteamAPI_GetHSteamPipe stays constant); calls are FWD-logged and watched in the live gate (52-11) |
| T-52-06 | Tampering | unresolved flat symbols | low | mitigate | NULL-tolerant dispatch (T-51-23) returns STATUS_ERR, never calls a NULL pointer |
