<objective>
Add the two strings for the honest notice on the SteamStub-forwarded path (amended done-when, 52-UAT
item 29). The existing 52-06 pair does not fit that path. Its body says "GameLib could not connect it to
your Mac Steam client", which was right for the unforwarded causes (`forwarder-not-built`,
`x86-deferred`, `setup-error`, `no-steam-api`, `withheld`). On the forwarded path it is false: UAT 24,
27 and 28 show HELLO plus `FWD CreateInterface ver=SteamClient017 native=present`, and then the stub's
file/forwarder check rejects the launch (Application load error 3, class O1). So this path gets its own
pair. The 52-06 pair is left untouched.

Strings (English, exact; plan 52-34 uses them verbatim as `i18next.t` defaults):
- `steam.bridge.steamstub.forwardedTitle`: `Steam DRM check not supported`
- `steam.bridge.steamstub.forwardedBody`: `This game uses Steam's DRM wrapper. GameLib connected it to your Mac Steam client, but the wrapper's launch check cannot be satisfied through the native Steam bridge, so the game will probably show a Steam error and not start.`

"probably" is deliberate. The rejection is measured on one title (Grim Dawn 219990). The forwarder file
the stub rejects is the same for every SteamStub title, so the claim generalises, but only as a
likelihood.

Output: the fill record and the 49 catalog plus 48 manifest edits, in one commit.
</objective>
