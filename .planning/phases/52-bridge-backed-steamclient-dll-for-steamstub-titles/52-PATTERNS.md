## Shared Patterns

### Regenerate-and-pin
**Source:** commit `8628ea5a7` file list. Any manifest or policy change => `pnpm gen-vtables`, commit all four generated files (`steam_api_shim.c`, `steam_api.def`, `steam_api64.def`, `bridge_dispatch.h`), update `shimCoverage.ts` + `shimCoverage.test.ts`. ### Argv-form spawn + numeric appId guard
**Source:** `B/importScan.ts` L47, L69-110. `NUMERIC_APP_ID = /^\d+$/`, `spawnAsync(bin, [args])`, never a shell string; failures are logged with `logWarning(..., LogPrefix.Steam)` and returned as typed results, never thrown.

### Path containment
**Source:** `shimGenerate.ts` L144-150 `isContainedWithin`. Apply before copying any DLL into the bottle and before building any registry value.

### Typed-result error handling
**Source:** `placeShimForGame` returns `{status:'error', error}` / `placed` / `placed-miss` / `already-placed`; `readBridgeVerdict` safe-parses and never throws. New setup code follows this: no throws into the launch path.

### Helper logging
`logts(cat, msg)` in `bridge_helper.c:195`; stderr lands in `gamelib.log` as `bridge helper [appId]: ...` (helperProcess.ts:301-307). No new channel.
