<objective>
Collapse cancel, failure, and (later) startup-resume into a single `finalizeToSteam` function — the
one recovery mechanism (D-04/D-05/D-07). It measures real bytes on disk, writes the honest
(possibly-incomplete) InstalledDepots map into a StateFlags=1026 manifest via Plan 02's writer LAST
(after files), and stops. Steam's own verify-repair pass (spike 001) reconciles the rest. Add
plain-language error classification (D-06) so a failed download shows "Steam servers dropped the
connection" / "Out of disk space" + Retry, not a raw stack. Reconcile Retry vs the always-on 1026
handoff (D-07): Retry just re-invokes downloadSteamDepots; the manifest-write-last ordering keeps
them non-racing.

Purpose: SNI-04 (D-04 handoff, D-06 error+Retry, D-07 reconciliation; D-05 startup reuse in Plan 08).
Output: finalizeToSteam + depotErrors.ts + recovery tests.
</objective>
