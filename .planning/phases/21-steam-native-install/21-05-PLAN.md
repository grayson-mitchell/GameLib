## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Decrypted filename → filesystem path | A malicious/corrupt manifest filename must not escape common/{installdir} |
| CDN chunk bytes → disk | Corrupt/tampered chunks must be rejected before persistence |
| Declared file size → memory/disk | An oversized declared size must not defeat streaming (OOM) |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-21-02 | Denial of Service | depot.ts streaming write | mitigate | Positional fd.write per ~1MB chunk; no whole-file Buffer.alloc; chunk fetches within a file bounded by an explicit CHUNK_CONCURRENCY pool (not an unbounded Promise.all over all chunks); peak memory O(file-concurrency × chunk-concurrency × chunk size) regardless of file/depot size |
