<objective>
Close WR-01 and WR-04 — the two manifest-injection / weak-sanitization warnings the verifier
tracked. `manifest.ts`'s `buildAppManifestText` rigorously guards its numeric fields but
interpolates the untrusted PICS-sourced `name` and `installdir` strings into `.acf` VDF text
UNESCAPED (manifest.ts:95-96). `name` comes straight from PICS `appinfo.common.name` with no
sanitization; `installdir`'s upstream `sanitizeInstalldir` (installLocation.ts:90-103) rejects
only `/`, `\`, and `..`. A value containing `"` or a newline can break the VDF structure or
inject a sibling AppState key (e.g. a crafted `name` emitting a second `"StateFlags" "4"` line)
into the exact state file Steam and `readAcfState` both parse.

Purpose: The `.acf` is a state-control file; an injected `StateFlags "4"` would tell Steam a
broken install is FullyInstalled. Escaping the string fields (WR-01) plus tightening the
installdir whitelist (WR-04) are defense-in-depth on the same untrusted string.
Output: A VDF-escaped manifest writer and a stricter installdir sanitizer, each with tests.

This plan is independent of and parallel to 21-13 (disjoint files: depot.ts is untouched here).
</objective>
