**One session directory, created once, before the first gesture:**

```sh

```
Record the value in this document's `session_dir` frontmatter field at run time.

**Exit-status capture uses the redirect form, never `| tee` + `${PIPESTATUS[0]}`.** This is
`34.9-GUARD-PROOF.md` §2.5 CONTRACT AMENDMENT v2 §A2, which is NORMATIVE: the piped idiom silently

file is the A2 failure signature. Do not use `cat -A` — macOS BSD `cat` has no `-A`.

> **Static evidence, offered as input to the decision procedure and NOT as a verdict:**
> `grep -n "arm64\|x64\|x86_64\|lipo" meta/verifyRunnerBundle.ts` returns exactly 2 matches, both in
> the CLI usage/help string — zero arch literals and no `lipo` in any check.
> `meta/preserveRunnerSymlinks.ts` (the F-34.9-01 symlink-restoring `closeBundle` plugin) likewise
> contains zero arch literals; it walks `public/` wholesale (verified 2026-08-24). Neither fact
> proves that a real x64 tree's file count, framework layout and PyInstaller output shape satisfy the
> same thresholds arm64 satisfies.

**Required evidence — all six:**
