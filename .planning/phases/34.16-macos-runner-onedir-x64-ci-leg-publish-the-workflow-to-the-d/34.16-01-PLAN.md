<objective>
Widen the `verify:runner-bundle` guard past arm64 in both macOS packaging scripts (D-05), which is
item 18 / C2-05's own named precondition for closing the auto-publish exposure (D-08), and rewrite
the `electron-builder.yml` prose that this change makes stale-by-behaviour (constraint 4, coverage
half).

Purpose: today `release:mac` builds `--x64 --arm64` behind a guard that only ever inspects
`build/bin/arm64/darwin`. An unverified x64 macOS build can therefore reach the `electron-updater`
feed with the guard green throughout. D-05's second invocation closes that.

Output: `package.json` `dist:mac` / `release:mac` each carry two literal, sequential per-arch guard
invocations; `electron-builder.yml`'s macOS comment block states what is actually true.
</objective>
