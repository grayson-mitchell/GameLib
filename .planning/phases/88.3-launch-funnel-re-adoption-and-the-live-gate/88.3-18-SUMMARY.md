# Phase 88.3 Plan 18: Steam dispatch joins the Rust single-flight table Summary

**The Steam dispatch's single flight (`dispatchSteamLaunch`, `dispatchSteamLaunchWithoutSteamOnce`, `restartSteamNowForAdoption`) now leads, joins and ends its flights in the one Rust table through three typed calls, behind the unchanged `singleFlightLaunch(runner, appName, onJoin, run)` shape; `launchSingleFlight.ts` and its test are deleted behind a RED-first slice.**

## What was built

- **`launchrust/flights.ts`**: `launchFlightBegin`, `launchFlightWait` and `launchFlightEnd`, one returned typed call each. `createRustLaunchFlights({ transport, warn? })` is the glue. `begin` answers `{ lead }` or `{ join: true }` (any other shape rejects `launch_flight_begin:bad-reply`). A leader runs `run`, then `end`s in a `finally` with its value (or `{ rejected: true }` on a rejection, rethrowing the leader's own error to the leader). A joiner calls `onJoin` in a caught microtask and `wait`s; it resolves the leader's value, and rejects for `abandoned`, the `rejected` marker, or a `:shutdown` rejection from Rust, each with a fixed message naming the cause. The glue creates no timer or handle: every wait is a Rust call that ends on the leader's `end`, the sidecar-EOF release or the shutdown token (the wait channel is already in `UNBOUNDED_RUST_CHANNELS`, 88.3-11).
- **`appRuntime.ts` / `sidecar/bootstrap.ts`**: `createAppRuntime({ transport, warn })`; the 'app-runtime' step passes `() => requireHost(state)` and a `logWarning(..., LogPrefix.Steam)`. The transport is read at call time, so construction still allocates no timer or listener.
- **`launchPortComplete.test.ts`**: `SINGLE_FLIGHT` slice (deleted: the file and its test; kept: `golden/single_flight` and `flights.ts`; forbidden: `createLaunchFlights`), run RED first (3 failing) and committed red, then green after the deletion.
- **`engineWineShimSchedule.test.ts`**: rows for the three shims and the glue, `deletedBy: 90.2`, callers `appRuntime.ts`, with a comment naming the three Steam callers.
- **Tests**: `flights.shims.test.ts` (each shim is one typed call and its args pass the zod schema; leader once, value to every joiner, `onJoin` per joiner; throwing and rejecting `onJoin`; leader rejection rejects the joiner and releases the key; sync throw from `run`; `abandoned`; `shutdown`; refused and malformed `begin` run nothing; lost `end` warns and keeps the result; no timer) over `fakeLaunchFlightTransport.ts`, a plain-object fake of the Rust table that models 88.3-11's reply shapes. The tracer is in `launchDispatch.test.ts`: two concurrent `dispatchSteamLaunch` calls make two begins, one wait and one end and launch once, over the glue (the pre-existing concurrent-dispatch, release-after-settle and Without-Steam-joins cases now run over it too).
