## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-88.3-20 | Tampering | a tampered or stale record naming an unrelated pid | high | mitigate | the record is only a proof: `identify` must match the stamp (and the pgid for a member) before adoption, and `kill_adopted_tree` re-checks before any signal; a record is never used to start a process |
| T-88.3-21 | Denial of Service | many or huge records stalling the boot | medium | mitigate | at most 64 records, 64 KiB each, inside `READOPT_BOOT_BOUND`; the rest are left with one line |
| T-88.3-22 | Elevation of Privilege | an owed after-script running at boot | medium | accept | the script is the user's own setting, run as before as a Helper with the same environment; bounded by the shutdown token and `READOPT_SCRIPT_LIMIT`; a behaviour change recorded by D-31 |
| T-88.3-SC | Tampering | npm/pip/cargo installs | high | mitigate | no crate is added |
