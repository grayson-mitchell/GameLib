<conversion_recipe>
The contract for every conversion plan in this phase. Later plans cite it as "67-05 recipe".

R1. Read, per channel: the handler in `src/backend/sidecar/<domain>FlowRegistration.ts` (the
    parameters after `_event`), the preload binding (`grep -rn "'<channel>'" src/preload/api`), and
    every renderer caller (`grep -rn "window.api.<fn>(" src/frontend`). The schema must accept every
    shape a real caller sends; it must not be inferred from the old TS type alone.
R2. Domain file shape (the census parser in `backend/testUtils/ipcDomainParse.ts` depends on it):
    `export const <domain>SyncArgs = {` (send), `<domain>AsyncArgs` (invoke), `<domain>TestSyncArgs`,
    `<domain>FrontendMessagesArgs` (push), keys at 2-space indent, block closed by `}` at column 0
    (optionally `} satisfies ArgsMap`). Then `interface <Domain>AsyncReturns { <key>: <existing full
    return type, e.g. Promise<DiskSpaceData>> }` and
    `export type <Domain>Sync = SendFns<typeof <domain>SyncArgs>`,
    `export type <Domain>Async = InvokeFns<typeof <domain>AsyncArgs, <Domain>AsyncReturns>`,
    `export type <Domain>FrontendMessages = PushFns<typeof <domain>FrontendMessagesArgs>`.
    Exported type names stay identical, so `ipc/index.ts` intersections do not change (D-04).
    Delete the hand-written interfaces in the same edit.
R3. Values: one tuple element per positional parameter, `z.tuple([])` for none. Trailing optional
    positional -> `optionalArg(x)` (JSON turns undefined into null). Objects -> `z.strictObject`
    declaring every key any caller sends (D-06). GameInfo-carrying args and settings writes ->
    `phase70Passthrough({ <keys the handler reads> })` (D-07). Strings -> `nonEmptyString()` where
    '' is never legitimate; `absolutePathArg()` only where every caller passes an absolute path;
    `urlArg()` for URLs (parse only, any scheme); `httpUrlArg()` only where every caller and the
    handler are http(s)-only (scheme allow-lists are Phase 72). Enums from the existing union or
    const array (e.g. `Runner`), written so a drift fails tsc (`satisfies` against the TS union or
    `z.enum(CONST_ARRAY)`). Integers `.int()` with ranges where cheap. Bound hostile-reachable
    strings and arrays with `.max()` (DoS, RESEARCH security table). No `.transform`/`preprocess`,
    no branded schemas, no reads of settings or the filesystem (D-05). Use `.meta({ title })` only
    where useful; it is required only for rustInvoke schemas.
R4. channelSchemas.ts: import the args maps and add `defineChannelEntries('send', x)` /
    `defineChannelEntries('invoke', x)` / `defineChannelEntries('push', x)` /
    `defineChannelEntries('send', x, { testOnly: true })` to `mergeChannelEntries(...)`. Tag
    `caller: 'shell'` for channels only the Rust shell calls and `caller: 'local'` for channels the
    preload serves itself (never reaching `sidecar_invoke`/`sidecar_send`); default is 'renderer'.
R5. Fixture test per domain at `src/backend/sidecar/__tests__/ipcSchemas/<domain>.test.ts` using
    `backend/testUtils/ipcSchemaFixtures`: a table keyed by channel with >= 1 `valid` args array
    copied from a real call site and >= 1 `invalid` args array (for object args, include an
    unknown-key case); `runFixtureTable` parses `roundTrip(args)` (= `JSON.parse(JSON.stringify(args))`)
    and asserts success/failure; `expectFixtureCoverage(argsMap, table)` fails if any schema key has
    no fixture.
R6. Ceiling: lower `CEILING.<bucket>` in `ipcSchemaCoverage.test.ts` by exactly the converted count
    in the same commit; never raise it. Record before/after in the SUMMARY.
R7. Do not edit `*FlowRegistration.ts` files: handler-level guards (`rendererPathGuard`,
    `Path.parse`, ad hoc `typeof` checks) stay as harmless redundancy (D-05; Claude's Discretion
    resolved: leave them). If `pnpm codecheck` shows a call site in `src/preload/api` or
    `src/frontend` that no longer type-checks, fix the call site (never loosen the schema to make
    a wrong call compile) and list each edit in the SUMMARY.
R8. Verify: `pnpm codecheck`; the domain fixture test; the domain's `*Flows.test.ts`;
    `ipcSchemaCoverage`, `ipcDomainCensus`, `flowRegistrationCensus`; `rendererZodGuard`;
    `npx prettier --check` over exactly the paths written.
</conversion_recipe>
