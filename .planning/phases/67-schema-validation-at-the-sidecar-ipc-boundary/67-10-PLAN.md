<objective>
Migrate the ten store-embed `dispatch_rust_channel` arms to the generated argument structs, after
first extending the generator so it can reproduce the arms' field-suffixed error strings.

Purpose: D-13, D-16, D-19. This is the first half of the old single plan 10 (split per plan-check
warning 2). The `x-field-errors` decision is taken here, up front, before any arm moves, so the
humble-login plan (67-11) and Phase 71 inherit one settled mechanism.

Decision (Claude's Discretion, recorded): extend the generator rather than keep arm-level field
checks. The store-embed parse helpers return per-field strings (`store_embed_open:bad-args:url`
and six more suffixes on open, four on set_bounds, one on navigate; measured during planning with
`grep -n 'bad-args:' src-tauri/src/store_embed.rs`). An arm-level check would have to re-read the
raw `Value` field by field before `from_args`, which is exactly the hand-written `value.get(...)`
ladder this phase's must-haves forbid (D-19). Generating that ladder from the schema is less code
in total (one emitter branch, three schemas tagged) and keeps the strings derived from one source.
</objective>
