<platform_gate>
`src/frontend/screens/Library/components/InstallModal/steamSectionGating.ts` - `platformRow`
branches on `input.hostPlatform`: the `'readonly-windows'` arm requires `=== 'win32'`, and the
`'absent'` arm requires NEITHER `'darwin'` NOR `'win32'` (i.e. Linux). On macOS the branch under
test is unreachable BY CONSTRUCTION, not by accident. That is why every one of these rows sat
pending for thirteen days without a single attempt.

`hasChoice` = native Steam installs ON **and** >1 registered library. `getSteamLibraries()`
(`src/backend/utils.ts:671`) filters candidates through `existsSync`, so LIBRARY COUNT is what the
gate reads - a registered-but-missing path does not count. This is what 38-S08 needs a second
library for.
</platform_gate>
