<objective>
Close G-48-8a (cards shrink and crop when input switches from mouse to controller) and G-48-8b
(mouse hover shows a thin border, the operator wants the thick controller-mode ring) in the
GameCard stylesheet, for every GameCard in the app.

**Operator decision (2026-10-07, relayed by the orchestrator; recorded here as the rationale for
both tasks).** Both GameCard changes are GLOBAL, not strip-only: (1) remove the `.gameCard.gamepad`
aspect-ratio overrides so controller mode never changes card geometry anywhere, strip and main
grid, and fix the 35px badge-bar art crop that goes with it; (2) every GameCard's mouse `:hover`
uses the console-style focus ring (`--focus-ring-width` 3px, +2px offset, halo, glow), not only
`.focusRowTrack .gameCard:hover`. The operator's own words in UAT item 8: "I want the thicker
border that is in controller mode (like console)" and "I dont want the tiles to 'shrink'". Do not
scope either change to `.focusRowTrack`.

**Why this does not conflict with SPEC R3's "grid unchanged" criterion.** R3's acceptance says
"the grid's output is unchanged against a pre-phase baseline for the same filter state". Output is
which games the grid shows and in what order; this plan changes neither. It changes controller-mode
card geometry and the hover look, by the operator's explicit ruling above.

**Root causes (from `.planning/debug/48-controller-mode-card-shrink-and-border.md`, confirmed in a
CDP harness of the real CSS).** 8a: `.gameCard.gamepad` (3/4) and `.gameCard.gamepad.justPlayed`
(328/205) override the base 173/275 and 275/205 whenever `activeController` is set
(`GameCard/index.tsx:498`); the class flips on every mouse/controller handoff
(`helpers/gamepad.ts` `emitControllerEvent`), so a 156px card goes 248 -> 208 and the 35px store
badge bar (kept in controller mode since commit 16560dbdd) crops 35px of art. The counterfactual
with the base ratios kept cards at 248 and uncropped the art. 8b: a deliberate, test-pinned split
(quick 260926-acw): hover is a 2px outline at -1px, focus is the 3px/+2px ring with halo and glow;
`gameCardFocusRing.test.ts:89-112` and `themes.scss:78-79` pin it.

**Out of this plan, by design.** The strip-end clipping of the now-thicker ring, the track's
stacking context, and the chevrons are 48-10 and 48-11 (they own `FocusRowStrip/index.css`).

Purpose: the library looks and sizes the same whichever input is active, and the mouse gets the
console-style ring the operator asked for.
Output: an edited `GameCard/index.css`, one new source gate, one rewritten source gate, one
corrected comment in `themes.scss`.
