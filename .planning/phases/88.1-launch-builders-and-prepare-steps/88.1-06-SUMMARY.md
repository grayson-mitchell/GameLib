## Deviations from Plan

### Auto-fixed / judgement calls

**1. [Rule 1 - Plan contradiction] shlex is ported, not wrapped; the crate is a dev-dependency**
- **Found during:** Task 1 (differential run of the crate over the 29 split and 11 join vectors)
- **Issue:** shlex 2.0.1 disagrees with npm shlex 2.1.2 on six recorded vectors: the three unterminated-quote and trailing-backslash errors (the crate answers `None` and cannot say which error), `a #b c` (the crate starts a comment), and two joins (`'a'"'"'b'` versus the crate's `"a'b"`). npm also reads `$'..'` and `$".."` and drops an escaped newline, which the crate does not. Parity rules around the crate would have been a second lexer anyway.
- **Fix:** `builders::wrappers::{split, join}` port the npm lexer and `quote` exactly; `shlex = "2"` is a dev-dependency used by a differential unit test that asserts agreement on plain input and names where the two differ. No new Cargo.lock name; the plan's "direct dependency" is a dev-dependency here.
- **Files modified:** src-tauri/crates/gamelib-launch/src/builders/wrappers.rs, src-tauri/crates/gamelib-launch/Cargo.toml
- **Commit:** 90dc2c918

**2. [Rule 1 - Plan contradiction] known_fix_env returns a Value, not a Map**
- **Found during:** Task 2
- **Issue:** the plan says `-> serde_json::Map`, but the golden records `known-fix-env-env-variables-is-a-string` as the string `"A=1"` and a list case as the list (the TS returns `envVariables || {}` raw).
- **Fix:** returns `serde_json::Value`: the raw value unless falsy (null, false, 0, ""), which is `{}`.
- **Commit:** 68b1d2e78

**3. [Rule 2 - Threat T-88.1-12] one TS log line differs, as a deltas.json entry**
- **Found during:** Task 2
- **Issue:** the TS "library folders missing" line names the wine installation and prints `Missing undefined and/or undefined!`; the Rust note logs fixed text with no wine name or path.
- **Fix:** a `replace` delta on `launcher_wineLibFolders--...linux...` events.json (level, platform and env map unchanged), plus two `parser-message` deltas for the two malformed-JSON known-fix cases (V8's parser text versus serde_json's, the same convention as gamelib-knownfix's golden/reader). All three have reasons, and the replay fails on an unused delta.
- **Files modified:** src-tauri/crates/gamelib-launch/tests/fixtures/golden/builders/deltas.json
- **Commit:** 68b1d2e78

**4. [Judgement] the three tasks were written in one pass and committed as three module-aligned commits**
- Each commit was rebuilt as a reduced variant (Task 1 with only the wrapper-env op and the wrapper and shlex kinds replayed, Task 2 without gamescope) and its own verify run green before committing, so every commit compiles and passes. The tracer's replay skips unported kinds by count until Task 2, as the plan describes.

**5. [Judgement] a probe whose child ended without an exit code answers ''**
- `code: None` without a timeout covers a spawn failure (the reason is in stderr, as the SpecRunner contract says) and a child a signal ended; both degrade to the old-CLI help, which is what the TS `catch` did for the first.
