## Known behaviour change (not fixed, outside scope)

`clearCache` (the renderer's "clear cache" and the sign-outs) used to empty the pci.ids device and vendor name caches on a user-requested
clear. gamelib-info has no clear verb for them, so that clear no longer happens. The entries are static name lookups with a 7-day
expiry, so the effect is that a user-triggered clear leaves up to a week of GPU names in place. A Rust clear verb would be a new native
channel (architectural, Rule 4), so it is recorded here rather than added; 88.1-19 or a later info plan can add one if wanted.
