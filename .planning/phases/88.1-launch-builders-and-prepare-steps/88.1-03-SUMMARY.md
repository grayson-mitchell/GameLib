# Phase 88.1 Plan 03: prepare_wine goldens Summary

**`prepareWineLaunch` is pinned by 391 TS-recorded two-part traces in gamelib-launch before any Rust prepare_wine code exists: each case is cut at the store-setup point into a begin and a finish half the two Rust ops can each replay from recorded inputs.**

## Accomplishments

- Task 1 (tracer): one Linux wine case (GOG runner, tier-1 winetricks fix, installed_games written) ran end to end through the real `createLauncher(fakeDeps).prepareWineLaunch` into `golden/prepare_wine`. Its `begin.json` ends with `prefixUpdated: true` and `finish.json` starts with the `prepareLaunch` hook call. The tracer's `<verify>` (jest in compare mode, the MANIFEST file, prettier) was re-run before expanding.
- Task 2: the slice grew to 391 cases. Three pairwise suites per cell (`flow`: runner, game and default wine validity, CrossOver bottle, prefix state, installed_games state, offline setting with `canRunOffline`, engine overlay, EOS overlay hook; `fixes`: tier-1 and tier-2 fixes, `mergesTier1Env`, deadline arm, DXVK family; `runtimes`: GOG comet and dummy, online monitor, EAC and BattlEye) give 352 generated rows, with `uncoveredPairs` empty for every cell and suite; 39 named cases cover the plan's incident list plus the DXVK family per wine type, the engine overlay and CrossOver bottle variants and the EAC and BattlEye states. 53 spawns record `prepare_wine.crossover_bottle_folder`, 63 `galaxy_winepath`, 20 `galaxy_sc_create` and 343 `verify_prefix`, all class `helper`.
- Per case: `input.json` (game info, stored settings, options, seeded fix files and installed_games, scripted replies by rule, hook answers, spawn scripts), `result.json`, `begin.json`, `finish.json` and `tree.json` (the prefix, bottle, engine and install folders after the run). Splits: 261 at the hook, 36 after the `Created/Updated Wineprefix` line (sideload has no hook), 64 at the registry request, 30 early exits with the whole trace in begin.

## Deviations from Plan

### Auto-fixed / judgement calls

**1. [Rule 3 - Blocking] the golden folder has five files, written by the oracle's own function**
- **Found during:** Task 1
- **Issue:** `writeOrCompareGolden` always writes `events.json`, `requests.json` and `spawns.json` too; the plan's artifact list is `input, result, begin, finish, tree`, and the ordered trace in begin and finish already holds every event, request and spawn.
- **Fix:** a 20-line write and compare function in the oracle test with the five files only; compare mode checks the file set and the bytes.
- **Files modified:** src/backend/__tests__/oracle/launchPrepareWine.oracle.test.ts
- **Commit:** 098350800

**2. [Rule 3 - Blocking] pairwise rows are generated by suite, not over one product**
- **Found during:** Task 2
- **Issue:** the plan asks for pairwise rows over about twenty axes per cell; the greedy generator enumerates the whole feasible product, which is too large.
- **Fix:** three suites per cell sharing the axes they interact on, and a feasible predicate that collapses an axis the step never reaches (see key-decisions). A narrower claim than "pairwise across all axes"; whether it is enough is the verifier's call (D5).
- **Commit:** a7366b230

**3. [Rule 1 - Plan contradiction] `RUST_ENGINE_RESOLVE_TOOL_SETTINGS` is scripted though the plan does not list it**
- **Found during:** Task 2
- **Issue:** the tier-1 `runInPrefix` step goes through `gatherGameCommandFacts` and `resolveToolTarget`, which ask `engine_resolve_tool_settings` before `wine_run_command_for_game`; the plan's channel list omits it and an unscripted channel fails the case by name.
- **Fix:** scripted (stored settings, or the engine's when the overlay is on) and recorded like every other reply; the trace shows both requests per program.
- **Commit:** a7366b230

**4. [Rule 3 - Blocking] Linux wine installations carry `lib` and `lib32`**
- **Found during:** Task 1
- **Issue:** a Linux wine with no library folders logs "Couldn't find all library folders" on every call of `setupWineEnvVars`, which would have drowned the traces in a line that is the builders' golden's business (88.1-01).
- **Fix:** the fake Linux wines and proton carry both folders; no case records that error.
- **Commit:** 098350800

**Total deviations:** 4 (1 contradiction, 3 blocking). **Impact:** none on the goldens' purpose, except deviation 2, which narrows the pairwise claim.
