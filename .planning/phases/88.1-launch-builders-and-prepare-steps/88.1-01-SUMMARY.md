# Phase 88.1 Plan 01: Builder and gamescope goldens Summary

**The launch builders and the gamescope command are pinned by 178 TS-recorded golden cases in gamelib-launch before any Rust builder exists, on a shared recording `LauncherDeps` the wave-2 plans reuse without editing.**

## Accomplishments

- Task 1 (tracer): `createFakeLauncherDeps` plus `recordingLogWriter` and the `injectExecutableOnPath` / `injectOnline` probes; `setupWrapperEnvVars` for all five runners ran end to end through the real `createLauncher` into `golden/builders` and compared green, with `classes.json` naming the 11 helper call sites. The tracer's `<verify>` was re-run (jest, manifest and classes files, prettier) before expanding.
- Task 2: `golden/builders` grew to 113 cases: 18+ `allPairs` wrapper rows with an `uncoveredPairs` assertion, 29 shlex split/join vectors (unterminated quotes record `{ error }`), 21 tier-1 known-fix env cases over local, bundled and remote layers (a remote file carrying tier-2 keys yields an env with no tier-2 key), 13 `removeQuoteIfNecessary` inputs, 18 `isMacSonomaOrHigher` platform x release cases with their log lines, and one case per `launcher_wineLibFolders.test.ts` title.
- Task 3: `golden/gamescope` holds 65 cases: pairwise `buildGameScopeCommand` rows over nine axes, per-axis method x help vectors, three probe forms recorded with their spawn (`prepare_launch.gamescope_help`, `timeoutMs` 5000, class `helper`), and a census over `gamescopeCommand.test.ts`.

## Deviations from Plan

### Auto-fixed / judgement calls

**1. [Rule 1 - Plan contradiction] gamescopeCommand census has two reasoned exclusions, not an empty map**
- **Found during:** Task 3
- **Issue:** the plan asks for an empty not-ported map and "10 titles covered"; the file has 11 titles and two of them (`launcher.ts gamescope wiring`) are source-text gates over `launcher.ts`, which 88-CONTEXT D-15 drops ("Source-text gate tests are dropped").
- **Fix:** the two gate titles are listed in the not-ported map with the reason "source-text gate, dropped per D-15"; the other nine are named cases, and the test also asserts no case exists without a title.
- **Files modified:** src/backend/__tests__/oracle/launchGamescope.oracle.test.ts
- **Commit:** 519fded61

**2. [Rule 3 - Blocking] cases.json is generated from the case tables, not hand-typed**
- **Found during:** Task 1
- **Issue:** the plan calls `cases.json` hand-authored, but the pairwise rows are `allPairs` output; a hand-typed list would drift from the axes.
- **Fix:** write mode writes `cases.json` from the tables and compare mode asserts the committed file equals the builder (the 88-05 reader oracle's approach). `deltas.json` is written as `[]` in write mode and is hand-edited after.
- **Commit:** 00f1ae456, 17f966412, 519fded61

**3. [Rule 1 - Bug] the wineEnv cases carry a `winePrefix`**
- **Found during:** Task 2
- **Issue:** the TS wineLibFolders test builds settings with no `winePrefix`, so `WINEPREFIX: undefined` vanished from the JSON golden and the Rust side could not tell absent from undefined.
- **Fix:** the named cases add `winePrefix: '/pins/prefix'`; the three titles and their assertions (error logged on Linux, never on macOS) are unchanged.
- **Commit:** 17f966412

**Total deviations:** 3 (1 plan contradiction, 1 blocking, 1 bug). **Impact:** none on the goldens' purpose; the census exclusion follows the already-recorded D-15 decision.
