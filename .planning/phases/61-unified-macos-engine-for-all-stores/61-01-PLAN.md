<objective>
Run spike 068 (the next free spike number; 067c is the last) to settle the two facts this phase
cannot plan around without measurement:

1. **D-18:** what `ps` shows for a Windows game that CrossOver launched from a macOS install
   path (which Wine sees as `Z:\...`), for each launch shape GameLib uses for Epic/legendary,
   GOG, Amazon/nile and sideload games. Plan 61-15 generalises the "first match" (game process
   exists) signal from this result, and arms the non-Steam launch deadline only if a shape
   works.
2. **RESEARCH A2 (feeds D-01):** whether CrossOver's `cxbottle --create` accepts per-game bottle
   names of the planned `GameLib-<runner>-<encoded appName>` shape: dots, `_xx` escapes, and
   lengths of 64 and about 120 characters.

Purpose: the launch deadline kills a game whose process is never seen. Arming it without a proven
match signal would kill running games at 180 s (59-REVIEW CR-01). This spike is the evidence.
Output: `.planning/spikes/068-nonsteam-first-match-signal/` (README, harness, logs, `verdict.json`)
and a MANIFEST row.
</objective>
