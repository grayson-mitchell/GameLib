<objective>
D-18's second half: generalise the "game process exists" first-match signal for non-Steam games
from spike 068's result, and arm the launch deadline for non-Steam launches only on that basis.

Decision rule (read `.planning/spikes/068-nonsteam-first-match-signal/verdict.json` first and
record which branch you implemented in the SUMMARY):
- `matchShape` `unix-path` or `z-path` (verdict VALIDATED or PARTIAL with the real-game run
  agreeing): `deriveGameProcessPrefix(installPath)` builds the case-insensitive prefix exactly as
  `prefixRule` says (trailing separator kept), and the watcher matches `ps` command lines that
  start with it.
- `exe-basename`: the watcher matches a command line whose final path component equals the
  game's executable basename (case-insensitive) AND contains the install path in any recorded
  form; if the executable is unknown at launch time, no watcher (fail-safe below).
- `none` (INVALIDATED): implement no matcher. `armEngineLaunchDeadline` logs
  `launch deadline not armed for <key>: no game-process signal for non-Steam games (spike 068)`
  once per launch and returns. Create `.planning/todos/pending/2026-11-07-nonsteam-launch-deadline-signal.md`
  with frontmatter `severity: major`, `platform: macos`, `ready: blocked` (in that order) naming
  spike 068's evidence.
In every branch, a launch with no derivable signal goes through `bindDeadlineToMonitor` with a
null handle, which stands the deadline down (CR-01 fail-safe).

Scope: bottle-backed launches only (`prefix.kind === 'bottle'`, CrossOver or fallback engine).
Plain-prefix pinned/Wine Manager launches have no bottle wineserver to stop and are not
CrossOver launches; they are not armed (document this in the module header).
Output: `gameProcessWatch.ts`, deadline arming and handler in `launchEngine.ts`, launcher wiring.
</objective>

| T-61-49 | Denial of service | killing another game's bottle | mitigate | Kill targets only this launch's bottle via killBottleWineServerWith (sanitize + containment); plain prefixes not armed |
