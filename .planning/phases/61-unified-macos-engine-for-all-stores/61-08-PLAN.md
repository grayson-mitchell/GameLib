<objective>
Make the engine decision and the engine switch store-agnostic, and add the D-16 per-bottle
refusal.

- `decideLaunchEngine`, `decideCreationEngine`, `preflightCrossover` and
  `listEngineOverrideOptions` take a game `key` (61-05 `EngineKey`) and default deps that need
  no Steam module. `prepareBottleForEngine` takes `key` and requires the caller to supply the
  CrossOver settings builder.
- Steam-only defaults move to a thin adapter, `steam/engine/steamEngineDeps.ts`; every Steam
  call site passes it, so Steam behaviour is unchanged (the steam/engine/ directory now holds
  only this adapter: CONTEXT discretion "whether steam/engine/ stays as a thin Steam adapter").
- D-16: the switch consults the per-bottle ledger and refuses with `bottle-busy` when another
  game runs in the bottle; for stores without an "own bottle" (non-Steam) the Steam-only
  `shared-bottle` refusal is skipped, so an idle shared bottle proceeds.

Output: decoupled decision/switch, the Steam adapter, repointed Steam call sites, tests.
</objective>
