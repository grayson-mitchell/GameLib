<objective>
Give the engine a store-agnostic game key and a per-bottle running-games ledger.

- `EngineKey` grammar (planner's choice, recorded here): a Steam title keeps its bare numeric
  appId (the store whose capability `appNameIsSteamAppId` is true), every other store uses
  `${runner}:${appName}`. The two forms are disjoint (only the second contains `:`), so a GOG
  numeric appName can never collide with a Steam appId, and the ~40 Steam call sites and the
  16k-line Steam test keep working unchanged.
- `engineRegistry` and `launchDeadline` accept any valid `EngineKey` instead of digits only.
- D-16: `bottleLedger` maps bottle name -> set of running `EngineKey`s. Steam registers its
  bridge launches in it now; non-Steam launches register in plan 61-11.

Output: `gameKey.ts`, `bottleLedger.ts`, re-keyed registry and deadline, Steam ledger wiring.
</objective>
