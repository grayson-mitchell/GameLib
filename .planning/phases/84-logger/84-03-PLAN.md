<objective>
Run the thinnest real path end to end — one TS `logInfo` from the sidecar reaches gamelib.log through the native writer,
golden-identical — then harden the forwarder (loss, order, backpressure, timestamps, calibrated batch numbers) and move
the existing suites that observed the TS general writer onto the forwarder. Runner and game logs stay on the TS writer
until 84-04 (different files, so no two writers share a file).

Purpose: prove the architecture (TS -> stdout frame -> reader thread -> writer thread -> file) on one path before
widening it, and replace research assumption A2 with measured numbers before game output rides the forwarder.
Output: shell init, frame arm, forwarder, stringifier, index.ts internals, transport binding, EOF flush, calibration,
tests.

Consolidated from the former 84-04 and the calibration task of the former 84-05 (both forwarder-level behaviour). This
plan writes no `shell_diag` call in new code (84-08 renames that function): new shell lines use `shell_eprintln!` plus
`gamelib_log::log(Prefix::Shell, ...)`.
</objective>
