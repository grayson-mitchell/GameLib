  <files>src-tauri/crates/gamelib-log/src/limiter.rs, src-tauri/crates/gamelib-log/src/writer.rs, src-tauri/crates/gamelib-log/tests/limiter_golden.rs</files>
  <behavior>
    Cases (t in seconds, all general target, INFO Backend unless stated):
    - 7 identical lines at t=0..6 -> 5 written; at t=60 (tick) one `<body> (repeated 2 more times)` line
    - 3 identical lines -> 3 written, no summary when the window closes
    - same body at WARNING and at INFO -> two keys, both written
    - `poll 1`, `poll 2`, ... `poll 300` -> all 300 written (Pitfall 9)
    - a 500-char body repeated 10 times -> the summary carries the first 200 chars then ` (repeated 5 more times)`
    - 257 distinct bodies each repeated 7 times in one window -> the first key is evicted with its summary before the window ends; memory holds at most 256 keys
    - 7 identical lines then silence -> the summary is written by the next 5 s tick after t=60 or by flush, whichever comes first
    - 100 identical raw chunks to a game target -> all 100 in the game log, none limited
    - 10,000 identical WARNING lines over 600 s -> at most 5 written plus one summary per 60 s window
  </behavior>
  <implementation>RateLimiter keyed by a hash of (prefix, level, body); admission uses the entry's own timestamp, expiry uses the Logger clock on ticks and at flush; summaries are formatted by format_line with the expiry time.</implementation>
</feature>
