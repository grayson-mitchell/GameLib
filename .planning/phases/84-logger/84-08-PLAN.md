## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| app -> dpaste.com | up to 10 MiB of an unredacted log leaves the machine on a user action |
| dpaste.com response -> store | a hostile or spoofed response decides which URL is stored |
| store file on disk | uploadedLogs.json may be corrupt or hand-edited |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-84-20 | Tampering / SSRF | validate_paste_url, ReqwestPaste | high | mitigate | https + host exactly dpaste.com before storing; redirects disabled on the shared client; tests for off-host, javascript: and 302 responses (the delete side is 84-09's T-84-35) |
| T-84-21 | Information Disclosure | upload content | medium | accept | inherited behaviour (T-34.3-13, loggerFlowRegistration D-09): the user picks the log and confirms in the dialog; redaction stays at the TS call sites; no automatic upload is added (prohibition) |
