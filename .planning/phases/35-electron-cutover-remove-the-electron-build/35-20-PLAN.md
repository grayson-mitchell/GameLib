## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| OS -> shell -> sidecar (`gamelib://` deep link) | Any local process can emit a `gamelib://` URL; the payload is untrusted input that now reaches one more runner |
| filesystem -> sidecar (`installed.json` watcher) | An externally-written file drives a backend refresh and now also drives a renderer message |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-35-100 | Elevation of Privilege | `RUNNERS` enum widening, `protocol.ts:15` | mitigate | `steam` only; `zoom` deliberately excluded with a recorded reason. The enum is a zod validator, so a `?runner=` value outside the five is rejected before dispatch. `handleLaunch`'s own-property `libraryManagerMap` guard (T-34.5-46-03) is a second, independent layer and is not weakened. |
| T-35-101 | Denial of Service | `protocol.ts` Steam deep-link dispatch | mitigate | Steam deep links bypass `launchEventCallback`'s `existsSync` + `askForceUninstall` precheck, so a deep link can no longer prompt an uninstall for a title whose Steam install path is not where GameLib expects it. Asserted by a test that a Steam protocol launch never reaches `launchEventCallback`. |
| T-35-102 | Tampering | `addRecentGame` on the Steam path | mitigate | The recent-games write is wrapped so a store-write failure cannot flip a successful launch into a reported failure; a failed launch writes no entry at all, so a poisoned `games.recent` cannot be seeded by a launch that did not happen. |
| T-35-103 | Information Disclosure | `sendFrontendMessage('refreshLibrary')` from a filesystem watcher | accept | The message carries a fixed literal runner name and no file content; an external writer can at worst cause an extra library re-render. Rate-bounded by the existing 500ms debounce. |
| T-35-SC | Tampering | npm/pip/cargo installs | mitigate | This plan installs no packages. No `[ASSUMED]`/`[SUS]` entry is reachable; if a task turns out to need one, stop and raise a blocking human legitimacy checkpoint. |
