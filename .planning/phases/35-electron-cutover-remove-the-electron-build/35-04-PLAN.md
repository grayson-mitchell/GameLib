<objective>
Close `R-34.5-G1-PKG`, both halves, and collapse `isPackaged` to a single derivation.

Purpose: half (b) — `electronStub.ts:207` hardcodes `isPackaged: false`, so `paths.ts:73-76`'s
`resolve(app.getAppPath(), app.isPackaged || process.env.CI === 'e2e' ? 'build' : 'public')` appends
`'public'` in a packaged run and never `'build'`. `main.rs:5495-5496` independently documents the
same defect from the Rust side. Half (a) — `bundle.resources` lists only `["../build/bin/"]`, so
the locale files are not in the artifact at all. **Either fix alone is inert: fixing (b) alone
resolves correctly to a directory that does not exist.**

The trap this plan exists to avoid: a `../`-prefixed resource entry does not land where `publicDir`
looks. Tauri hoists the parent-traversal into a `_up_` segment — which is exactly what the
2026-08-22 DMG probe saw in `GameLib.app/Contents/Resources/` (`_up_` and `icon.icns`, nothing
else). Adding `"../build/locales/"` next to `"../build/bin/"` ships the files to
`Resources/_up_/build/locales/` while `publicDir` resolves `Resources/build/locales/`. Green diff,
same empty directory.

Output: one `isPackaged` derivation, a bundle that carries the whole `publicDir` tree at a
reachable path, and artifact-level proof from a real `.app`.
</objective>
