<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| sidecar -> shell (rustInvoke args) | a runner call's argv, env and log targets cross from the sidecar |
| runner output -> logs | a runner's output and command line reach the runner, game and general logs, which users upload |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-88.2-10 | Information disclosure | runner credentials in logs | high | mitigate | Only `get_runner_call_without_credentials` output is logged; the eight-flag exact-element and PowerShell vectors replay byte-equal (Tasks 1, 3) |
| T-88.2-11 | Tampering | command injection through runner args | high | mitigate | Argv arrays only, never a shell; the PowerShell argument string is built by the exact ported escaping and replayed against the TS goldens including quotes and backslashes; the Windows command line is cross-checked against Node in 88.2-10 (Task 2) |
| T-88.2-12 | Tampering | malformed rustInvoke args | medium | mitigate | `RunnerCallArgs` is a `deny_unknown_fields` serde struct; a bad argument answers the fixed `launch_runner_call:bad-args` and never echoes input (Task 1) |
| T-88.2-SC | Tampering | npm/pip/cargo installs | high | mitigate | Workspace crates only; `cargo tree` and cargoFeatures.test.ts prove no new lockfile crate (Task 1) |
</threat_model>
