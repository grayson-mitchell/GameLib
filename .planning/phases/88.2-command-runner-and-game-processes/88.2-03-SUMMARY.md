## Accomplishments

- `golden/redaction/vectors.json` holds 88 `{ name, kind, input, output }` vectors. 16 are the eight flags, each as a plain argv and a PowerShell `-ArgumentList` argv; the rest are adjacency, all eight at once, a trailing flag with no value, a repeated flag, ten env-diff cases against the pinned base, quoting, three LegendaryCommand object inputs, and shapes that must pass through untouched.
- 33 sanitizer vectors cover gog's four token keys and nile's four: all keys, some absent, none, nested objects, key order, numbers (`12345678901234567890` becomes `12345678901234567000`, `1.0` becomes `1`), unicode escapes, a duplicate key, an array, non-JSON, empty and whitespace lines, truncated JSON, two objects in one chunk, pretty-printed input.
- Compare mode checks the committed input list against the builder, every recorded output, the manifest (count equals the list, floor 88), that each flag's vectors carry `<redacted>` and not the synthetic value, that non-JSON lines come back unchanged, and that no operator path is in the file.

## Decisions Made

- One `vectors.json` for the slice instead of a folder per vector (see key-decisions). The oracle test file and the manifest stay in the shape 88.2-08 can replay: read the list, run each input, compare the string.
- Env-diff vectors use only the pinned base values (`PATH`, `LANG`) for the equal-value case, so no fake-HOME path is in a fixture.
- Top-level JSON primitives (`123`, `null`, `"text"`) are not vectors: the sanitizer's assignment on a primitive throws in strict mode and is silently ignored in sloppy mode, so the recorded answer would depend on how the sidecar bundle is emitted rather than on the function. An array is recorded because it behaves the same either way.
