## Decisions Made

- **The known-red state 88.2-22 handed over is resolved by retirement.** `runner.oracle.test.ts` "deltas.json is exactly the documented delta table" failed because `golden/runner/deltas.json` carries a `game-merged-streams` entry (added 88.2-11/12) that the test's `DELTAS` table lacked. The test is deleted, so the end state is green without touching the table or the fixture. The Rust replay reads `deltas.json` itself.
- **The `mask-secret` re-recording (88.2-08, 88.2-22) was not done.** It needs a Rust recording run and would change a golden, and the plan forbids mixing a fix into a golden diff and lists no fixture among its files. The case keeps its documented `test-local-sanitizer` delta in `golden_runner.rs`. With the TS driver gone, nothing but a Rust recording can regenerate it; that todo stays open and is no longer blocked on this plan.
- RF1's "wine binary is CrossOver's" is asserted over `prepare_wine_command`'s spawned program rather than a store `--wine` flag (see key-decisions).
