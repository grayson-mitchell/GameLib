- `trackedKill(deps, filter)` (launchrust/runner.ts) is `requestRustInvoke(RUST_LAUNCH_TRACKED_KILL, [filter])`, which
  rejects on a transport timeout and on Rust errors. The four call sites await it bare before the wine block:
  legendary/games.ts `stop()` (:1227), nile/games.ts `stop()` (:671), sideload/games.ts `stop()` (:128 sideload key, :131
  wine key). `shutdownWine` lives in backend/utils.ts and, for non-CrossOver settings with a wineserver, calls
  `deps.spawnAsync(wineserver, ['-k'], ...)`.
- engineWineShimSchedule.test.ts: every export of a file under `src/backend/launchrust/` is discovered and must be a
  one-call shim row, and each row's `callers` must equal that file's importers exactly (RUNNER_SHIM_IMPORTERS lists the
  three managers). A non-shim helper in launchrust would fail the gate; a new leaf module that the managers call with the
  promise `trackedKill(...)` returns keeps the gate untouched.
- runnerCallSites.test.ts `rig()` records every `requestRustInvoke` and answers `engine_launch_settings_get` with
  WINE_SETTINGS and everything else with 1; its sideload test shows how to mock `getGameInfo`, `isNative`, `getSettings`
  and `deps.spawnAsync`. Tests elsewhere observe the logger with `jest.spyOn(logger, 'logWarning')`
  (humble/__tests__/oracle/userHarness.ts).
- quitHandler.ts: "Value imports: none"; the Yes path ends the Rust games with a catch that answers 0 and logs nothing
  (:98). bootstrap.ts builds the deps at :1883-1912 and already imports `logError` and `LogPrefix` from '../logger'.
  quitTeardownWiring.test.ts pins those deps with `extractBracedBlock(code, 'createQuitHandler(')`.
- spawnAsync.ts: a fixed count of 40 retries 25 ms apart (:66-67), a rejected kill ends the retries (:158); the timer is
  unref'd and cleared in the finally. spawnAsync.test.ts's rig takes a `kill(streamId, calls)` answer function; the
  'refused kill' test (:270) asserts the rejection is swallowed. Jest 29.7 (`jest.advanceTimersByTimeAsync` is used in
  src/backend/logger/__tests__).
- At HEAD the four test files pass (49 tests); every TS file this plan writes reports `"ignored": false` with the
