| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-88.2-22 | Tampering | malformed rustInvoke args or frames | medium | mitigate | Serde `deny_unknown_fields` args with fixed bad-args literals in the shell; zod validation of every frame in the listener, a malformed frame dropped (Task 1) |
| T-88.2-23 | Spoofing | a frame from the renderer posing as `runnerOutput` | medium | mitigate | The frames are sidecar-internal send channels, not in the renderer allow-list (the `engineSelectionChanged` precedent); the listener only feeds open streams by id (Task 1) |
| T-88.2-24 | DoS | a kill or abort reaching another run | low | mitigate | Kill is by the stream id the caller opened and abort by the id Rust registered for that run; Rust answers false for an unknown id (Task 2) |
