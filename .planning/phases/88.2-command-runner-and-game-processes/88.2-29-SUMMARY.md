# Phase 88.2 Plan 29: A clean helper exit releases its Job (WR-03) Summary

On Windows a `SpecProcRunner` child that exits by itself now has its kill-on-close Job released before the handle closes, so a backgrounded service or an installer's handed-off child keeps running as it does on unix; a timeout, cancel, shutdown or GameLib SIGKILL still ends the whole tree.

## What changed

- **job.rs:** `Job::release(&self) -> bool` (Windows only). Zeroed `JOBOBJECT_EXTENDED_LIMIT_INFORMATION` through `SetInformationJobObject`; on failure logs fixed text with the Win32 error number and returns `false`, leaving the limit set. Documented that after a release closing the handle leaves members running.
- **children.rs:** `ChildSet::release(pid)`; `HelperGuard` gained a flag and `ended_on_its_own()`; `Drop` calls `release` when set, `unregister` otherwise. `terminate_all` and `terminate_one` are untouched (a drained pid's later release is a no-op). The Entry `job` doc names the release.
- **spec.rs:** the guard is now `mut guard`; `run_spec` calls `guard.ended_on_its_own()` on `End::Exited` only. Module doc and `stop()` doc rewritten (timeout, cancel and shutdown close the Job with kill-on-close; a clean exit releases it first).
- **standin.rs:** `detach` mode (wait for `go`, spawn one `idle` grandchild, print its pid, exit 0), `--spec-detach` flag (runs `detach` through `SpecProcRunner`, waits bounded for the run to return before the manifest), manifest `detached` array (always present, empty without the flag).
- **spec_runner.rs:** `a_clean_exit_leaves_what_the_child_started_running` and `a_timeout_kills_the_standin_grandchild_too`, both unconditional (three OS), with a local `Strays` drop guard and `kill_pid` copied from orphans.rs.
- **orphans.rs:** `a_spec_childs_background_process_survives_its_clean_exit_and_the_quit` (three OS): detached pid alive before quit, stays alive through a polled 2.5 s window after the parent exited, shared assertion still sees every helper and grandchild die and the game survive.
- **Disposition:** WR-03 `fixed`, Source `88.2-29: 584f1ad3f`, `open: 3`.
- `runner.rs` (ProcRunner), steamcm's macowned.rs, Cargo.toml and Cargo.lock are unchanged.
