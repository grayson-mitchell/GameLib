## Decisions Made

- Own scripted runner in `runnerTrace.ts` rather than `createSpawnTracer`. The tracer records an env diff against a base, not the options, and has no way to end a run with a signal, `killedByUs` or an abort while held.
- The PATH probe is answered from the case (`onPath`) as a dep, which is stronger than spying on `searchForExecutableOnPath`. `injectPlatform` is still used.
- `deltas.json` is a name-keyed object, the `prepare_launch` shape. It is written from a `DELTAS` table in write mode and compared in compare mode.
- The three source-scanning titles of the census-gate describe become cases that pin the same eight flags (posix argv, PowerShell argv, the comet pair), since a source scan has no Rust twin.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Own scripted runner instead of `createSpawnTracer`**
- **Found during:** Task 1
- **Issue:** The plan has `runner` come from `createSpawnTracer`. That tracer records only an env diff, no `resolveOn`, `track`, timeout or `windowsHide`, and cannot script a signal exit, `killedByUs`, a held run or an abort.
- **Fix:** `createRunnerTrace` builds its own `ProcessRunner` whose steps carry those outcomes; it records the full `RunOptions`. `onSpawn` and a per-step `program` match are included for 88.2-04 and 88.2-05.
- **Files modified:** src/backend/testUtils/launchOracle/runnerTrace.ts
- **Verification:** runnerTrace.test.ts and the oracle pass in compare mode
- **Committed in:** 5f6bda40b

**2. [Rule 3 - Blocking] Golden file names follow the shared harness**
- **Found during:** Task 1

- **Fix:** Kept the harness names, added `logFrames.json`, `stream.json` and `calls.json` through its `extra` slot. `requests.json` and `tree.json` are empty in every runner case.
