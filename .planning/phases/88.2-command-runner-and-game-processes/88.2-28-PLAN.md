<objective>
Close WR-01 of G-88.2-2 (88.2-UAT.md test 2; diagnosis .planning/debug/88.2-review-warnings-fix-in-phase.md): on unix
`ChildSet::terminate_all` decides a helper is done when its leader exits, so a group member that ignores SIGTERM survives
a graceful quit and the reaper is told to forget it. The diagnosis reproduced it on macOS and showed the review's
one-function fix is not enough for tokio-registered helpers (the SpecProcRunner shape), whose SIGKILL is also gated by a
stamp read that fails once the leader is reaped.

Purpose: a wine tree or download helper whose child is slow to handle SIGTERM must not outlive GameLib's graceful quit.
Output: children.rs fixed and unit-tested, a stand-in mode and an orphan arm, WR-01 set to fixed.
</objective>

## Facts at planning time (HEAD bac11b689)

- children.rs (unix): `still_ours` (:146-156) is true for an owned entry, else compares `probe::start_time(pid)` with the
  stored stamp (or `is_alive` when none was stored); `exited` (:158-171) tests only the leader (owned: try_wait; else
  `!is_alive(pid)`); `terminate_entries` (:173-228) SIGTERMs groups that are still ours, polls `exited` to the deadline,
  then SIGKILLs the pending groups still ours and waits for owned children; `terminate_entry` (:232-280, the one-helper
  kill) already polls `probe::group_alive`. `terminate_all` unregisters every pid from the reaper afterwards.
- `ChildSet::new()` is private, so a `#[cfg(test)] mod tests` inside children.rs can build a local set and never touch
  the global one other tests share; `register_owned(label, Child, JobSlot)` and `register_pid(label, pid, JobSlot)` take
  `()` as the JobSlot on unix. Registering with the reaper when none was started is a no-op send. children.rs has no
  tests module yet.
- The diagnosis's reproduction: a helper `sh -c "(trap '' TERM; exec sleep 60) & echo $!; exec sleep 60"` registered with
  `spawn_helper_with_pipes`: `terminate_all(1500 ms)` returned in 50 ms, hard_killed empty, the member alive. With only
  the review's `exited` fix a tokio-registered entry still kept its member alive after a full 1.5 s (still_ours read None).
- standin.rs: `self_command(mode, extra)` gives null stdio; `spec_tree` waits for `go`, spawns an `idle` grandchild, prints
  its own pid and the grandchild's; `run_spec_tree` runs it through SpecProcRunner on a background current-thread runtime;
  `parent` drains with `global().terminate_all(1500 ms)` on `quit`, then disarms the reaper. libc is a unix dependency of
  this crate. orphans.rs's `assert_helpers_die_and_game_survives` waits up to 15 s for every `helpers` and
  `grandchildren` pid to die.
- Rust files have no prettier parser (`--file-info` inferredParser null); rustfmt checks them. The disposition file is
  prettier-ignored.
