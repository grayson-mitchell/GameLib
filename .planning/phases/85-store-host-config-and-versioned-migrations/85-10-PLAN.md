<objective>
Build the sidecar's write path to the Rust owner and prove it end to end on one store: TS GameLibStore -> MirrorCell ->
ordered `kind:"store"` frame -> shell reader -> store-frames worker -> StoreHost -> disk, with the applied event back.

Purpose: the TS side reads synchronously (~60 consumer files, sync `init()`), so it cannot become an async client;
research prescribes an in-memory mirror per file path that sends ordered frames to a single Rust writer. Proving the
architecture on one real store before any family flips catches a dead end after one commit (tracer-first).
Output: store_dispatch.rs, the reader arm, storeFrames.ts, mirrorCell.ts, storeOwnership.ts, the GameLibStore facade, the
tracer override, the end-to-end test.
</objective>
