## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| store file -> engine | a file may be corrupt, newer or hostile |
| backup and corrupt copies -> disk | copies may hold token-bearing content |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-85-15 | Repudiation | engine corrupt/newer paths | high | mitigate | bytes never overwritten on Failed or Newer; corrupt copy written first; engine_golden and corpus assert byte equality |
| T-85-16 | Information Disclosure | backup.rs copies | medium | mitigate | backups and corrupt copies written 0600 through write_atomic in the store's own directory; at most 3 of each kept |
| T-85-17 | Denial of Service | corrupt copies on every boot | low | mitigate | newest-equal skip and the cap of 3 stop a permanently corrupt file from filling the disk |
| T-85-SC | Tampering | crate dependencies | low | accept | chrono, if used, is already locked; no new package enters the lockfile |
</threat_model>
