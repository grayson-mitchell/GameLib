Make the engine install and the bridge-bottle creation stop on abort (verification gap E,
review WR-03; the bottle half of gap C, review CR-01), and stop CrossOver's wineserver before
deleting a failed bottle (gap G, review WR-04). This plan owns `fallbackEngine.ts` and
`bottle.ts`; 59-29 then wires the install flow in `games.ts` to these APIs.

Purpose: the sidecar exit contract (half 2: no in-flight work started after quit) and the
cancel-during-provisioning bug (G13) both need every long step to observe the abort, not only the
download proper.

Output: abort-aware `installArtifact`, signal-aware bottle creation with partial-dir removal,
`PROVISION_ABORTED`, `discardNewBridgeBottle`, WR-04 kills, tests.
</objective>
