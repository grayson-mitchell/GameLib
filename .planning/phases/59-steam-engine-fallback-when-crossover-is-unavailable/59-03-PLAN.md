<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub release CDN -> sidecar | Downloaded archives are untrusted until hashed |
| archive contents -> filesystem | tar entries and symlinks could escape the target |
| renderer -> per-game setting | steamEngineOverride is written by the renderer |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-59-11 | Tampering | ensurePinnedEngine | mitigate | sha256 + size pinned in enginePins.ts source; streaming hash before extraction; delete on mismatch; never fall back to a `latest` URL |
| T-59-12 | Tampering / EoP | extraction | mitigate | Extract into an empty mkdtemp dir; walk with lstat and require every symlink target to stay inside via path.relative; rename into place only after the check |
| T-59-13 | Elevation | steamEngineOverride | mitigate | parseEngineOverride closed grammar; no `/`, `\\`, `..`; unknown values become `automatic`; WM ids are resolved against the installed list, never used as paths |
| T-59-14 | Denial of service | concurrent downloads / disk | mitigate | Single-flight map per pin id; pruning keeps only current and previous pins and runs only after success |
| T-59-15 | Denial of service | sidecar exit | mitigate | No work at module load; download only on first need (D-05); in-flight map empty at boot |
| T-59-SC | Tampering | package installs | accept | No npm/pip/cargo packages are added (RESEARCH Package Legitimacy Audit: none) |
</threat_model>
