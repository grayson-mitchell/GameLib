<objective>
Phase gate and live check. Run every automated gate, snapshot the operator's real profile, let the
sidecar version it for real (smoke run), plant a newer-version store file, and have the operator
confirm in `pnpm tauri:dev` that nothing reset and that the read-only notice behaves (D-05, D-15).

Why this plan is the first to touch the real profile: `pnpm smoke:sidecar` and `pnpm tauri:dev` both
boot against `~/Library/Application Support/GameLib`, and the first boot of this build migrates
`config.json` (v0 -> v1) and stamps files on write. Every earlier plan forbade those commands so the
snapshot taken here is a true pre-upgrade copy.

Live-launch rules (MEMORY): launch with `pnpm tauri:dev`, never `pnpm tauri:dev:run` (it skips the
dev-vault flag, so Keychain prompts every launch); `tauri dev` does not rebuild the SEA sidecar and a
fresh worktree needs `pnpm build:sidecar-sea` and `pnpm exec vite build` first; check
`build/main/sidecar.js` mtime is newer than the last backend change.

Output: no source changes; a scratch record of measurements and the operator's verdict, carried into
the SUMMARY.
</objective>
