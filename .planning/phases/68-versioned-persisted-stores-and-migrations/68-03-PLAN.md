(D-02, D-14), and lock it with a ratchet test. This plan is the "planner lists every store with its
kind" deliverable of D-02.

Purpose: the engine from plan 02 only versions a path once a declaring constructor has registered
it; until this plan lands, production stores construct without a declaration and pass through.

Task sizing note: Task 1 touches 25 files but each edit is a one-line constructor argument. It is not split: the parameter is required on purpose (the compile error is half of D-01's enforcement), so a split would need a throwaway intermediate where the parameter is optional only to keep `pnpm codecheck` green between tasks, and that intermediate state is exactly the unenforced state D-01 forbids.

Output: required `declaration` parameters on `TypeCheckedStoreBackend` and `CacheStore`, a kind on
all 51 production constructions, updated test constructions, and `storeKinds.test.ts`.
