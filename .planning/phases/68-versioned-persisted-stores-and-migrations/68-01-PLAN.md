|----------|-------------|
| local disk -> sidecar | Store files are local JSON written by this app or an older/newer build; content is untrusted in shape, trusted in origin |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-68-01 | Information disclosure | backup.ts `writePreMigrationBackup` | mitigate | Backups always written via `atomicWritePrivate` at mode 0o600 (never `copyFileSync`, which would copy the live 0o666 mode); new directories 0o700 |
| T-68-02 | Tampering | backup.ts prune | mitigate | Prune deletes only names matching the exact per-store backup regex inside `dirname(storePath)`; resolve+relative containment assert on every computed path |
| T-68-03 | Information disclosure | backup.ts / atomic write logging | mitigate | Log basename and `err.message` only, never file bytes (T-28-04); `logSecretGate.test.ts` in verify |
| T-68-04 | Denial of service | repeated backups on retried failure | mitigate | Dedupe against newest backup via `Buffer.equals`; cap of 3 per store |
| T-68-SC | Tampering | package installs | accept | No packages installed by this plan (RESEARCH Package Legitimacy Audit: none) |
</threat_model>
