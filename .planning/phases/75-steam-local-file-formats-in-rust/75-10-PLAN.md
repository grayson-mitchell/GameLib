<objective>
Implement the local library scan in Rust (P75-C): libraryfolders.vdf roots, the batched ACF scan across steamapps dirs, and the first-match ACF lookup.

Purpose: `getSteamLibraries`, the four installed-map builders, `readAcfState`, `scanDownloadingAppIds`, `findOtherManifestsWithInstalldir` and the census all sit on these three functions (plans 15, 19). Hot-path sizing (open question, resolved by reading `installPolling.ts`/`runningPoll.ts`): install polling ticks every 3 s per polled app and calls `readAcfState` once per tick; the running poll ticks every 5 s; so one invoke per tick (find_acf over the dir list) and one invoke per scan (scan_acfs over all dirs) is well inside the 60 s rustInvoke timeout, and none of these go on UNBOUNDED_RUST_CHANNELS.
Output: library.rs and tests.
