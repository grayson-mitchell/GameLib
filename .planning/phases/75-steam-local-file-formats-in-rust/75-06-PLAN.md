<interfaces>
Contract this plan creates (consumed by plan 09):
- `pub enum BinNode { Map(Vec<(Vec<u8>, BinNode)>), Str(Vec<u8>), Int32(i32), Float32([u8; 4]), Ptr([u8; 4]), WStr(Vec<u8>), Color([u8; 4]), Uint64([u8; 8]), Int64([u8; 8]) }` (fixed-size payloads stored as raw little-endian bytes so they round-trip exactly; WStr holds the UTF-16LE bytes before the 2-byte terminator)
- `pub struct BinDoc { pub root: Vec<(Vec<u8>, BinNode)>, pub trailing: Vec<u8> }`
- `pub struct BinLimits { pub max_bytes: usize, pub max_depth: usize }` with `BinLimits::shortcuts()` (16 MiB, 64)
- `pub fn parse_bin(bytes: &[u8], limits: &BinLimits) -> Result<BinDoc, BinError>`; `BinError { kind: BinErrorKind, offset: usize }` kinds TooLarge, TooDeep, Truncated, UnknownType(u8)
- `pub fn serialize_bin(doc: &BinDoc) -> Vec<u8>`
- Type bytes: 0x00 map, 0x01 string (NUL-terminated), 0x02 int32, 0x03 float32, 0x04 ptr, 0x05 wstring (UTF-16LE, 0x0000-terminated), 0x06 color, 0x07 uint64, 0x08 end of map, 0x0A int64 (A1 in RESEARCH: assumed from Valve's KeyValues binary format; the local real-file round trip in plan 23 is the proof)
