- `#[serde(tag = "op")] pub enum ShortcutsOp { #[serde(rename = "add")] Add { entry: Vec<EntryField>, create_if_missing: bool }, #[serde(rename = "update")] Update { app_name: String, fields: Vec<EntryField> }, #[serde(rename = "remove")] Remove { app_name: String } }`
- `pub struct ShortcutsApplyResult { written: bool, read_error: Option<String>, already_present: bool, matched: bool, index_key: Option<String>, removed_exe: Option<String>, removed_app_name: Option<String> }`; `pub fn apply_shortcuts(path: &Path, op: &ShortcutsOp) -> ShortcutsApplyResult`
