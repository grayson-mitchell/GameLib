## Sampling Rate

- **After every task commit:** the targeted jest file(s) for that task + `cd src-tauri && cargo test humble_login` when the task touches Rust
- **After every plan wave:** `npm run test:ci` **and** `cd src-tauri && cargo test` (both — the Rust suite is not CI-gated, so a wave merge is the only place it is systematically run)
- **Before `/gsd-verify-work`:** both suites green **and** the REQ-34.4.1-12 blocking live gate executed
- **Max feedback latency:** 20 seconds (targeted run)
