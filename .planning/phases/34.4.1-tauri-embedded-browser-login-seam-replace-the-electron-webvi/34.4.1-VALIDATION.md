- **After every task commit:** the targeted jest file(s) for that task + `cd src-tauri && cargo test humble_login` when the task touches Rust

## Manual-Only Verifications

The REQ-34.4.1-12 live gate. **Blocking — failure becomes a gap cycle inside 34.4.1.** All items run under `pnpm tauri:dev` on macOS; sidecar output is read from `~/Library/Logs/GameLib/gamelib.log`, **not** the `tauri:dev` terminal.

| Behavior | Requirement | Why Manual | Test Instructions |
|----------|-------------|------------|-------------------|
| **1. Humble login FROM SCRATCH** — no Electron-captured session | REQ-34.4.1-02, REQ-34.4.1-12 | Needs a real browser engine, a real Cloudflare-fronted origin and real credentials. This is the phase's headline deliverable and the statement 34.4 D-09 had to declare impossible. | Numbered preconditions in `34.4.1-LIVE-GATE.md`, including an explicit **"start from no stored Humble credential"** step. |
| **2. Session survives quit-and-relaunch** | REQ-34.4.1-12 | Process-lifetime behavior jest cannot exercise. | Prove at the **persistence layer** (the present-to-absent store proof 34.4-10 established), not by a UI check. |
| **3. `humbleDisconnect` leaves no `humblebundle.com` cookie; re-login is genuinely fresh** | REQ-34.4.1-06, REQ-34.4.1-12 | Requires reading the real platform cookie jar after a real sign-out. | Verify domain-scoped deletion **and** that non-Humble cookies survive — a blanket wipe passes item 3 while being the exact defect D-08 forbids. |
| **4. `humbleRevealKey`'s real outcome recorded (pass or 403)** | REQ-34.4.1-05, REQ-34.4.1-12 | Cloudflare Bot Management scores a live TLS/HTTP fingerprint; unreproducible offline. | Reveal **is** live-testable: per Phase 14's D-30 realignment `redeemed_key_val` means *revealed, not activated*, so unlike 34.4 D-08's refused `redeemSteamKey` it is irreversible at Humble but not destructive. **Record the outcome either way — a 403 is a valid, declarable result, not a phase failure.** |
| Linux / Windows behavior | REQ-34.4.1-13 | **Deliberately NOT verified live** (D-09) — verified by reading the crate and declared per-platform. | Recorded in `34.4.1-PORTED-CHANNELS.md` so the omission reads as a decision, not an oversight. |
