### 4. Evidence protection against log rotation — SATISFIED, capture in place

**Root cause of the original run's near-miss, confirmed by reading `src/backend/logger/log_writer.ts`
directly (not inferred):** `LogWriter#archiveOldLogFile()` renames `gamelib.log` to `gamelib.log.old`
— **overwriting any existing `.old`** — the first time a NEW process instance writes to it. This
means every `pnpm tauri:dev` relaunch (a new process = a new `LogWriter`) rotates exactly once, and
only the immediately-preceding session's log survives as `.old`; anything from two relaunches back is
gone the moment a third relaunch's first write lands. Item 2 (survives quit-and-relaunch) and any
recovery/retry cycle during Task 2 are exactly the situations that trigger this.

**Mitigation in place:** a `tail -F` process (BSD `tail`'s reopen-on-replace mode, which detects the
rename and transparently reopens the new file at the same path) is running in the background,
appending every line `gamelib.log` ever contains — across every relaunch's rotation, for the whole
gate run — into a single, never-rotated capture file:
```
/private/tmp/claude-501/-Users-graysonmitchell-Projects-GameLib/0b7c97ea-dd2b-439d-8d1b-e73f0d38b43b/scratchpad/34.4.1-20-gate-rerun-gamelib-log-capture.log
```
Verified running (PID `60078` at the time Task 1 started it; confirm with
`ps aux | grep "tail -F"` if it needs to be restarted) and confirmed to already contain the current
`gamelib.log`'s content (22 lines, matching the 2239-byte file from the rebuild-verification launch
above).

**Instructions for the operator (Task 2):** grep or read this capture file, not `gamelib.log`
directly, whenever a check needs to look back across a relaunch. `gamelib.log` itself is still the
right file to `tail -f` live during any single session (nothing about the live view changes) — the
capture file exists so that a moment already passed does not become unrecoverable the way item 1
and item 4's evidence nearly did last time. If the `tail -F` process is found not running at the
start of Task 2, restart it before proceeding:
```
nohup tail -F -n +1 ~/Library/Logs/GameLib/gamelib.log >> /private/tmp/claude-501/-Users-graysonmitchell-Projects-GameLib/0b7c97ea-dd2b-439d-8d1b-e73f0d38b43b/scratchpad/34.4.1-20-gate-rerun-gamelib-log-capture.log 2>&1 &

```
**Take a FRESH baseline offset (line count or byte offset into the capture file) at the moment Task
