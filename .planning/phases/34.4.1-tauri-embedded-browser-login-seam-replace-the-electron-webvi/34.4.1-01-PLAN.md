fail-closed child `WebviewWindow` on any https URL, observe its main-frame navigations, read and
delete cookies with a correct domain-suffix match, and close it — plus the `#[cfg(test)]` proofs
for their pure logic and the phase's blocking live-gate contract.

Purpose: this is D-02's resolved shape (Rust arms driven by the sidecar) and the ONLY thing
Phase 34.5 actually inherits. It is deliberately runner-agnostic: nothing in Rust knows what
Humble is.

Output: `src-tauri/src/main.rs` arms + tests, `RUST_HUMBLE_LOGIN_*` constants, and
`34.4.1-LIVE-GATE.md`.

Arm contracts (args are the JSON array carried by the rustInvoke frame):
  humble_login_open        args [url: string, visible: bool, user_agent: string]
                           -> Value::String(label)
  humble_login_cookies     args [label: string, host: string, names: string[]]
                           -> { "total": number, "matched": [ {"name","domain","value"} ] }
                              total   = webview.cookies()?.len()  (UNFILTERED — the liveness proof)
                              matched = domain-suffix-matched entries whose name is in `names`
                                        (all matched entries when `names` is empty)
  humble_login_take_events args [label: string]
                           -> [ {"event": "started"|"finished", "url": string} ]  (drains the queue)
  humble_login_close       args [label: string] -> Value::Bool(existed)
  humble_login_clear_cookies args [label: string, domain: string] -> Value::Number(deleted_count)

Error strings follow this file's existing flat convention:
  "humble_login_open:bad-args" | "humble_login_open:bad-url" | "humble_login:no-window:<label>"

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| sidecar (Node) → Rust `dispatch_rust_channel` | The sidecar supplies a URL, a user agent and a window label; all three cross into a native window-construction API |
| remote origin (humblebundle.com et al.) → app process | Untrusted third-party content executing inside a Tauri webview that shares the app-wide cookie jar |
| Rust cookie jar → sidecar stdio JSON-RPC | Live session-cookie values leave the platform jar and travel over the stdio channel |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-34.4.1-01 | Elevation of Privilege | `next_login_window_label()` | mitigate | Generated label (`loginwin-` + counter + nanos + entropy), never derived from any argument, never `main`/`about`; asserted by `login_window_label_is_never_reserved` / `_never_derived_from_url` (T-34.1-27). Child labels never join `capabilities/default.json`'s `windows` array, so the window matches NO capability and gets zero command access. |
| T-34.4.1-02 | Information Disclosure | `humble_login_cookies` | mitigate | Values returned only for explicitly requested cookie NAMES; `total` is a count, never a value dump; no `eprintln!` of any cookie value anywhere in the arms (name/domain/length only). |
| T-34.4.1-03 | Denial of Service (to the user's other sessions) | `humble_login_clear_cookies` | mitigate | Domain-suffix-scoped `delete_cookie()` loop; `clear_all_browsing_data()` is forbidden and grep-asserted absent. The jar is app-wide and will hold Epic/GOG/Amazon cookies after 34.5. |
| T-34.4.1-04 | Spoofing (phishing) | `WebviewWindowBuilder` | mitigate | No `.title()` on remote-content windows (WR-07) — the loaded document's own title shows, so an attacker page cannot present itself as `GameLib`. |
| T-34.4.1-05 | Elevation of Privilege | `window.__TAURI__` injected into third-party origins | accept | Spike 014b confirmed every invoke from a remote origin is ACL-refused (`rejected: … Plugin not found`) even with `remote.urls` declared. Surface is real but inert; named here rather than newly mitigated, and no capability file is edited. |
| T-34.4.1-08 | Tampering / Spoofing | `login_window_url_arg` | mitigate | Scheme allowlist: only `https` URLs open a window; `http`/`file`/`javascript` are rejected with `humble_login_open:bad-url`, unit-asserted. |
| T-34.4.1-09 | Denial of Service | `LOGIN_WINDOW_EVENTS` queue | mitigate | Per-label cap of 50 entries with oldest-dropped, and the queue is drained by `humble_login_take_events`; a page that navigates in a loop cannot grow it without bound. |
| T-34.4.1-SC | Tampering | npm/cargo installs | accept | This plan installs ZERO new packages — every API ships in the already-pinned `tauri` 2.11.5 / `wry` 0.55.1 / `tao` 0.35.3 tree (34.4.1-RESEARCH.md § Package Legitimacy Audit: N/A).
