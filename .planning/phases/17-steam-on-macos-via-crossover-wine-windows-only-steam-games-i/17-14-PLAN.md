Close the TWO MAJOR live-UI reconciliation gaps found in Phase 17 session-3 human UAT (real macOS + CrossOver). The game DOES install and launch — these are display-only defects on the bottle-install path:

1. **GAP-17-BOTTLE-PROGRESS (MACSTEAM-05):** during a bottle install the progress bar sits at 0% the whole download. Persisted state is correct; only LIVE reconciliation is missing.

Purpose: unblocks the remaining session-3 UAT (resume from step 3) so install progress and completion are observable without a nav/focus round-trip.
Output: bottle poller surfaces ACF-derived percent to the progress bar; the game page flips to Play on completion live; CI tests lock both derivations.

Do NOT add pause/cancel controls (D-07: the Steam client controls install; GameLib only displays state).
