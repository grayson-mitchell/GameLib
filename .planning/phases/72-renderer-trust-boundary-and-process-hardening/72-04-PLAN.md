<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| sidecar -> Rust shell (rustInvoke frame) | a compromised or buggy sidecar supplies the path |
| Rust shell -> OS opener | Finder/Explorer/xdg-open act on the path |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-72-12 | Elevation of Privilege | ShellOpenPath launching an .app or executable | mitigate | `open_path_policy_check`: directory only, canonicalize then bundle-extension reject (symlink case tested) |
| T-72-13 | Elevation of Privilege | file:// / smb:// / UNC passed as a path | mitigate | shape_check rejects `://`, leading `\\` and `//`, non-absolute; fixture cases |
| T-72-14 | Information Disclosure | rejection logs echoing the path | mitigate | fixed-literal errors, category-only `shell_eprintln!` |
| T-72-15 | Tampering | TOCTOU between canonicalize and open | accept | local single-user desktop; the attacker would need write access to the same path between two syscalls, and the result is opening a folder |
</threat_model>
