<objective>
Delete the renderer-reachable `removeFolder` channel and make the internal helper an awaitable, timer-free, retrying
delete (amended D-09, operator-confirmed after research).

Purpose: the channel let renderer content recursively delete under any parent path, and containing it against
`defaultInstallPath` is circular (renderer-writable via `setSetting`) and breaks custom install locations. No renderer
code calls it (`window.api.removeFolder` has zero callers; the preload export is in the knip baseline). The 5 s / 2 s
`setTimeout`s waited for an aborted runner to release files; `fs.promises.rm` retries cover that without a timer.
Output: channel removed end to end, helper rewritten, tests updated.
</objective>
