<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| meta tool → child processes (CLI, objdump) | Children must not see or write the operator's real profile |
| operator's real game library → sweep output | Output must not leak paths or bytes |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-63-39 | Information disclosure | CLI / objdump spawns from meta/ | mitigate | Fresh `createFakeHomeProfile` per invocation (batch = one invocation), `dispose()` on every exit path; fakeHomeIsolation.test.ts (D-04) |
| T-63-40 | Information disclosure | sweep report | mitigate | Directories hashed (`redactPath`), basename only; diffs show parse facts only; stdout only, `writeFileSync` absent (T-51-39 discipline) |
| T-63-41 | Tampering | command injection via paths | mitigate | argv-form spawns only (no shell); JSON args serialised, never interpolated |
| T-63-42 | Repudiation | vacuous green sweep | mitigate | Exit 3 on zero inputs; `oracleBroken` abort when the TS oracle cannot run objdump |
| T-63-43 | Tampering | cargo build under fake HOME | mitigate | Build is a package.json prefix in the real env; helper never spawns cargo; clear error when binary missing |
</threat_model>
