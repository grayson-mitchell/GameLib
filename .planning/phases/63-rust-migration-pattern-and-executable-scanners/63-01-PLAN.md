`src/contain.rs`, per D-10: `pub fn contained_real(path: &Path, root_dir: &Path) -> ContainedReal`, where `ContainedReal { real: Option<String>, reason: Option<ContainReason> }` serialises camelCase. `ContainReason` serialises as kebab-case strings `root-unresolvable`, `realpath-failed` and `escapes`. The rules:
- `std::fs::canonicalize(root_dir)`; on failure return reason `root-unresolvable`.
- `canonicalize(path)`; on failure return `realpath-failed`.
- The path is contained iff `real.strip_prefix(&root_real)` succeeds and the remainder is non-empty and its first component's string does NOT start with `..`. This reproduces the TS `rel.startsWith('..')` quirk.
- Otherwise return `escapes`.
- A path that is not UTF-8 maps to `realpath-failed` (never lossy-convert a path that will later be opened).
- On Windows, strip a leading `\\?\` verbatim prefix from the returned string only; the comparison runs on the canonical forms of both sides.
- Never use string-prefix containment.
