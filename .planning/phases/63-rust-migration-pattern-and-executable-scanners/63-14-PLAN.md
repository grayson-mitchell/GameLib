Write `src-tauri/crates/README.md`, "Moving sidecar code to Rust: the pattern", for the next port (the Steam depot pipeline, crate `gamelib-depot`). Name concrete files from this phase as the worked example. It should cover nine things.

1. **Layout.** The app crate stays the workspace root; each port adds `src-tauri/crates/<name>` (Tauri-free lib) and, if headless tools need it, a `<name>-cli` bin. It needs `rust-version = "1.77.2"`, the two `[lints.clippy]` deny lines, and no new lock names without updating `EXPECTED_LOCKFILE_CRATE_NAMES` in the same commit (cargoFeatures.test.ts).
2. **Library contract.** `dispatch(op, args)`, `OPS`, `CLI_ONLY_OPS`, the `catch_unwind` guard, `deny_unknown_fields` camelCase args, and the rule "results not errors" (Err only for bad args, unknown ops or panics).
3. **App path.** A `RUST_*` const plus a `RUST_INVOKE_CHANNELS` entry, a one-line `"op" => {` arm in `dispatch_rust_channel` calling `<crate>::dispatch`, a static parity test like `scanChannelParity.test.ts`, a typed `invokeScan`-style helper with all-string args (no bytes over the pipe), wrappers with fail-closed catch mappings, and caller tests mocking `requestRustInvoke`.
4. **Headless path.** The CLI argv/`--ndjson`/`--list` contract, `meta/gamelibScanCli.ts`, the `scan-cli:build` package.json prefix (cargo runs in the real env), and a fresh fake-HOME profile per spawn.
5. **Fallback flag during migration.** A per-unit env var plus a defaults table, starting at `ts`, flipped per unit after a clean sweep, and deleted at the end. Say why it was env-only and not AppSettings.
6. **Parity harness.** Tier 1 is TS-builder fixtures plus a generator plus `expected.json`, Jest TS==golden and `cargo test` Rust==golden, with the `rustOverride` + `divergenceNote` rule. Tier 2 is a local sweep with redacted output and exit codes 0/1/3. The normaliser defines exactly what parity ignores.
7. **Verification and deletion.** The live gate contract (authored by one plan, run by another, using the live-gate-contract-authoring standard), the deletion checklist, and the deletion gate test.
8. **CI.** An explicit `cargo test -p` step on both legs and `clippy --workspace`; the default member hides the crates otherwise.
9. **Lessons from this port.** Taken from the SUMMARYs: D-07 divergences found and A5's outcome.

Keep it factual and short, with tables where useful. Cross-reference `.planning/phases/63-*` for history; do not duplicate the plans.
