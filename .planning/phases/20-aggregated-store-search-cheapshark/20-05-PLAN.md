Build the presentational layer of the store-search screen: a pure `$X USD` currency formatter, the collapsed `StoreSearchRow` (thumb, title, store-attributed badge stack with cap/overflow, cheapest price, expand chevron), and the lazy `StoreSearchBreakdown` panel (per-store rows with external buy handoff). Output: `helpers.ts`, `StoreSearchRow/`, `StoreSearchBreakdown/`, `index.css`, and two tests. i18n JSON keys are added by Plan 06 (this plan uses `t('key','Default')` inline defaults so strings render regardless).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| deal.buyUrl → openExternalUrl → shell.openExternal | pre-built (Plan 04) verbatim redirect URL opened in the user's real browser |
| CheapShark deal fields → rendered DOM | untrusted store names/prices rendered into the UI |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-20-01 | Tampering | breakdown buy handoff | mitigate | The row opens ONLY the backend-built `deal.buyUrl` (fixed cheapshark.com/redirect prefix, Plan 04) — it never constructs a URL from arbitrary CheapShark fields. openExternalUrl's backend restricts to shell.openExternal for http-prefixed URLs. |
| T-20-02 | Injection | rendering CheapShark store names/titles | mitigate | Values render as React text children (auto-escaped), never via dangerouslySetInnerHTML. currencyCode is GameLib-applied, not rendered from raw CheapShark. |
| T-20-03 | Spoofing (false badge) | badge stack render | mitigate | The row renders the already-resolved prop from Plan 03 (Steam exact-only); it never re-derives ownership, so no fuzzy Steam badge can appear here. |
| T-20-SC | Tampering | npm installs | accept | Zero new packages this plan. |
</threat_model>
