<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GameLib backend → CheapShark (outbound HTTP) | backend initiates request to a fixed host; user query is a param value |
| CheapShark JSON → typed payload → renderer | untrusted third-party JSON shaped and sent over IPC |
| dealID → redirect URL → shell.openExternal (Plan 05) | untrusted fragment interpolated into an external-open URL |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-20-01 | Tampering / Spoofing | buildRedirectUrl → shell.openExternal | mitigate | Redirect URL is constructed from a fixed hardcoded `https://www.cheapshark.com/redirect?dealID=` prefix with ONLY the dealID fragment interpolated — never a full URL-shaped field trusted from CheapShark. This keeps a malicious `javascript:`/`file:` URL out of the shell-open path even if CheapShark returns hostile data. |
| T-20-02 | Tampering (SSRF-adjacent) | searchGames outbound request | mitigate | Host is fixed/hardcoded; the user query is only ever a query-parameter VALUE via axios `params` (auto-encoded), never used to construct the request host — no host-injection vector (RESEARCH Security V5). |
| T-20-04 | Denial (CheapShark traffic reputation) | searchStores handler | accept | Load-bearing mitigation is the frontend D-11 debounce (Plan 06); backend adds no rate limiter (CheapShark has no documented enforcement). 15s axios timeout bounds a hung request. |
| T-20-SC | Tampering | npm installs | accept | Zero new packages (CheapShark consumed via existing axios). No install task, no legitimacy checkpoint required. |
</threat_model>
