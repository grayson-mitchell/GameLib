<objective>
Close UAT gap B: Steam games that are no longer available on Steam (delisted) must not appear in the Console grid and must not be install/launch-activatable. UAT (tests 3 + 6) found delisted games showing the placeholder image and, if activated, firing a `steam://install` handoff that cannot succeed.

Purpose: Persist an `is_delisted` flag derived from the Steam appdetails API's `success:false` response, then filter delisted games out of the Console grid and block their activation — while being careful NOT to hide games during transient/offline API failures (which must never set the flag).
Output: an `is_delisted` field on GameInfo + the Steam metadata cache, backend logic that sets/clears it only on a definitive appdetails verdict, and frontend filtering + an activation guard in Console mode.

Root-cause anchors (08-UAT.md Diagnosis B): `steam/games.ts:184-186` already has the "Game may be delisted or API temporarily unavailable" branch (appdetails returns no `data`); it currently just returns. We upgrade it to distinguish a definitive `success:false` (delisted) from a transient failure.

Gap-closure note: Follow-on behavior fix for an already-shipped, verified Phase 8.
</objective>
