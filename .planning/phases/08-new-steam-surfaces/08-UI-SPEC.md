# Phase 8 — UI Design Contract: New Steam Surfaces

> Visual and interaction contract for Phase 8 (STORE-01 + CONSOLE-01). Generated by gsd-ui-researcher.
>
> This phase introduces NO new visual language. It slots Steam into two existing surfaces
> (Sidebar Stores submenu and Console mode) by reusing established components and SCSS tokens.
> The contract below locks the exact rendering choices, copy strings, and interaction timing
> so the executor can implement without design ambiguity.

## Surface 1: Sidebar Stores Submenu (STORE-01)

### Sub-item ordering

Within the `SidebarSubmenu` inside `SidebarItemWithSubmenu` for Stores
(`src/frontend/components/UI/Sidebar/components/SidebarLinks/index.tsx`, lines 142–167):

```
Epic Store     ← existing
GOG Store      ← existing
Amazon Luna    ← existing
Steam Store    ← NEW (always rendered; Steam is first-class, no conditional guard)
Zoom Store     ← existing (conditional on zoom.enabled)
```

**Rationale:** Steam is positioned after the three legacy stores and before Zoom (which is experimental/conditional). This mirrors the chronological addition order and keeps first-class stores together.

### Sub-item component

```tsx
<SidebarItem
  className="SidebarLinks__subItem"
  url="/store/steam"
  label={t('steam-store', 'Steam Store')}
/>
```

No icon at the sub-item level — existing sub-items (Epic, GOG, Amazon, Zoom) have no icons. Do not add a SteamLogo here.

**i18n key:** `steam-store` → `"Steam Store"` (English fallback)

### WebView wiring (no new screen)

Additions to `src/frontend/screens/WebView/index.tsx`:

1. `validStoredUrl`: add `case 'steam': return url.includes('store.steampowered.com')`
2. `urls` map: add `'/store/steam': 'https://store.steampowered.com/'`
3. `partition`: already `persist:${store}` → resolves to `persist:steam` with zero changes
4. `showLoginWarningFor` state type: do NOT add `'steam'` — type stays `null | 'epic' | 'gog' | 'amazon' | 'zoom'` (D-06)
5. LoginWarning useEffect: do NOT add a Steam branch (D-06)

The WebView chrome (`WebviewControls`, back/forward, "open in browser" button) is reused as-is. The Steam store tab looks and behaves identically to the other store tabs from a chrome perspective.

## Surface 2: Console Mode Store Filter Chip (CONSOLE-01)

### Chip label and position

Add to `storeFilters` array in `src/frontend/screens/ConsoleMode/index.tsx` (currently lines 159–183):

```tsx
{ key: 'steam', label: 'Steam', enabled: storesWithGames.has('steam') }
```

**Position in array:** after `{ key: 'nile', label: 'Amazon', ... }` and before `{ key: 'sideload', label: 'Other', ... }`.

Full filter order after change:
1. All
2. Epic
3. GOG
4. Amazon
5. **Steam** ← new
6. Other (sideload)
7. ZOOM

**Chip label is "Steam"** — no i18n wrapping needed (consistent with how 'Epic', 'GOG', 'ZOOM' are hardcoded strings in the existing filter array).

### allGames composition

Add `...steam.library` to the spread in `useMemo` (line 116–131):

```tsx
const allGames = useMemo<GameInfo[]>(() => {
  const all: GameInfo[] = [
    ...epic.library,
    ...gog.library,
    ...amazon.library,
    ...steam.library,   // ← add here, after amazon, before zoom
    ...zoom.library,
    ...sideloadedLibrary
  ]
  return all.filter((g) => !g.install?.is_dlc && !g.thirdPartyManagedApp)
}, [epic.library, gog.library, amazon.library, steam.library, zoom.library, sideloadedLibrary])
```

### Refresh guard

Add `steam.library.length === 0` to the initial refresh condition (lines 99–114) alongside the existing epic/gog/amazon/zoom checks. Trigger a background refresh so an empty Steam library auto-populates.

### Empty state

No Steam-specific empty state string. When `activeStore === 'steam'` and `visibleGames.length === 0`:
- If `filteringByInstalled` is true: the existing `console.empty` copy applies ("No installed games to show. Install something first.")
- This case is rare — the Steam chip is only enabled when `storesWithGames.has('steam')` is true, meaning Steam games exist in `allGames`

**No new i18n keys needed for the empty state.**

### Brand icon in Console

The `ConsoleCard` component renders game art. For Steam games, existing artwork URLs from the Steam metadata cache are used (already resolved by Phase 2/7). No new card-level UI changes for this phase.

`StoreLogos` component (`src/frontend/components/UI/StoreLogos/index.tsx`) already handles `runner === 'steam'` → `<SteamLogo />`. If `StoreLogos` is used anywhere in ConsoleCard, it already works. No changes needed.

## Surface 3: LaunchOverlay — Steam Fire-and-Forget (CONSOLE-01)

### Behavior contract

Steam launch (`steam://rungameid/{appId}`) resolves immediately via `shell.openExternal`. The existing `launch().finally(onDismiss)` pattern would dismiss before the user sees any feedback. The Steam branch must hold the overlay visible for exactly **1500ms** before calling `onDismiss`.

**Implementation pattern in `LaunchOverlay/index.tsx`:**

```
if (game.runner === 'steam') {
  fire launch()
  setTimeout(onDismiss, 1500)
} else {
  existing finally → onDismiss() path
}
```

### Visual state

| Element | State |
|---------|-------|
| `.consoleLaunchSpinner` | `idle` class (success green, slow 2.4s spin) — signals "done, not waiting" |
| `.consoleLaunchText` | "Launched in Steam" (CSS uppercases via `text-transform: uppercase`) |
| `.consoleLaunchGameTitle` | `game.title` as usual |
| `BackHint` | Not rendered for Steam (no cancellable in-flight operation) |
| Hold-to-cancel | Not active for Steam (skip `useCancelOnHold` or disable via `active: false`) |

**i18n key:** `console.steam.launched` → `"Launched in Steam"`

**Why `idle` spinner:** The `.consoleLaunchSpinner.idle` CSS rule applies `border-top-color: var(--status-success, #2bbd60)` and `animation-duration: 2.4s` — visually communicating "completed, not loading". This reuses an existing state without new SCSS.

### Dismiss animation

No explicit fade-out animation. Parent sets `setLaunchingGame(null)` after 1500ms, unmounting the overlay. The existing `overlayFade` enter animation plays on mount (220ms ease). Unmount is instant — acceptable at 1500ms dwell time.

## Surface 4: InstallOverlay — Steam Handoff (CONSOLE-01)

### Behavior contract

Activating a not-installed Steam game shows the `InstallOverlay`. For Steam, skip the GameLib-managed install flow entirely (no platform selector, no Wine selector, no path). Fire `steam://install/{appId}` via the existing install helper, show a brief notice, then auto-dismiss after **1500ms**.

### Visual layout

Reuse the existing `consoleInstallOverlay` → `consoleModal` shell. Replace the modal body contents with a minimal handoff view:

```
[consoleModalTitle]    "Opening Steam to install…"
[consoleModalGameTitle] game.title
```

No `consoleInstallFields` rows. No install button. No cancel button in the UI (Escape/gamepad-back still dismiss immediately via existing keydown handler).

| Element | State |
|---------|-------|
| `.consoleModalTitle` | "Opening Steam to install…" (CSS uppercases via `text-transform: uppercase; letter-spacing: 0.2em`) |
| `.consoleModalGameTitle` | `game.title` |
| Install fields | Not rendered (skip `consoleInstallFields` block) |
| Install / Cancel buttons | Not rendered |
| Escape / Back button | Dismiss immediately (existing `onDismiss` via keydown listener) |

**i18n key:** `console.steam.installing` → `"Opening Steam to install…"`

### Auto-dismiss timing

On mount (via `useEffect`):
1. Call the install handoff (`steam://install/{appId}` via existing helper)
2. `setTimeout(onDismiss, 1500)`

If user presses Escape before 1500ms: `onDismiss()` fires immediately, cancelling the timer.

**Implementation note:** Use a `cancelled` ref pattern (set on cleanup) to prevent `onDismiss` from firing after unmount if Escape was already pressed.

## Interaction Summary Table

| User Action | Surface | Result |
|------------|---------|--------|
| Clicks "Stores" in sidebar | Sidebar | Submenu expands showing Epic, GOG, Amazon, Steam Store, Zoom |
| Clicks "Steam Store" sub-item | Sidebar | Navigates to `/store/steam` → WebView loads `https://store.steampowered.com/` (or last-visited Steam store URL) |
| Navigates in Steam WebView | WebView | URL persisted to `sessionStorage['last-url-steam']` if it includes `store.steampowered.com` |
| Returns to Steam store tab | WebView | Last-visited URL restored from sessionStorage |
| Opens Console mode | ConsoleMode | Steam games appear in grid; "Steam" chip appears in filter bar when Steam library non-empty |
| Clicks "Steam" chip | ConsoleMode | Grid filters to show only Steam games |
| Activates installed Steam game | ConsoleMode | LaunchOverlay mounts → fires `steam://rungameid` → shows "Launched in Steam" for 1500ms → auto-dismisses |
| Activates not-installed Steam game | ConsoleMode | InstallOverlay mounts (simplified) → fires `steam://install` → shows "Opening Steam to install…" for 1500ms → auto-dismisses |
| Presses Escape during Steam overlays | Both overlays | Immediate dismiss; auto-dismiss timer is cancelled |
