## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Jest 29 (`ts-jest` preset, **transpile-only** — type errors do NOT fail a suite; `tsc --noEmit` is a separate gate). **Rust is in scope this phase** — A-03's `keyring_account()` slot edits `src-tauri/src/main.rs`, so `cargo check` + `cargo test` are mandatory, not optional. |
| **Config file** | Root `jest.config.js` (5 projects) → `src/backend/jest.config.js` (`displayName: 'Backend'`, `rootDir: '../..'`, `roots: ['<rootDir>/src/backend']`, `setupFiles: jest.setupContainment.ts`, `globalSetup: jest.globalSetup.js`); `src/frontend/jest.config.js` (`displayName: 'Frontend'`); `src-tauri/Cargo.toml` |
| **Quick run command** | `npx jest --selectProjects Backend --testPathPattern "<suite>"` (run from repo root) |
| **Full suite command** | `npx jest --selectProjects Backend` + `npx jest --selectProjects Frontend` + `npx tsc --noEmit` + `cd src-tauri && cargo check && cargo test keyring` |
| **Estimated runtime** | Backend project ~90s; targeted `--testPathPattern` run <10s; `cargo check` ~20s warm |

⚠ **Two command-shape hazards measured during planning — do not regress them.**

1. **`--selectProjects` is CASE-SENSITIVE and fails OPEN.** The project displayNames are
   `Backend` and `Frontend`, capitalised. `npx jest --selectProjects backend --listTests`
   prints *"You provided values --selectProjects but no projects found matching selection"*
   **and exits 0**. A task or CI step written with the lowercase form is a **silently vacuous
   green** — it asserts nothing and reports success. Every automated command in this file uses
   the capitalised form. Any new one must too.
2. **Do not gate on a full `pnpm test`.** This project has a recorded lesson that a full-suite
   run manufactures a *different* failure set under load (988s in-suite vs 0.7s alone). Gate on
   the per-project runs above. Equally, do **not** substitute a module-scoped `cd src/backend &&
   npx jest` — that form has shipped a red HEAD here for a day by missing same-shape fixtures in
   other directories.

## Sampling Rate

- **After every task commit:** `npx jest --selectProjects Backend --testPathPattern "<the suite(s) this task touched>"`
- **After every plan wave:** full `Backend` + `Frontend` project runs, plus `npx tsc --noEmit`; on any wave touching `src-tauri/`, also `cargo check`
- **Before `/gsd:verify-work`:** both project runs green, `tsc --noEmit` clean, `cargo check` clean, `preload-surface-gate.py` green (D-03), and the blocking live gate PASS
- **Max feedback latency:** ~90 seconds (full Backend project); <10 seconds for the targeted per-task form
