<objective>
Close gap G-47-12a (major): the Store Search query and its results are lost when the user leaves the screen and comes back.

Root cause (binding, from `.planning/debug/store-search-query-lost-on-leave.md`): query, debounced query, results,
status, pricedCountry and errorCode are plain component-local `useState` in `useDebouncedStoreSearch`, and the
`store-search` leaf route unmounts on navigation (App.tsx:269). The Stores tab remembers `/store-search` (quick
261029-n4v), so the user lands back on a freshly mounted, empty screen. Only the region survives, through localStorage.
An omission since Phase 20, not a regression.

Choices recorded (Claude's discretion, from the debug session's recommended direction):
- A module-scope in-memory store, `storeSearchSession.ts`, shaped like `Library/librarySessionSearch.ts` (the Library
  search's own session store from quick 261029-n4v). Never localStorage or sessionStorage: D-22/WR-11 forbid a storage
  key for search text, and the rows carry prices that the backend only treats as fresh for an hour.
- Keep query and rows ("tier 2"), not just the query, so the rows are on screen on the first frame.
- Kept rows are restored only when they were fetched for the same trimmed query and the same country less than
  `KEPT_RESULTS_MAX_AGE_MS` (one hour, mirroring the backend's `ITAD_FRESH_MS`) ago, and only for a 'results' or 'empty'
  status. Otherwise the query is kept and the debounced query is seeded with it, so the search re-runs on mount without
  waiting out the 400 ms debounce. An 'error' status is never resurrected.
- When restored rows already match the committed query and country, the fetch effect does not re-fetch on mount (the
  backend would answer from the same hour-fresh cache), and the debounce effect does not start a timer for a query equal to
  the committed one. Together these mean no loading flash and no spinner on return.
- Adding a production file under `src/frontend` changes the i18n gate's fork-touched set, so Task 3 records it (the
  47-16 precedent, commit 168372010).

Purpose: the user can step away from Store Search (theme, settings) and come back to the search they were reading.
Output: storeSearchSession.ts, hook wiring, hook/screen/session tests, i18n gate-scope bookkeeping.
</objective>
