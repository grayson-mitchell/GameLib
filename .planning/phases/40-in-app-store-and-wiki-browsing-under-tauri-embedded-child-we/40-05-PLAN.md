<planning_findings>
1. **The Rust arms this seam calls are exactly the five plan `40-02` shipped**: `store_embed_open`,
   `store_embed_set_bounds`, `store_embed_hide`, `store_embed_show`, `store_embed_close`. Read
   `40-02-SUMMARY.md` for their final argument and return shapes before writing the coercion code —
   a seam written against this plan's prose rather than the shipped arms is a silent mismatch.

2. **Navigation commands do NOT exist yet.** Plan `40-02` deliberately did not add
   `back` / `forward` / `reload` / `navigate` arms; plan `40-07` adds them against the D-25 verdict.
   This seam must therefore define the navigation surface as part of its INTERFACE — so `40-07` has a
   contract to implement — while leaving the implementation to throw a declared-unimplemented Error
   rather than returning a plausible default. A declared-unimplemented throw is legible; a coerced
   default is the F-34.4.2-19 defect class.

3. **`humbleLoginFlowRegistration.ts` is the exact analog** (483 lines). Two of its disciplines are
   load-bearing here and are stated in its own doc comment: every response coercion throws on a
   malformed shape rather than defaulting, because a silently-coerced default recreates the defect of
   a dead Rust channel misreporting as a healthy empty one; and every handler resolves a safe default
   on catch while every send arm wraps its body so a rejection can never become unhandled.

4. **Send-versus-handle mismatches fail 100% silently** under the sidecar transport — no reject, no
   timeout, no console line. Every registration must be cross-checked against the kind the preload
   binder uses for that same channel name. `setBounds` is the one channel that must be a SEND: it
   fires on every `ResizeObserver` tick and must not accumulate promises.

5. **`.planning/IPC-PORT-INVENTORY.md`'s Totals deliberately sit one above the union.** Adding
   channels changes counts; follow the file's own stated convention and do not "fix" the offset.

6. **Bounds are LOGICAL px and must pass through untouched.** Spike 017 proved two geometry writers
   silently last-write-wins with no error. The TypeScript layer is a courier here, not a participant:
   no rounding, no clamping, no default, no fallback rect. If a bound is missing or non-finite the
   send must throw at the preload boundary rather than substituting a value — a substituted rect is
   a second writer wearing a disguise.
</planning_findings>
