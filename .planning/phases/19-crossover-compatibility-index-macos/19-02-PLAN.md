<objective>
Build the measurement harness that decides — empirically, before any UI ships — whether
non-Steam library titles can be matched onto the CrossOver dump's canonical names, and
extract the winning name normalizer into its own file as the CrossOver **matching key**,
kept structurally distinct from the URL `slugify()` (D-20).

Purpose: D-02's promotion gate is the hinge of this phase. Its verdict (does non-Steam name
matching ship in v1, or defer to a follow-up phase?) governs a user-facing correctness claim
("this game runs / won't run on your Mac"). The gate bounds are pre-committed so the number
cannot be rationalized after the fact; this plan makes the gate a runnable, auditable
instrument rather than a theory.

Output:
- `meta/measureCrossoverMatching.ts` — scores candidate normalizers against THREE
  separately-denominated samples plus a whole-dump self-collision proxy, evaluates the
  pre-committed D-02 gate on the 123-pair ground-truth set, and writes a dated Markdown report.
- `src/backend/crossover_index/normalize.ts` — the winning normalizer, exported as `normalize()`.
- `src/backend/crossover_index/__tests__/normalize.test.ts` — the synthetic adversarial set as
  a permanent Jest regression suite.
</objective>

  (~3.09 MB gzipped → 23.7 MB XML; Content-Length verified 3,088,416 bytes.)
- Dump XML shape (Pitfall T-02): root path is `c4p > applications > app[]`; the Mac medal and
  steamid live INSIDE `<appprofile>`, NOT as direct children of `<app>`. Extracting against the
  wrong shape silently yields ZERO records.
- fast-xml-parser@5 entity-limit fix (Pitfall T-01): pass a `processEntities` object with
  `enabled: true`, `maxTotalExpansions: 500_000`, `maxExpandedLength: 50_000_000`,
  `maxEntityCount: 1_000`. Do NOT use `processEntities: false` — that would leave `&amp;`
  undecoded in names like "Command & Conquer". `isArray` must cover `['app','name','medal','category']`.
- Medal rule → rating: 5/4/3/2/1 on the highest-cxversion medal (verified 6/6 against the live
  site in the findings note). Rating spread across the 2,866 Mac-medal games:
  1054×5 / 655×4 / 475×3 / 347×2 / 335×1.
- Local library caches (VERIFIED paths): `~/Library/Application Support/GameLib/store_cache/`
  → `steam_library.json` (377 titles), `legendary_library.json` (15 Epic, ~10 DLC/art/wallpaper),
  `gog_library.json` (0), `nile_library.json` (0). Locate them via `CacheStore`'s on-disk
  convention (`cwd: 'store_cache'`) rather than hardcoding an absolute path (see src/backend/cache.ts:22-26).
- Ground-truth set: Steam library ∩ dump-by-AppID = 123 pairs where the correct dump record is
  known by exact AppID join. n=123 makes a single wrong hit 0.81% — below the 2% bound.
- Research feasibility preview (NOT the measurement — Steam titles are the easiest case,
  optimistically biased): candidates A/B/C scored 0 wrong hits at 77.2% / 80.5% / 84.6% hit.
  Self-collision over 2,866 names: punctuation stripping = 0 rating-disagreeing collisions (free);
  edition-suffix stripping = 11 disagreeing keys / 33 records at risk (1.2%) — the live trade-off.
