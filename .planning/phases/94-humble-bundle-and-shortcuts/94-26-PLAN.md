## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer -> key actions | requests to reveal, override or record a gift are untrusted |
| crate -> Humble redeem | a reveal consumes a key server-side |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-94-49 | Elevation of Privilege | override and gift-link actions | high | mitigate | server-side re-validation inside the ops (fuzzy-only; owned-elsewhere and UNREVEALED); goldens pin the refusals |
| T-94-50 | Information Disclosure | revealed key values | high | mitigate | C4: one value-bearing op; an assertion over every log line, event and result; no logging in the reveal path |
| T-94-51 | Tampering | accidental reveal of an owned-elsewhere key | high | mitigate | C2 block before any redeem request, pinned by a golden with zero requests |
| T-94-SC | Tampering | package installs | low | accept | no new dependency |
</threat_model>
