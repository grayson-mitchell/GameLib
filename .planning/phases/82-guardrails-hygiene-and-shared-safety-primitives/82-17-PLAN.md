<objective>
Close the crate half of verification gap 1 (CR-01 / WR-01) and gaps 2 and 4 (WR-04, WR-08) in `gamelib-safety`.

Purpose: `check_trust_root` resolves the trust root with a bare canonicalise, so a trust root folder that does not
exist reads unknown. GOG always sends `<gogdl config>/gog-support` as a trust root, and that folder usually does not
exist, so a normal GOG uninstall is refused before `unins000.exe` runs. A Steam cancel that lands before
`steamapps/common` exists is refused the same way and leaves its manifest and breadcrumb behind. The fix is in the
crate, so every caller is covered (per D-17 and the D-08 README rule "readers distinguish absent from
could-not-read": absent is not a canonicalisation failure). An empty `trustRoot` string is currently read as "no trust
root" and skips containment (WR-04), and the four lexical-row tests can pass on zero rows (WR-08, the D-05 failure
mode).

This plan also creates the shared trust-root contract fixture. 82-19 runs the same rows against the TS fake
transport, which is what stops a fake/crate divergence from hiding a defect like CR-01 again.

Output: `resolve_trust_root`, the fixed `check_trust_root`, the contract fixture plus its crate test, new adversarial
rows, and the README trust-root rule.
</objective>
