## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| future code change -> guarded files | The source gates are the backstop that stops a later edit from adding an unguarded recursive delete to an uninstall/reset/cancel file |
| sidecar -> Rust shell (rustInvoke) | The sidecar's timeout decides how a slow delete's outcome is reported to the user and whether a retry races it |
