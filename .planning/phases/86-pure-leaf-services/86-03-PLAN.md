<objective>
Create `gamelib-info` and `gamelib-info-cli` with the three shared seams every slice uses: the TS `CacheStore`
semantics over the shipped StoreHost (`cache_view`), an `Http` trait with a reqwest implementation and a request-pinning
`Replay`, and the op dispatcher that holds a shutdown registrant around each op. Register both crates in the workspace
and CI.

Purpose: research found the leaves' parity risk is in small JS-isms around simple HTTP: TTL and `__timestamp` dot
writes, `Date()` strings, axios query encoding, redirect and timeout behaviour. Built once here, no slice re-derives
them. D-02 fixes the single-crate shape.
Output: the two crates, their tests, CI and lockfile registration, README entry.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| remote service -> ReqwestHttp | untrusted response bodies and redirects |
| crate -> logs and errors | URLs carry the ITAD key in the query |
| shell exit -> in-flight ops | HTTP in flight when GameLib quits |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-86-04 | Information Disclosure | ReqwestHttp error mapping | high | mitigate | every reqwest::Error goes through `.without_url()` before it becomes an HttpError; a test asserts a `key=SECRET` URL never appears in error text |
| T-86-05 | Denial of Service | response bodies | medium | mitigate | 16 MiB default cap with per-call smaller caps; a test proves TooLarge without reading the rest |
| T-86-06 | Tampering | redirects | low | accept | `Policy::limited(5)` matches axios's default, so a redirect chain behaves as before (parity); HTTPS-only checks stay where TS had them (the crossover index `assertHttps`, 86-19) |
| T-86-07 | Denial of Service | exit path | medium | mitigate | each op holds a Registrant and races the Shutdown token, so quit cancels in-flight HTTP inside the 3.5 s drain budget |
| T-86-SC | Tampering | crate dependencies | low | accept | no new package: reqwest, rustls, url, jiff, tokio, serde are already locked; Cargo.lock gains only the two in-repo crates |
