## Interaction Contracts

### Tri-State Filter Control (LIB-09)

Affects: "Show Hidden" and "Show non-Available games" rows in `LibraryFilters`.

**Cycle:** Off → Show → Only → Off (single click on the primary control, or click "only" button to jump directly to Only from any state).

**Control affordance:** Use the existing `toggleWithOnly` composite control already present in `LibraryFilters` for stores and platforms — `ToggleSwitch` + `"only"` button side-by-side. Adapt semantics:

| Current state | Click ToggleSwitch | Click "only" button |
|---------------|-------------------|---------------------|
| Off | → Show | → Only |
| Show | → Off | → Only |
| Only | → Show | → Off |

**Both-"Only" union (D-09):** When both Hidden and Non-available are set to "Only", show games that are hidden OR non-available (union). Do not intersect.

**Visual state of the "only" button:**
- When current filter is "Only": apply the accent color (`var(--accent)`) to the button text/border to signal active state — consistent with how the "active" `consoleChip` in ConsoleMode uses accent.
- When current filter is Off or Show: button renders at muted/neutral (existing `.only` class style, no accent).

**Persistence:** Store tri-state values in `localStorage` extending the existing `showHidden` / `showNonAvailable` keys. Store as string values `'off' | 'show' | 'only'`. Read/write follows the existing LibraryContext `localStorage` pattern.

**Keyboard:** The "only" button is a `<button>` element, already keyboard-reachable. No additional keyboard handling required beyond existing tab order.

**ARIA:** `aria-pressed="true"` on the "only" button when in Only state; `aria-pressed="false"` otherwise. The ToggleSwitch `role="switch"` `aria-checked` reflects On (Show or Only) vs Off.

---

### Delisted Tile Rendering (LIB-08)

**When shown:** Only visible when the Non-available filter is "Show" or "Only". Hidden by default (Off state, D-03).

**Art treatment:**
- Not-installed delisted: `filter: grayscale(1); opacity: 0.5` on `.gameImg` — full desaturation.
- Installed delisted: `filter: sepia(100%); opacity: 0.7` on `.gameImg.installed` — warm grey (reuses existing `.notAvailable.installed` rule, no new CSS needed).

**Badge — "Game no longer available":**
- Position: Absolute, top-left of the card, beneath the store icon (z-index 3, same as `.gameTitle`).
- Style: Extends the existing `.gameCardUpdateBadge` visual pattern — `background: var(--status-default)`, `color: var(--neutral-01)`, `font-size: var(--text-sm)`, `font-weight: var(--semibold)`, `padding: var(--space-3xs) var(--space-2xs)`, `border-radius: var(--space-3xs)`.
- New CSS class: `.gameCardDelistedBadge` — do NOT reuse `.gameCardUpdateBadge` (different semantic; different color).
- `pointer-events: none` (badge is informational only).
- `aria-label="Game no longer available"` on the badge element.

**Install button:** Hidden (render `null` or `display: none`) for delisted games where `is_delisted === true`. Do not merely disable — Steam's `steam://install` for a delisted AppID returns an error silently; hiding is cleaner than a disabled state with no tooltip.

**Launch + uninstall:** Remain fully visible and enabled for already-installed delisted games (D-06). The install path is the only dead action.

**Tile click:** Navigates to game details page (D-04). The entire card `<a>` link remains intact — no `pointer-events: none` on the card itself.

**Hover:** Standard `transform: scale(1.05)` (existing `.gameCard:hover` rule — no change).

## State Machine — Library Filter States

```
showHidden: 'off' | 'show' | 'only'
showNonAvailable: 'off' | 'show' | 'only'

Library visible set:
  Base = all non-delisted, non-hidden games
  + if showHidden == 'show'  → add hidden games
  + if showNonAvailable == 'show' → add non-available/delisted games
  if showHidden == 'only' AND showNonAvailable == 'only' → show hidden UNION non-available
  if showHidden == 'only' (and other is not 'only') → show only hidden games
  if showNonAvailable == 'only' (and other is not 'only') → show only non-available/delisted games
```

This replaces the existing boolean filter logic at `Library/index.tsx` ~L511-530 and ~L343, L571-572.
