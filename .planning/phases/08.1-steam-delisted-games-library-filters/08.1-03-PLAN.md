<objective>
Migrate the two boolean Library filters (showHidden, showNonAvailable) to a tri-state
`'off' | 'show' | 'only'` model (LIB-09) and wire Steam's delisted signal into the frontend
non-available determination (LIB-07 frontend half). This is the atomic type-migration core: the
`FilterMode` type change in types.ts cascades to every consumer, so all five files change together
to keep `tsc` green.

Purpose: Deliver the tri-state filter behavior and make the "show non-available" filter actually
work for Steam delisted games (including not-installed delisted games that never enter the
`nonAvailableGames` localStorage key).
Output: FilterMode type, retyped context + defaults, migrated Library state + tri-state filter
chain (collapsing the duplicate block), RecentlyPlayed prop retype, and tri-state LibraryFilters
controls.
</objective>
