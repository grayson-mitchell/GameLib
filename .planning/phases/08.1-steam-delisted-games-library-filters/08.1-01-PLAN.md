<objective>
Wire Steam's delisted signal into the backend availability check (LIB-07, backend half) and
register the three new phase requirements in REQUIREMENTS.md so the phase traces cleanly.

`isGameAvailable()` currently returns `false` for any not-installed Steam game. Per D-01/D-02,
"non-available" must mean *delisted*, not *not-installed*. This plan adds a delisted guard so an
installed OR not-installed delisted game reports non-available, while a not-installed but still
purchasable game reports available.

Purpose: Make the backend the source of truth for Steam availability=delisted, feeding the
frontend `nonAvailableGames` path for installed games (the frontend also adds a direct
`is_delisted` check in Plan 03 for not-installed games).
Output: Modified `isGameAvailable()`, two new unit tests, and REQUIREMENTS.md traceability rows.
</objective>

async isGameAvailable(): Promise<boolean> {
  return new Promise((resolve) => {
    const info = this.getGameInfo()
    resolve(
      Boolean(
        info?.is_installed &&
        info.install?.install_path &&
        existsSync(info.install.install_path)
      )
    )
  })
}
