# Phase 34.2 Plan 12: Digest-Pin Do-Not-Touch Gates + Real-i18next Launch-Options Assertion Summary

**Replaced two assertions that could never fail (a HEAD-vs-working-tree git comparison that is always true on a clean checkout, and a toEqual comparing two calls to the same uninitialized i18next.t()) with a committed sha256 digest pin plus semantic channel-set pin, and a real-i18next-backed translation assertion that explicitly rejects `undefined` and the raw key.**

## Accomplishments

- WR-01 closed: `gameDetailsImportGate.test.ts` Gate 7 (settingsFlowRegistration.ts) and Gate 8
  (electronUntouched.test.ts) no longer shell out to `git show HEAD:<path>` and compare it to the
  working tree — a comparison that is unconditionally true on any clean checkout and had protected
  nothing since the moment 34.2 was committed. Both are now pinned to a committed sha256 digest
  computed with `node:crypto`'s `createHash`, with a failure message naming the requirement
  (REQ-34.2-10/D-09, REQ-34.2-14) and the remediation (recompute deliberately, state the reason in
  the commit). `execFileSync` import removed entirely; no `git` subprocess remains in the file.
- Added two Layer-2 semantic pins for `settingsFlowRegistration.ts`: an exact ten-channel set
  (parsed via regex over comment-stripped source, asserted with set equality AND length so both
  silent widening and silent narrowing fail) and a `steamLibrary.has(` presence check (over
  comment-stripped source, so a docstring mention alone cannot satisfy it) — protecting the
  specific D-09 bottle-launch fix the digest alone would only catch as an opaque hash mismatch.
- WR-04 closed: `gameDetailsModules.test.ts`'s `getLaunchOptions` default-label test no longer
  derives its expected value from the same uninitialized `i18next.t()` call the code under test
  makes. A new `beforeAll` initializes the real i18next singleton (guarded by `isInitialized`)
  using resources read directly from `public/locales/en/gamepage.json` on disk. The rewritten test
  asserts the returned option's `name` equals the on-disk `launch.default` value AND is neither
  `undefined` nor the literal key `'launch.default'` — closing both the uninitialized-singleton
  blind spot and the project-wide `__mocks__/i18next.ts` automock echo blind spot in one assertion
  pair.

## Decisions Made

- Digest pins are the primary do-not-touch enforcement mechanism (byte-identity, cannot be
  satisfied by anything other than the exact committed bytes); the semantic pins are a secondary
  Layer 2 that survives a legitimate reformat (which changes the digest but not the channel set)
  while still catching a structural rewrite — per the plan's own T-34.2-60 threat-register
  reasoning ("a digest pin alone would be defeated by nothing, but a semantic pin alone could be
  satisfied by prose").
- The `getLaunchOptions` test reads `public/locales/en/gamepage.json` directly (not a hardcoded
  fixture string) so the assertion breaks if `launch.default` is ever renamed or deleted — the
  plan's explicit rationale for why a fixture would hide exactly this regression.
- Introduced a narrow `as { name: string }` cast on `result[0]` in the rewritten
  `getLaunchOptions` test (not called for by the plan text) — `LaunchOption` is a union type
  (`BaseLaunchOption | AltExeLaunchOption | DLCLaunchOption`) and only the `basic` variant carries
  `name`; the preceding `toMatchObject({ parameters: '', type: 'basic' })` assertion already
  proves the runtime shape, so the cast merely satisfies the type checker. This was required to
  keep `npx tsc --noEmit` clean (Rule 3 — blocking build error).

## Deviations from Plan

- **Found during:** Task 2, `npx tsc --noEmit` verification step
- **Issue:** Accessing `result[0].name` directly on the `LaunchOption`-typed return value produced

- **Fix:** Introduced `const defaultOption = result[0] as { name: string }` immediately after the
  `toMatchObject({ parameters: '', type: 'basic' })` runtime-shape assertion, with an inline
  comment stating the cast is type-only (the preceding assertion already proves the shape at
  runtime).
