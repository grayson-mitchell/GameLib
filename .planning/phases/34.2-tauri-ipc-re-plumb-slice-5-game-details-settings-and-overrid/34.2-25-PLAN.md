## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| jest worker → host filesystem | Test code writes real `electron-store` JSON (`fileStore.ts`) and real log files; the containment root is the only thing keeping those writes off the developer's real `$HOME`. |
