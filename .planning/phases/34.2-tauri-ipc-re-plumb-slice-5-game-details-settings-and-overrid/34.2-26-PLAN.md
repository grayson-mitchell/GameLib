## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer → sidecar (`logError` send channel) | Untrusted, caller-supplied `unknown` message crosses here over the newline-delimited JSON RPC transport. |
| sidecar → stdout / stderr | stdout carries the RPC frame protocol; any non-frame byte written there corrupts the transport. stderr is the only safe diagnostic sink. |
| sidecar → log file | A caller-controlled message is appended to a real file on disk. |
