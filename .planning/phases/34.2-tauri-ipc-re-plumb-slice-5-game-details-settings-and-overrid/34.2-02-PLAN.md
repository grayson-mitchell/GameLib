<objective>
Extract the 19 `main.ts`-hosted handler bodies of this slice into Electron-free modules
under `src/backend/gamedetails/`, leaving `main.ts` with one-line delegations, so the
sidecar can import and run the SAME code the Electron build runs.

Purpose: D-03 carries Phase 34.1's D-07/D-08 forward unchanged. The alternative —
re-implementing the bodies in a curated sidecar module while `main.ts` keeps its own
copies — ships two implementations that can drift silently between the two builds, and
reverses a decision made one phase ago. 34.1 already gave up the
textually-untouched-Electron-entry-point invariant and re-expressed the additive
guarantee as behavioral; this slice pays no new price for the same move.

Output: `gamedetails/dispatch.ts`, `gamedetails/overrides.ts`, a mechanical `main.ts`
diff, and behavior tests that run the extracted functions directly.
</objective>
