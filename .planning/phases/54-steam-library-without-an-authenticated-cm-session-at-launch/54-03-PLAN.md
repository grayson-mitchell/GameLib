<objective>
Turn `SteamUser` into the single gated owner of every authenticated CM logon (ROADMAP SC3, SC6).

- `acquireAuthenticated(opts)`: refcounted lease. The first acquire runs today's `ensureConnected`
  body (keyring read, verdict reporting, epoch fence) with the cold connect wrapped in
  `withMacSteamOffline` (plan 01). The last release arms a 60 s idle timer that logs off.
- `acquireOpenAuthenticated(reason)`: a lease on a session that is ALREADY open, or null. Never
  reads the keyring, never logs on. Launch-path consumers (mount refresh, Play-time shared redists,
  installdir and launch-target fallbacks) use this so they can reuse an install's session but can
  never open one.
- Own every logon (spike 046c): `autoRelogin: false`; post-logon drop = session ended; the canary's
  stale-socket path re-enters the wrapped cold connect instead of calling `client.relog()`.
- Sign-in still logs on (ROADMAP allows it), but through the same wrapped entry point; the steamId
  comes from the steam-session `LoginSession.steamID`, which needs no CM.

Sequencing note (not a scope cut): `ensureConnected()` keeps its public name and boolean contract
in this plan because library.ts, depot.ts, games.ts, launchTarget.ts and installLocation.ts still
call it; plans 04, 05, 06 and 08 move every caller to the lease API, and plan 09's source gate then
forbids any `ensureConnected(` call outside user.ts. Because its internals change here, every
remaining caller is already wrapped and autoRelogin-off from this plan onward. A bare
`ensureConnected()` takes no lease, so it never arms the idle timer (a long install run by a
not-yet-migrated caller is never logged off mid-download).

Planner decisions (Claude's discretion, recorded):
- `AUTH_SESSION_IDLE_GRACE_MS = 60000` (RESEARCH Pattern 2: 30-60 s; prescreen -> install -> shim
  resolve -> shared redist must not thrash).
- `AUTH_LOGON_BOUND_MS = 35000` replaces the 15 s fallback + separate 20 s grace window for the
  authenticated connect: the wrap cannot fire `goonline` while a logon is still in flight, so the
  connect waits up to 35 s for `loggedOn`/`error`, then `logOff()`s the attempt. This keeps the slow
  cold-reconnect allowance debug/steam-relogin-no-autorefresh needed.
- Persona name is fetched only for `reason === 'login'`, after `loggedOn`, bounded 5 s with
  `withTimeout`; fallback `session.accountName`, then `'Steam User'`. Other reasons skip it, which
  shortens the window Mac Steam is offline.
- Refusal vocabulary (`AuthSessionRefusal`): `'shutting-down' | 'not-signed-in' | 'token-unreadable'
  | 'token-absent' | 'logon-rejected' | 'client-not-ready' | 'go-offline-required'`.

Output: user.ts lease API + rewritten connect lifecycle; one new test file; updated user tests.
</objective>
