<objective>
Build the two leaf modules every later Phase 54 plan stands on, plus the IPC contract types for the
guided Go Offline step.

1. `macSteamOffline.ts`: the go-offline wrap spike 046 proved (`steam://open/gooffline`, wait for
   Mac Steam's user-initiated LogOff in `connection_log.txt`, log on, `steam://open/goonline` in a
   `finally`). It decides nothing about sessions; `user.ts` (plan 03) calls it around every cold
   authenticated connect.
2. `anonymousClient.ts`: one shared anonymous steam-user client for public PICS reads
   (`getProductInfo`). Plans 04 and 06 move platform capture, install location and the bridge
   launch target onto it.
3. Contract types: `SteamGoOfflinePayload` (backend push) and `steamGoOfflineRetry` (renderer
   invoke), so plans 03 and 07 build against one shape.

Purpose: ROADMAP SC6 (every authenticated logon wrapped on macOS; never a silent logon when the
LogOff is not seen) and SC2 (public reads on an anonymous session).

Planner decisions (no CONTEXT.md; ROADMAP is locked; these are Claude's discretion, recorded):
- Wrap trigger: toggle when Mac Steam is running AND the last `[State, n, m]` bracket is anything
  other than `Logged Off` (so `Connecting`/`Logging On`/unreadable-log while running all take the
  evidence-gated toggle). Not running means no Friends session to protect: connect directly.
- Running probe: `/usr/bin/pgrep -x steam_osx` with a 2 s `timeout`. Exit 0 = running, exit 1 = not
  running, any other failure (ENOENT, timeout) = throw `GuidedOfflineRequiredError`. Rationale:
  assuming "not running" risks a Friends flip; assuming "running" risks `steam://` launching Steam.
  The guided step does neither.
- Evidence regex is strict: `/user initiated logoff/` only (046a: the line lands within 0.25 s).
- Settle before `goonline`: 2000 ms after a successful connect (046b's tested value; shorter is
  untested). On a connect failure `goonline` fires with no settle.
- Guided restore: `checkGuidedOfflineReady()` (the renderer's Continue button, plan 07) arms a
  one-shot, 10-minute flag so the next wrapped logon that finds Steam `Logged Off` fires `goonline`
  afterwards: the user went offline because GameLib asked. Without the flag a user-chosen offline
  state is never undone (RESEARCH Pattern 3 pitfall).
- Log path: `join(<defaultSteamPath with ' stripped>, 'logs', 'connection_log.txt')`, the same
  `GlobalConfig.get().getSettings().defaultSteamPath` derivation `clientSetup.ts`
  `hasLibraryFoldersVdf()` uses (macOS default `~/Library/Application Support/Steam`). Tests inject
  the path; no test touches the real profile.

Output: two backend modules with unit tests, three exported types, two IPC map entries.
</objective>
