<objective>
Move the two single-app public PICS reads onto the anonymous session (ROADMAP SC2): the install
location (`fetchInstalldir`) and the bridge launch target (`resolveBridgeLaunchExe`, called by Play,
the post-install shim placement and uninstall). Platform capture moved in plan 04.

The anonymous answer is a public subset for license-gated apps (`public_only`, RESEARCH Finding 4:
50 of 700 sampled ids, no `config` at all). ROADMAP SC2 accepts benign degradation; this plan keeps
it benign and avoids a Play regression for installed gated bridge titles (RESEARCH Pitfall 3):

1. anonymous PICS;
2. if missing/public_only: the authenticated session ONLY if one is already open
   (`acquireOpenAuthenticated`, which never logs on). At install time one is open (plan 08 acquires
   before target resolution and shim placement), so installs still get full data;
3. launch target only: the record persisted at the last successful resolve (`bridge.launchTarget`
   in steamMetadataStore via bridgeVerdict.ts, zod-declared so it survives the strip-on-read).

Planner decision (Claude's discretion, recorded): the persisted record stores the raw PICS
`executable` (Windows separators) and `installdir`; the absolute path is recomputed on read through
the same `sanitizeInstalldir(installdir, appId, steamappsDir)` containment check, so a tampered
record cannot escape the bottle's steamapps dir.
</objective>
