<objective>
Add the new filter state model to `Library` and expose it through `LibraryContext`, without yet
changing what the grid shows.

Purpose: every panel component built in Wave 3 reads and writes through `LibraryContext`, and the
chip row in Wave 4 renders directly off it. That surface has to exist and be correct before any of
them can be written. This plan is deliberately **additive**: the legacy `storesFilters`,
`platformsFilters` and `crossoverRatingFilters` state and context fields stay in place, because
`LibraryFilters` and `CategoryFilter` are still mounted and still consume them until plan 10 retires
all three together. Removing them here would red the TypeScript build for three waves.

Output: new state + new context fields (including the active **descriptor list**, not just a count)
+ the D-02 migration + the one shared facet-label module, all live but not yet driving the grid.
Plan 05 rewires the pipeline onto them.
</objective>
