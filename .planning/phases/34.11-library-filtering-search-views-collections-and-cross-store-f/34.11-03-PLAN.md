Purpose: D-31 and D-32 hand these to this phase explicitly. CR-01 and CR-02 were deferred at 34.10

(`--divider`) matters more here than it did in 34.10 because `.NavShell__tier2` is the column this

`gruvbox_dark` and `dracula`, both mandatory stress-test themes for this phase, are among the 9
that do not define it. Per the CSS Custom Properties spec an undefined custom property with no
fallback is invalid at computed-value time, which drops the whole `border-inline-end` shorthand:
the divider does not fall back to a default colour, it disappears.

This is the **third** instance of the no-fallback-custom-property defect class in this codebase, and
the first two were both caught only by a live human sweep. That is the argument for the source gate
in Task 3.

Output: three source fixes plus a new committed jest gate. Wave 1, no dependencies — nothing in
this plan touches any file another Wave 1 plan touches.

| window chrome → OS drag/resize | `-webkit-app-region: drag` hands a DOM region to the OS window manager. An over-broad drag region swallows clicks on controls inside it. |
| CSS custom property resolution | An undefined no-fallback custom property silently drops its whole declaration; the failure is invisible in source review and in a green test suite. |
