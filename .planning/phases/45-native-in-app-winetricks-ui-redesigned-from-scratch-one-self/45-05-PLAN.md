- Task-group membership (CONTEXT discretion within D-05/D-07; every member must carry a D-08 family):
  runtimes = vcrun2022, vcrun2019, vcrun2013, vcrun2012, vcrun2010, vcrun2008, dotnet48, dotnet40,
  vb6run; directx = d3dx9, d3dx10, d3dx11_43, d3dcompiler_43, d3dcompiler_47, dxvk, physx, xact,
  xinput; fonts = corefonts, tahoma, arial, times, cjkfonts; media = wmp9, wmp10, wmp11, quartz, mf;
  wineSettings = fontsmooth=rgb, fontsmooth=gray, fontsmooth=disable, csmt=on, csmt=off,
  videomemorysize=default, videomemorysize=2048, vd=1024x768, vd=off. (UI-SPEC's illustrative counts
  6/9/4/5/4 were a mock; the rendered badge counts whatever resolves.)
- Family prefixes (D-08): vcrun = `^vcrun`; dotnet = `^dotnet\d`; vbrun = `^vb\d+run$`;
  d3dx = `^(d3dx|d3dcompiler_)`; dxvk = `^dxvk\d*$` (NOT `dxvk_nvapi*`); physx = `^physx$`;
  xactXinput = `^(xact|xinput)`; fonts = category `fonts`; media = `^wmp\d+$`, `^quartz`, `^mf$`;
  fontsmooth/videomemorysize/csmt/vd = the `<name>=` prefix. Family-to-group: vcrun/dotnet/vbrun ->
  runtimes; d3dx/dxvk/physx/xactXinput -> directx; fonts -> fonts; media -> media; the four settings
  families -> wineSettings.
- `attributeProgressEvent` is REMOVED, not extended. CONTEXT asks to extend the pure seams, but this
  function's job — classifying a line as an error by a `' err'` substring — is exactly what D-15 moves
  to the backend; per-verb failure now arrives as a queue outcome (`failed`, from the exit code), which
  `foldRunOutcomes` folds. Its only consumer was deleted by plan 45-02; keeping it would be dead code
  (`pnpm find-deadcode` runs pre-push).
- `displayTitle` is a planner addition within D-08/specifics ("row shows family or title"): upstream
  titles carry trailing DLL lists such as "Visual C++ 2015-2019 libraries (concrt140.dll,…)"; the
  row shows the cleaned title and keeps the full upstream title in the native `title` tooltip (45-07).
