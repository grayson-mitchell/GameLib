## Evidence-capture instruction

Implements the dual-sink standard
(`.claude/skills/spike-findings-gamelib/references/live-gate-contract-authoring.md` §3) literally.
**Sink partition, stated explicitly so no item can be written against the wrong sink again:**

- Rust `[shell]`-prefixed lines reach `tauri:dev`'s own stdout/stderr, and therefore the
  **session transcript** ONLY. They never reach `gamelib.log`.
- Sidecar `logInfo`/`logWarning` calls (`src/backend/logger/index.ts`) reach **`gamelib.log`
  ONLY** — the sidecar's stdout is consumed as the RPC frame pipe, not surfaced as human-readable
  text (this project's own `sidecar-console-and-logger-are-invisible` lesson).
- Sidecar STDERR reaches the session transcript, prefixed `[sidecar:err]`.
- Sidecar `console.*` calls reach **nothing at all**.

**Every required literal in every item below is annotated `(session transcript)` or
(`gamelib.log`)`. No sidecar-emitted literal is required of the transcript anywhere in this
document — this is the exact fix for F-34.4.2-14.**

### 1. One-time session setup, before the first launch

```
export GATE_SESSION_DIR="/tmp/gamelib-gate-$(date -u +%Y%m%dT%H%M%SZ)"
mkdir -p "$GATE_SESSION_DIR"
```
Named with a UTC timestamp so a prior gate run's evidence can never be mixed in or overwritten.
Confirm no prior session directory is reused: `ls -d /tmp/gamelib-gate-* 2>/dev/null` before
creating this one, and note any prior ones as unrelated (do not delete them).

**Archive any pre-existing `.old` file before the first launch** — it may hold evidence from a
launch before this session began:
```
[ -f ~/Library/Logs/GameLib/gamelib.log.old ] && cp ~/Library/Logs/GameLib/gamelib.log.old \
  "$GATE_SESSION_DIR/gamelib-launch-0-preexisting-old.log"
```
The exact current filenames, resolved at authoring time (`ls -la ~/Library/Logs/GameLib/`, quoted
verbatim, not guessed):
```
-rw-r--r--@  1 graysonmitchell  staff     2191 Aug  6 18:39 gamelib.log
-rw-r--r--@  1 graysonmitchell  staff     2191 Aug  6 18:38 gamelib.log.old
```
(plus several dated backup files from unrelated prior sessions — e.g.
`gamelib.log.34.5-g6-gate2` — which are historical and not touched by this run). The active file
this run reads and archives is `~/Library/Logs/GameLib/gamelib.log`, exactly this name, no suffix.

### 2. Per-launch delimiter — write BEFORE each launch, exact literal text

```
echo "=== GATE LAUNCH ${N} — $(date -u +%Y-%m-%dT%H:%M:%SZ) ===" | tee -a "$GATE_SESSION_DIR/terminal.log"
```
where `${N}` is the launch ordinal (1, 2, 3, ...). A reader greps section boundaries with
`grep -n '^=== GATE LAUNCH' "$GATE_SESSION_DIR/terminal.log"`.

### 3. The launch command itself — `tee -a`, never bare `tee`, never `>`

```
npm run tauri:dev 2>&1 | tee -a "$GATE_SESSION_DIR/terminal.log"
```
Optionally prefixed `GAMELIB_DEV_SECRET_VAULT=1` (carried from RERUN-3's own amendment, unchanged
justification): it bypasses only this project's own `TokenStore` path, not the macOS system
Passwords/AutoFill store item 3(d) observes, so it does not affect any item's evidence.

### 4. Per-launch `gamelib.log` archive — AFTER that launch's app has quit, BEFORE the next launch starts

```
cp ~/Library/Logs/GameLib/gamelib.log "$GATE_SESSION_DIR/gamelib-launch-${N}.log"
```
**Mandatory ordering reason:** `src/backend/logger/log_writer.ts:1` imports `existsSync,
renameSync`; its rotation method (`log_writer.ts:74`, `return renameSync(this.logFilePath,
this.oldLogFilePath)`) renames the live file to `.old` on the very next process's first write. A
third launch would otherwise destroy the first launch's sidecar evidence outright — this archive
step must run before that happens.

### 5. Per-item launch-ordinal recording

Every item's `Observed:` field (filled only by plan 34.4.2-20) must record which launch ordinal(s)
covered it, so a reader can locate both the transcript delimiter section AND the archived
`gamelib-launch-${N}.log` without guessing.
