<objective>
Run the fresh six-item blocking live gate on real macOS hardware and record the measured result.

Purpose: this project has now been shown five times that a fully green automated suite proves nothing
about live login-window behaviour — 3279/3279, 3387/3387, 3447/3447, 3735/3735, 3740/3740 and now
3747/3747 were all green while blocking defects were live, and **every blocking defect in phases
34.4.1 and 34.4.2 was found by a human driving the UI, none by automation.** This plan is the only
source of truth about whether the login surface actually works end to end.

**What is genuinely new this run:**
- **Item 6(a) is a re-test, not a first test.** F-34.4.2-12 — the hard, unbounded main-thread wedge
  on the Humble disconnect — is diagnosed (a reentrancy self-deadlock on tao's `EventLoopHandler`
  handler mutex, proven by a 4185/4185-sample hung-process backtrace), fixed at source
  (`6bad86227`), and its mechanically-identical residual closed by plan 34.4.2-17. **A source fix
  closes nothing in this phase.** This item is its live discharge, and it now carries an independent
  filesystem-channel proof alongside the log line, because this phase has twice recorded a PASS whose
  own decisive log evidence was unavailable.
- **Item 6(b) has NEVER been attempted, across five gate runs.** Every time, something upstream ended
  the session first. The contract now runs it in its own launch, BEFORE 6(a), specifically so that
  coupling cannot happen a sixth time. If 6(a) fails afterwards, 6(b)'s recorded result stands.
- **Items 3 and 5 have never had transcript corroboration.** Both PASSED in gate run 3 on the
  operator's word alone, because the contract's own `tee` truncated on the relaunch it also mandated
  (F-34.4.2-11). The capture is fixed. Measure them properly this time.
- **Item 4's aggregate sync-completion line has never been captured.** It goes to `gamelib.log`, not
  the terminal transcript (F-34.4.2-14) — the contract now asks the right sink.
- **All six items are re-measured, none inherited** (D-F1). `src-tauri/src/main.rs` changed twice
  this cycle. This phase's standing rule is that a fix does not inherit a previous run's result.

Discipline inherited from plans 06, 10, 12 and 16 and not relaxed: transcribe what the operator
observed, verbatim; assert no root cause; record an honest NOT ATTEMPTED rather than a guessed PASS;
apply the no-partial-pass rule at the item level; never use a transcript's silence to prove a backend
path did not run; and propagate whatever result arrives, including a bad one.

Output: a filled gate document, an updated threat roll-up, correct requirement checkboxes, and
ROADMAP/STATE/ledger propagation.
