## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] `login_window_wk_webview`'s planned `Cell` capture does not compile**
- **Found during:** Task 2, first `cargo build` run
- **Issue:** The plan's action text suggested capturing the resolved address "through a `Cell`/`Option` in the enclosing scope." `tauri::WebviewWindow::with_webview` requires its closure to be `Send + 'static`; a closure borrowing a stack-local `Cell<Option<usize>>` by reference fails `E0277` (`Cell` is not `Sync`, and the borrow is not `'static` regardless).
- **Fix:** Replaced the `Cell` with `Arc<Mutex<Option<usize>>>`, cloning the `Arc` into the `move` closure and reading the shared cell back out after `with_webview` returns -- the same wrapper shape `open_pristine_epic_login_window`'s own `monitor_slot` already uses for an identical capture-out-of-a-main-thread-closure need.
- **Files modified:** `src-tauri/src/main.rs`
- **Verification:** `cargo build --manifest-path src-tauri/Cargo.toml` succeeds; `cargo test` 93 passed / 1 ignored, no regression.
- **Committed in:** `dfa5d7a71` (Task 2 commit)
