<objective>
Measure, with the compiler, the MSVC C++ ABI layout of the Steamworks `CCallbackBase` hierarchy on
x64 and x86, and pin it as named constants. The roadmap forbids assuming the slot of
`Run(void*)`. Research measured (pinned zig 0.16.0): index 0 = `Run(void*, bool, SteamAPICall_t)`,
index 1 = `Run(void*)`, index 2 = `GetCallbackSizeBytes()`, index 3 = the `CCallbackImpl` virtual
dtor (MSVC reverses overloaded virtuals). Object layout: x64 flags +8, m_iCallback +12; x86 flags
+4, m_iCallback +8. This plan makes that measurement a committed, repeatable test.

Planner decisions (recorded):
- Constants live in a NEW module `meta/msvcCallbackLayout.ts`, not in meta/gen_vtables.ts, so this
  plan shares no file with 55-01 (parallel wave 1, single working tree) and 55-04 imports them.
- Two test arms: arm A (runs everywhere, including the ubuntu CI runner where pinned zig is not
  available because `meta/downloadZig.ts` pins `aarch64-macos` only) parses the COMMITTED dump and
  asserts the constants; arm B (darwin + pinned zig) re-runs the dumper for both triples and asserts
  the fresh output parses to the same constants. Arm B skips with an explicit reason elsewhere.
  This is the honest limit: the live re-measurement runs on the operator's Mac, not in CI.
- The measurement is clang's emulation of MSVC, corroborated by external sources (RESEARCH
  Pitfall 1). The live gate (55-07) is the independent confirmation against a real MSVC-built game.

Purpose: "measured, never assumed" is enforced by a test, not a comment.
Output: fixture, committed dump, constants module, measurement test.
</objective>

<interfaces>
SDK source to reproduce (SteamworksSDK steam_api_common.h, ~lines 138-230), described in prose:
- typedefs: uint8 = unsigned char, uint64 = unsigned long long, SteamAPICall_t = uint64.
- class CCallbackBase: public ctor zeroing m_nCallbackFlags and m_iCallback; NO virtual destructor;
  in declaration order: `virtual void Run(void *pvParam) = 0;` then
  `virtual void Run(void *pvParam, bool bIOFailure, SteamAPICall_t hSteamAPICall) = 0;` then
  non-virtual `int GetICallback()`, then `virtual int GetCallbackSizeBytes() = 0;`;
  protected: enum { k_ECallbackFlagsRegistered = 0x01, k_ECallbackFlagsGameServer = 0x02 };
  `uint8 m_nCallbackFlags; int m_iCallback;` and `friend class CCallbackMgr;`.
- template<int sizeof_P> class CCallbackImpl : protected CCallbackBase: virtual destructor;
  `Run(void*, bool, SteamAPICall_t)` overridden to forward to `Run(pvParam)`;
  `GetCallbackSizeBytes()` returns sizeof_P.
- template<class T, class P, bool bGameserver = false> class CCallback : public CCallbackImpl<sizeof(P)>:
  member function pointer to T plus T* object; `Run(void*)` override calls (obj->*func)((P*)pvParam).
- The TU must force vtable emission: define a struct Obj with a handler method, a struct P
  (e.g. 2572-byte struct), and a function that constructs a CCallback<Obj,P> on the stack.
