<objective>
Wire the two real end-to-end flows through the sidecar, reusing the existing store-manager code unchanged (the whole point per CONTEXT — prove the real logic runs behind the new transport). The read flow: the renderer's `refreshLibrary` invoke reaches the real `SteamLibraryManager.refresh()` in the sidecar, and each Steam game arrives at the renderer as a `pushGameToLibrary` frontend message that GlobalState renders into `steam.library`. The action flow: the renderer's `launch` invoke reaches `SteamGame.launch()`, whose native branch fires `shell.openExternal(buildSteamProtocolUrl('rungameid', appId))` — bridged through the sidecar's electron stub to the Rust shell's `tauri-plugin-opener` command.

Purpose: REQ-27-04 (real Steam library read flow) + REQ-27-05 (real steam:// action flow via opener parity). Scope-held: wire ONLY the 2–4 channels these flows need; do NOT re-plumb the other ~217 endpoints (deferred per CONTEXT/ROADMAP).

Output: the curated flow registration, the expanded handler registry, and an integration test dispatching both flows through the RPC server.
</objective>
