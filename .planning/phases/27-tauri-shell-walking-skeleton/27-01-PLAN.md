<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer (webview) → Rust shell | Tauri command args cross from untrusted web content into native code |
| Rust shell → Node sidecar | JSON-RPC frames over the child process's stdio |
| npm/crate registries → build | third-party package code enters the build |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-27-01 | Spoofing/Tampering | sidecar transport channel | mitigate | Use stdio JSON-RPC (private to the parent↔child pipe), NOT a loopback TCP port — Wine on macOS shares the host netns, so a loopback port would be reachable by bottled processes. |
| T-27-02 | Elevation | `open_external` command | mitigate | The command opens a URL via tauri-plugin-opener; the steam:// URL is constructed by the backend's `buildSteamProtocolUrl` numeric-appId guard (T-03-01) before it reaches the sidecar — the Rust command does not build URLs from renderer free-text in the skeleton flows. |
| T-27-SC | Tampering | @tauri-apps/* npm + tauri/keyring crates | mitigate | Task 1 blocking-human legitimacy gate before install; all verified live in spike 011. |
</threat_model>
