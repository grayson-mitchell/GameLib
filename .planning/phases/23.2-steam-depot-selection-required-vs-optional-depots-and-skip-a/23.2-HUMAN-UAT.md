### 1. Live KCD2 install completes with the blocked depot skipped
expected: Trigger a live GameLib install of KCD2 (Steam appId 1771300) on the same macOS/CrossOver account used for the 2026-08-19 official-client diagnostic, letting Steam refuse depot 1771304's key as it did before. The install **completes rather than aborting**, and `appmanifest_1771300.acf` shows `StateFlags "4"`, `InstalledDepots = {1771302, 1771303, 1771306}` with **1771304 absent**, `SizeOnDisk 96422090071`, and a non-zero `buildid` — matching the official Windows client's own manifest exactly.
why_human: This is the phase's own acceptance benchmark, and it is authored by Valve's client rather than by us — which is what makes it worth testing. No live install ran during the phase by design. Every claim above is proven only against jest-level simulation (`depot.finalize.test.ts`'s KCD2-shaped end-to-end test mocks `fetchChunk` and `getDepotDecryptionKey`). A jest mock returning `eresult=40` on cue is not proof that Steam's real CM server behaves identically on a fresh connection.

### 2. The user actually sees the skip notice, rendered for real
expected: On that same install, **two distinct OS-level notifications** appear: the ordinary "Installation Finished" toast **and** the new depot-skip toast naming depot 1771304, reading approximately "Installed without depot 1771304. Steam wouldn't release its key for this account, so that content was skipped — the game should still run."
why_human: `library.test.ts` asserts on the **options object** passed to a mocked `i18next.t` — necessarily so, because the jest i18next mock discards interpolation options (documented against REQ-23.2-06). That proves the depot id reaches the translation layer; it does **not** prove the real catalog string renders, nor that the OS notification surfaces. This project has been bitten before by a UAT pass covering a surface that could not render at all. Confirm both toasts co-occur — a native-handoff install that skipped a depot is exactly the case where the old shared-flag bug would have suppressed one of them.
