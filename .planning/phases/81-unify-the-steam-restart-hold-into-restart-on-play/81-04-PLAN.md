<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Steam-written logs and VDFs -> Rust | content_log.txt, connection_log.txt, libraryfolders.vdf are local files any process of the user can write |
| Windows registry -> Rust | HKCU ActiveProcess values |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-81-15 | Denial of service | log and VDF reads | low | mitigate | 256 KiB log window, 64 KiB connection_log tail, LIBRARY_MAX_BYTES for the VDF; partial lines deferred; every failure = no evidence |
| T-81-16 | Spoofing | crafted log line or VDF entry claims adoption | low | accept | a false "adopted" only skips one Steam restart (worst case: Steam's install dialog on Play); the writer would already be a local process of the same user |
| T-81-17 | Spoofing | pid change read as adoption off macOS | medium | mitigate | rule excluded on Windows/Linux and pinned by four tests (sign-out restarts Steam, spikes 087/088 r4) |
| T-81-18 | Information disclosure | logs | low | mitigate | evidence kind and appId only; no paths or account ids |
| T-81-SC | Tampering | npm/pip/cargo installs | low | accept | no package added |
</threat_model>
