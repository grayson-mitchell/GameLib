<objective>
Make restart-on-Play the one unadopted-install mechanism on macOS, Windows and Linux (D-14): the
Play gate, the record writer at install end and the unadopted direct uninstall all run on every
OS, and Play consults the Rust adoption read (helper on macOS, per-OS evidence elsewhere) before it
restarts Steam. Adds the D-03 signed-out branch, keeps D-04/D-05 behaviour, and pins D-06.

Purpose: this must land before the hold is deleted off macOS (RESEARCH Pitfall 1). While the hold
still exists (until 81-08) the new Windows/Linux records are harmless: the hold keeps Play
unavailable until Steam restarts, and the watch clears the record on the evidence.
Output: `playAdoption.ts`, a generalised `macSteamAdoption.ts`, the per-OS record writer, the
generalised uninstall gate and the D-06 pin.
</objective>

and spikes 087/088 made that every OS, so the record is no longer a Mac-only side path.

source, the Rust adoption read (helper on macOS, ACF rewrite / content_log / libraryfolders
elsewhere); the steam_osx pid rule stays a macOS-only input used only when that read fails (D-10).

every supported platform produces exactly one pending-adoption record and no hold.
</assumption_delta_decision>
