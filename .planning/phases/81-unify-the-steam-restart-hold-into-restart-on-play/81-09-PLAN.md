<objective>
Migrate holds persisted by older builds into pending-adoption records (D-12) now that nothing
re-arms them (81-08), using RESEARCH Pattern 3 so each store keeps one writer: Rust drains and
validates `steam_restart_hold.json`, TS writes and watches the pending records, Rust deletes the file.

Purpose: no game is left stuck and none silently loses its restart across the upgrade.
Output: two steampoll ops on all layers, `hold_migration.rs`, `migrateRestartHolds` and its boot wiring.
</objective>
