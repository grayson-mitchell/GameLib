<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| sidecar -> Rust watch args | manifest path and baseline content arrive from the TS record store (disk content, written by TS) |
| Steam-written files -> Rust | the current ACF is written by Steam or by GameLib; parsed leniently |
| Rust -> sidecar state event | adoptionState validated by zod before the handler runs |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-81-01 | Tampering | AdoptionWatchArgs.manifest_path | medium | mitigate | validate_watch_args: absolute path, file name exactly appmanifest_<appId>.acf, parent dir steamapps; the watch only reads the file, never writes or deletes |
| T-81-02 | Denial of service | ACF read and watch map | low | mitigate | ACF read capped at ADOPTION_ACF_MAX_BYTES; one task for all apps; Delay ticks so a slow probe never overlaps; task exits when the map is empty |
| T-81-03 | Spoofing | false adoption reading | medium | mitigate | content-only ACF compare (no cross-runtime mtime), bit 4 + real buildid required; pid evidence macOS-only, pinned by Win32/Linux tests |
| T-81-04 | Information disclosure | logs | low | mitigate | log appId and evidence kind only (T-28-04); no path, title or SteamID |
| T-81-05 | Tampering | adoptionState from shell | low | mitigate | caller 'shell' + strict zod object; handler idempotent, stale seq consumed |
| T-81-SC | Tampering | npm/pip/cargo installs | low | accept | no package is added by this plan (RESEARCH: no new libraries); nothing to audit |
</threat_model>
