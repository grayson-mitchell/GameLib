RESEARCH Pattern 3 so each store keeps one writer: Rust drains and validates
`steam_restart_hold.json`, TS (81-13) writes and watches the pending records, Rust deletes the file.

Purpose: 81-13's boot migration calls these two ops; nothing calls them before then.

81-09): plans 81-10, 81-11, 81-12 and 81-13 ship in the same release (T-81-48).
Output: `hold_migration.rs` and two steampoll ops on every layer.
