<objective>
Build and wire the one bounded boot probe pass (R3): five probes in parallel inside one 45 s
window, started after READY and only on an online edge, re-run only on a later connectivity
transition, never overlapping, with every handle `unref()`'d and every child aborted at the bound.
Then close the folded Humble keyring todo, whose remedy this pass permanently supersedes.

Purpose: this is the step that turns per-store probes into a boot-time signal without breaking the
sidecar exit contract or READY ordering — the two constraints that have each broken boot before.

Output: `src/backend/signInProbe/pass.ts`, two bootstrap blocks, the READY-ordering gate, the
boot-wire test, the held-out dismiss backstop test, and the todo closure.
</objective>

| Handle / work | Created by | Disposition |
|---|---|---|
| first-run `setImmediate` | `startSignInProbePass` (only if already online) | `.unref?.()` at creation; fires once |
| per-probe bound timer | `boundedSignInProbe` | `.unref?.()` at creation; `clearTimeout` in `finally` |
| runner child (`legendary status`, `gogdl auth`, `nile list-updates`) | `callRunner` via 49-05 probes (not `unref()`'d, `launcher.ts:1726`) | bounded: at `SIGN_IN_PROBE_BOUND_MS` the pass calls `callAbortController(SIGN_IN_PROBE_ABORT_IDS[store])` |
| `keyring_get` invoke (Steam, Humble) | `SidecarKeyringSlotStore.readToken` | RPC timer already `unref()`'d (`sidecarRpc.ts:430`); bounded by Rust 45 s and the 60 s invoke ceiling; the pass resolves `unknown` at the bound |
| Humble `getGamekeys` HTTP request | `humbleRequest` | bounded by `REQUEST_TIMEOUT_MS` (`adapter.ts:149-162`) |
| connectivity listener | `onConnectivityChange` (registered once) | an `EventEmitter` listener holds no libuv handle |

There is no `setInterval` and no re-run timer: re-runs are event-driven (D-03). Exit stays by
event-loop drain at stdin EOF.
