| Boundary | Description |
|----------|-------------|
| app → Humble API | Outgoing authenticated HTTP carrying the `_simpleauth_sess` bearer cookie |
| Humble API → app | Untrusted, undocumented JSON responses parsed by the adapter |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-01 | Information Disclosure | adapter.ts logging | mitigate | Never interpolate cookie value or full response body into logger calls; test asserts no logger mock receives the cookie |
| T-10-02 | Tampering (data integrity) | Humble JSON response | mitigate | zod `safeParse` on every response; `schema_error` typed return instead of blind cast (C5) |
| T-10-03 | Spoofing / access-denial confusion | 401 vs 403 handling | mitigate | Distinct `session_expired` (401) vs `access_denied` (403) results so re-login is not triggered on a Humble-side block |
| T-10-SC | Tampering | npm installs | mitigate | Zero new packages this phase (RESEARCH.md Package Legitimacy Audit: N/A); no install task present |
