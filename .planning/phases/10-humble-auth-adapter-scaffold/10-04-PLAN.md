|----------|-------------|
| renderer state ← IPC push | humbleAuthState updates the tile; must never receive the cookie |
| user → disconnect | Destructive action gated by a confirmation dialog (blocking modal — correct here) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-12 | Information Disclosure | frontend state / logs | mitigate | Slice holds only username/expired/encryptionDegraded — the cookie never reaches the renderer (enforced by the Plan 03 channel type) |
| T-10-13 | Repudiation / accidental disconnect | disconnect action | mitigate | Confirmation dialog (D-03) before humbleDisconnect wipes the account |
| T-10-14 | Information Disclosure | degraded encryption on Linux | mitigate | `encryptionDegraded` flag renders a user-visible reduced-encryption warning (success criterion 5) |
| T-10-19 | Denial of Service (UX) | expiry notification blocking the UI | mitigate | Expiry prompt is a non-blocking dismissible toast (D-09), never a modal — the app stays usable while it shows |
