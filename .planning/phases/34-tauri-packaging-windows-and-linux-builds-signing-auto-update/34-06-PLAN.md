<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub Actions secrets → CI job | Signing certs + minisign private key are injected into the runner at build time |
| CI runner → GitHub Release | The pipeline publishes artifacts a human later ships to users |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-34-04 | Denial of Service | secrets-less CI run | mitigate | Windows signing override gated behind `env.WINDOWS_CERTIFICATE != ''`; base config has no `certificateThumbprint`; macOS skips natively — a run with no certs ships unsigned, emits an explicit `::warning::Signing skipped`, and the job stays green (D-04) |
| T-34-05 | Information Disclosure | minisign private key + Apple/Windows certs in CI | mitigate | All read via `env:` blocks from GitHub secrets (auto-redacted in logs), never inlined into `run:` strings; the Windows `.pfx` is base64-decoded in-memory only, never written to a cached/persisted artifact |
| T-34-07 | Tampering | sidecar substitution between build + bundle | mitigate | `build:sidecar-sea` runs in the SAME leg that bundles — no cross-job artifact hand-off window |
| T-34-11 | Spoofing | artifact-name collision on the shared release | mitigate | Confirm Tauri default artifact names do not collide with electron-builder's `-Setup-/-Portable-/-macOS-/-linux-` names on the co-triggered `v*` release (Pitfall 7) |
| T-34-SC | Tampering | GitHub Actions third-party actions | accept | Pin `tauri-action@v1`, `dtolnay/rust-toolchain@stable`, `swatinem/rust-cache@v2`, `actions/checkout@v6` — official/established actions per RESEARCH |
</threat_model>
