<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| updater client → GitHub Releases feed | The installed app polls a remote `latest.json`; a wrong/attacker feed is a spoofing risk |
| renderer webview → Rust IPC (capabilities) | Capability grants gate what the webview can invoke |
| bundled externalBin → OS process spawn | The sidecar binary is launched as a child process |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-34-01 | Spoofing | plugins.updater.endpoints | mitigate | Hardcode the `grayson-mitchell/GameLib` feed literal; never derive from `package.json.repository`; tauriConf negative test forbids `Heroic-Games-Launcher` |
| T-34-06 | Tampering | update artifact signature | mitigate | `plugins.updater.pubkey` = the 34-03 minisign public key; `tauri-plugin-updater` verifies every artifact before install (Ed25519/minisign) |
| T-34-09 | Elevation of Privilege | shell:allow-execute grant | mitigate | Scope `shell:allow-execute` to `{name:"binaries/gamelib-sidecar", sidecar:true}` only — no broad shell execution exposed to the webview; document the narrowing in `description` |
| T-34-10 | Tampering | base config signing fields | mitigate | Keep `certificateThumbprint`/`signCommand` OUT of the committed config; signing is injected only via the CI `--config` override (34-06) so a secrets-less build never fails (D-04) |
</threat_model>
