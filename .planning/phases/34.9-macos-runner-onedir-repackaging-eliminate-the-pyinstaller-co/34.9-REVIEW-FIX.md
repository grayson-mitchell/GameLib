## Why this file exists

`34.9-REVIEW.md` carries `status: issues_found` and `findings.critical: 1`. That status records
what the review found on 2026-08-11 and, per `reviewStatus()`'s own doc comment in
`~/.vscode/extensions/gsd-phase-status/parse.js`, is "never rewritten when the fixes land" — the
review file itself is not the place to record remediation. The sanctioned way to state where a
review now stands is this fix-pass sibling: when a `REVIEW-FIX.md` exists beside a `REVIEW.md`,
`reviewStatus()` reads the fix pass's `status:` instead of falling back to the review's own
(stale) status or its unaddressed-critical rule.

This file changes no behaviour and touches no code. It is a record, sourced verbatim from
