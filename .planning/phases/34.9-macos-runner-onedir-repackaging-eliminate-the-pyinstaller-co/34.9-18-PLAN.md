## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| vendored PyInstaller onedir tree (`public/bin/{arch}/darwin/{runner}/`) -> build output (`build/`) | The onedir trees are produced by a separate `build-runners-onedir` step from externally-sourced upstream runner binaries (legendary/gogdl/nile) and their bundled CPython framework. They are NOT authored in this repo and, per the descoped REQ-34.9-04, their digests are NOT verified. Every byte that crosses this boundary -- including each symlink's raw target string -- is untrusted input. |
| build output (`build/`) -> packaged `.app` -> end-user machine | `electron-builder` copies `build/` verbatim into the shipped application bundle. Anything this module writes into `build/` is shipped, signed, and extracted on a user's disk. |
| `closeBundle` hook -> `electron-vite build` exit status -> `electron-builder` | A hook that returns normally is treated as success. This is the boundary CR-01 identifies: the integrity signal for the whole restoration step crosses it as nothing more than stdout text. |
