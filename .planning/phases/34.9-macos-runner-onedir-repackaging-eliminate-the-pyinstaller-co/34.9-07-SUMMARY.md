## Decisions Made
- **`bundle.resources` uses the trailing-slash directory-copy form, not a glob.** `["../build/bin/"]` preserves the nested onedir directory structure under `$RESOURCE/build/bin/...`; a glob form (`"../build/bin/**/*"`) would flatten every matched file into one target directory per the schema's own documented behavior, which would break the nested `{runner}/{runner}` shape `archSpecificBinary()` expects.
- **R-34.5-G1-PKG stays descoped**, exactly as `34.9-CONTEXT.md`'s locked scope decision requires. No `isPackaged` branch, no `publicDir` edit, no packaged-Tauri fix. `34.9-PACKAGING-LIMITATIONS.md` states this explicitly and quotes the deferred-item's own wording verbatim so the ownership citation cannot drift from the source.
- **Test file parses config structurally, not by regex**, following the established `runnersOnedirWorkflow.test.ts`/`js-yaml` precedent -- this is required specifically because the new `electron-builder.yml` comment (added in Task 1) mentions `linux`, `win32`, and `**` while explaining why they're absent, and a regex-based test could be satisfied or defeated by that comment text alone.
