<objective>
Read a Steam game's macOS build architecture from PICS appinfo and make a confirmed 32-bit mac game bottle-eligible (MAC32-01, MAC32-02).

Purpose: This is the pre-install detection + routing core. A missing/blank `osarch` must resolve to `unknown` (native path), never `32` — over-routing on a missing tag would push documented good 64-bit games (A Hat in Time, Metro: Last Light, BattleBlock Theater) into emulation. Routing plugs into the existing `isBottleEligible()` D-11 chokepoint as an independent reason, because a 32-bit mac game has `is_mac_native === true` and would otherwise silently fall through the native path and fail to launch on Catalina+.
Output: `parseOsArchHint()` in library.ts; `ensureMacArchHint()` + `isBottleEligible()` extension in games.ts; wired into install/launch/uninstall; unit tests against the Plan 01 fixtures.
</objective>
