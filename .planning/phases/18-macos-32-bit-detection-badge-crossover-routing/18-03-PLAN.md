<objective>
Add the post-install Mach-O ground-truth check that catches i386-only mac binaries Steam left un-tagged, and the user-consented i386 recovery flow (MAC32-03).

Purpose: `osarch` is developer-set metadata, not a binary probe — a mac depot can be i386-only with a blank `osarch`, so it takes the native path pre-install and fails silently on Catalina+. Inspecting the installed Mach-O header (`lipo -archs`, `file` fallback) is the only ground truth. When it flips a natively-installed game to 32-bit, GameLib prompts the user (CONTEXT D-6, resolving RESEARCH Open Question #1), then `forceUninstall()`s the dead native copy and re-installs through the bottle. A missing/inconclusive tool result is NEVER treated as a 32-bit verdict.
Output: `machOArchsOf` / `verdictFromArchs` / `locateMachOBinary` / `verifyMacArchGroundTruth` in library.ts; a fire-and-forget hook in `pollInstallOnce`'s installed branch; the i386 recovery prompt+reinstall; unit tests with mocked `child_process`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ACF installdir → filesystem path → lipo/file | install path derives from an untrusted ACF file and reaches a subprocess |
| Mach-O verdict → routing/uninstall | a wrong verdict could force-uninstall a working native game |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-03-01 | Tampering (command injection) | machOArchsOf lipo/file invocation | mitigate | argv-form execFileSync (command + array), never exec()/template-string shell — matches library.ts convention; this phase must not introduce the module's first exec() |
| T-18-03-02 | Tampering (destructive misroute) | verifyMacArchGroundTruth i386 flip → forceUninstall | mitigate | Recovery is confirm-gated via showDialogBoxModalAuto (CONTEXT D-6); inconclusive tool result → null verdict, no flip, no uninstall |
| T-18-03-03 | Tampering (false 32-bit) | verdictFromArchs on empty/failed tool output | mitigate | [] → null (inconclusive), never '32'; existing hint retained — the false-flag-safe invariant at the subprocess boundary |
| T-18-03-04 | Elevation / wrong-target inspection | locateMachOBinary scanning install path | mitigate | Bounded to installPath subtree via join(); returns null (log+skip) on any miss, never traverses outside or throws |
| T-18-03-SC | Tampering | package installs | accept | No packages installed — child_process is built-in (RESEARCH.md audit N/A) |
</threat_model>
