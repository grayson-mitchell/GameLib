<objective>
Carry a mac depot answer on the existing eligibility verdict so D-12's widened
`resolveDepotAvailability` has a `probeHasMacDepot` to read.

Purpose: **this is a gap neither RESEARCH.md nor PATTERNS.md surfaced.** D-12 requires
`resolveDepotAvailability` to resolve a mac triple "from the identical fetch, at the identical
moment" as the Windows one. But `SteamBottleEligibilityVerdict` (`common/types/steam.ts:59-77`)
carries ONLY `eligible` / `hasWindowsDepot` / `platformsCaptured` / `wineVersion` / `bottleName` —
there is no mac field. Without this plan, the mac side would have to fall back to the seed
`gameInfo.is_mac_native`, which `library.ts:785` already collapsed `undefined -> false` one layer
upstream — reintroducing the exact conflation item 3 exists to remove.

Output: the verdict widened by one boolean, populated at the same cache read as its Windows
sibling, and threaded through the probe's state machine.
</objective>
