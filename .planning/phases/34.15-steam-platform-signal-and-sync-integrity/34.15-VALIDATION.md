## Manual-Only Verifications

**D-16: ONE BLOCKING human UAT gate covering items 1 and 2.** Both concern behaviour a warm,
online library cannot reproduce on demand — the same constraint that shaped 34.14's D-08.

| Behavior | Decision | Why Manual | Test Instructions |
|----------|----------|------------|-------------------|
| Bulk PICS call actually populates the cache against a real ~378-game library; measure elapsed time; confirm the real-world `oslist` presence rate | D-01/D-02/D-03 | Requires a live CM socket and a real large library. Synthesizing it destroys the exact thing being measured. **The `oslist` wire shape is MEDIUM confidence** — this gate is what confirms it empirically. | Cold-start with a real Steam account, trigger a full Steam refresh, inspect the metadata store for populated flags + `platformsCaptured` |
| PICS failure actually fails soft — sync completes, library renders, flags stay `undefined` | D-03 | Timeout path only runs under a real hang | Block the CM host with an **unroutable IP** (below), then refresh |
| Steam sync failure shows an inline notice with a working Steam-scoped retry, and other runners' games stay visible and interactive | D-07/D-08/D-10 | The original repro needed a real merged grid with 6 GOG games behind the overlay | Force Steam unreachable with other runners' libraries populated; confirm no centred overlay covers the grid |

### Forcing-procedure constraints (mandatory — carried from this project's ledger)

- **Block with an unroutable IP such as `203.0.113.1`, NEVER `127.0.0.1`.** Loopback **REFUSES
  in ~1ms**, so the timeout path never runs and a pending UI stays invisible. Confirm with
  `curl` exit **28** (hang) vs **7** (refused). `dig` does **not** read `/etc/hosts`.
- **Name a concrete, repeatable forcing procedure per branch.** 34.14 D-08's lesson: a gate
  without an explicit forcing step is authored against a condition that never renders.
- **Never record a `pass` for a surface that could not render.** Use `blocked` / `n-a`. This
  project has ledgered a `pass` that covered an unreachable surface.
- **The verification file's `status` stays `human_needed` until the gate is discharged.**
  Switching it to `gaps_found` makes the phase vanish from `gsd-sdk query audit-uat` entirely.
