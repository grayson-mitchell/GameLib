---

## Sampling Rate

- **After every task commit:** `npx jest <changed-file>.test.ts` + `cargo check` (fast correctness signal)
- **After every plan wave:** full backend `npx jest` + `cargo test` (manual) + `tsc --noEmit`
- **Before `/gsd-verify-work`:** full suite green **AND** the REQ-34.3-11 five-item live gate passed (**blocking** per D-13)
- **Max feedback latency:** ~90 seconds (targeted run: <10s)

## Manual-Only Verifications

Per D-11/D-12/D-13 these are **blocking phase-close conditions**, not deferred UAT. This slice
deliberately breaks the Phase 30 D-04 → 34.1 D-15 → 34.2 D-11 unit-proven-only precedent, because
most of its channels' entire purpose is an observable OS side effect that jest structurally cannot
see, and it ships two Rust arms CI never compiles.

Sidecar output is read from `~/Library/Logs/GameLib/gamelib.log` — **not** the `tauri:dev` terminal.
