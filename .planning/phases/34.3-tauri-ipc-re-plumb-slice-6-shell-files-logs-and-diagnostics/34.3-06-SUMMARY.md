## Decisions Made

- **Direct-call test harness instead of the full sidecar-over-stdio bootstrap.** `shellFilesFlows.test.ts`/`appShellFlows.test.ts` boot the entire `handlers.ts` module graph via `bootstrap.ts`'s `init()`, which requires mocking `axios`/`GlobalConfig`/`backend/storeManagers`/dialog/legendary `electronStores` because those OTHER registration modules' side effects all run at import time. `clipboardFlowRegistration.ts` touches none of that surface, so `clipboardFlows.test.ts` imports and calls `registerClipboardFlows()` directly (never importing `../bootstrap` or `../handlers`), mirroring `lifecycleStub.test.ts`'s lighter "mock only the Rust boundary, invoke electronStub's real members directly" shape — proving the identical channel+args+logged-not-thrown contract with a much smaller, more targeted mock surface.
- **The negative-scope guard snapshots BEFORE calling `registerClipboardFlows()`, not just after.** Since this test file's isolated module graph never imports any OTHER registration module, the 8 foreign channels (`abort`, `getSystemInfo`, `hasExecutable`, `isIntelMac`, `getLegendaryVersion`, `getGogdlVersion`, `getCometVersion`, `getNileVersion`) would read as unregistered regardless of what `registerClipboardFlows()` does — a bare "assert absent" test would be vacuously true. Capturing a snapshot immediately after import (before the one registration call this file makes) and comparing it to a post-call snapshot makes the assertion load-bearing: it proves the CALL itself adds nothing for these channels.
- **`registerClipboardFlows()`'s registered channels round-trip through the REAL `electronStub.clipboard.writeText`/`readText`**, never a mock of the handler under test — `clipboardWriteText`'s and `copySystemInfoToClipboard`'s coverage exercises the actual D-01/D-03 fire-and-forget forward built in Plan 05, and `clipboardReadText`'s coverage exercises this plan's own D-04 bypass, with only `requestRustInvoke` (the Rust transport boundary) and `utils/systeminfo` (the systeminfo boundary) mocked.
