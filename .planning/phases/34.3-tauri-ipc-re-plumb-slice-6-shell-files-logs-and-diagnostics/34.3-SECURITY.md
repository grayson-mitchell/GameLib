## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|----------------|
| renderer → sidecar `openExternalUrl`/`openFolder` | Renderer-supplied string, routed through `utils.ts`'s `openUrlOrFile` (`url.startsWith('http') ? shell.openExternal : shell.openPath`) — no scheme allow-list. Forwarded to `tauri-plugin-opener`'s own scoping. | Arbitrary string → OS-level open/execute |
| renderer → sidecar `checkDiskSpace` | Renderer path, gated by the zod `Path` schema's `.parse()` (throw-on-invalid). | Arbitrary string → validated filesystem path |
| renderer → sidecar `removeFolder` | Renderer `[folderPath, folderName]` tuple, **no validation**, reaches a recursive delete. Electron parity, not port-introduced or widened. | Arbitrary path segments → recursive delete |
| renderer → Rust `clipboard_write_text`/`clipboard_read_text` | `capabilities/default.json` grants **zero** `clipboard-manager:*` permissions — the webview cannot reach these directly. Only path is via the sidecar's IPC relay, gated by `clipboard_text_arg`'s JSON-string validation on write. | Renderer string ⇄ host OS clipboard, mediated by sidecar |
| renderer → sidecar `uploadLogFile` | Up to 10 MiB of local log content POSTed to a public third-party paste (`dpaste.com`), no redaction. Gated behind a confirm dialog. | Local log file contents → public internet, 2-day expiry |
| `src-tauri/Cargo.toml` → dependency tree | `tauri-plugin-clipboard-manager = "2"` pulled 27 new transitive crates into `Cargo.lock`. | Third-party crate source |
| macOS `shell_show_item_in_folder` → `osascript` | Renderer/sidecar-supplied path passed to `osascript` as an `argv` element (`on run argv`), never interpolated into script text. | Path string → AppleScript argv (not script text) |
