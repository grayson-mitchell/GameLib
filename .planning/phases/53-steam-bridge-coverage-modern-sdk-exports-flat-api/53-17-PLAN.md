<objective>
Close VERIFICATION gap 2 (53-GAP-REVIEW CR-01) and the generator half of gap 3 (WR-02, WR-03, WR-04).

CR-01: the shared flat export `SteamAPI_ISteamGameServer_GetPublicIP` uses the Win64 hidden-pointer form, because GameServer014/015 return a 20-byte struct. GameServer012 was dropped from the export via `FLAT_UNREPRESENTABLE_CASES`. A 012-era caller passes self in RCX, which the export reads as `ret`. Neither branch matches, so the fallback `memset(ret, 0, 20)` zeroes `g_steamgameserver012_instance`, including its vtable pointer. The next call through that instance crashes inside the shim. The fix makes the fallback recognise every served instance and dispatch the dropped RAX-form version correctly.

WR-02/03/04 are latent out-buffer marshalling defects from 53-14, in the same generator:
- the reported length is not tied to the bytes copied;
- the `char*` NUL terminator can be written one byte past the caller's capacity;
- the helper's static scratch buffer is never cleared, so stale bytes can be returned.

Purpose: per D-53-01/D-53-05, a flat export must behave exactly like the proxy's own vtable slot. It must never corrupt shim state.
Output: generator fixes, 53-17 tests, regenerated `steam_api_shim.c` and `bridge_dispatch.h`.
</objective>
