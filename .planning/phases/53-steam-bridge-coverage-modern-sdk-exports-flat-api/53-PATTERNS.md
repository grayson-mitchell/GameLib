## Pattern Assignments

### `meta/gen_vtables.ts` - flat export emitter (generator, transform)

**Analog:** `meta/gen_vtables.ts` itself. There is no existing "call through `self->vptr[slot]`" emitter, so combine three existing pieces: the export body table, the per-instance naming, and `g_iface_table`.

**Export body table shape** (L660-690): a `const NAME = [...] as const` list drives both the `.def` and a `Record<name, cBody>`. Flat exports copy this: names go to `generateDefFile` (x64 only), bodies go inside the `#if defined(__x86_64__)` block next to `modernLookupExports` (L1762-1770).
```typescript
export const MODERN_LOOKUP_FLAT_EXPORTS = [
  'SteamInternal_CreateInterface',
  ...
] as const
const MODERN_LOOKUP_FLAT_EXPORT_BODIES: Record<(typeof MODERN_LOOKUP_FLAT_EXPORTS)[number], string> = {
  SteamInternal_CreateInterface:
    'void *SteamInternal_CreateInterface(const char *pszVersion) {\n' +
    '  void *resolved = resolve_iface_by_exact_version(pszVersion);\n' +
    '  if (resolved != NULL) return resolved;\n' +
    '  return (void *)&g_x64_null_object_instance;\n' +
    '}',
```

**Per-version instance and vtable naming** (`emitVtableArray` L1362-1375). The flat switch compares `self` to these:
```typescript
const varName = `g_${manifest.interface.toLowerCase()}_vtbl`
const instanceName = `g_${manifest.interface.toLowerCase()}_instance`
const structName = `Fake${manifest.interface}`
`struct ${structName} { vfn *vptr; };\n` +
`static struct ${structName} ${instanceName} = { ${varName} };\n`
```

**Typed params for the call** (`emitVtableStub` L1138-1160): use `cType(p.type)` per param exactly as the stub does, so floats and 64-bit values travel in the right registers (do not copy the stubs' `dummyN` pattern).
```typescript
const realParams = method.params.map((p) => `${cType(p.type)} ${p.name}`).join(', ')
```

**Arch guards** (`archGuard` L2453-2461): wrap each manifest's contribution to a flat switch in the same guard, and make the whole flat section x64-only (`#if defined(__x86_64__)`), as the modern lookup block does.

**Generator assertion to add** (RESEARCH Pattern 1): refuse a `class` return with `structSize > 8` for a flat export. Use `isSretReturn(method)` (L216) as the predicate.

**`GetISteamX` NULL-on-miss body (D-53-07)**: do NOT call the stub (stub falls back to the null object). Copy the lookup, drop the fallback:
```typescript
// from SteamInternal_CreateInterface body, minus the last line
'  void *resolved = resolve_iface_by_exact_version(pszVersion);\n' +
'  if (resolved != NULL) return resolved;\n' +
'  /* log bounded version string, then */ return NULL;\n'
```
Log bound: reuse the `FWD_VERSION_LOG_MAX_BYTES = 128` convention (L2066). Do not read `g_bridge_steamstub_path_active` (CR-01 flag, L1722-1726).

**Idempotency/commit pattern**: `main()` L2593-2623 writes the four generated files. A new committed `shimExports.generated.ts` is written here too (RESEARCH Pitfall 5), with the same JEST_WORKER_ID guard at L2632.

### `src/backend/storeManagers/steam/bridge/managedImports.ts` (utility, ranged-read parser)

**Analog:** `src/backend/storeManagers/steam/bridge/peSteamDrm.ts`. Copy its whole discipline; there is no CLI-metadata parser in the repo (RESEARCH confirms no npm option).

**Header contract** (L29-39): zero imports (`grep -c "^import" ... == 0`), only `Uint8Array`/`DataView`/`String.fromCharCode`, every read bounds-checked, hard caps, never throws, wrapped in try/catch. Document it the same way and name threat ids.

**Reader primitives to copy verbatim** (L58-89):
```typescript
type PeReader = (offset: number, length: number) => Uint8Array | null
class BoundsError extends Error {}
function readExact(read: PeReader, offset: number, length: number): DataView {
  if (!Number.isSafeInteger(offset) || offset < 0 || length < 0) throw new BoundsError('bad offset')
  const bytes = read(offset, length)
  if (!bytes || bytes.length < length) throw new BoundsError('short read')
  return new DataView(bytes.buffer, bytes.byteOffset, length)
}
const u16 = (read: PeReader, offset: number) => readExact(read, offset, 2).getUint16(0, true)
const u32 = (read: PeReader, offset: number) => readExact(read, offset, 4).getUint32(0, true)
```
Do not import them from `peSteamDrm.ts` unless it exports them (they are file-private); either export a minimal shared helper or duplicate, keeping both files at zero imports. If `peSteamDrm.ts` exports from a new shared module, that module also must have zero imports because `meta/bridgeCensus.ts` bundles standalone.

**Section/RVA mapping** (L132-168 of `detectSteamDrmInPe`): section table walk with `MAX_SECTIONS = 96`, `container = sections.find(s => s.va <= rva && rva < s.va + s.span)`, then `rawPtr + (rva - va)`. Reuse this for data directory 14 (CLR header: dir index 14 at `dirsOffset + 14*8`, flags at CLR header +16) and for the metadata root and stream offsets. Add caps for streams, row counts and total bytes read (RESEARCH Pattern 3 hardening).

**Return shape**: follow `PeSteamDrmResult` (`parsed: boolean` + data; `unparsed()` helper at L64-68). Output should include `{ parsed, modules, importsByModule (steam_api / steam_api64 case-insensitive, optional .dll), versionStrings (UTF-16 from #US), clrFlags }`. Tolerate `CSteamworks`/`CSteamworks64` without treating them as steam_api.

**File-opening wrapper** (callers pass a `PeReader`): copy `readExeMachineArch` (shimGenerate L954-975) or `readDelayImports` (importScan L166-189): `openSync`, `Buffer.alloc(length)`, `readSync(handle, buf, 0, length, offset)`, `n < length ? null : new Uint8Array(...)`, `closeSync` in finally. Never slurp (Overlooting exe is 322 MB).

### `peSteamDrm.ts` - `readPeClrFlags` / AnyCPU rule (utility, file-I/O)

**Analog:** `readPeMachineArch` (L224-237).
```typescript
export function readPeMachineArch(read: PeReader): 'x86' | 'x64' | null {
  try {
    const mz = readExact(read, 0, 2)
    if (mz.getUint8(0) !== 0x4d || mz.getUint8(1) !== 0x5a) return null
    const peOffset = u32(read, 0x3c)
    if (u32(read, peOffset) !== 0x00004550) return null
    const machine = u16(read, peOffset + 4)
    if (machine === 0x14c) return 'x86'
    if (machine === 0x8664) return 'x64'
    return null
  } catch { return null }
}
```
Add a sibling returning the CLR header `Flags` (or null when no CLR header). The effective-arch decision (D-53-10 amended) lives in one pure function used by both `shimGenerate.ts` and the census: machine 0x14c AND CLR header present AND `(flags & 0x2) === 0` AND `(flags & 0x20000) === 0` -> x64; otherwise machine arch. Keep it null-safe, never throw. `readExeMachineArch` in shimGenerate (L954) and the equivalent in census (`scanExeSteamDrm` ~L1242) both switch to it.

export function parseInterfaceVersionStrings(bytes: Buffer): string[] {
