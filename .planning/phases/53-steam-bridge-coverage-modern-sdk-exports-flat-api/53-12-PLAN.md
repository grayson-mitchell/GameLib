<objective>
Make Steamworks.NET's `SteamAPI.Init` succeed for the sampled Unity titles. The UAT and verifier
traced Rogue Waters', Vampire's Fall's and Hell Clock's `[Steamworks.NET] SteamAPI_Init() failed`
to `NOVER flat lookup ver=STEAMSCREENSHOTS_INTERFACE_VERSION003`. Planet Crafter logs the same
NOVER; its "clean" Player.log only means the game does not print the failure.

Serving Screenshots003 alone would just move the failure to the next row, because NOVER only ever
names the FIRST unserved version. Steamworks.NET 20.x `CSteamAPIContext.Init` fetches 27
interfaces in a fixed order and returns false on the first zero pointer. That order was read from
the upstream source at tag 20.2.0, `com.rlabrecque.steamworks.net/Runtime/Steam.cs`:

1. CreateInterface(SteamClient)
2. User
3. Friends
4. Utils
5. Matchmaking
6. MatchmakingServers
7. UserStats
8. Apps
9. Networking
10. RemoteStorage
11. **Screenshots**
12. **GameSearch**
13. **HTTP**
14. **UGC**
15. **AppList**
16. **Music**
17. **MusicRemote**
18. **HTMLSurface**
19. **Inventory**
20. **Video**
21. **ParentalSettings**
22. Input
23. **Parties**
24. **RemotePlay**
25. NetworkingUtils, via SteamInternal_FindOrCreateUserInterface (null object on x64, D-53-08)
26. NetworkingSockets, the same way
27. NetworkingMessages, the same way

Every bold row is unserved today.

The four titles' own version constants were measured at planning time as UTF-16 user strings in
`<Game>_Data/Managed/com.rlabrecque.steamworks.net.dll`. The unserved Init set is:
- STEAMSCREENSHOTS_INTERFACE_VERSION003
- SteamMatchGameSearch001
- STEAMHTTP_INTERFACE_VERSION003
- STEAMUGC_INTERFACE_VERSION016 / 017 / 020
- STEAMAPPLIST_INTERFACE_VERSION001 (absent from Hell Clock's build)
- STEAMMUSIC_INTERFACE_VERSION001
- STEAMMUSICREMOTE_INTERFACE_VERSION001
- STEAMHTMLSURFACE_INTERFACE_VERSION_005
- STEAMINVENTORY_INTERFACE_V003
- STEAMVIDEO_INTERFACE_V002
- STEAMPARENTALSETTINGS_INTERFACE_VERSION001
- SteamParties002
- STEAMREMOTEPLAY_INTERFACE_VERSION001 / 002

The plan also adds the measured coverage misses SteamUtils009, SteamController006 and
SteamGameServer012.

Purpose: this is the largest single lever on the done-when count (3 to 4 Unity rows), and it is
the measured D-53-06 fix. Manifests are extracted with the existing tool, so the cost is
mechanical rather than hand-authored.
Output: the extractor `_ret` hardening, 19 new manifests, the served map, regenerated committed outputs, and a fixture-pinned Init-coverage test.
</objective>
