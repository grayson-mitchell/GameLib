| T-53-23 | Tampering | log injection via version string | medium | mitigate | sanitize_ver before logging; call names come only from generator-validated manifest identifiers |
| T-53-24 | Information Disclosure | CALL trace | medium | mitigate | name only, no args/returns; no SteamID, token or persona |
| T-53-25 | Denial of Service | log volume | low | mitigate | CALL once per method per process (BD_CALL_COUNT bound); NOVER bounded by the shim's 16-report cap |
