| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-53-43 | Spoofing | CALL attribution by continuation line | mitigate | continuation lines attribute only to the nearest preceding `bridge helper [id]:` prefix; lines under another appid's prefix never count (tested) |
| T-53-44 | Repudiation | stale logs inflating or deflating verdicts | mitigate | backup/prev logs excluded; app evidence limited to the latest launch segment |
| T-53-45 | Denial of Service | log reads | mitigate | keep MAX_APP_LOGS / MAX_APP_LOG_BYTES tail reads and MAX_ENGINE_LOGS; lstat regular files only, no symlinks |
| T-53-46 | Information Disclosure | CensusRow detail | mitigate | the detail carries only a version string or fixed reason, never a path or log line (T-51-39 holds; NOVER detail is the sanitised version token) |
