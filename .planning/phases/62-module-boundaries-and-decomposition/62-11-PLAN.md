## Channel -> domain assignment rule (planner decision, RESEARCH OQ5)
R1. Channel registered in exactly one `<d>FlowRegistration.ts` -> `ipc/<d>.ts` (paired).
R2. Sync/Async/TestSync channel registered by no FlowRegistration: find its handler
    (`grep -rn "ipcMain\.\(handle\|on\)(\s*'<name>'" src/backend`): handler under
    `storeManagers/<runner>/` -> `ipc/<runner>.ts`; window-control channels (zoom, minimize,
    maximize, close, fullscreen, titlebar) -> `ipc/window.ts`; TestSync stubs and anything with no
    handler -> `ipc/testStubs.ts`; any other handler -> `ipc/mainProcess.ts`. These are UNPAIRED files.
R3. FrontendMessages (push-only) -> by sender (`grep -rn "sendFrontendMessage(\s*'<name>'" src/backend`):
    sender under `storeManagers/steam/` or a `steam*` file -> `steam`; `downloadmanager/` ->
    `downloadQueue`; `storeManagers/<runner>/` -> `<runner>`; `humble/` -> `humble`; `wine/` or
    `tools/` -> `wineTools`; `logger/` -> `logger`; anything else or no sender -> `appShell`.
    Multiple sender domains -> the domain of the first sender in path order, noted in the mapping.
R4. A channel registered in two FlowRegistrations: stop and report (not expected).
Produce the full mapping with a scratch script (session scratchpad, not committed), paste the
table (channel, umbrella, domain, rule) into the SUMMARY — Task 2 encodes the unpaired part of it in the census test.

## Domain file shape
Each `ipc/<d>.ts` holds only the parts it has, named `<D>Sync`, `<D>TestSync`, `<D>Async`,
`<D>FrontendMessages` (PascalCase domain, e.g. `SteamAuthAsync`), declared as `export interface`
with `// ts-prune-ignore-next` above each, members byte-for-byte in their original relative order
with their comments. Types used only by one domain's members move into that file; types used by
several stay imported from their existing homes. `index.ts` declares
`export type AsyncIPCFunctions = SteamAuthAsync & SteamAsync & ...` (every `*Async` part, sorted
by domain name) and likewise for the other three, each with `// ts-prune-ignore-next`, and
`export type { SteamSyncStatus } from './<domain>'`.
