<objective>
Deliver a real install size in the download-manager queue for Steam games (LIB-06),
replacing the `'?? MB'` fallback with a best-effort figure sourced from the public
Steam store `appdetails` API.

This is a two-part fix (both required — either alone has no visible effect):
1. Backend: fetch and parse a storage figure at enqueue time, populate `params.size`.
2. Frontend: fix a pre-existing blocking bug where `DownloadManagerItem` never
   renders Steam rows because `steam.library` is absent from its lookup array.

Purpose: The DM queue is currently useless for Steam — it either shows nothing
(render bug) or `'?? MB'` (no size source). This makes it informative.
Output: getSteamInstallSize/parseSteamStorageRequirement helpers, a Steam
runner-gate in the DM queue, and the DownloadManagerItem render fix.

**LIB-05 coverage note:** LIB-05 (playtime on library-grid tiles) is intentionally
NOT implemented in this phase. Per D-01 it is met via the existing game-details-page
display (`TimeContainer`, quick task `260628-pi7`). A prior grid-card attempt was
removed (`325cf7f4`) because it never rendered. No new implementation — LIB-05 is
listed here only so the source audit records it as "met via existing details-page
display (D-01)". Do NOT add any grid-tile playtime work.
</objective>
