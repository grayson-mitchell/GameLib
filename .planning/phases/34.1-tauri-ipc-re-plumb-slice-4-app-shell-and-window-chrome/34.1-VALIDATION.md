## Sampling Rate

- **After every task commit:** Run the targeted `pnpm jest <new-test-file>` for that task's file
- **After every plan wave:** Run the cross-file sweep `pnpm jest appShellFlows|misc|capabilitiesDefault|electronUntouched` (naming mirrors Phase 34's `tauriConf|cargoFeatures|releaseWorkflow` sweep convention)
- **Before `/gsd:verify-work`:** `pnpm test:ci` full suite green **plus** `cargo check` in `src-tauri/`
- **Max feedback latency:** ~10 seconds for targeted runs

## Manual-Only Verifications

**This section is unusually load-bearing for this phase.** Per CONTEXT.md D-15, every item below is a *deferred* UAT item — none gates phase closure — and that is a deliberate, recorded decision.

| Behavior | Requirement | Why Manual | Test Instructions |
|----------|-------------|------------|-------------------|
| The frameless toggle visually applies | D-05 / D-06 | Jest can assert `setDecorations()` was called; it cannot see the window | `pnpm tauri:dev`, toggle `framelessWindow` in Settings, confirm chrome changes without a visible flip |
| The window buttons actually move the real OS window | D-01 | Requires a real OS window manager | `pnpm tauri:dev`, click minimize / maximize / unmaximize / close in the custom titlebar |
| The tray icon appears and its colour changes | D-11 | Requires a real OS tray; structurally impossible in jest | `pnpm tauri:dev`, confirm tray icon present, change tray colour in Settings |
| Gamepad navigation works end-to-end | D-10 | Requires real gamepad hardware | Connect a controller, navigate `/console` routes |
| macOS traffic lights vs custom buttons looks right | D-06 | Aesthetic call — must be looked at | `pnpm tauri:dev` on macOS with `framelessWindow` on |

**The unavoidable gap, in D-15's own terms:** every automated test above proves *wiring* — that the right Tauri API was called with the right arguments. None proves the window on screen actually did the thing. `34.1-PORTED-CHANNELS.md` must state this plainly and must not soften it into "wired and unit-proven" language a later reader could misread as "seen working" — the precise failure mode D-15 names from the G-30-02 precedent.
