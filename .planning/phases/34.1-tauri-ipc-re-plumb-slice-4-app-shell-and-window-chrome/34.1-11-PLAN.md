<objective>
Close the frontend half of gap G4 (UAT test 9, DECISION REVERSAL, major): now that the macOS main
window is created in overlay mode with native traffic lights (plan 34.1-10), the shell must clear
them, must stop rendering GameLib's own duplicate buttons on macOS, and must stop reserving
trailing space for buttons that no longer exist there.

Purpose: `--traffic-light-inset: 0px` was never a design position — `NavShell/index.scss:24-33`
documents it as correct *because nothing overlaid the titlebar*, and says in its own words
"This exists as a token so that adopting overlay mode later is a value change, not a re-layout."
Overlay mode is exactly the trigger that flips it. 78px is not a guess: `Skill("sketch-findings-gamelib")`
lists it as one of exactly TWO constraints that OVERRIDE aesthetics — *"78px at the window's
top-left belongs to the macOS traffic lights whenever the Tauri titlebar is transparent or
overlaid. No top-mounted bar starts at x=0."*

Output: a macOS-scoped 78px reserve, `WindowControls` gated off on macOS, the trailing reserve
scoped to non-macOS, `shellTokens.test.ts` RETUNED (never deleted), and the stale D-05 comment
corrected.

**Depends on 34.1-09** because this plan rewrites `NavShell/index.scss`'s D-05 comment, which
currently asserts that `WindowControls` "keeps `grid-area: content`" — a claim 34.1-09 falsifies.
Correcting it before 34.1-09 lands would make the comment wrong in the other direction.

<why_a_single_token_declaration>
`shellTokens.test.ts:55` asserts `--traffic-light-inset:` is declared EXACTLY ONCE across every
stylesheet under `src/frontend`. That gate is correct and stays. So the platform decision must NOT
be expressed as a second declaration of the token — express it in the CONSUMER instead:

  :root { --traffic-light-inset: 78px; }             <- the constant: what macOS traffic lights cost
  .App.macOverlayTitlebar .NavShell__navbar { padding-inline-start: var(--traffic-light-inset); }

The token means "the macOS traffic-light reserve", a fixed quantity. Whether it APPLIES is a
platform question, and platform questions belong on the selector.
</why_a_single_token_declaration>
