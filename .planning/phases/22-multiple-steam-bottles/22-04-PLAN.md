<objective>
Rewire `SteamGame`'s four bottle-eligible methods (getSettings, install, launch,
uninstall) to resolver-first routing (D-05): call `resolveFamilyForApp(appId)`
first, branch on `needs-provision` to guided setup for that specific family
(carrying the resolved `bottleName` in the `steamBottleSetupRequired` payload —
Pitfall 4), then thread the resolved `bottleName` into every downstream
`tellBottledSteamTo*` / `installBottleNative` / `startInstallPolling` call.

warns the four blocks are near-identical and easy to update only three of — the
mitigation is a single shared private helper so drift is impossible.

</objective>
