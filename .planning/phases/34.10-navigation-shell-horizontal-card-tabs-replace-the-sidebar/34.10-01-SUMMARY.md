## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Test assertion corrected: `ref` lives on `ReactElement.ref`, not `props.ref`, in React 18**
- **Found during:** Task 2 (`GamesPanel` ref-forwarding test)
- **Issue:** The plan's task text and acceptance criteria describe asserting `GamesPanel()`'s returned element's `props.ref` against the context's `setTarget`. Running the test against the actual implementation showed `element.props.ref` is `undefined` -- confirmed against `node_modules/react/cjs/react-jsx-runtime.development.js` (`ref = config.ref` is extracted onto the element's top-level `ref` field, not copied into `.props`, in React 18.3.1; this only changes in React 19).
- **Fix:** Changed the assertion to `element.ref`, with an inline comment recording why and citing the source file checked.
- **Files modified:** `src/frontend/components/UI/NavShell/__tests__/GamesPanel.test.tsx`
- **Verification:** `npx jest --config src/frontend/jest.config.js src/frontend/components/UI/NavShell/__tests__/GamesPanel.test.tsx` -- all 5 tests pass.
- **Committed in:** `f11c108ff` (Task 2 GREEN commit)
