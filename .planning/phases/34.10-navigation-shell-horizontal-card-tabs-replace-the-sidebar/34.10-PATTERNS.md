### Tier-1 tab strip — `NavBar/index.tsx` (component, request-response/route-driven)

**Analog 1 (a11y scaffolding):** `src/frontend/screens/WineManager/index.tsx:222-239`

```tsx
<Tabs
  className="tabs"
  value={repository.value}
  onChange={(e, value) => {
    const repo = repositories.find((setting) => setting.value === value)
    if (repo) { handleChangeTab(e, repo) }
  }}
  variant="scrollable"
  scrollButtons="auto"
>
  {repositories.map(({ type, value }) => (
    <Tab value={value} label={type} key={value} />
  ))}
</Tabs>
```
**Adaptation required, not a literal copy:** this usage is `value`/`onChange` **state**-driven (switches a data source, not a URL) — WineManager's tabs never navigate. The tier-1 bar must be **route**-driven instead: give each `<Tab>` `component={NavLink}` + `to={...}` (standard MUI+react-router integration, not exercised anywhere else in this codebase today — new usage of an existing dependency, confirmed by RESEARCH.md `## Tab Pattern Recommendation`). Reject MUI's default blue underline indicator entirely and fully reskin per UI-SPEC's Color/Typography/States tables — do not carry over WineManager's `className="tabs"` styling.

**Styling idiom confirmed:** WineManager wraps `<Tabs>` in a plain `className="tabsWrapper"` div and applies CSS via a sibling `.scss`/`.css` file selector, **not** MUI's `sx` prop and not styled-components. Follow this same plain-className + external-stylesheet idiom for the new navbar (matches every other UI component in this tree — `SidebarItem`, `CurrentDownload`, `Header` all use colocated `index.css`/`index.scss` + plain `className`, never `sx`).

**Analog 2 (aria contract, explicitly NOT to be reused for tier 2):** `src/frontend/components/UI/TabPanel/index.tsx` (24 lines, full file):
```tsx
function TabPanel({ children, value, index, ...other }: TabPanelProps) {
  return (
    <div role="tabpanel" id={`tabpanel-${index}`} aria-labelledby={`tab-${index}`} {...other}>
      {value === index && <div>{children}</div>}
    </div>
  )
}
```
UI-SPEC's Accessibility section (`## States & Interactions`, bottom) requires `role="tablist"`/`role="tab"`/`aria-selected` on tier 1 and `id="tab-{index}"` matching this exact `aria-labelledby="tab-{index}"` contract — reuse the **ID-naming convention**, but do NOT reuse the `TabPanel` component itself for tier 2 (RESEARCH.md's explicit recommendation: tier-2's four cases — filters/nav-list/nav-list/nothing — don't fit a generic `value === index` show/hide wrapper). Use a plain conditional render (`{activeTab === 'games' && <GamesTier2 />}`) inside the shell component instead.

// 5. Walk the returned React-element object graph directly:
function collectElements(node: ReactNode, out: ReactElement[] = []): ReactElement[] {
  if (node === null || node === undefined || typeof node === 'boolean') return out
  if (Array.isArray(node)) { node.forEach((child) => collectElements(child, out)); return out }
  if (typeof node === 'object' && 'type' in node) {
    out.push(node as ReactElement)
    if ((node as ReactElement).props?.children !== undefined) {
      collectElements((node as ReactElement).props.children, out)
    }
  }
  return out

### Source-text / CSS-gate test idiom — for the `--tier2-width` single-definition test

**Source (full mechanism, `cssBlock()` helper):** `src/frontend/screens/Login/__tests__/index.test.tsx:34-90`
```tsx
import { readFileSync } from 'fs'
import { join } from 'path'
import { stripSourceComments } from 'backend/testUtils/stripSourceComments'

const REPO_ROOT = join(__dirname, '..', '..', '..', '..', '..')
const read = (relPath: string) => stripSourceComments(readFileSync(join(REPO_ROOT, relPath), 'utf8'))
const APP_CSS = 'src/frontend/App.css'

function cssBlock(source: string, selector: string): string {
  const start = source.indexOf(`${selector} {`)
  if (start === -1) throw new Error(`selector ${selector} not found`)
  let depth = 0
  for (let i = source.indexOf('{', start); i < source.length; i++) {
    if (source[i] === '{') depth++
    if (source[i] === '}') { depth--; if (depth === 0) return source.slice(source.indexOf('{', start) + 1, i) }
  }
  throw new Error(`unterminated block for ${selector}`)
}

describe('F-10: no percentage height may resolve against .App\'s 1fr row', () => {
  it('REGRESSION GATE ...', () => {
    const block = cssBlock(read(APP_CSS), '.App .content')
    expect(block).not.toMatch(/min-height:\s*[\d.]+%/)
  })
})
```
**Apply to:** a new source-gate test asserting exactly one `--tier2-width:` declaration exists across the new navbar/tier2 SCSS (grep/regex over source text, not a rendered assertion) — protects D-10's "one-line change for 34.11" goal.
