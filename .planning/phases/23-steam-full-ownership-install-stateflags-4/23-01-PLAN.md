<objective>
Extend the depot writer to replicate the full `EDepotFileFlag` mode set on every downloaded file (D-06, REQ-23-06). Today `downloadSingleFile` applies only `Executable(32)`/`CustomExecutable(128)` (spike-003) and `Directory(64)`/`Symlink(512)` (Phase 21). `ReadOnly(8)` and `Hidden(16)` are the known gap. Under `StateFlags=4` Steam runs no verify pass, so nothing downstream applies these modes — GameLib must.

Purpose: A trustworthy `StateFlags=4` install must be launch-ready, not just byte-correct. sha1 guarantees content, not filesystem mode — the exec-bit surprise (`os error 256`) is the template for this whole class of risk.
Output: New `depot/fileAttributes.ts` (`applyDepotFileFlags`) + a `downloadSingleFile` call site + tests. This produces the file-mode-application signal the Wave 2 completeness gate consumes (a mode failure must land in `DepotDownloadResult.failures`).
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Steam CM manifest → local filesystem | depot manifest `filename` + `flags` are attacker-influenceable if a CM/content server is compromised; they drive path resolution and subprocess arguments |
| Node → OS subprocess (`attrib.exe`) | file path flows into a spawned process argv on Windows |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23-01 | Tampering / Elevation | `fileAttributes.ts` Windows `attrib.exe` call | mitigate | argv-form `spawnSync` only, hardcoded `+R/-R/+H/-H` flags, file path as a single argv element, `windowsHide:true`; NEVER shell-form or template-string command (grep-gated in acceptance criteria) |
| T-23-02 | Tampering | `downloadSingleFile` path used for chmod/attrib | mitigate | reuse the existing `resolveContainedPath` result (`dest`); do not recompute — path traversal already blocked upstream by `PathTraversalError` |
| T-23-03 | Repudiation | Silent mode-application failure masking a non-launchable install | mitigate | a failed `applyDepotFileFlags` becomes a `DepotDownloadFailure`, forcing the Wave-2 gate to fall back to 1026 rather than assert a broken StateFlags=4 |
| T-23-SC | Tampering | npm/pip/cargo installs | mitigate | zero new packages this plan (RESEARCH Package Legitimacy Audit: none); `attrib.exe`/`chmod` are stock OS facilities |
