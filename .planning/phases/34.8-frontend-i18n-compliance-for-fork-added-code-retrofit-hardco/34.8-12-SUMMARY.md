# Plan 34.8-12 — Prove the machine-fill and the runtime namespace load

## What was delivered

The two things this phase could not prove with unit tests alone.

**Task 1 — two real locales.** `de` and `fr`, 124 keys each, **0 skipped, 0 preserved** on the
first run. Verified by hand before committing: every `{{placeholder}}` reproduced verbatim
(0 mismatches), every glossary brand term intact (0 drops), no unpaired `_one`/`_other`
sibling, and each `gamelib.mt.json` listing exactly the 124 filled keys with the model ID and
a fill timestamp, with 0 stale keys.

**Idempotence, measured not asserted:** an immediate second run reported
`[de] filled 0 new key(s), 124 preserved, 0 skipped` (same for `fr`), issued **0 API requests**,
and left all four files byte-identical by sha256. D-09's "never overwrites a non-empty value"
holds against real data, not just a fixture.

**Task 2 — `meta/__tests__/gamelibCatalogParity.test.ts`**, 11 tests. Glob-discovered,
count-free, reusing `validateTranslation` from the fill itself. Mutation-proven rather than
merely green: corrupting `{{detail}}` → `{{details}}` in `de/gamelib.json` fails the suite
naming the locale and key path —

```
de: 'app.routeError' -- translation drops placeholder {{detail}} present in the source
de: 'app.routeError' -- translation introduces placeholder {{details}} not present in the source
```

— then restored byte-identical by checksum.

**Task 3 — `34.8-RUNTIME-CHECK.md`.** Both runtimes PASS. Full evidence and the explicit
NOT OBSERVED / NOT CONFIRMED entries are in that document.

## What the live run exposed

Plan 12 exists because correctness on real data is only observable by running the thing. It
found three defects in `meta/machineFillGamelib.ts` that the 29-test hermetic suite could not
see, because `createAnthropicTranslator` is the one function deliberately excluded from it:

1. **A 124-key batch could not fit its own token budget.** One request, `max_tokens: 4096`,
   and a model that now runs adaptive thinking by default → the whole budget went to a
   thinking block and no text block was returned.
2. **`?? '[]'` turned that into silence.** Zero translations, zero files written, **exit 0**.
3. **`filledAt` was re-stamped on every run**, so the idempotence re-run rewrote both
   provenance sidecars.

A fourth, intermittent: one chunk returned a fenced array and aborted the locale.

All four fixed, with 9 new tests (29 → 38 in that suite). The `filledAt` fix is RED-proven
against the unfixed code.
