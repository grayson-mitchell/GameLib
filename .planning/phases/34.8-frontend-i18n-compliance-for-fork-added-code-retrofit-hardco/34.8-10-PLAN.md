<objective>
Flip the gate from reporting to blocking, and write the standing contract that records what this
phase deliberately did NOT do.

Purpose: D-12 is "blocking in CI from day one — no advisory grace period", justified because an
advisory gate nobody fails is exactly the failure mode this phase exists to prevent; hardcoded
constants already shipped once in the Steam features. That is only safe because the gate has now
proven itself: plan 03's negative fixtures show it fails on real violations, plan 04's positive
fixtures show it tolerates all four D-14 idioms, plan 05's stale-exemption tests show the D-18
mechanism fires in both directions, and plans 06–08 cleared the measured backlog.

The contract document exists because several of this phase's decisions are deliberate
NON-actions. Without a written record, a future reader sees them as omissions: fork keys sitting
in upstream catalogs, brand names left literal, `PlatformSupport.tsx` untouched, no Weblate
project, and a gate that does not care which namespace a `t()` call targets.

Output: the blocking assertion and `34.8-I18N-CONTRACT.md`.
</objective>
