## Residual-violation closure (the 62-item discovery, closed under Rule 1)

`34.8-AUDIT.md`'s own `## Closure → Independent Re-Measurement` recorded `violations: 62` against
the real committed scope — every one already classified `not-user-facing` (60) or `glossary` (2)
in `## Triage`, never a real i18n violation, but not yet recognised as such by the scanner itself.
Closed via:

- **New content-shape checks** (`isTechnicalToken`): icon-size multipliers (`2x`/`3x`), a bare
  single ALL-CAPS word (internal enum/state discriminators — `MESSAGE`/`ERROR`/`REDEEMED`/
  `UNREDEEMABLE`/`UNPICKED`/`REVEALED`/`THE`/`CANVAS`/`IMG`), 32-character hex GUIDs, CDN
  query-string fragments (`?h=800&resize=1&w=600`), bare DNS hostnames
  (`store.steampowered.com`), and a `??`-prefixed backend placeholder sentinel (`'?? MB'`)
- **New structural-position checks** (`isStructuralNonCandidate`): DOM/browser API technical
  arguments (`querySelector`/`querySelectorAll`/`getContext`/`setUserAgent`/`sessionStorage`
  `getItem`/`setItem`), internal string-comparison arguments
  (`includes`/`endsWith`/`startsWith`/`replace`, any argument position), and
  `[...].includes()` array literal elements (`['Denied','Broken','Unknown'].includes(...)`)
- **`walkUpThroughComposingWrappers`** — extracted the existing ternary/`+`/parenthesized
  composing walk into a shared helper, added `??` and template-interpolation hops, and reused it
  for a NEW `findAssignedBindingNameNode` (ternary-composed variable assignment, not only direct
  `const x = 'text'`) — this is what closed `MacArchBadge.tsx`'s CSS-modifier-assigned-to-variable
  case and `TauriLoginPanel.tsx`'s two template-interpolated-fallback cases
- **`isAssignedThenPassedToT` broadened** from "reference passed to `t()`" to "reference safely
  consumed" — also exempt if a diagnostic log argument (`repairFailure.ts`'s `errorText`), nested
  in an excluded JSX attribute (`MacArchBadge.tsx`'s `variantClass` inside `className={}`), or a
  technical DOM API argument (`WebView/index.tsx`'s `userAgent` inside `setUserAgent(userAgent)`)
- **`isPartOfSplitGlossaryTerm`** — a NEW jsx-text-only check recognising a glossary term
  (`GameLib`) split across sibling JSX nodes (`SidebarLinks/index.tsx`'s
  `Game<span>Lib</span>`), walking up through single-child JsxElement wrappers so the "Lib" text
  node (nested one level deeper than "Game") resolves to the same Fragment-level sibling scan
- **`GameLibSteam` added to `meta/i18nGlossary.json`** — `steamBottleDefaults.ts`'s internal
  CrossOver bottle-name constant, a compound of two already-glossed terms
- **A second real user of the 34.8-08c declaration-scoped `i18n-gate-exempt:` marker** —
  `StoreSearch/helpers.ts`'s `buildOwnedBadgeLabel()`, whose returned `{key, defaultValue,
  values}` object IS consumed via `t(ownedLabel.key, ownedLabel.defaultValue, ownedLabel.values)`
  at `StoreSearchRow/index.tsx:48` (verified by direct read), one function-return/call-site hop
  beyond the gate's same-file-only reference tracing — cross-file dataflow the scanner should not
  be extended to trace

**A load-bearing constraint respected throughout:** the phase's own negative-proof fixture ("still
flags a string compared against an unrelated property — the exemption is scoped to `.key`
specifically") pins that the gate must never grow a general "any equality-comparison operand is
exempt" rule. Every new check above is gated on a specific method/property name or content shape,
confirmed against the real occurrence by direct read — not a broad comparison-based carve-out.
