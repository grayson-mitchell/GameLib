<objective>
Retrofit the phase's flagship named target — `RedeemSteamKeyDialog/copy.ts`, a module that
bypasses i18n entirely — and land `bootErrorSurface.ts`'s exemption comment.

Purpose: `copy.ts` is a plain module, not a component and not a hook, so it has no
`useTranslation()`. There is no single canonical non-hook `t()` idiom in this repo — two real
ones compete, and they differ behaviourally, not just stylistically: `GlobalStateV2.ts`'s
module-scope `import { t } from 'i18next'` is not guaranteed to have a lazily-loaded namespace
resolved at call time, while `repairFailure.ts`'s injected `TFunction` parameter inherits the
calling component's Suspense-resolved `t`. The injected-parameter shape is the safe one here
because `redeemOutcomeCopy()` runs during render and event handling.

`bootErrorSurface.ts` is the opposite case: it runs before i18next boots, so D-19 gives it an
exemption comment rather than a retrofit.

Output: `copy.ts` on the injected-`TFunction` idiom with `gamelib:`-namespaced keys, its caller
and test updated, and `bootErrorSurface.ts`'s exemption comment.
</objective>

<!-- The retrofit contract. `copy.ts`'s signature changes, so every caller and test must move. -->

  // BEFORE
  export function redeemOutcomeCopy(
    outcome: RedeemKeyOutcome,
    packageName?: string
  ): RedeemOutcomeCopy

  // AFTER — injected TFunction, mirroring repairFailure.ts's idiom
  import { TFunction } from 'i18next'
  export function redeemOutcomeCopy(
    outcome: RedeemKeyOutcome,
    t: TFunction,
    packageName?: string
  ): RedeemOutcomeCopy

`RedeemOutcomeCopy` (`{ message: string; tone: 'success' | 'error' }`) is UNCHANGED.

Key convention for the `gamelib` namespace (`keySeparator: '.'`, `namespaceSeparator: ':'`
already configured): `gamelib:<feature>.<slug>` — e.g. `gamelib:redeemKey.successWithPackage`.
Every call is TWO-argument `t(key, 'English default')`, never a bare `t(key)`: `fallbackLng: 'en'`
plus `returnEmptyString: false` plus the parser's `defaultValue: ''` is what makes an
extracted-but-empty key fall through to the inline English default, and that is this phase's
whole compliance bar.

Gate exemption marker (plan 04): `i18n-gate-exempt:` followed by reason text on the same line.
A bare marker with no reason does NOT exempt.
