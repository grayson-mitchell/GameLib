<objective>
Generate the fork-owned English catalog, and make the "we never touch upstream catalogs" promise
something CI proves rather than something the phase asserts.

Purpose: D-04 supersedes ROADMAP item (3) — the deliverable is `en/gamelib.json` generated
repeatably, not a sync of the stale upstream `en` catalogs. D-05 is the mechanical backstop that
makes D-06's split-brain and D-11's permissive translation-memory reads safe: if a `t()` call is
ever mis-namespaced, the parser writes into `translation.json` and this guard catches it. D-15
scopes `lintTranslations.ts`'s catalog checks to `gamelib.json` when wired into CI, because
running them across all 49 locales surfaces a wall of pre-existing upstream failures on
Weblate-sourced data the fork does not own and cannot fix — and a gate with unactionable noise
stops being read.

**Revert discipline:** the `pnpm i18n` run in task 1 mutates the working tree across 49 locale
directories. Before running it, confirm `git status --porcelain public/locales/` is empty. After
running it, inspect `git diff --stat public/locales/`; if ANY path outside `*/gamelib.json`
changed, run `git checkout -- public/locales/` immediately and treat it as a defect to diagnose,
not as something to hand-edit away.

Output: `public/locales/en/gamelib.json`, the churn guard plus its test, and the D-15 scoping.
</objective>

  export interface ChurnClassification {
    gamelib: string[]    // changed paths ending in /gamelib.json — allowed
    upstream: string[]   // any other changed path under public/locales/ — forbidden

  export class UpstreamChurnError extends Error {}

Parser config facts that govern the generated catalog (plan 01 verified them):
  `keepRemoved: true`, `locales: ['en']`, `defaultValue: ''`, `sort: true`,
  `namespaceSeparator: ':'`, `keySeparator: '.'`,
  `output: 'public/locales/$LOCALE/$NAMESPACE.json'`, `input: ['src/**/*.{ts,tsx}']`.

Because `defaultValue: ''` and `returnEmptyString: false` and `fallbackLng: 'en'`, an extracted
key with an empty value renders its inline `t(key, 'Default')` second argument. Empty values in
`en/gamelib.json` are therefore CORRECT and expected, not a defect — `lintTranslations.ts`'s
empty-string check must not be run against `en` for this reason.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `pnpm i18n` → 49 locale directories | A single parser run can rewrite every catalog in the repo |
| `t()` namespace prefix → catalog file written | A mis-namespaced call silently mutates an upstream-owned file |
| catalog values → rendered UI | Content-less tag mismatches and stray interpolations reach the UI through translations |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-34.8-25 | Tampering | `pnpm i18n` mutating upstream catalogs | mitigate | `keepRemoved: true` (plan 01) plus task 1's precondition check plus `assertNoUpstreamChurn`; a non-gamelib change triggers an immediate `git checkout -- public/locales/` and a stop, never a hand-edit |
| T-34.8-26 | Tampering | markup injection via a translated catalog value | mitigate | `lintTranslations.ts`'s content-less-tag mismatch check now covers `gamelib.json` (it is added to `readFiles()`), catching a translation that adds content inside an indexed `<1></1>` tag or drops one the English carries |
| T-34.8-27 | Elevation of Privilege | churn guard shelling out to git | mitigate | `execFileSync('git', [fixed argv])`, never `execSync` with an interpolated string |

| T-34.8-SC | Tampering | npm/pip/cargo installs | accept | Zero new packages (RESEARCH.md § Package Legitimacy Audit). Any newly-required install → STOP and raise a blocking-human legitimacy checkpoint. |
