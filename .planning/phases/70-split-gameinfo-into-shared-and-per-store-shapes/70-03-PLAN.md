<objective>
Expand-contract needs a way for each reader plan to prove "this file compiles once GameInfo is the
union" while `GameInfo` is still fat. This plan builds that proof as a committed tool: the
TypeScript compiler API, a CompilerHost that serves a flipped copy of src/common/types.ts from
memory (fat interface replaced by the union, store-key regions deleted), and a per-file diagnostic
report. It never writes to disk and never spawns a child process, so no fake-HOME arm is needed
and an interrupted run cannot leave the repo modified. Plan 11 deletes the tool, its test, its
script and the markers when the real flip lands.

Output: the probe, its unit test, a `gameinfo-flip-probe` script, and the measured inventory.
</objective>
