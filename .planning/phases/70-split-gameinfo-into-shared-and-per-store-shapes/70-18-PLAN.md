<objective>

Contract to create (consumed by 70-19, 70-20, 70-21, 70-22 — do not change names):

- `export interface StripOptions { readonly dropInvalidOptional: boolean }` — required at every call site (no default) so each caller states its data-loss policy. All current callers pass true: GameInfo callers because the data is a regenerable cache; settings callers (orchestrator decision, revision 1) because under `.partial()` every member is optional, so only a value the strict IPC schema cannot accept is dropped and its default applies, while the Phase 68 engine's 0600 pre-migration backup keeps the original. The `false` mode stays supported and tested for future callers.
- `export function stripToSchema(value: unknown, schema: z.ZodType, options: StripOptions): unknown`

Project schema facts the strip must handle (zod ^4.6.7):
- `z.strictObject(...)` everywhere in gameInfoSchema.ts / settingsSchema.ts; `.optional()` members; `legendary.save_path` is `str().nullable().optional()`; `focusRow` is `.nullable()` (required, null meaningful).
- Arrays of strict objects: `extra.reqs` (`z.array(reqsSchema).max(256)`, REQUIRED inside extra), `gog_save_location`, `enviromentOptions`, `wrapperOptions`, `gogSaves`.
- Record of strict objects: `install.manifest.perLangSize` (`z.record(z.string(), z.strictObject(...))`).
- Loose objects (must pass through untouched): `dlcList` = `z.array(z.looseObject({}))` behind an `as unknown as z.ZodType<...>` cast (`epicDlcMetadataArg()`); `wineVersionArg` = `z.union([wineInstallationArg() /* looseObject */, noWineInstallation /* looseObject */])` behind a cast. Casts are type-only; runtime instances are unchanged.
- Unions: `launchOptionSchema` = `z.union([...three strictObjects])`; `gameInfoSchema` = `z.discriminatedUnion('runner', [...])`.
- `str().brand<'Path'>()` and `nonEmptyString()` are leaves.

    rules below. Implement `stripToSchema(value, schema, options)`:
    1. Unwrap `ZodOptional`, `ZodNullable`, `ZodDefault` repeatedly (via `.unwrap()` / `def.innerType`) to find the structural schema; the ORIGINAL member schema is what null/undefined/validity checks run against.
