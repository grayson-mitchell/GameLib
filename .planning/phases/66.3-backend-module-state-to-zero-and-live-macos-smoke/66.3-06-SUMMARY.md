## Decisions Made

- Non-launch `createGameLogWriter` callers pass `verboseLogs: false`: both settings stay required (T-66.3-19), and `verboseLogs` only matters for type `launch`.
- `EngineServices` carries `globalSettings` (Record, for engine config reads) beside `globalGameSettings` (GameSettings, for fallback bottle settings) rather than widening one type, to avoid casts in the engine.
- The Humble digest notification lost its `click` listener. It never ran: the sidecar's Notification stand-in accepted and ignored `click`, and `Notifications.show` has no click callback. `Notification.isSupported()` (always true) is gone.
- `steamhelper.ts` background art: `generateImage` ran `executeJavaScript` on the stand-in window, which always returned `''`; deleted, background stays `''` as before.
