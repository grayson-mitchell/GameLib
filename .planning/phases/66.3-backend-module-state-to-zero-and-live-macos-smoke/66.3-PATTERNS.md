```typescript
export function createIpcRegistry() {
  const handlers = new Map<string, IpcHandler>()      // closure fields, not module state
  const listeners = new Map<string, IpcListener[]>()
  return {
    handle: (c, h) => { handlers.set(c, h) },
    removeHandler: (c) => { handlers.delete(c) },
    on: ..., once: ...,
    getHandler: (c) => handlers.get(c),               // sidecarRpc dispatchInvoke reads this
```

### Factory, narrow slice, no default args, no locator
**Source:** `createRunningPoll` (`runningPoll.ts:146-200`), `createSteamProcesses` (`steamProcesses.ts:25-67`), `ManagerDeps` (`services/types.ts:100-125`).
**Apply to:** every owner in this phase. Never receive the whole `AppContext`/`BootServices` outside a composition root; no `deps = defaultX()`; no `getContext()`; no static facade over the new object.

### Boot step wiring and ordering
**Source:** `bootstrap.ts:1126-1160` (`command-runner`), `:1224-1253` (`store-managers`), `:1415-1424` (`i18n` ordering comment), `:1550-1559` (`transport`), `:1646-1657` (`online-monitor` placement).
**Apply to:** every new boot-owned object. A named step, `prebuilt.<x> ?? create...`, a "ran before" throw, a boot-order test.

### Exit contract (CLAUDE.md convention 3)
**Source:** `stdinEofRelease.ts:1-103` (`releaseOnStdinEof`, deps passed in; `released` latch; best-effort `try/catch` per release), `process/runner.ts` clock timers.
**Apply to:** `online_monitor`, `anonymousClient`, `SteamUser`, `winetricksQueue`, `shimCoverage`, `appState` wake locks. Timers on `ctx.clock` (unref'd); no unbounded in-flight work at boot; release what cannot be unref'd in `releaseOnStdinEof`; never in `startRpcServer`. `smoke:sidecar` misses slow exit, so also assert unref/clock use in unit tests with `fakeClock`.

### Dialog/guard crash-safety
**Source:** `platform/index.ts:519-...` (never-throw dialogs), `processGuards.ts` header (`unhandledRejection` log-only, `uncaughtException` fatal by design).
