## Contracts

- `createSignInEpochs()` -> `{ capture, isCurrent, bump }`. One instance per boot, shared by the outcomes owner, the pass, the verdict and every store's user module (Pitfall 10); a bump on one store never moves another's epoch (unit-tested), a stale capture is rejected.
- `createSignInProbeOutcomes({ ipc, push, epochs })` -> `{ get, record, publish, registerHandler, noteSignInSucceeded, noteSignedOut }`. `registerHandler` is idempotent per instance and uses `handleTyped` on the host registry; `push` is `host.pushFrontendMessage`.
- `createSignInProbePass({ epochs, outcomes })` -> `{ request, start }`. passInFlight/rerunPending/started/lastStatus/configuredDeps are closure fields. `request()` before `start()` still logs the C-WR-5 warning and runs nothing; a request during a pass sets rerunPending and runs exactly one more. Pure helpers (`createSignInProbePassDeps`, `boundedSignInProbe`, `runSignInProbePass`) stay exported; the pass deps now carry `epochs` and `outcomes`. The test-worker guard (`JEST_WORKER_ID`) is unchanged.
- `applySignInVerdict` deps gained `epochs: Pick<SignInEpochs,'isCurrent'>`.
- `createSteamSignInState()` -> the same get/set/add/take/reset functions as before (session, QR state, last-logged status, credential state, settle callbacks), as members.
- `createSteamAuthTrigger()` -> `{ noteSteamAuthTrigger, isSteamAuthUnlocked, currentTriggerLabel, resetSteamAuthTrigger, consumeSteamRefreshLogonGrant, noteRefreshTrigger }`. `DELIBERATE_TRIGGERS` and `LOGON_GRANTING_TRIGGERS` are `Object.freeze([...] as const)` arrays used with `.includes` (D-66.3-09); membership is unchanged. `mapRefreshOriginToTrigger` stays a pure export.
- `createSteamLibraryState()` -> `{ library, pendingFetches, acquireMetadataSlot, releaseMetadataSlot }`; the slot counter and waiter queue are closure fields. `MAX_CONCURRENT_METADATA_FETCHES` / `METADATA_FETCH_TIMEOUT_MS` remain constants.
- `createSteamGameSessionState()` -> `{ nativeInstallsInFlight, bridgeLaunchesInFlight, bridgeLaunchBottles, bridgeFailedThisSession, loggedEmptyGameInfoMisses, markBridgeFailedThisSession, clearBridgeFailedThisSession, isNativeInstallInFlight }`. `markForcedWindowsViaBottle` / `clearForcedWindowsViaBottle` are pure store writers and stay free functions.
