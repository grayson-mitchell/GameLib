## Decisions Made

- sendFrontendMessage returns true after `pushFrontendMessage`. The transport buffers before its output stream is bound, so a push made before the rpc-server boot step is now flushed instead of dropped by the fake window. The destroyed-window guards (Thread D-1) have no window object left to guard. main_window.test.ts rewritten for the new contract.
- images_cache.ts: the no-op `protocol.handle('imagecache', ...)` registration is removed; `getImageFromCache` is exported so the file keeps its `pending` Map (census unchanged). The file is already knip-baselined as unused.
- steamgrid/secureKey.ts: `isEncryptionAvailable()` was always false, so the branches that needed it were deleted. Plaintext in, '' out for `sgdb:v1:` ciphertext; the legacy decrypt-failure result is unchanged.
- quitHandler: `getMainWindow` dep and `window.hide()` removed (no-op on the stand-in window); showMessageBox takes options only.
- GPU info on Linux: `app.getGPUInfo` stand-in returned `{}`; kept as an explicit `{}` so the schema parse throws exactly as before.
