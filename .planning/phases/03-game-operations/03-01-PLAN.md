<objective>
Deliver the Launch vertical slice: a user viewing an installed Steam game can press Play and the Steam client launches the game. This is the first end-to-end Steam game operation.

GAME-01 is satisfied by `SteamGame.launch()` firing `steam://rungameid/{appId}` through `shell.openExternal`. GAME-04 is satisfied by *absence*: `SteamGame.isNative()` already returns `true`, so `launchEventCallback` (launcher.ts:198-224) skips `checkWineBeforeLaunch` — Steam games never enter Heroic's Wine/Proton code path; Steam decides Proton vs native itself.

Because the real launch path (`launchEventCallback`) calls `game.getSettings()` (launcher.ts:132) *before* launching and aborts if it throws, this slice must also implement the supporting `Game`-interface methods (`getSettings`, `getExtraInfo`, `isGameAvailable`, `stop`) that currently throw "not implemented until Phase 2". Without them the Play button and the GamePage are broken end-to-end.

Purpose: Replace the Phase-1 stubs in `SteamGame` with the launch delegation layer.
Output: A working Play button for Steam games; supporting read methods that let the GamePage render.
</objective>
