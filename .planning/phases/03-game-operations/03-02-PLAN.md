<objective>
Deliver the Install + Uninstall vertical slice with focus-driven state reconciliation. The user can hand a Steam install or uninstall off to the Steam client, and GamerLib's install badges reconcile with the real on-disk state when the user tabs back.

GAME-02: `SteamGame.install()` fires `steam://install/{appId}`. GAME-03: `SteamGame.uninstall()` fires `steam://uninstall/{appId}` and delegates the confirmation entirely to Steam — GamerLib shows no pre-confirmation dialog (D-05). State reconciliation (D-01/D-02): install state is never assumed from a click; a `BrowserWindow 'focus'` listener re-reads ACF manifests via the existing `buildInstalledMap()` and pushes only the games whose install state actually changed.

Purpose: Complete the backend Steam operation surface and the one genuinely new wiring (focus → ACF re-read → frontend push).
Output: Working install/uninstall delegation + live badge reconciliation on focus.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer → IPC → backend | appId reaches install()/uninstall() from the frontend; untrusted |
| backend → OS | shell.openExternal hands steam://install|uninstall URLs to the OS |
| OS/disk → backend | ACF manifest files on disk are read during focus re-read |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering / Injection | install()/uninstall() steam:// URL construction | mitigate | All steam:// URLs built through `buildSteamProtocolUrl` (03-01) which enforces `/^\d+$/` on appId before interpolation. |
| T-03-03 | Tampering | BrowserWindow 'focus' → refreshInstallState IPC push | mitigate | Focus handler takes no renderer-supplied arguments; refreshInstallState reads only local ACF and the in-memory library Map. No untrusted input enters the re-read path. |
| T-03-04 | Information Disclosure | ACF parse during focus re-read | accept | buildInstalledMap already swallows corrupt/missing ACF without throwing (Phase 2 T-2-01 mitigation); reused as-is. |
| T-03-SC | Tampering | npm/pip/cargo installs | accept | Zero new packages this phase. No package-legitimacy gate needed. |
</threat_model>
