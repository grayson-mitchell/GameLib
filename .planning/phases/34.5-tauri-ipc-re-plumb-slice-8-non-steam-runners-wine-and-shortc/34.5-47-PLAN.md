Close two of gap cycle 6's Cluster 3 residues, both of which are "the backend succeeded and the
frontend did not tell the truth about it":

**Defect A (F-34.5-G6-14 / U-34.5-08)** — `GlobalState.tsx:1087` defaults `origin = 'unknown'`.

there. **Exactly nine** production call sites live outside that file and pass none. So long as any

after this plan, `origin=unknown` is reachable only from outside `src/frontend/`, so if it survives
the next live session it has *identified itself* as a non-frontend emitter — the two standing
candidates being `main.ts`'s `sendFrontendMessage('refreshLibrary')` and
`shellFilesFlowRegistration.ts`'s `pushFrontendMessage('refreshLibrary')` (both already named in
`GlobalState.tsx`'s own header comment at L60-L68), plus the `refresh not implemented on Sideload

the Library half.
