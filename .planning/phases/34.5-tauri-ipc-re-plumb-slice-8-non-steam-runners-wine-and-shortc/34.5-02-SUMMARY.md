# Phase 34.5 Plan 02: Host-Anchor nile's OAuth Redirect Matcher Summary

**nile's `matchOAuthRedirect` now rejects any `openid.oa2.authorization_code` not sourced from `www.amazon.com`, closing T-34.4.1-44b and leaving an origin-only log line for live-gate falsification of Assumption A1.**

## Accomplishments
- `nile` case in `matchOAuthRedirect` now checks `parsed.hostname !== 'www.amazon.com'` before reading the authorization-code param, matching the `legendary`/`gog` sibling cases' host-anchored shape — three consistent host-anchored cases in the switch.
- Added an origin-only evidence log (`logWarning` with `parsed.origin` only) that fires exactly when a rejected candidate carries the `openid.oa2.authorization_code` param, giving live-gate item 3 a way to confirm or falsify the `www.amazon.com` anchor against one real redirect without ever logging the code itself.
- Retired the old host-free comment block; replaced it with one recording the obligation's closure for nile, zoom's void status (D-02), the anchor's MEDIUM-confidence provenance, and the correct remediation path (documented suffix match, not anchor removal) if a country-TLD variant surfaces.
- Extended `oauthLoginCapture.test.ts` from 36 to 42 assertions (6 new, 0 deleted): a positive match on `www.amazon.com`, an attacker-controlled origin (`evil.example`), a suffix-confusion origin (`amazon.com.evil.example`), the near-miss `amazon.com` (no `www.`) explicitly flagged as the case live-gate item 3 may falsify, a no-code-param negative, a spy-based assertion that the evidence log fires once and never contains the captured code value, and a guard re-running `legendary`/`gog` positive assertions to catch any future regression to this switch.

## Decisions Made
- Kept the anchor as an exact hostname match (`www.amazon.com`), not a pathname constraint — upstream nile's `openid.return_to` is the bare origin, so a pathname check would be an invented constraint not present in the source of truth.
- The evidence log intentionally only fires on "param present, origin wrong" rather than every navigation event, keeping the log path meaningful and easy to grep during the live gate rather than noisy.
