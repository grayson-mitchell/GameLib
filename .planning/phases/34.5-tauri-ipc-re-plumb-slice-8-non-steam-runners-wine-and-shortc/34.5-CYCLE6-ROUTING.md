# Phase 34.5 — gap cycle 6 routing and scope fence

This file is the **binding scope fence for gap cycle 6**, recorded at planning time from four
operator decisions taken 2026-08-11. The planner, the plan-checker and every executor read this
file. Where it conflicts with an older cycle's routing document, **this file wins for cycle 6
only** — it does not rewrite the record of cycles 3, 4 or 5.

## Why there is a cycle 6

Phase 34.5's blocking live gate has run three times (`34.5-LIVE-GATE.md`,
`34.5-LIVE-GATE-RERUN.md`, `34.5-LIVE-GATE-RERUN-2.md`) and returned **FAIL, 0 of 5 clean**, every
time. Per **D-08's no-partial-pass rule** the phase does not close on a partial result, and a FAIL
routes to another gap cycle inside 34.5 — never to a deferred UAT entry, an advisory note, or a
pre-authorised override.

A partial UAT (`34.5-UAT.md`, 2026-08-03, `status: partial`) then ran against the ~30 ported
channels no gate item exercises. It recorded 6 pass / 2 issue / 8 pending / 6 blocked and **5 new
gaps**, and it is explicitly **not** a phase-closing artifact.

### Cluster 4 — EOS dishonest degradation

The EOS overlay panel renders "not installed", offers an Install button, shows an installing state
with a Cancel button, and reverts on cancel — **while making zero backend calls**. `grep -ic -E
"eos|overlay"` across the entire session log returns **0**: not one EOS line and, decisively, not
one `[GAMELIB_UNPORTED_CHANNEL]` rejection for any of the 8 deferred EOS channels. The cancel click
then produced `Aborting not possible. Could not find a matching abort controller for
98bc04bc842e4906993fd6d6644ffb8d` — nothing to abort, because nothing started.

This **falsifies, at the UI layer**, `34.5-PORTED-CHANNELS.md`'s claim that deferring means "let it
reject and declare it honestly": nothing rejects and nothing is declared. Plan 34.5-13's SEAM
Invariant B test proves only that the 19 names are **absent from the registries** — not that the UI
ever **calls** them. **Both statements are true and do not contradict each other**, which is exactly
why that test could not catch this class of defect, and why a new assertion must target the call,
not the registry.

The correct behaviour exists in the same session and is the model to copy: `[WebView] in-app
store/wiki browsing unavailable under Tauri (pathname=/store/gog) -- tracked as its own deferral
(D-05)` — it names itself, names its deferral, and declines visibly.

The operator's own read ("this seems ok for transition") is reasonable from the UI alone, **and that
is the defect**: it is indistinguishable from a working install that happens to be cancellable.

**SteamGridDB artwork (the remaining 5 deferred channels) was never exercised** — it is reached

## Standing rules this cycle inherits

1. **Ledger Rule 1 — a row retires ONLY by the observation named in its own cell**, never by a
   passing test suite and never by inference from a neighbouring row. Cluster 2 contains two live
   temptations to break this (the observed non-Steam Wine execution, and the wine-type version now
   on disk). Both are evidence *for a future attempt*, not substitutes for one.
2. **Ledger Rule 2** — any plan that creates a new untested hole adds its row in the same commit.
3. **Ledger Rule 3** — the gate contract names every OPEN row its own items would have covered as a
   known hole.
4. **A green suite is necessary and never sufficient.** This phase's live gate has beaten a green
   suite three times. A test that reconstructs the call site rather than importing the production
   wiring is a replica and drifts silently.
5. **A gotcha comment at one call site is not a fix — it is a debt marker for every sibling call
   site until something sweeps them all.** The `publicdir-getapppath-chunking` family reached FOUR
   recurrences that way. `34.5-APP-ROOT-SWEEP.md` is the sweep that should have existed from the
   first recurrence.
6. **Weight test design over explanatory fit.** `f10-diagnosis-process-lesson`: when two readings
   both fit the evidence, build the discriminator. The teardown/unmount hypothesis in this phase's
   own UAT gap was plausible, unifying, and **wrong**.
