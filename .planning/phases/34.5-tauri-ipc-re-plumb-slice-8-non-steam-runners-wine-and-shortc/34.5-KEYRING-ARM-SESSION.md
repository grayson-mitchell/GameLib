## Failure-class section

Authored now, rather than after the fact — three distinct outcomes, and how to tell them apart from
the log alone:

- **`keyring:timeout`** — `bounded_keyring_read` exceeded its bound; the Keychain was reachable but
  the read did not complete in time. This is the class every prior run hit.
- **`keyring:unavailable:...` with `In dark wake, no UI possible`** — the Keychain could not present
  approval UI at all. **A precondition failure, not a product result.** If this appears, the session
  is **ABORTED** and re-run with the screen unlocked; it is NOT recorded as a FAIL of either row.
- **A successful read** — the only outcome that can satisfy `U-34.5-01`'s condition (4).
