**Env-gated, loudly-warned, packaged-build-refused plaintext TokenStore/HumbleSecretStore vault that lets a live gate run skip macOS Keychain prompts for flows that never touch the keyring, wired into bootstrap.ts as an exclusive branch against the real keyring stores.**

## Accomplishments
- `devSecretVault.ts`: a dev-only plaintext secret store, opt-in only via `GAMELIB_DEV_SECRET_VAULT === '1'` (exact match, never truthiness), refused in packaged builds and whenever build kind cannot be determined (reusing `isPackagedSidecar()` verbatim), loudly warning on install/read/write while never logging a secret value, substring, or length, and creating its backing file with owner-only `0o600` permissions reasserted on every write.

## Decisions Made
- Both vault classes read/write through one shared JSON file under `pathShim`'s `temp` resolution (never `userData`), named to contain `dev-secret-vault` so it is unmistakable in a directory listing.
- `installDevSecretVault()` fails closed on three independent axes: env var not exactly `'1'`, `isPackagedSidecar()` returning `true` OR throwing, and the vault file failing to be created/chmod'd to `0o600` — any one of the three refuses installation and logs the refusal (except the unset-env-var case, which is silent by design, matching every other guardrail's own precedent of "the disabled path is silent").
- `bootstrap.ts`'s branch calls `installDevSecretVault()` FIRST and checks its return value before touching either keyring install, specifically so a vault-enabled boot never lets `installSidecarHumbleSecretStore()`'s fire-and-forget `migrateHumbleSecrets()` fire underneath it.
- Task 2's tests live inside `devSecretVault.test.ts` (not a new file) per the plan's declared `files_modified` — the file's logger/pathShim mocks were reworked from full `jest.mock()` replacements to `jest.requireActual`-spread + `jest.spyOn` overrides specifically so the real `../bootstrap` `init()` (needed by Task 2's nested describe block) still resolves `initHeadless`, `registerHumbleFlows`, and `electronStub.app.getPath` for real.
