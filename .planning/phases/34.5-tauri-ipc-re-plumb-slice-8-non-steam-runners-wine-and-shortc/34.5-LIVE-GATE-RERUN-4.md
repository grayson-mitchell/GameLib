## Evidence-handling rule (T-34.5-G6-02, extended for `code_verifier`)

Restated and extended from every prior contract's own version, binding on every Result slot and
every pasted excerpt below. This document lives in a public fork's repository.

**Never paste, in any Result slot or excerpt, any of the following SEVEN value classes** (six
inherited plus a new seventh, added this cycle because `F-34.5-G6-17`/`-20`/`-22` all establish
that this project logs PKCE `code_verifier` material, not merely OAuth `code`):

1. an `access_token` value
2. a `refresh_token` value
3. a cookie value
4. a session identifier
5. an OAuth `code=` value
6. a Steam `userdata` account id
7. **a PKCE `code_verifier` value** (new this cycle)

Quote only the specific log lines an item or precondition names. If a required line contains one of
these values inline, **redact it in place** (e.g. `access_token=<REDACTED>`,
`code_verifier=<REDACTED>`) rather than omitting the whole line — the surrounding structure (which
field was populated, that a value was non-empty) is still evidence; the value itself is not needed
to prove a PASS.

**The mandatory pre-commit sweep**, extended with the seventh value class. Before committing the

**Re-validated at THIS document's own authoring time (2026-08-14) against 4 safe specimens and 4

## Dual-sink evidence-capture standard (Section 3 of `live-gate-contract-authoring.md`, reproduced in full as binding instructions)

- **One session directory per gate run**, created ONCE before the first launch, named with a UTC
  timestamp: `mkdir -p /tmp/gamelib-gate-$(date -u +%Y%m%dT%H%M%SZ)/`.
- **The terminal transcript is APPENDED, never truncated.** `tee -a <session-dir>/terminal.log` into
  a single session-scoped file for every launch. **Never a bare `tee`, never a `>` redirect.**
- **A delimiter line before each launch**, exact text: `echo "=== GATE LAUNCH ${N} —
  $(date -u +%Y-%m-%dT%H:%M:%SZ) ===" | tee -a <session-dir>/terminal.log`, so a reader can
  `grep -n '^=== GATE LAUNCH'` to find each launch's section boundary.
- **`gamelib.log` archived per launch**, `cp ~/Library/Logs/GameLib/gamelib.log
  <session-dir>/gamelib-launch-${N}.log`, taken **before the next launch's first write renames it
  to `.old`** (`src/backend/logger/log_writer.ts:72-74`). Archive any pre-existing `.old` file on
  the very first pass too.
- **Every item records which launch ordinal covered it.**
- **A closing inventory**: `ls -la <session-dir>/` plus `wc -l <session-dir>/*`, run at session end,
  so a missing or zero-length capture is visible immediately.
- **Exactly ONE app instance for the whole run — asserted, not assumed.** Before EVERY launch:
  `pgrep -f 'target/debug/gamelib-shell'` must be EMPTY. After the window appears, record the
  single PID into the transcript. At teardown, record it again. **If the count is ever not 1, the
  launch is ABORTED and re-run — its evidence is not scorable.**

**Sink partition, stated explicitly so no clause below demands a line from a sink that cannot carry
it:**
- Rust `[shell]`-prefixed `eprintln!` lines (e.g. the banner-injection confirmation lines, item 1's
