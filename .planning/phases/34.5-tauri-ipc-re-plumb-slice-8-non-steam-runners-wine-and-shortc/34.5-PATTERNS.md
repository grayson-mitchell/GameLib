**Analog:** itself (`src/backend/sidecar/pathShim.ts`, full file — 61 lines, already read in full)

**Current shape to match exactly** (lines 45-60):
```typescript
export function getPath(name: string): string {
  switch (name) {
    case 'appData':
      return resolveAppDataDir()
    case 'userData':

    case 'temp':
      return tmpdir()
```

that needs an explicit guard (env var may be unset), and RESEARCH.md's Pattern 1 gives the exact
shape to add (see next excerpt) — it still ends in the same throw-loudly convention, just reached
via an `if` instead of via `default`.
