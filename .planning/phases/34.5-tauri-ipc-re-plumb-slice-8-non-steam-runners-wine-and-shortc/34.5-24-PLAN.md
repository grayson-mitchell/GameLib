## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| remote login page → `event.url` → `gamelib.log` | Navigated URLs are attacker/remote-controlled and carry OAuth authorization codes in query strings |
| environment → user-agent → remote site | An operator-supplied UA string is forwarded verbatim to a live storefront |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-34.5-G6-11 | Information disclosure | the new `nav host=` log line | mitigate | Log `new URL(event.url).hostname` ONLY — never origin+path, never `search`, never `href`. A dedicated test asserts a `?code=SECRETVALUE` event leaves no trace of `SECRETVALUE` in any logged string |
| T-34.5-G6-12 | Spoofing | `GAMELIB_OAUTH_UA_LEGENDARY` | accept | An environment variable is only settable by a process already running as the user, who can edit the source anyway. It cannot widen the redirect matcher, which stays host-anchored (`localhost` for Epic, REQ-34.5-02's `www.amazon.com` for nile). Empty/whitespace falls back to the default so it cannot produce the token-less UA the spike record forbids |
| T-34.5-G6-13 | Repudiation | UA override in effect but unrecorded | mitigate | An override emits a `user-agent-override len=` line, so a later reader can tell which arm produced a given log; length-only, matching the house pattern for remote-influenced strings |
| T-34.5-G6-SC | Tampering | npm/cargo installs | mitigate | This plan installs no packages. Any install requires `slopcheck` plus a blocking human checkpoint first |
