## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| sidecar → Steam shortcut VDF | A value written here becomes a command Steam executes, outside this app's control |
| sidecar → macOS `.app` `run.sh` | A value written here becomes a command Finder executes |
| Rust shell → sidecar (`GAMELIB_SHELL_EXE`) | The single source of the value crossing both boundaries above |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-34.5-39 | Tampering | an empty or unset `exe` interpolated into a Steam VDF `Exe` field | mitigate | `pathShim` throws loudly (plan 34.5-01); this plan adds no catch, fallback or default; and the test asserts NO file is written on the unset and empty paths, verified against the filesystem rather than the promise state. |
| T-34.5-40 | Tampering | the node interpreter written as the launch command | mitigate | Test asserts the written `Exe` value differs from `process.execPath` — D-10's explicitly rejected alternative. |
