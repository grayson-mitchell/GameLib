<interfaces>
New IPC channel (install family, src/common/types/ipc/install.ts):
- args: `getSteamUpdateInfo: z.tuple([nonEmptyString(), optionalArg(z.strictObject({ computeSize: z.boolean() }))])`
- return: `Promise<SteamUpdateInfo | null>` where (declare in a common types file the renderer can import, next to the IPC types)
  `interface SteamUpdateInfo { kind: 'bridge' | 'registered'; state: 'stale' | 'current' | 'unknown'; installedBuild: string; targetBuild?: string; branch: string; reason?: string; estimate?: { downloadBytes: number; peakBytes: number; oldManifestAvailable: boolean; isEstimate: true; freeBytes?: number }; sizeError?: string }`
Backend: `export async function getSteamUpdateInfo(deps, appId: string, opts?: { computeSize?: boolean }): Promise<SteamUpdateInfo | null>`
  - Non-numeric appId or not an installed Steam game -> null.
  - Uses getLastKnownSteamUpdateState; if none, detectSteamUpdates({appIds:[appId]}) (anonymous, cached; bounded by STEAM_UPDATE_REFRESH_TIMEOUT_MS).
  - estimate: the cached estimate when its targetBuild equals the state's targetBuild. Only when `computeSize === true` AND kind 'bridge' AND state 'stale' does it call estimateBridgeUpdate (explicit user action -> authenticated lease allowed) and fill `freeBytes` from `getDiskInfo(deps, <bridge install root>)` (a getDiskInfo failure leaves freeBytes undefined). Registered games never get an estimate (Steam reports its own sizes).
Context consts from plan 06: 'steam-update-planning', 'steam-update-committing'.
</interfaces>
</context>
