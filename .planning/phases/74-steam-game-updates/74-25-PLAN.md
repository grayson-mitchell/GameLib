<objective>
Finish WR-09 (review WR-01): a transient failure to get the old manifest's request code from Node
still degrades to `ManifestUnavailable`, which `is_definitive_old_manifest_failure` treats as
definitive, so a CM blip turns a 1 GB delta into a whole-install SHA reconcile and leaves retired
depots' files behind. Also correct the `max_download_bytes` doc comment (IN-02, Rust half; the UI
copy half is in 74-28).

The ambiguity is end to end: the Node handler returns `null` both when Steam gave no code and when
its own call threw (`depotHostRegistration.ts` catch -> `return null`), and the crate maps every
non-Blocked host error to `Ok(None)` too. Both ends change.

Purpose: D-14 fallback is for a definitively unavailable old manifest only; D-16 says a failure
leaves the old build intact and resumable.
Output: a tagged Node failure reply, shell translation, crate classification, a fallback test.
</objective>
