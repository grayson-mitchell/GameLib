<objective>
Productionise spike 076's chunk-level delta inside `gamelib-depot`: a new `delta.rs` that, for a
`mode: install` job whose `DepotRef.fromManifest` carries the installed GID, plans against the old
manifest, reuses SHA-1-verified local chunks, fetches only the rest from the CDN, builds changed
files as temps beside the old tree, then commits (rename, delete removed, apply modes, finalize ACF).

Purpose: STEAM-02 needs GameLib to update bridge games itself; Phase 73 reserved `fromManifest`
and refuses it. This plan lifts the refusal for the supported shape and adds the wire fields later
TS plans consume (`retiredDepots`, the `stage` event, `Outcome.delta`).

Output: `delta.rs`, routing in `download.rs`, wire additions in `job.rs`/`events.rs`/`outcome.rs`,
`tests/delta.rs`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CDN/manifest -> crate | Manifest filenames, symlink targets and chunk bytes are untrusted network input |
| Install root on disk -> crate | Old files may be modified, corrupt, or symlinks planted in the tree |
| Sidecar -> crate (job JSON) | fromManifest/retiredDepots ids are parsed from the wire |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-74-01 | Tampering | delta.rs path handling (work set, temp, rename, delete) | mitigate | Every read/write/rename/delete path goes through `post::resolve_contained_path`; `../` names fail as path_traversal (test delta_traversal_rejected). Fixes the spike's `root.join(filename)` hole |
| T-74-02 | Tampering | symlinks in old tree used as chunk sources or delete targets | mitigate | Candidate reads skip symlinks via symlink_metadata; deletes remove the link, never the target; manifest symlink targets go through `check_symlink_target` |
| T-74-03 | Tampering | reused local chunk bytes | mitigate | SHA-1 at plan time AND re-checked at build time (TOCTOU); temp verified against sha_content before rename |
| T-74-04 | Tampering/DoS | removed-file deletion | mitigate | Delete only old-manifest-owned paths absent (case-folded) from every new manifest; unowned files never touched (test delta_keeps_unowned_and_unchanged_modified) |
| T-74-05 | Info disclosure | new logs/events | mitigate | No DepotRef/key/request code logged; Stage/Warning messages carry no tokens; redacted Debug only |
| T-74-06 | Tampering | wire ids (fromManifest, retiredDepots) | mitigate | Numeric-id and 64-hex key validation in DepotJob::validate before any path or network use |
</threat_model>
