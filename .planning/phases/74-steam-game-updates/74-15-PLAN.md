<objective>
Close the two update-correctness blockers in TypeScript. WR-01: `retired = installed minus selected`
deletes content the new build still has (DLC, language, OS, skipped-for-EResult-40 depots) and
fetches the retired key with the base app id. WR-06: when the abort signal fires as Rust returns a
committed delta, install.ts rewrites the outcome to cancelled, so the shim re-handover, redists,
DRM verdicts and cache invalidation are skipped on an already-updated tree.

Purpose: an update must never destroy content the user keeps, and a committed update must finish
its follow-ups (the shim may already be replaced by the new genuine DLL).
Output: a branch-aware retire rule with real owners, and committed-wins outcome mapping.
No new user-facing strings in this plan.
</objective>
