<objective>
Close the backend half of the UAT 23 signed-out blocker. Under Tauri `SteamLibraryManager.init()`
is never called (library/index.ts:192-193), so the backend `libraryState.library` map is only
filled by a full authenticated sync in `refresh()`. Signed out, `refresh()` bails at
library/refresh.ts:80 (granted) or in `refuseDeferred` (ungranted), the map stays empty, launches
and `detectSteamUpdates` (which iterates that map) see nothing, and the boot logs
`update check apps=0`. Restore the cached library plus local install state on every non-sync
exit so installed games stay usable and update detection (anonymous PICS) runs over them.

Purpose: installed Steam games must list, launch and get update checks while signed out of Steam
in GameLib (todo 2026-11-13-installed-steam-games-hidden-when-signed-out). The frontend half
(visibility filter, sign-in update check) is plan 74-32.
Output: library/localLibrary.ts, refresh.ts wiring, tests.

Scope decision (planner discretion, recorded): the restore seeds from the persisted library cache
of the last successful sync and reconciles install state from ACFs; it does not enumerate
installed ACFs that were never in an owned-apps sync. A signed-out profile always had a prior
sync (sign-out requires a sign-in), and every bridge install needs a signed-in session, so every
installed owned game is in the cache. Enumerating ACF-only apps would surface Steamworks
redistributables (appid 228980) and similar non-games; the never-synced limitation is already
recorded in src/frontend/screens/Library/steamLibraryVisibility.ts's header.
</objective>
