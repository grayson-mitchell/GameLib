through OldIndex), so "Download up to 6.6 GiB" showed for a 0.9 GiB Manor Lords update. In TS a
depot with no old GID is skipped, so its bytes are missing from download and peak and the disk check
can pass wrongly.

Purpose: an honest estimate that does not deter updates and does not under-count disk.
Output: corrected Rust estimate and TS aggregation, with tests. No new user-facing strings.
</objective>
