<decisions>
- Scope of kinds: bridge = `findBridgeInstallBottle(deps.paths, appId) !== null` (bridgeBottle.ts:136); registered = an ACF found in the native Steam library roots (`readAcfUpdateState(deps, appId, 'native')`). Phase 17 GameLibSteam bottle installs are neither: the bottled Windows Steam client owns their updates, so they are not returned (no badge). Recorded as a scope note in the SUMMARY.
- Candidate set: installed entries in `deps.steamSession.libraryState.library` (is_installed true), optionally narrowed by opts.appIds.
- Branch for bridge = `readAcfBetaKey(steamappsDir, appId)` else 'public'. Do NOT use `chooseInstallBranch` (it falls back to public; detection must return unknown).
- Registered PICS cross-check only when `listSteamClientPids(deps)` returns an empty array (Steam definitely not running). `undefined` (unknown) means ACF only.
- The registered-pending predicate deliberately does not treat a bare non-zero BytesToDownload as stale: Steam leaves counters from the last download in an up-to-date ACF. ScheduledAutoUpdate counts only together with BytesToDownload > BytesDownloaded. TargetBuildID "0"/absent never counts. The live gate (plan 13) records the real flags.
- Cache: results stored in `deps.steamInstallRuntime.updateStates`; a bridge app's PICS answer is reused while younger than STEAM_UPDATE_PICS_TTL_MS unless `force`. ACF reads are never cached (they are local and cheap).
</decisions>
