job.rs `DepotSummary` gains:
  `#[serde(default, skip_serializing_if = "Option::is_none")] pub delta: Option<DeltaEstimate>`
and a new struct (camelCase on the wire):
  `pub struct DeltaEstimate { pub old_manifest_available: bool, pub changed_bytes: u64, pub max_download_bytes: u64, pub changed_files: u64, pub removed_files: u64 }`
  - old manifest available: changed_bytes = sum of work-set file sizes (compute_work_set.changed);
    max_download_bytes = sum of cb_compressed over the UNIQUE chunk SHAs of the work set (local reuse
    can only lower it); changed_files = work-set count; removed_files = removed_paths count for this depot.
  - old manifest unavailable (D-14): old_manifest_available false, changed_bytes = size of the largest
    single new-manifest file (the reconcile path rewrites one file at a time; confirm against how
    download.rs writes a file and use the true per-file peak), max_download_bytes = sum of cb_compressed
    over all unique chunk SHAs of the new manifest, changed_files = new regular-file count, removed_files = 0.
  - fromManifest None: `delta` is None and the summary is byte-identical to today.
  - fromManifest equal to manifestId: delta Some with zeros.
ManifestStore::prune signature becomes `pub fn prune(&self, depot_id: &str, keep_gid: &str, protected: &[&str])`.
