# Phase 66.1 Code Review

## Critical

### A-CR-1: boot System Information dump adds ref'd, unbounded, untracked boot work (exit-contract violation) — FIXED in 2e911b4e3
`src/backend/logger/index.ts:151-165`, called from `sidecar/bootstrap.ts:1220` (66.1-22g). Pre-66.1 `initHeadless()` deliberately skipped the dump ("can outlive a short-lived caller"). Now every boot runs `getGpuInfo/getOsInfo` → `genericSpawnWrapper` (bare `child_process.spawn`: no unref, no timeout, untracked — lspci/powershell/df), `getCometVersion` → `spawnSync` with no timeout in a microtask (blocks the event loop/RPC frames), and the runner `--version` probes with `timeout: none`. A hung Windows `Get-CimInstance` holds the sidecar past stdin EOF. The 22g docblock claims "no added work … runner unrefs every child", which is false. **Fix:** do not fetch at boot (lazy on first `getSystemInfo` RPC or a non-boot trigger); if kept, route all probes through `runner.run({ timeoutMs })`; correct the docblock.

- **A-WR-1** `process/runner.ts:183-189,251-265`: `run()` never settles if the child exits and a grandchild holds the pipes.
