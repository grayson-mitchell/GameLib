## Pattern Assignments

### `process/runner.ts` + `process/types.ts` (Plan 01: C-02 fixes and caller capabilities)

**Analog:** the shipped runner itself. Plan 01 edits only these ranges, so no caller plan touches `process/`.

**WR-01 drain-grace site** (`runner.ts:177-207`). Today `finish` is wired as `child.on('close', finish)` (plus `'exit'` if `resolveOn==='exit'`). Add the grace here, with `deps.clock` (unref'd) not a bare timer:
```typescript
const finish = (code: number | null, signal: NodeJS.Signals | null): void => {
  if (settled) return
  settled = true
  deps.clock.clear(timer)
  resolve({ code, signal, stdout, stderr, timedOut, aborted, truncated, pid: child.pid })
}
...
if (resolveOn === 'exit') child.on('exit', finish)
child.on('close', finish)
```
Target shape: on `exit` when `resolveOn==='exit' || timedOut || aborted`, `deps.clock.setTimeout(() => { child.stdout?.destroy(); child.stderr?.destroy(); finish(code, signal, /*drainTimedOut*/ true) }, DRAIN_GRACE_MS /*250*/)`; clear on `close`. Also untrack on `exit` for the cut-short path (the registry untracks on close/error only; see `registry.ts:26`).

**WR-02:** `capture()` at `runner.ts:151-162` already increments `outBytes`/`errBytes` for dropped chunks, so no splice can occur. Change only readability (explicit per-stream `stopped` flag) and add the regression test.

**WR-03:** `killPid` at `runner.ts:84-94` discards the `taskkill` result and returns `true`:
```typescript
runSync('taskkill', ['/PID', String(pid), '/T', '/F'], { timeoutMs: 5_000, reason: '...' })
...
return true
```
Fix: `const r = runSync(...); return r.code === 0 && !r.error`. `runSync` at `runner.ts:64-72` passes no `maxBuffer`; add `maxBuffer: DEFAULT_MAX_BUFFER_BYTES` (const at `runner.ts:34`).

**No-timeout opt-out** (RESEARCH A1). `runner.ts:118-121`:
```typescript
const timeoutMs = opts.timeoutMs ?? DEFAULT_RUN_TIMEOUT_MS
if (!positiveFinite(timeoutMs)) throw new TypeError('run requires a positive finite timeoutMs (D-10)')
```
Mirror the existing mandatory-reason idiom of `TimerOptions.keepAlive` (`types.ts:10-12`) and `RunSyncOptions.reason` (`runner.ts:61-63`: non-empty `reason` or `TypeError`). Add `RunOptions.timeout?: { none: true; reason: string }`, skip arming the timer when present, validate the reason with the same `trim().length === 0` check.

**ChildHandle** (`types.ts:29-32`) is `{ pid, kill }`; `handleOf` at `runner.ts:106-111` builds it. Add getters there:
```typescript
function handleOf(child: ChildProcess): ChildHandle {
  return { pid: child.pid, kill: (signal) => child.kill(signal),
           get exitCode() { return child.exitCode }, get signalCode() { return child.signalCode } }
}
```
The scripted runner's `noChild` (`scriptedRunner.ts:41`) must grow the same two fields.

**Test pattern for plan 01** (copy from `process/__tests__/runner.test.ts:1-60`): real runner with `createFakeHomeProfile()` + `make({ clock })`, `NODE = process.execPath`, `afterEach(() => { runner.killAllTracked(); profile.dispose() })`. For WR-01 use `createRealRunner()` (`testUtils/realRunner.ts:20-55`) with the RESEARCH grandchild script; assert `Date.now()` elapsed under 2,000 ms and `timedOut: true`.

## Shared Patterns

### D-03 factory shape (no `deps = defaultDeps`)
**Source:** `process/context.ts:30-52` (`createAppContext(input)`), `process/runner.ts:42` (`createProcessRunner(deps: ProcessRunnerDeps)`), `process/registry.ts:26,74` (`createTrackedRegistry(deps)`, `createTeardownRegistry(deps)`).
**Apply to:** `createStores`, `createStoreManagers`, `createCommandRunner`, `createLauncher`, `createSpawnAsync`, `createQuitHandler`, every `registerXFlows`. A narrow `deps` interface typed from `AppContext` fields (`runner: AppContext['runner']`); never the whole context, never `getContext()`.

### One boot per test, fake context, no module mocks
**Source:** `sidecar/__tests__/helpers/sidecarHarness.ts:103-146`, `testUtils/testContext.ts:28-66`.
**Apply to:** every sidecar test touched in Plans 03, 05-07; replaces `jest.mock('backend/storeManagers')` (55 calls), store mocks (102) and `child_process` mocks. New tests that need a spawn use `createScriptedRunner` / `createRealRunner()` only.

### Ratchet: lower in the same commit, shard-scoped
**Source:** `meta/backendDiCeilings/<shard>.json` (e.g. `storeManagers.sideload.json` is `{"moduleState": {"src/backend/storeManagers/sideload/stores.ts": 1}}`), checker `node meta/backendDiCeilings.cjs --shard <name>`.
**Apply to:** each plan per the RESEARCH "Ceilings map". An entry whose file is deleted or reaches zero must be removed (stale entries fail). A new test file with `jest.mock` fails with "new violation ... no baseline entry"; `jest.doMock` is an uncounted loophole that must not be used.

### Import budget header on new leaf files
**Source:** `process/types.ts:4-7`, `process/context.ts:10`, `process/runner.ts:16`.
**Apply to:** `stores/storeRegistry.ts` (Node builtins and its own types only), `launcher/commandRunner.ts` (runner type plus injected functions only; no `backend/utils`/`config`/`logger` to avoid the SCC and the `runner-is-a-leaf` rule if it ever sits under `process/`).

### Exit contract
**Source:** `process/runner.ts:9-12`, CLAUDE.md convention 3.
**Apply to:** boot steps (`register-handlers`, `stores`, `store-managers`), the C-04 replacement, comet/helper spawns. `unref()` every handle; no unbounded in-flight work at boot. Verify with `pnpm build:sidecar && pnpm smoke:sidecar`.

### Fake-HOME rule
**Source:** `testUtils/realRunner.ts:20-55`, `fakeHomeIsolation.test.ts`.
**Apply to:** any plan test that really spawns (Plan 01 WR-01/03, Plan 02 Layer 2 real-child cases, `spawnAsync` real case). No hand-rolled `env`; no real-profile arm without a named defect.
