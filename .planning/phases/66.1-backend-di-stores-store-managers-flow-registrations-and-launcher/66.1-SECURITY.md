## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| sidecar -> child processes | runner spawns argv-only children (store CLIs, wine, comet, bridge helper, installers) | argv with credentials, env, paths |
| renderer -> RPC handlers | handler args (appName, runner, store names, settings) are renderer-supplied | untrusted strings |
| sidecar boot -> token-bearing stores | steam/gog/legendary/nile/humble config stores | refresh/access tokens |
| OS -> protocol handler | gamelib:// URLs | untrusted URL |
| sidecar -> logs | runner command lines in app and per-game logs | credentials (must be redacted) |
| test -> real children | real spawns under fake HOME | operator profile |
| operator machine -> real accounts | live UAT | real logins |
