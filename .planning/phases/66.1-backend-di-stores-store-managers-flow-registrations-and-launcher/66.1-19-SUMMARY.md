# Phase 66.1 Plan 19: Shared-module store reads on slices Summary

`config.ts`, `utils.ts`, `recent_games`, `nonesteamgame` and `appshell/language` no longer import `key_value_stores`, `wine/manager/stores`, `wiki_game_info/stores` or any `storeManagers/*/stores`; they take the slice by parameter (R3).

## What changed

- `GlobalConfig.setSetting(key, value, { configStore })`, `getAlternativeWine({ wineDownloaderInfoStore }, scanCustom)` (abstract signature updated too).
- `utils.ts`: `clearCache(deps, library?, fromVersionChange?)` (exports `ClearCacheDeps`), `clearAchievementCache(deps, appName)`, `detectVCRedist(deps)`, `downloadDefaultWine(deps)`, `checkWineBeforeLaunch(deps, ...)`, `writeConfig(deps, appName, config)`. `execAsync`, the VC probe spawn and `wineserver -k` untouched (A2); one `child_process` import remains.
- `recent_games`: `getRecentGames/addRecentGame/removeRecentGame/setRecentGames` take `RecentGamesDeps`. `addNonSteamGame` takes `NonSteamGameDeps` (tsStore). `changeLanguage(deps, language)`.

settingsFlowRegistration (setSetting + writeConfig, `registerSettingsFlows({ stores })`), wineToolsFlowRegistration (`WineToolsFlowDeps.stores`), appshell/language, steamgrid/secretStore (3, via constructor deps), sidecar/steamgridSecretStore (migration, `installSidecarSteamGridDbSecretStore(deps)`), storeManagers/steam/installFormIpc (`persistInstallFormWineVersion(deps, input)`), utils.ts downloadDefaultWine/checkWineBeforeLaunch. GameConfig.setSetting call sites are unrelated and unchanged.

- `checkWineBeforeLaunch(deps, ...)`: callers gog/nile setup (`SetupDeps` gains `stores`; `nileSetup(deps, appName, path)`), steam `provisionBottle(deps, opts)`, launcher.ts via transitional `legacyWineStores()` (plan 23 deletes).
