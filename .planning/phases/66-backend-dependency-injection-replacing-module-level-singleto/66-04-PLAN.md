<interfaces>
Current harness (`src/backend/sidecar/__tests__/helpers/sidecarHarness.ts`): static `import { init } from '../../bootstrap'`;
exports `Frame`, `startSidecar(): { input: PassThrough; frames: Frame[] }` (calls `init(input, output)`),
`writeInvoke(input, id, channel, args)`, `writeSend(...)`, `findResponse(frames, id)`; private `collectFrames(stream)`.
13 files use `startSidecar` (66-05/06/07/09 migrate them); keep it working unchanged in this plan.

New export (this plan):

```typescript
export interface FreshSidecar { input: PassThrough; output: PassThrough; frames: Frame[] }
export function bootFresh(opts?: { before?: () => void }): FreshSidecar
// 1. jest.resetModules()   2. opts.before?.()   3. const { init } = require('../../bootstrap')
// 4. init(input, output)   5. return { input, output, frames }
```

Backend jest project has `resetMocks: true` (src/backend/jest.config.js:11): jest.fn implementations
reset before each test; `jest.mock` factories re-run per registry after resetModules, so a mock imported
at file top is a DIFFERENT object from the one the freshly required bootstrap sees.

Migration recipe per file (apply mechanically, preserving every behavioural assertion):
- Delete `import { init } from '../bootstrap'`.
- Replace top-level imports of modules the test inspects after boot (e.g. `handlerRegistry`/`listenerRegistry`
  from `../../platform`, `axios`, logger functions) with `let` bindings assigned inside the test or a
  `beforeEach` right after `bootFresh()` via `require(...)`; keep `import type` for types.
- Mock configuration that must be in place before boot (e.g. `mockResolvedValue`, `GlobalConfig.get` returns)
  goes into `bootFresh({ before: () => { ... require(...) ... } })`.
- A test that called `init()` N times to prove a once-guard becomes: one `bootFresh()`, then assert the
  wiring happened exactly once (listener count 1, spy called once). Name it "one boot ... exactly once".
  The "second init() throws" assertion is added in 66-08, not here.
- `jest.mock(...)` factory calls at file top stay (hoisted; they apply to every registry).
