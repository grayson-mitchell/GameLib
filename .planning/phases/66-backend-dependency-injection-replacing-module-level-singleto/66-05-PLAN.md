Migration recipe (same as 66-04):
- Remove `import { init } from '../bootstrap'` and `startSidecar` usage; boot with `bootFresh()` once per test case
  (in the test body or a `beforeEach`).
- After the boot, obtain every module the test inspects or reconfigures with `require(...)` (the fresh
  registry); top-level imports of mocked modules are stale after `jest.resetModules()`. Keep `import type`.
- Configuration that must precede boot goes into `bootFresh({ before: () => { ... } })`.
- A test that booted N times to prove "only once" becomes one boot plus an exactly-once assertion.
- A test that needs two boots (e.g. comparing two process lifetimes) becomes two test cases.
- `jest.mock(...)` factories stay at file top.
