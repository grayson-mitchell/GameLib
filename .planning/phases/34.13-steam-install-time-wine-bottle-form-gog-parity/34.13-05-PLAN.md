<objective>
Create the pure, SCSS-free module that turns the UI-SPEC Section-Gating Matrix into executable,
Jest-provable logic — the trigger predicate (does the Steam install form open at all?) and the
section verdict (which of platform row / library dropdown / wine section / free-space line renders,
and what state the platform row is in).

Purpose: this repo has **no jsdom and no react-test-renderer** (`34.13-VALIDATION.md`, hard
constraint). A test that imports any `.tsx` dialog dies at `import './index.scss'` before the first
assertion. This module is therefore the ONLY part of the Section-Gating Matrix that Jest can prove,
and it is the reason it exists as a separate file rather than an if/else chain inside
`SteamDialog/index.tsx` and `InstallModal/index.tsx`.

The failure this plan exists to prevent: a matrix `NO` row silently flipping to `YES` reverses
Phase 21's locked decision D-09 (zero-friction install for a 0/1-library setup). Nine of the sixteen
rows are `NO` rows. A partial or vacuous matrix test is the single highest-risk defect in this phase.

Output: two files — the module and its exhaustive test. **Zero consumers are wired in this plan.**
34.13-08 consumes `steamInstallFormOpens()`; 34.13-10 and 34.13-12 consume
`resolveSteamSectionGating()`. Do not edit any dialog, store, or backend file here.
