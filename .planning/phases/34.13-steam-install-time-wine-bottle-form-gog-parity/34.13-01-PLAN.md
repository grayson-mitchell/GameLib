| T-34.13-02 | Information Disclosure | `SteamBottleEligibilityVerdict.wineVersion` carries a `WineInstallation`, whose `bin` field is an absolute host filesystem path, toward the renderer | accept | No new class of data crosses the boundary. `WineInstallation` objects — including `bin`, `lib`, `lib32`, `wineserver` paths — are already returned to the renderer wholesale by the existing `getAlternativeWine()` and `requestAppSettings()` channels, which `InstallModal` and `SteamBottleSetup.tsx` both already consume.
