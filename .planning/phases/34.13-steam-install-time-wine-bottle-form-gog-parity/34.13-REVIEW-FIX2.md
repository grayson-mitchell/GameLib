## Notes on method

**No worktree was used, deliberately.** The system prompt's `setup_worktree`
step conflicts with two hard constraints here: this repo's
`.husky/post-checkout` hook runs a download that fails deterministically
(making every checkout-family command destructive), and the fenced files'
value is entirely in their **uncommitted** state, which a fresh worktree would
not carry. I worked in the main tree and staged every commit by explicit path.
`git status --porcelain` was checked before each commit; no `git add -A`,
`git stash`, `git checkout --`, `git reset` or `git restore` was ever run.

**RED proofs used real sources, never replicas.** Where I needed a pre-fix
specimen I produced it with `git show HEAD:<path> > <path>` (a redirect, not a
checkout) and restored from a scratchpad copy, or by mutating the real source
text in-test. No known-bad input in this pass is hand-written.

**One class of collateral damage worth naming:** four pre-existing gates broke
during this pass for **formatting** reasons alone, after `prettier --write`
reflowed the statements they were reading line-by-line
(`steamBottleSetupSeeding`'s guard, `installModalSource`'s two, and
`steamEligibilityProbe`'s IPC census). Each reported a scary behavioural
failure ("the IPC is gone", "guard line not found") for a file whose behaviour
had not changed. All four are now whitespace-insensitive. This is C-12's real
cost and is worth a standing note: **a line-scoped source gate in a
prettier-enforced repo is a gate with a formatting-shaped failure mode.**
