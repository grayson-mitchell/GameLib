## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer -> backend settings read | The toggle writes and reads `AppSettings.alwaysShowSteamInstallForm` through the pre-existing `requestAppSettings` / settings-write channels. This plan adds NO new IPC channel and NO new preload surface. |
| local filesystem -> backend | `GlobalConfig` reads the on-disk global config JSON. The new accessor is one more consumer of an already-trusted local store. |

**No new auth, session, network or crypto surface is introduced by this plan.** The only new data
is one local boolean UI preference. `sanitizeBottleName` / `SAFE_INSTALLDIR` are untouched.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-34.13-04-01 | Tampering | Local global-config JSON — an attacker with local write access flips `alwaysShowSteamInstallForm` | accept | The value's entire effect is whether a confirmation dialog appears before an install the user already initiated. An attacker with write access to the config file already has strictly greater capability than this key confers. |
