<objective>
Accept the installdirs Steam itself produces, and make the rejection path honest.

Purpose: `SAFE_INSTALLDIR = /^[A-Za-z0-9 ._-]+$/` excludes the apostrophe, so installing Sid Meier's
Civilization V logged `rejected hostile PICS installdir "Sid Meier's Civilization V" for appId 8930,
using fallback "app_8930"` and silently redirected 7.2 GB. Measured against REAL installdir values
read from Steam's own `appmanifest_*.acf` files on this machine, **1 of 18** fails (`Len's Island`,
currently installed via Steam), plus Civ V observed live. Do not quote the title-based 36% figure —
Steam strips colons before they reach an installdir, and colons are 108 of those 139 hits. The
apostrophe is the character that actually survives.

Output: acceptability decided by CONTAINMENT against the resolved install root, plus a narrow
explicit denylist as defence in depth; the two fallback triggers split into a security ABORT and a
logged fallback.

**Do NOT simply add `'` to the allow-list.** The check exists to stop a hostile PICS response
directing writes outside the install root. A widening without a RED traversal test trades this
defect for a worse one — that is D-02, and it is also what the todo's own "Test that fails first"
section demands.

**Two filed claims are DISPROVEN — do not act on them:**
1. The todo's "Steam cannot adopt it" argument is WRONG. GameLib writes the *fallback* name into the
   manifest too, so the ACF and the directory AGREE — 3 of 3 fallback installs with a manifest are
   self-consistent. Harms #2 (non-portable layout) and #3 (`app_*` accumulation) stand.
2. The todo's `CORRECTION 2026-08-22` harm #1 is DISPROVEN. `common/Sid Meier's Civilization V`
   contains only `installscript.vdf` dated 2026-07-19 — a STEAM-written file, a month BEFORE
   GameLib's attempt. The other three stubs contain only `.DS_Store` with mtimes from April–May.
   All are Steam-uninstall leftovers; GameLib created none of them. The duplication-risk-by-that-route
   argument falls with it, so no plan task may be justified by it.
3. `app_259130`'s real trigger was NOT the character class. Its installdir `Wasteland` passes
   `SAFE_INSTALLDIR` cleanly; it was produced by the `!candidate` branch, which returns the fallback
   **with no log at all**. Closing that branch is half of D-04 and is a required task here.
