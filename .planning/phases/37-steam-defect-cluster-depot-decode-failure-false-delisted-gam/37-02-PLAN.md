<objective>
Stop the depot error classifier from attributing non-network causes to the network, and move the
"Retry"/"Sign in" affordance out of translated prose into a structured field.

Purpose: A 142-chunk decode failure — every request HTTP 200 — told the user "Steam servers dropped
the connection. Retry to continue." Anyone debugging from that message starts on the network and
finds nothing wrong, because nothing is. An auth abort at 1ms with no stored refresh token told the
user the same thing, and "Retry to continue" is actively harmful there: retrying without signing in
can only fail again.

Output: `classifyDepotError` branches on CAUSE, carries a `DepotErrorAction`, and the auth case
reaches the user with a working "Sign in to Steam" button.
</objective>
