## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| app process -> reaper process | the reaper outlives the app and signals groups the app registered |
| argv -> fn main | anyone can run the GameLib binary with --gamelib-reaper |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-83-27 | Elevation | reaper mode via argv | medium | mitigate | reaper mode only reads its own stdin and signals groups named there (registered by its parent); with no parent writing it reaps nothing; it never starts the app, proven by running the built binary in reaper mode |
| T-83-28 | Denial of Service | startup | high | mitigate | reaper start failure logs `reaper unavailable:` and continues (never `?`, never panic out of did_finish_launching, the SIGABRT history); the live gate asserts the line is absent |
| T-83-29 | Denial of Service (user's game) | sidecar group kill | medium | accept | D-15: on unix a SIGKILL of GameLib now kills TS-launched games too; accepted by the operator for this phase, recorded in SUMMARY, UAT notes and a ready: blocked todo; fixed by Phase 88/95-97 adopting SpawnClass::Game |
| T-83-30 | Information Disclosure | orphaned authenticated helper | high | mitigate | a SIGKILL no longer leaves comet, legendary/gogdl/nile or the mac-owned helper running with a session: the reaper kills the sidecar group and every Rust Helper group |
| T-83-SC | Tampering | dependencies | low | accept | in-repo path dependencies only; no lockfile name added |
</threat_model>
