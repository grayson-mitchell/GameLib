<objective>
Build the unix reaper and prove D-11 (FND-04): after a SIGKILL of the parent, no helper survives on macOS or Linux, a
Game tree does, and the proof cannot pass vacuously (negative control). Also prove D-10's TS-spawned case with a Node
stand-in sidecar on all three OSes.

Purpose: SIGKILL skips every exit path, so only a separate process (unix) or the kernel's Job handle close (Windows,
plan 83-04) can reap. Research Pattern 5 picks a re-exec'd reaper over PR_SET_PDEATHSIG (thread-scoped and cleared on
fork, Pitfall 4) and over a boot-time sweep (D-11: orphans would live until the next launch).
Output: reaper and protocol modules, ChildSet wiring, three new harness legs.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| app -> reaper control pipe | anything that can write to the reaper's stdin can make it signal groups |
| reaper -> OS process table | the reaper signals groups after the app is gone, with nobody to check it |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-83-22 | Elevation / DoS | reaper signalling | high | mitigate | only registered groups are signalled; pgid <= 1 refused at parse and at reap; recycled leaders skipped by start-time check; groups only (never single pids, never names) |
| T-83-23 | Tampering | control pipe | medium | mitigate | the pipe is the reaper's stdin, created by the app with CLOEXEC on the write end (std default) before any other child exists; no other process holds it in normal operation; the protocol has no command that names an arbitrary pid other than a group the app created |
| T-83-24 | Denial of Service | reaper liveness | medium | mitigate | own process group and SIG_IGN for INT/HUP/TERM so a terminal Ctrl-C or group signal cannot take it with the app; getppid() poll covers a leaked write end |
| T-83-25 | Denial of Service (user's game) | reaper scope | high | mitigate | Game-class children are never registered; the SIGKILL leg asserts the game survives |
| T-83-26 | Repudiation | reaper output | low | mitigate | fixed literals with counts only on stderr (`[reaper] parent gone: signalled <n> group(s)`, `[reaper] disarmed`); labels are sanitised; no args or paths |
| T-83-SC | Tampering | dependencies | low | accept | no dependency change (libc and windows-sys were declared by 83-04) |
</threat_model>
