### `src/native_router.rs` (router, request-response + FIFO)

**Analog:** `src/relay_commands.rs`

**Rejection shape and verdict to run first** (`relay_commands.rs:26-35`, constant at `ipc_contract.rs:19`):
```rust
pub(crate) fn relay_channel_verdict(channel: &str) -> Result<(), String> {
    if is_renderer_channel(channel) {
        Ok(())
    } else {
        Err(format!(
            "{IPC_INVALID_CHANNEL_MARKER} channel not allowed: {}",
            echo_channel(channel)
        ))
    }
}
```
`echo_channel` (`:6-22`) cuts to 64 chars and maps non-printable-ASCII to `?`. Reuse it for every log or error that echoes a channel name; never log args (T-34.6-16-02).

**Per-slice FIFO queue: clone this shape** (`relay_commands.rs:162-184`):
```rust
pub(crate) fn spawn_send_writer<W>(write: W) -> Sender<SidecarRpcRequest>
where
    W: Fn(&SidecarRpcRequest) -> Result<(), String> + Send + 'static,
{
    let (tx, rx) = mpsc_channel::<SidecarRpcRequest>();
    thread::spawn(move || {
        for req in rx {
            if let Err(e) = write(&req) {
                shell_eprintln!("[shell] send-trace: write_frame FAILED for '{}': {e}", req.channel);
            }
        }
    });
    tx
}
```
Generic writer closure + one std thread, so tests use a fake with no child process. Register the worker thread's lifetime with `Shutdown`/convention D-14 (a parked std thread does not hold the process open).

**Insert the lookup after the verdict in both commands.** `sidecar_send` is a non-async command (runs on the MAIN thread, must only enqueue; `relay_commands.rs:~119-126` doc, 2026-10-05 freeze). `sidecar_invoke` is `async` and offloads with `tauri::async_runtime::spawn_blocking` (`:39-50`). Current send body to extend (`:134-158`):
```rust
if let Err(e) = relay_channel_verdict(&channel) {
    shell_eprintln!("[shell] relay rejected send: {}", echo_channel(&channel));
    return Err(e);
}
// NEW: if let Some(entry) = router.lookup(&channel, Kind::Send) { return entry.submit_send(args); }
let req = SidecarRpcRequest { id: state.next_id(), kind: "send", channel, args };
queue.0.send(req).map_err(|rejected| { ... })
```

**Rejection rules (RESEARCH Pattern 2, supersedes D-03 wording):**
- Off-allow-list name: unchanged INVALID_CHANNEL (verdict runs first).
- Bad args on native invoke: `Err("[GAMELIB_IPC_INVALID_ARGS] {json}")`, JSON `{code:"IPC_INVALID_ARGS", channel, paths, codes}` (marker and shape verbatim from `src/common/types/sidecarTransport.ts:1271,1281-1291`; sanitising per `src/backend/sidecar/ipcValidation.ts:35-70`, no values or key names). Unmarked text classifies as `fatal` in `src/frontend/bootErrorSurface.ts:43-70`.
- Bad args on native send: log channel name only, return `Ok(())`, drop.
- Handler runtime error on invoke: plain `Err(String)`; never fall back to sidecar (D-04).

**Tests to copy** (`relay_commands.rs:386-437`): `send_writer_enqueue_does_not_wait_for_a_blocked_write` (release-channel gate, 500 ms bound, order `["a","b","c"]`) and `send_writer_keeps_going_after_a_failed_write`. Add: native-send-while-sidecar-send interleave keeps each queue's own order.

### `crates/gamelib-core/src/shutdown.rs`

**Analog:** `crates/gamelib-depot/src/registry.rs:1-45` (`JobDone` condvar wait, runs on the main thread at exit):
```rust
fn wait_until(&self, deadline: Instant) -> bool {
    let mut g = self.done.lock().unwrap_or_else(|e| e.into_inner());
    while !*g {
        let now = Instant::now();
        if now >= deadline { return false; }
        g = self.cv.wait_timeout(g, deadline - now).unwrap_or_else(|e| e.into_inner()).0;
    }
    true
}
```
Poison-tolerant locking (`unwrap_or_else(|e| e.into_inner())`) is the convention. `Shutdown` = `CancellationToken` + registrants (drop = done); `begin(TOTAL=5s)` returns a `Report { still_running: Vec<&'static str> }`. Constants: `TOTAL = 5 s`, `CHILD_GRACE = 1.5 s` (D-16). Keep the log style `[shell] depot jobs still running at exit deadline: {n}` (counts and names only).

## Shared Patterns

### Logging and error hygiene
**Source:** `relay_commands.rs` (`echo_channel`, `shell_eprintln!`), `shell_open.rs` (fixed-literal errors).
**Apply to:** `native_router.rs`, `native_handlers.rs`, `gamelib-proc`. Channel name only, never args or URLs; fixed literal error strings; no panics in exit/setup paths.

### Unsafe + platform gating
**Source:** `sidecar.rs` (`kill_process_group`, `create_kill_on_close_job`). **Apply to:** all `gamelib-proc` code. Every `unsafe` has a `// SAFETY:` comment; `#[cfg(unix)]` / `#[cfg(windows)]` with a deliberate no-op counterpart; refuse `pgid <= 1`.

### Poison-tolerant locks
**Source:** `gamelib-depot/src/registry.rs`, `shell_state.rs:123-129`. **Apply to:** Shutdown, ChildSet, queues: `unwrap_or_else(|e| e.into_inner())` with a logged recovery.

### Never block the main thread
**Source:** `relay_commands.rs` `sidecar_send` doc and `SidecarSendQueue`. **Apply to:** every native send handler (enqueue only; Windows `open_url` goes to its own short-lived thread).

### Vacuous-pass guards (Phase 82 D-05)
**Source:** `src/backend/testUtils/censusFloor.ts`. **Apply to:** snapshot gate, `nativeSeamPortComplete`, one-owner census, manifest negative-vector test.

### Fake-HOME isolation for spawned processes
**Source:** `crates/gamelib-testutil` `FakeHome` (Rust), `createFakeHomeProfile()` (TS). **Apply to:** all harness spawns.

### Prettier verify (CLAUDE.md convention 5)
Every task `<verify>` for TS/JSON/MD paths: `npx prettier --check <exact paths>`; check `--file-info` first and omit if all ignored (the committed snapshot JSON and generated files may be ignored).
