<objective>
Prove the router's send kind (FND-03, D-01, D-02) by moving `openExternalUrl` — the renderer-controlled URL opener — to
Rust as one atomic channel move: manifest entry, Rust validation (D-18 `url`), a FIFO slice queue off the main thread,
and deletion of its TS registration and zod entry. Then delete the unused `open_external` Tauri command (D-17).

Purpose: the send kind is the one with the freeze history (2026-10-05) and the head-of-line history (D-UAT-19); proving
it here means later slices inherit a queue that cannot block the UI or itself.
Output: router send path, handler, TS deletions, census updates, the D-17 removal.
</objective>

</canon_breadcrumbs>
