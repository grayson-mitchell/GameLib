<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| filesystem paths -> CX_ENV -> CrossOver wrapper | Paths become shell-ish tokens that the CrossOver wrapper parses |
| user's Mac Steam install -> injected code | Valve's dylibs from the user's own install are loaded into the game |
| registry -> every per-appId wine spawn | A registered runner decides which binary runs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-60-07-01 | Tampering | buildOverlayCxTokens / appendCxEnvTokens | mitigate | Reject `'`, `:`, control chars and non-absolute paths; appId regex; quote guard on merge; fail open with step 'env' |
| T-60-07-02 | Elevation of privilege | injected Steam dylibs | accept | They come from the user's own Mac Steam install; GameLib redistributes nothing of Valve's; regular-file checks only |
| T-60-07-03 | Tampering | shim path substitution | mitigate | lstat regular-file check, no symlink follow; the path is GameLib's own bundle dir (builtOverlayShimPath) |
| T-60-07-04 | Elevation of privilege | registry accepting an arbitrary runner path | mitigate | BRIDGE_RUNNER_CXROOT_RE with kind/group match, derived-path equality checks, control-char rejection |
| T-60-07-05 | Denial of service | mixed wineservers on a runner change | mitigate | endPerGameBridgeBottleSessionWith stops with the previous runner's wineserver; per-game bottle guard |
</threat_model>
