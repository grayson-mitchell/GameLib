## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| sidecar -> CrossOver wrapper (CX_ENV) | Env tokens cross into the wine process tree |
| known-fix / per-game config -> routing | Data on disk decides whether injection happens |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-60-08-01 | Tampering | CX_ENV assembly | mitigate | Tokens come only from buildOverlayCxTokens (validated); merge via appendCxEnvTokens with the quote guard; failure means launch without tokens |
| T-60-08-02 | Denial of service | overlay setup blocking launch | mitigate | Every overlay call is wrapped in try/catch, result objects only; launch proceeds on stock or DRM-without-tokens (D-08) |
| T-60-08-03 | Repudiation | why the overlay did or did not inject | mitigate | Per-launch `overlay=<on/off> source=` line plus `[bridge-notice]` lines with sanitised causes |
| T-60-08-04 | Tampering | a known fix swapping the runner mid-launch | mitigate | Runner restore guard before spawn, mirroring DRM's D-11 guard |
| T-60-08-05 | Elevation of privilege | injection on an unverified engine | mitigate | No injection on the fallback engine (D-07); DRM injection only when wineloaderResigned is true |
| T-60-08-06 | Information disclosure | spawns | accept | No new spawn sites; runWineCommand is the existing declared real-profile launch path (needs the real bottle and Mac Steam) |
</threat_model>
