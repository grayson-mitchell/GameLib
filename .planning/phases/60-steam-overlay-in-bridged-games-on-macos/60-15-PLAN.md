<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GameLib -> bottle registry (V-CLIP) | GameLib writes a Wine config value in the user's bridge bottle |
| GameLib dylib -> game process (V-REASSERT/V-INPUT) | GameLib code intercepts cursor calls inside the game |
| marker file | records what GameLib changed so it can undo it |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-60-15-01 | Tampering | user's own Mac Driver value | mitigate | write only on overlay-on CrossOver launches; restore/remove only with a GameLib marker; never touch a value with no marker |
| T-60-15-02 | Tampering | marker JSON | mitigate | 0600 file under the 0700 overlay root, appId regex, previous accepted only as 'y'/'n'/null, anything else = no marker |
| T-60-15-03 | Denial of Service | reg command hang | mitigate | raced against an unref'd timeout like the DRM registry write; failure logs and continues (D-08) |
| T-60-15-04 | Elevation of Privilege | overlay_input.dylib injection | mitigate | built from in-repo source, lstat isFile (no symlink follow), safePath, inserted after the Steam dylibs; behaviour limited to deferring winemac-attributed cursor calls while the overlay is open |
| T-60-15-05 | Denial of Service | a stuck "open" state leaving the cursor released | mitigate | replay on close marker; deferred state only while open; smoke test covers open, close and replay |
</threat_model>
