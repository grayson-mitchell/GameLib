<objective>
Teach the DRM runner clone to re-sign `bin/wineloader` (D-05), best-effort so a failure never
blocks DRM mode (orchestrator resolution 1). Factor `runnerClone.ts`'s clone, re-sign, xattr
scrub and version-read steps into exported helpers that plan 05's overlay clone reuses (CONTEXT
discretion: a parameterised re-sign list rather than duplicated code).

Purpose: `bin/wine` execs `bin/wineloader` first, and that loader strips `DYLD_*` unless it is
re-signed (spike 062 run 2). Without this re-sign, DRM-mode titles such as Grim Dawn cannot get
the overlay.
Output: refactored runnerClone.ts, marker schema 2, and updated tests.
</objective>
