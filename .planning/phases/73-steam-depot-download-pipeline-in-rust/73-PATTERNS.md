### `gamelib-depot/src/container.rs` (utility, transform) and crypto

**Analog:** `depot/crypto.ts` (full, 52 lines) plus the 067b `rust-bench/src/main.rs` (`steam_decrypt`).

`crypto.ts` L18-40 is the byte-exact spec:
```ts
export function steamDecrypt(ciphertext: Buffer, key: Buffer): Buffer {
  // first 16 bytes: IV, AES-256-ECB encrypted under key
  const ivDec = nodeCrypto.createDecipheriv('aes-256-ecb', key, null); ivDec.setAutoPadding(false)
  ...
  // remainder: AES-256-CBC, no auto padding; then manual PKCS7 strip
  const pad = plain[plain.length - 1] ?? 0
  const padOk = pad >= 1 && pad <= 16 && plain.subarray(plain.length - pad).every((b) => b === pad)
  return padOk ? plain.subarray(0, plain.length - pad) : plain
}
```
Note the lenient padding: invalid padding returns the plaintext **unstripped** (does not error). A strict `Pkcs7` unpad in Rust would diverge; use `NoPadding` then strip manually to match. `decryptFilename` (L47-52) cuts at first NUL then utf8. Container formats (VZ, VSZa, PK, manifest zip) per RESEARCH Pitfall 6; check `len == cb_original` before SHA1.

## Shared Patterns

### Results, not errors; no panics across the boundary
**Source:** `gamelib-scan/src/lib.rs` header + README section 2. **Apply to:** every `gamelib-depot` entry point. `catch_unwind` in `dispatch`; `Err(String)` is `"{op}:bad-args"` / unknown op / panic only; job failure is an Outcome value.

### Wire types
**Source:** `gamelib-scan/src/lib.rs` L30-60. **Apply to:** all job/event/outcome structs: `#[serde(rename_all = "camelCase", deny_unknown_fields)]`, 64-bit ids as `String`, no bytes on the pipe.

### Secrets never logged
**Source:** `sidecar.rs` (logs channel names only, T-28-04) and the unrecognized-frame diagnostic (L632-633, "kind/id only, never args/result"). **Apply to:** `depot_dispatch.rs`, `rustDepot.ts`, every `Debug` impl on job/token types. Depot keys and CDN tokens ride these frames.

### Cancellation and single convergence
**Source:** `finalize.ts` header (L11-30) and `download.ts` `signal.aborted` checks. **Apply to:** `download.rs`, `acf.rs`, `lib.rs`. One `CancellationToken` per job, checked before every chunk attempt, every file, and inside backoff sleeps; cancel, failure and success all await `finalize`.

### Exit contract
**Source:** `rustScan.ts` ("no timers, no handles, no work at import"), `Skill("gamelib-conventions")` rule 3. **Apply to:** all new sidecar TS. The abort-on-EOF path (`releaseOnStdinEof`) fires-and-forgets the cancel and never awaits Rust.

### Fake-HOME spawn
**Source:** `meta/gamelibScanCli.ts`. **Apply to:** every spawn of `gamelib-depot-cli` from `src/` or `meta/`, including Jest tests and the parity sweep.

### Verify blocks
`npx prettier --check` over the exact paths written; check `--file-info` first (generated `ipc_contract.rs` and `.rs` files are not prettier targets, omit the check for those).
