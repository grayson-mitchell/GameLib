## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Case-sensitive rider-token mismatch on first gate run against the real document**

- **Found during:** Task 2, first `python3 ported-channels-gate.py` run against the real `34.4-PORTED-CHANNELS.md`.
- **Issue:** `REQUIRED_RIDER_TOKENS` included `"declared partial (D-05)"` (lowercase `d`), but the real document's prose reads `**Declared partial (D-05)**` (capitalized, sentence-initial, inside a bold span). `check_rider_tokens`'s substring match is case-sensitive, so the gate failed against the genuinely-correct document.
- **Fix:** Corrected the token in `REQUIRED_RIDER_TOKENS` to match the document's actual capitalization (`"Declared partial (D-05)"`), rather than rewording the document's prose to satisfy an arbitrary lowercase token.
- **Files modified:** `.planning/phases/34.4-tauri-ipc-re-plumb-slice-7-steam-completion-and-humble/ported-channels-gate.py` (pre-commit; not a separate commit).
- **Verification:** `python3 ported-channels-gate.py` exits 0 against the real document afterward.

**2. [Rule 1 - Bug] Whole-section prose extraction produced a false positive on REQ-34.4-16's `isLoggedIn` negative-scope check**

- **Found during:** Task 2, second `python3 ported-channels-gate.py` run against the real `IPC-PORT-INVENTORY.md`.
- **Issue:** The initial `_channel_names_in_backtick_list` implementation extracted every backtick-quoted token from an entire section (heading-to-heading), rather than only the dedicated channel-list line. The real inventory's slice-7 section explains the D-01/D-02/D-03 scope surgery in prose that itself names `isLoggedIn` and all 6 Phase 34.4.1 channels (e.g. "`isLoggedIn` moved to Phase 34.5 (it is `LegendaryUser.isLoggedIn()`..."), which the whole-section extraction misread as those channels still being declared slice-7 members — a false GATE FAILED against a genuinely-correct, unedited inventory.
- **Fix:** Rewrote `_channel_names_in_backtick_list` to scan section lines and extract names only from the FIRST line matching a dedicated whole-line comma-separated-backtick-list pattern (`^`name`(, `name`)*\.?$`), mirroring how `34.4-PORTED-CHANNELS.md`'s own `ROW_PATTERN` is anchored to row-leading position rather than any-mention-in-prose.
- **Files modified:** `.planning/phases/34.4-tauri-ipc-re-plumb-slice-7-steam-completion-and-humble/ported-channels-gate.py` (pre-commit; not a separate commit).
- **Verification:** `python3 ported-channels-gate.py` exits 0 against the real, unedited `IPC-PORT-INVENTORY.md`; a `--self-test` case (case 7) still proves the assertion correctly rejects a genuinely reverted inventory (the 6 Phase 34.4.1 channels and `isLoggedIn` folded back into a single-line slice-7 list).
