## Decisions Made

- **Structural fallback for Group 2's unreachability proof, not the behavioral form.** `WebView` is hook-heavy and cannot be invoked as a plain function (`Invalid hook call`) without a React dispatcher, and this project deliberately has no jsdom/react-test-renderer (`src/frontend/jest.config.js` docstring). The gate instead reads `WebView/index.tsx`'s real source, strips comments via the shared `backend/testUtils/stripSourceComments` util, and asserts a balanced-brace structural shape: an `if (isTauri())` sub-block that renders `WebviewUnavailablePanel`, followed — strictly after that sub-block closes — by a `return <></>`. Four self-tests prove the gate is not vacuous: it rejects a fully merged single-return source (the exact hand RED-proof mutation), a source where the Electron fallback was silently dropped, a source where the Electron arm was silently changed to also render the panel, and it positively accepts the plan's own specified shape (a positive control, so the gate isn't vacuously `false` either).
- **Log line placement.** Kept inline in the render branch rather than in a new `useEffect`, so the diff stays confined to the exact region the plan's acceptance criteria require (`git diff` shows only the `!webviewPreloadPath` block and the two new imports). This means the log can fire on every re-render while the app remains in the gap state, not exactly once — accepted as a minor, harmless tradeoff given the alternative (a new top-level hook) would violate the confined-diff constraint.
- **`window.api.logInfo`, not `logError`.** The Tauri gap is an expected structural state (not a bug) today, matching how this codebase already uses `logInfo` for expected-but-noteworthy states elsewhere (e.g. `GlobalState.tsx`'s "No cache found..." lines).
- **No copy affordance in the panel.** The plan explicitly names this as the simplest compliant choice under `navigator-clipboard-noops-under-tauri`; adding one would require routing through `window.api.clipboardWriteText` for no real user benefit here.
