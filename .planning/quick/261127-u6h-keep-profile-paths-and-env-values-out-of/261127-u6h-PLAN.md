<objective>
Keep profile paths and environment values out of the runner's and the Wine command's `gamelib.log` lines, closing
two todos in one change (the wine todo's Solution asks for exactly that). The project rule for `gamelib.log` is that
no line carries a URL, query, header, token, account name or profile path (88.2-VERIFICATION prohibition 1, PARTIAL;
accepted in 88.2 UAT test 2 on condition of these todos). `gamelib.log` is uploadable (`src-tauri/src/log_upload.rs`).

Purpose: a user who shares `gamelib.log` no longer shares their profile directory or the values of the environment
variables a runner was started with. The per-game logs keep the full text, where the user expects it.

Output: the reductions in `redact.rs`, the runner's three general lines and the Wine command's three general lines in
reduced form, a test-side oracle and one named delta per replay, and both todos closed.

Decisions made at planning time (Claude's discretion, recorded so the executor does not re-decide them):

- The TS twin named in the runner todo (`src/backend/commandRunner.ts:470`) no longer exists: 88.2-24 deleted it
  (`686537757`, "delete the TS command runner behind commandRunnerPortComplete"). Only Rust changes.
- "Re-record the goldens" cannot be done literally: the TS recorders (`runner.oracle.test.ts`,
  `runnerWine.oracle.test.ts`, `runnerTrace.ts`) were deleted with the runner, and the replays read the recorded
  slices as the TS's record (`launchPortComplete.test.ts` keeps them). This crate's mechanism for a deliberate Rust
  difference is a named entry in the slice's `deltas.json` that the replay applies (precedents: `wine-path-error-line`
  and `epic-status-log-fixed-text`, both prohibition-1 fixes; quick 261125-uzz, "no golden JSON is edited"). So the
  golden diff is two `deltas.json` entries plus the replay code. No `expected/**` file and no `MANIFEST.json` changes.
- Scope includes the runner's `Abort command` and `Error running command` lines. They print the same credential-free
  command into the same file; the 88.2 sweep missed them. Reducing only `Running command` would leave the todo's
  stated harm (an uploaded `gamelib.log` shares the profile path) in place.
- Arguments are reduced as well as the runner path: `--base-path <home>/Games` and `gogdl launch <install path>` put
  a profile path on the same line, and the request is "reduce paths to the file name".
- Only absolute paths of two or more segments are reduced. Windows switches (`/S`, `/VERYSILENT`, `/v`, `/f`) share
  the one-segment shape and must stay readable; one segment cannot hold a profile directory.
- Env goes last as ` (env: NAME, NAME)`, so a name can never be read as part of the command.
</objective>
