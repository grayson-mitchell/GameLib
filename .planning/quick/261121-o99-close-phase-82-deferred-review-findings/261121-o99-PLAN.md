WR-02 (safe_path.rs): add one public helper that places a reference path the crate could not resolve. Walk the ancestors of the path, starting with the path itself, and take the first one that `dunce::canonicalize` resolves; join the remaining names onto it lexically. If no ancestor resolves, return the path as given. A Windows drive that is not present is that case: every ancestor up to `X:\` fails. `fold_key` already strips the verbatim prefix and folds case, so this needs no extra normalisation. In the doc comment, call it the normalised lexical form of a reference. Anchoring at the deepest ancestor that resolves keeps it comparable with canonical target locations through symlinked ancestors such as macOS `/var` to `/private/var`.

WR-02 (remove.rs, location_keys): change the rules for caller-supplied reference paths, which are protected roots and known installs.
