**Defect 1 — `index.tsx`, around lines 577-598.** Re-confirm the line numbers before editing.

Replace `variant="scrollable"` and `scrollButtons="auto"` on the `<Tabs>` element with a single
`variant="fullWidth"`. With exactly two tabs, `fullWidth` gives each `flex-grow: 1` and
`max-width: none`, so the row sizes to the content instead of reserving space for scroll buttons
that the `scrollable` variant will not surrender. `scrollButtons` is meaningless outside the
`scrollable`/`auto` variants and must be deleted, not left inert.

Delete the wrapping `<div className="tabsWrapper">` (`:578`) and its closing `</div>` (`:598`),
promoting `<Tabs>` to be a direct child of the returned fragment. Re-indent the `<Tabs>` block by
one level.

**Do not** replace it with a scoped `.tabsWrapper` rule. Recorded rationale: with `fullWidth`
there is nothing left for the row to need — `.steamLoginBody` is already a column flex container
with `align-items: stretch`, so `<Tabs>` gets full width for free. Inventing a rule to justify a
class name is backwards; and this repo has been bitten by classes that look load-bearing while
styling nothing, and separately by an unscoped selector leaking app-wide. Keeping a second,
unscoped `.tabsWrapper` in the app while a `.wineManager .tabsWrapper` rule exists is exactly the
setup for that leak. The class goes.
