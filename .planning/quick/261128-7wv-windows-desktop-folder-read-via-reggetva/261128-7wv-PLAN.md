<objective>
Read the Windows `User Shell Folders` values through the registry API, which is UTF-16, instead of through `reg.exe`
console output. `reg.exe` prints in the console code page, so a redirected Desktop or Documents path holding a character
outside that page is mangled into U+FFFD, rejected, and dropped without a word. The Rust Desktop path (shortcuts) and
the TS Documents path (`save_sync.ts`, `'Personal'`) both move to one Win32 implementation in Rust. `reg.exe` stays as
the fallback, and a rejected Desktop answer now logs one line saying why.

Purpose: the Desktop shortcut is no longer skipped without a word, and cloud-save Documents is no longer silently dropped,
for a user whose redirected folder holds non-OEM characters (CJK or accented names on a Western OEM page, OneDrive).
Output: the native read seam, its shell wiring and one-line diagnostic (Task 1), the `windows_shell_folder_read`
rustInvoke channel (Task 2), the TS consumer and the closed todo (Task 3).
</objective>
