# Quick 261101-j03: DRM GetAppBuildId manifest lookup (WR-02) Summary

DRM-mode `GetAppBuildId` now resolves the appmanifest from the running exe's own library, then the default library, then up to 8 `libraryfolders.vdf` paths. It parses ACF as KeyValues (top-level `AppState.buildid` only) and reads to EOF into a 256 KiB bounded heap buffer. Shipped as `-p58c` and pinned.
