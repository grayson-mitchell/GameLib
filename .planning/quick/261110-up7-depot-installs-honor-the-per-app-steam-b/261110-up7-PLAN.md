  decodes as binary KeyValues: `00 "UserConfig\0"` (open map) `01 "language\0" "english\0"`
  (string) `01 "BetaKey\0" "public\0"` (string) `08` (end UserConfig) `08` (end root).

Binary KV type bytes: 0x00 map (key cstring, then children until 0x08), 0x01 string (key cstring,
value cstring, UTF-8), 0x02 int32 LE (4 bytes), 0x03 float32 (4), 0x07 uint64 LE (8), 0x08 end of
current map. Anything else = undecodable -> undefined.

`steamapps/appmanifest_333300.acf` as Steam writes it:
  "UserConfig" { "language" "english"  "BetaKey" "public" }  "MountedConfig" { same }.
userdata dir name = SteamID64 - 76561197960265728 (35601368 here).
