# Quick Task 260630-ud4: Wire Steam AppID directly into ProtonDB

## Problem

ProtonDB compatibility (the inline tier on the game page + the "Check
Compatibility" submenu link) resolves a game's Steam AppID *indirectly* by
looking it up on GamesDB / PCGamingWiki by title or appName. For native Steam
library games we already hold the real AppID — `gameInfo.app_name` IS the Steam
AppID (`storeManagers/steam/library.ts:168`). The wiki round-trip is unnecessary
and unreliable for these games (title lookups can miss or mismatch).

## Approach

When `runner === 'steam'`, use `app_name` as the Steam AppID directly,
short-circuiting the wiki lookup. Falls back to the existing wiki-based
resolution for all other runners.

## Tasks

### Task 1 — Backend: use Steam app_name as steamID
- **files:** `src/backend/wiki_game_info/wiki_game_info.ts`
- **action:** In the `isLinux` block, derive `steamID` as
  `runner === 'steam' ? appName : gamesdb?.steamID || pcgamingwiki?.steamID`.
  This feeds both `getInfoFromProtonDB` and `getSteamDeckComp` the real AppID.
- **verify:** `npx tsc --noEmit -p tsconfig.json` (file compiles); read-back shows steam branch
- **done:** Steam games resolve ProtonDB tier from their own AppID

### Task 2 — Frontend submenu: direct ProtonDB URL for Steam
- **files:** `src/frontend/screens/Game/GameSubMenu/index.tsx`
- **action:** In the effect that sets `protonDBurl`, short-circuit for `isSteam`
  to `https://www.protondb.com/app/${appName}` without the `getWikiGameInfo`
  round-trip.
- **verify:** read-back shows isSteam branch setting direct URL
- **done:** "Check Compatibility" opens the exact app page instantly for Steam games

### Task 3 — Game-page compat link: direct ProtonDB URL for Steam
- **files:** `src/frontend/screens/Game/GamePage/components/CompatibilityInfo.tsx`
- **action:** Prefer `gameInfo.runner === 'steam'` → `app/${gameInfo.app_name}`
  over the pcgamingwiki steamID when building `protonDBurl`.
- **verify:** read-back shows steam branch
- **done:** inline compat row links to the correct app page for Steam games
