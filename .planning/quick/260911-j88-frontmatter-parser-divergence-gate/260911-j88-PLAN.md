# Quick 260911-j88 — the gate's positive control is the defect

## Origin

`.planning/planning-frontmatter-gate.py` carries an explicit ACCEPT self-test case labelled
*"valid STATE-shaped document, both narrative fields as `|-` blocks with raw quotes inside"*.
That shape is exactly what empties those fields for every GSD consumer: the SDK's hand-rolled
`parseFrontmatterYamlLines` has no block-scalar support and returns the literal two-character
string `"|-"`. `phase-lifecycle.js:1122` then rewrites with `/stopped_at:\s*.+/`, and `.` does not
cross newlines, so it replaces the `stopped_at: |-` line and **orphans the narrative beneath it**.

Quick 260911-hyy defused that bomb in STATE.md. This gate would let anyone re-arm it — including a
GSD agent following the gate's own documented example. **The gate's positive control is the bug.**

**The todo's population of 53 is the wrong population.** The real defect is 56 fields wide, in the

STATE.md today costs exactly **1 character** for the single-quote convention (368 SDK vs 367
js-yaml, from one `''`). That is the whole price.
