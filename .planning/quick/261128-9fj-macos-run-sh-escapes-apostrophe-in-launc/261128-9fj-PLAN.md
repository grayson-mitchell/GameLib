<objective>
Fix the macOS shortcut `run.sh` so that an apostrophe in an app name or runner can no longer close the single quotes
around the launch URL. `run_sh()` in `src-tauri/crates/gamelib-shortcuts/src/mac.rs` (line 83) single-quotes the URL.
`encode_uri_component` (`src-tauri/crates/gamelib-shortcuts/src/launch_url.rs`) matches JavaScript's
`encodeURIComponent` and leaves `'` alone, so a name like `a'b'; touch pwned; '` breaks the quoting and the shortcut does
not launch. This closes `.planning/todos/pending/2026-11-24-macos-shortcut-run-sh-breaks-on-single-quote-in-app-name.md`.
