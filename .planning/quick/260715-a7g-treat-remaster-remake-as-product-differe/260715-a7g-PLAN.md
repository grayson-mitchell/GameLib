<objective>
Fix a false-positive "Owned" badge (Phase 20 store-search) and a false Humble-dedup match: an original game title fuzzy-matches its remaster/remake because `normalizeTitle()` strips `'remastered'`, collapsing "Alan Wake" and "Alan Wake Remastered" to the same normalized string (similarity 1.0).

A remaster/remake is a DIFFERENT product — owning the original grants nothing. Unlike deluxe/GOTY/definitive/collection editions, which are the SAME base game and MUST keep matching (Humble dedup, Phase 12). The fix lives in the single shared matcher (`common/matching/titleMatch.ts`, locked decision D-02) so both the Humble ownership-dedup surface and the store-search badge resolver benefit identically.

Purpose: Stop marking games as Owned/duplicate when the user only owns a different edition (remaster/remake) of a related title.
Output: A remaster/remake product-differentiator guard, mirroring the existing DLC guard, plus regression-protected tests.
</objective>
