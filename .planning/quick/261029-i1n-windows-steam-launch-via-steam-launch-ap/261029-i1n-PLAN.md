# Quick 261029-i1n: Windows Steam launches use `steam://launch/<appId>/Dialog`

<objective>
On Windows, launch native Steam games with `steam://launch/<appId>/Dialog` instead of
`steam://rungameid/<appId>`, so Steam stops drawing its "Starting game / LAUNCHING — Open Steam"
window on every Play. macOS and Linux keep `rungameid` unchanged. Correct the
activate:false todo that blamed Steam itself for that window, and commit it.

Purpose: on 2026-10-29 the operator showed on their Windows box (WazHack, appId 264160) that the
window comes from the `rungameid` verb. `steam.exe -silent "steam://rungameid/264160"` still shows
it, and `cmd /c start "" "steam://launch/264160/Dialog"` (Playnite's form) does not. The verb is
the whole fix. No `steam.exe` spawn and no `-silent`.

Output: one code commit (games.ts and games.test.ts) and one docs commit (the todo, which is
currently untracked).
</objective>
