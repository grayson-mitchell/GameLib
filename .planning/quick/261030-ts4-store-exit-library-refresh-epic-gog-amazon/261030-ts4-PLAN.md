**F2. No origin allowlist is needed for Epic/GOG/Amazon.** The sidecar handler
(`src/backend/sidecar/steamFlowRegistration.ts` ~L164) calls
`noteRefreshTrigger(rawRunner, rawOrigin)`, and `noteRefreshTrigger`
(`src/backend/storeManagers/steam/authTrigger.ts` L213) returns immediately unless the runner is
`steam`/`all`/null/undefined. `libraryManagerMap[runner].refresh()` for `legendary`, `gog`,
`nile` takes no origin and has no origin gate: each checks only `isLoggedIn()` (GOG also
`isOnline()` and stored credentials) and then makes ordinary API/CLI calls on stored tokens.
So `authTrigger.ts` is NOT modified (and the sidecar needs no rebuild for this task).

**F3. Amazon caveat (record, do not fix here).** `nile/library.ts` `refresh()` calls
`this.refreshNile()` (the `nile library sync`) WITHOUT awaiting it (comment "F6"), then reads
the local library immediately. So an exit refresh may publish the pre-sync list; a manual
Refresh has the identical behaviour. The live gate must observe whether the claimed title
appears from the single exit refresh; if it does not, record that as a finding in the SUMMARY
and the todo (separate fix), not as a defect of this task.

**F4. Runner / sign-in mapping** (`index.tsx` L349-361, `src/frontend/helpers/signInInputs.ts`):
