# Quick 261030-o77: non-native Steam installs always use GameLib's depot installer

Every bottle-route Steam install on macOS now goes through `installBottleNative()` (GameLib's own depot download) with the toggle ON or OFF. The bottled-Steam "Start Steam to finish" handoff is gone. A bottle-route install that falls back to StateFlags 1026 is marked incomplete and resumable instead of waiting on bottled Steam.

## What changed

**Task 1 (cb97d3d45).** `SteamGame.install()`'s `routeThroughBottle` branch calls `installBottleNative(args)` unconditionally. The D-17 `markForcedWindowsViaBottle` rule is unchanged. The toggle-OFF `tellBottledSteamToInstall` fallthrough and its imports are deleted. The mac-native branch (`isSteamNativeInstallEnabled()` -> `installNative`, else `steam://install`) and `installDepotDownload` code are untouched (only two comments reworded; the diff gate confirmed no change to the deferredPoll / poller-start / installNative / steam://install lines).

**Task 2 (43384ffa7).** In `library.ts`, the poller's bottle-source arm now converts `isWaitingForSteamRestart && source === 'bottle'` into: `logWarning`, `stopInstallPolling`, `markSteamInstallIncomplete`, `gameStatusUpdate {status:'done'}`, return. Removed: `bottledHandoff.ts`, the `steamFinishBottledInstall` IPC (registration, ipc.ts, preload), `tellBottledSteamToInstall`, `awaitingBottledSteam`/`bottledSteamDispatched`, `isAwaitingBottledSteamAdoption`/`markBottledSteamDispatched`, the two `*-bottled-steam` status contexts, the MainButton/GameStatus/constants handoff UI, and the `steam.bottle.finishInstall` object from all 49 `gamelib.json`. IPC census: steamAuthFlowRegistration invoke 23 -> 22. The StateFlags 4 fast path, the native `steam-waiting-for-restart` handoff and the bridge arm are unchanged.

**Task 3 (9f12d0a5c).** `listSteamLibraryTargets(appName?)`: toggle ON returns targets; toggle OFF returns targets only when `getSteamBottleEligibilityVerdict(appName).eligible` (appName shape-checked `^\d+$`, any throw -> `[]`, T-o77-01). All frontend callers pass `appName` (InstallGameModal, InstallModal, ConsoleMode overlay via a new optional `probeSteamQuickInstallTarget(appName)` param). Settings help copy updated; comments in nativeInstallSetting.ts / steamSectionGating.ts / ipc.ts updated.
