<decisions>
- P-01 Enumeration: on win32, reuse 9p6's constant PowerShell CIM listing through the injected
  runner (`scanSteamLaunchedPids` -> `findPidsRunningFromFolder` win32 arm). It is present on
  every Windows 11, never interpolates the folder, and is already tested. `wmic` is deprecated.
  `Get-Process` pays the same PowerShell startup cost. Because of the measured cost, a scan runs
  only at the search and confirm points (P-02 to P-04).
- P-02 Running-phase liveness: every 500 ms (`alivePollMs`), call
  `process.kill(pid, 0)` in-process on the tracked pids, through an injected `pidAlive` dep.
  EPERM counts as alive. A dead pid is dropped at once, so the PID-reuse window is one tick.
  Stop's fresh folder scan remains the escape hatch if a reused pid ever holds a card on Playing.
- P-03 Exit confirm: when every tracked pid is dead, run one PowerShell scan. Pids it finds under
  the folder (a launcher -> game chain, or a self-restart) become the new tracked set. An empty
  scan sends `done`. On win32 this replaces the posix two-empty-scan flap guard.
- P-04 Start-phase gate and bail: each `pollMs` (2000) start tick reads RunningAppID through the
  existing `readRunningAppId` (reg.exe) and runs the PowerShell scan only when it equals the
  appId. Steam sets it 0.27 s after the exe starts. Five consecutive empty scans while Steam
  reports the appId end the watch with no status, handing over to the poller (the game's process
  lives outside the install folder). The cost is bounded at about 5 scans. The 90 s start window
  is unchanged.
- P-05 Ownership (win32 only): the watch takes `runningPoll.hold(appId)` synchronously at start,
  and the poller sends nothing for that appId while the claim exists. `hold` returns a release
  bound to that claim, so a stale release is a no-op.
  - `release(true)` means the watch sent `done`, or the watch was cancelled (Stop owns the
    terminal frame). The claim then drains: the poller stays silent until it reads a different
    RunningAppID. If it still reads the appId after `drainMs` (20 s), it sends `playing`. 20 s
    covers Stop's typical worst case (taskkill, 5 s grace, rescan, force, Steam's 2.1 s clear and
    a 5 s poll phase, about 14 s) with margin, and still heals a premature `done` within about
    25 s.
  - `release(false)` means the watch handed back. The claim is deleted, and if the poller
    already reads the appId it sends `playing` now.
- P-06 Scope: win32 only. macOS keeps the 9mj `pollerReports` hand-off and posix scans, because
  the Mac poller reads 0 (registry.vdf has no RunningAppID). Linux keeps them too, because it
  cannot be live-gated here. 7wo's C1/C2 pin that and stay unmodified.
- P-07 Stop (goal 2): no Stop mechanism change. `stopSteamLaunchedGame.ts`, `runningFromFolder.ts`
  and `games.ts` are not edited. 9p6 stands, live-gated 2026-11-11: `taskkill /PID <pid>` without
  /T or /F (a close request), a 5 s grace, then TerminateProcess only for survivors that a fresh
  rescan still finds.
  - No /T: a tree kill would reach processes outside the install folder that the game spawned (a
    browser, a third-party launcher). GameLib did not launch those, and the folder scan already
    covers the game's own helpers.
  - Close before force: this lets the game save and exit cleanly, so Steam records playtime and
    cloud sync normally.
  - The only Stop-related change in a9g is ownership: stop() already cancels the watch first, and
    cancel releases with `true`, so the poller stays silent and the wire carries exactly one
    `done`. The regression guard is the named 9p6 tests in the measurements block.
- P-08 Todos: the Stop todo is already closed in `.planning/todos/completed/` (`79ac86c96`). a9g
  does not edit it or reopen it.
  - The poller todo records its Windows half as PASSED and changes `platform: windows` to
    `platform: macos`, because the only remaining gate (the WazHack no-flicker check) needs the
    Mac. Its `severity` is unchanged, since re-triaging it is the operator's call.
  - The poller todo also carries the a9g operator check: quit timing plus a Stop regression
    re-check.
