## Decisions Made
- Used a single literal-union prop (`'primary' | 'alternative'`) instead of two booleans, per the plan's own reasoning: only one of Epic's two tiles is ever SIDLogin, so two independent booleans would admit an invalid state.
- Followed the plan's inverted-relative-to-intuition wiring exactly: under Tauri the *primary* tile is SIDLogin and gets marked; under Electron the *alternative* tile is SIDLogin and gets marked. Verified this against the current `Login/index.tsx` pivot code (lines ~166–180) before wiring, confirming the plan's `<critical_finding>` reading is correct for the code as it exists today.
- Used `outline`/`outline-offset: -1px` rather than `border` on the wrapper, matching the plan's stated rationale (fixed 60px flex-row height; an inset outline paints without reflow) and the T-D62-02 threat-register mitigation.
