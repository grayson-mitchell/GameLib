## Problem

Verified live at HEAD, reproducing the todo's own counts exactly:

- `tour.sidebar.settings` — 28 locales contain "Heroic" (LIVE, nav tour step 4)
- `tour.sidebar.docs` — 27 locales (LIVE, step 9)
- `tour.sidebar.community` — 28 locales (LIVE, step 10)
- `tour.sidebar.version` — 28 locales, but **unreferenced in `src/`** → DEAD
- `info.heroic.version` — 38 locales (LIVE, `HeroicVersion/index.tsx:102`)

English source strings are already correctly branded ("GameLib"); only the translated
catalogs are stale. `tour.sidebar.community` additionally suffers **content drift** — all
28 translations promise a Discord community, while the English source is only
"Support GameLib's development." and the row it anchors was renamed Ko-fi → Donate.

## Approach

Apply todo 20's sanctioned partition rule: a key whose **English** value says "GameLib" is a
product self-reference and may be renamed; a key whose English still says "Heroic" is
deliberate and must be left alone. All five keys here are self-references by that rule.

Scoped deliberately to the two surfaces this todo reports — **not** the wholesale
1967-occurrence rebrand of todo 20 (`2026-09-01-non-english-catalogs-are-unrebranded`),
which is `ready: human` and needs a re-runnable `meta/` script plus a partition design.

## Decisions

- **D-1 — Rename in place rather than mint new `gamelib:` keys.** The todo's prescribed fix
  (mint `tour.nav.*` for all 12 steps in `gamelib.json`) is blocked: the presence baseline
  `meta/i18nCatalogPresenceBaseline.json` sits at `totalPairs: 0`, so 12 new keys × 48
  locales = 576 unrecorded pairs would turn R13 red, and `pnpm machine-fill-gamelib` still
  401s. Minting would also downgrade 48 locales from translated-but-stale to English-only.
  Renaming in place keeps them translated and correct.
- **D-2 — Editing upstream-owned `translation.json` is CI-safe once committed.** The D-05
  churn guard's `live tree` test runs `git diff --name-only -- public/locales`, which is
  **unstaged-only**; a committed edit is invisible to it. (The test's own comment claims
  "staged or unstaged", which inverts what the command does.) Cost accepted and recorded:
  these files stop being byte-identical to upstream, so the next catalog refresh needs a
  merge rather than a wholesale copy — already anticipated by todo 20.
- **D-3 — `tour.sidebar.version` left untouched.** It is dead (no `src/` reference), so
  editing it would be churn on an upstream-owned file with no user-visible effect.
- **D-4 — `community` translations realigned to the English source**, dropping the Discord
  promise. English is the source of truth, and the anchored row is now "Donate" → Ko-fi, so
  the Discord claim is false in every one of the 28 languages.
- **D-5 — Inflection handled by hand, not by token swap.** Genitive/elided forms are
  corrected per language rather than left as a mechanical substitution.

## Tasks

2. Rewrite `tour.sidebar.community` in 28 locales to match the English source.

4. Verify: zero "Heroic" left in the five live keys; JSON round-trips byte-identically
