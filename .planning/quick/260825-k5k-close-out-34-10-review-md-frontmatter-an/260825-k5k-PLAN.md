- **IN-01** cites `components/UI/CategoryFilter/index.tsx:76` and
  `components/UI/LibraryFilters/index.tsx:264`. **Both directories no longer exist.**
  `grep -rn data-tour src/frontend` returns no `<Dropdown>` call site anywhere in the tree.
- **WR-02** cites the same deleted `LibraryFilters/index.tsx`. `RunnerToStore` now lives at
  `screens/Library/facetLabels.ts:26`. The specific defect WR-02 described — `t()` invoked with
  a computed key never registered in `translation.json` — cannot occur at the successor sites
  because **`t()` is no longer called on these values at all**:
  `NavShell/components/FilterStoreFacet/index.tsx:73` renders `RunnerToStore[value]` bare, and
  `FilterChipRow/chipLabels.ts:106-110` returns `{ literal: brand }`, a variant deliberately
  typed as distinct from that module's `{ ns, key, defaultText }` variant. Brand names as
  untranslated literals is a Phase 34.11 design decision, not an escaped 34.10 defect.
  `'Steam'` / `'ZOOM Platform'` remaining absent from `translation.json` is now CORRECT.

Closing by deletion is a distinct disposition from "fixed" and must be recorded as such — see
the precedent already in this file's own header comment, where a frozen `findings:` census was
misread as live state for 14 days.
