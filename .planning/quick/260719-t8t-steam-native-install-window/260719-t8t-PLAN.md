<objective>
Replace the current native-Steam install UX (zero-friction immediate install for 0/1 library + a
bare `SteamInstallLocationPicker` dropdown for multi-library) with a single GOG-styled install
window that ALWAYS shows for every native Steam install.

Purpose: give native Steam installs the same considered, informative install dialog GOG/Epic/Amazon
get — game art + title, a library-location picker, free disk space, and a best-effort download size —
instead of the abrupt zero-friction path and the minimal dropdown.

Output: one dedicated `SteamDownloadDialog` component (reusing GOG's `DownloadDialog` layout,
styling and shared `Dialog` UI), the retirement of `SteamInstallLocationPicker`, and an always-open
entry chokepoint in `InstallGameModal.ts`.
</objective>
