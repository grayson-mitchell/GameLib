# Quick Task 261008-gf1: restrictive CSP on the bundled Tauri webview

Closes todo `2026-10-05-set-a-restrictive-csp-on-the-tauri-webview.md` (`ready: live-gate`).

## Three Tauri facts that shaped the policy (verified against `tauri-2.11.5` source)

1. **CSP applies only to HTML Tauri serves itself.** `manager/mod.rs get_asset` sets the
   `Content-Security-Policy` response header on `tauri://` asset responses (a `<meta>` on Linux).
   With `build.devUrl` set, `tauri-codegen` embeds NO assets (`FrontendDist::Url => Default`), so
   under `tauri dev` nothing passes through Tauri and no policy applies. `devCsp` is therefore
   inert here and is deliberately not set. The live gate must be a bundled build.
2. **IPC is `fetch('ipc://localhost/<cmd>')` on desktop** (`scripts/ipc-protocol.js`; Windows
   `http://ipc.localhost`). `connect-src` must carry `ipc: http://ipc.localhost` or every
   `window.api.*` call fails. The postMessage fallback only engages if the fetch *errors*, and a
   CSP block is reported as a TypeError — so it may fall back, but we do not rely on that.
3. **Tauri nonces/hashes its own injected scripts** (`set_csp` -> `replace_csp_nonce`), so
   `script-src 'self'` is sufficient; `withGlobalTauri`'s bundle is an initialization script,
   outside CSP.

## Renderer origin census (2026-10-08, `src/frontend` + `src/preload`, tests excluded)

| Surface | Found | Directive |
|---|---|---|
| scripts | Vite module bundle only; built `index.html` has no inline `<script>` | `script-src 'self'` |
| styles | Vite CSS; MUI/emotion runtime `<style>`; **Settings -> Custom CSS writes user CSS into `<style id="customCSS">`** | `style-src 'self' 'unsafe-inline'` |
| images | store artwork from arbitrary CDNs; SGDB / `steamgrid.usebottles.com` results; user sideload URLs; backend `data:` login background. `file://` never loaded (no asset protocol) | `img-src 'self' data: https: http:` |
| fonts | `NotoColorEmoji.subset.ttf` bundled | `font-src 'self'` |
| connect | all `window.api.*` = Tauri invoke; i18n `locales/<lng>/<ns>.json` relative; ONE direct remote: `SideloadDialog` axios to `steamgrid.usebottles.com` | `connect-src 'self' ipc: http://ipc.localhost https://steamgrid.usebottles.com` |
| iframes / objects / workers / wasm / websockets / media | none — store embeds and login windows are native child webviews on remote URLs, which Tauri does not CSP | `object-src/frame-src/worker-src 'none'` |
| base / forms | hash router; React forms with handlers | `base-uri 'self'; form-action 'self'` |

## Honest scope of the live gate

macOS WebKit only. WebKitGTK and WebView2 are unmeasured; the policy uses only directives every
engine honours in both header and `<meta>` form, and the forwarder makes a violation on those
platforms a one-line log find rather than a silent missing image. The store embeds and login
windows are remote-URL native webviews and are not governed by this policy at all, so they are
not part of the gate's claim.
