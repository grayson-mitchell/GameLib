Wire frames (all little-endian):
- Request:  [u32 len][u32 request_id][u16 ordinal][u16 slot][args...]   where len = 8 + argLen (len covers everything after itself)
- Response: [u32 len][u32 request_id][u8 status][blob...]              where len = 5 + blobLen; status 0 = OK, non-zero = STATUS_ERR
- The shim sends the 12-byte header and the args in SEPARATE send() calls. The fake helper must accumulate bytes per socket and parse whole frames.
- CONTROL ordinal = 0xffff. Slots: HELLO = 2, DRAIN_CALLBACKS = 6, REPORT_CB_DISPATCH = 10 (others: 3,4,5,7,8,9 are not expected in this run).
- HELLO: args = the 64 ASCII lowercase-hex secret bytes. The shim requires the reply to be exactly len=5, same request_id, status 0 (empty blob).
- DRAIN (no args) reply blob: `[u32 count]`, and when count == 1, `[i32 iCallback][u32 cub][cub bytes]`. For 168: cub MUST be 2572, so the blob is 2584 bytes. The shim breaks on any count other than 1, so an empty queue is the 4-byte blob `00 00 00 00`.
- REPORT_CB_DISPATCH args: `[i32 id][u32 ndispatched][u32 held]` (12 bytes); reply OK with an empty blob.
- The connection: `bridge_ensure_connected()` lazily reads `gamelib_bridge.cfg` from beside the DLL's OWN path (GetModuleFileNameA of the module). It needs a `port=<1024..65535>` line and a `secret=<exactly 64 [0-9a-f]>` line, or it refuses to connect (fail closed). It connects to 127.0.0.1:port and sends HELLO before any other frame on every new socket.
- The connection is lazy: SteamAPI_RunCallbacks alone triggers it. Do NOT call SteamAPI_Init, because it would add HELLO, REPORT_INIT and REQUEST_CURRENT_STATS frames.

  - Body: `mov eax, esp` (ESP at entry, pointing at the return address); `push eax`; `push dword ptr [eax+4]` (the single stack arg = pvParam); `push ecx` (`this`); `call _gl_record_run` (a cdecl C function taking self, param, esp_at_entry); `add esp, 12`; then `ret 4`.   - gl_record_run appends to a fixed array of up to 8 records: self, param, esp_at_entry, the return address read from `*(uint32_t*)esp_at_entry`, and the iCallback field read from self at offset 8. It also memcmps param against the expected payload and records the result.
- `gl_run1_c` is `static void __attribute__((thiscall)) gl_run1_c(void *self, void *param)`, a compiler-emitted thiscall callee. It records self, param and the payload memcmp. No ESP is recorded, because it cannot read it portably.
