<objective>
The operator reported that a Steam game's Install Info shows "Version:" with no value.
`InstalledInfo.tsx` renders `gameInfo.install.version`, and no Steam code path ever sets it. This
plan carries the ACF `buildid` from the producers, `buildInstalledMap*` and `readAcfState`, into
`install.version` at every site that builds a Steam install block. It also keeps the value fresh
after a Steam update.

Purpose: Install Info shows the installed Steam Build ID.
Output: backend-only changes plus unit tests. The frontend does not change.
</objective>
