# Quick 260925-7zf — Automated MT quality audit (operator-chosen route)

**Deviation from the standard quick path:** this task was run by the orchestrator, with no
gsd-planner and no gsd-executor. The work is review fan-out, and `gsd-executor` cannot spawn
reviewer agents. No source or locale file was modified.

1. Build per-locale review inputs, `{key, en, tr}` for every key in `gamelib.mt.json`, for
   `et fi hu hr sl da nb_NO sv`.
2. Run 8 independent `opus` reviewer agents, one per locale, read-only, each writing
   `findings/<locale>.json` with a row count that must equal its input count.
3. Run a deterministic structural pass over all 48 locales: placeholder and tag parity, English
   left identical, length ratio, dropped terminal punctuation.
4. Aggregate the results, look for keys that fail in several locales, and write REPORT.md.
5. Update the parent todo (it stays open), file follow-up todos, and keep `pnpm planning-gates`
   green.
