<objective>
Stop the CrossOver rating from depending on the per-page CodeWeavers scrape, which Cloudflare now answers with HTTP 403. Source macOS ratings from the daily crossover index only, cache a real index miss as "checked, none found", keep "index unavailable" retryable, drop the dead Linux scrape traffic, and delete the scrape code.

Purpose: today an index miss on macOS falls through to `getInfoFromCodeweavers`, gets 403, throws, and returns null. The CrossOver row disappears, nothing is cached, and two blocked requests repeat on every page visit. Linux makes the same blocked request for a `linuxRating` that is never rendered.
Output: an index-only lookup with three distinct outcomes, a trimmed `codeweavers/utils.ts` that keeps only `slugify`, updated tests, and the todo moved to completed.
</objective>
