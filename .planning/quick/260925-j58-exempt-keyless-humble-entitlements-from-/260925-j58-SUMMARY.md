## Deviations from plan

### 1. [Rule 1 — plan premise measured FALSE] Only `en`'s `humbleKeys` block is sorted

The plan stated the block is "sorted case-insensitively ascending" in every locale and that the
new key therefore "goes immediately before `keyLoading` in every locale", and instructed me to
verify rather than trust it. Verified — and it is wrong for 48 of 49:

| locale | keys | case-insensitive sort breaks |
| ------ | ---- | ---------------------------- |
| `en`   | 84   | **0**                        |
| `de`   | 84   | 4                            |
| `fr`   | 89   | 9                            |

The non-`en` blocks are several appended runs (later key waves were added at the end rather than
merged), so there is no single sorted sequence to insert into. The operator's mechanical rule —
insert before the first EXISTING key that sorts after yours — was applied per file as written,
which lands the key before `keyLoading` in `en` and before `openStore` in the other 48. No block
was reflowed: every `gamelib.json` diff is exactly `+1/-0` and every `gamelib.mt.json` exactly
`+2/-1` (numstat-verified, zero exceptions).

### 2. [Rule 3 — conflicting acceptance criteria] `grep -c endsWith` vs. the documentation ask

Task 1's `<action>` asked me to document that the predicate is **not** `keyType.endsWith('_keyless')`;
its `<done>` required `grep -c "endsWith"` over the same file to return `0`. Both cannot hold with
the anti-pattern spelled literally. The comment was reworded to "a `_keyless` suffix test (nor any
regex)", which names the rejected implementation just as unambiguously and satisfies the grep. The
predicate itself is a `Record<string, true>` lookup; `grep -c endsWith` now returns `0`.

### 3. Round-trip format verified, not assumed

Per the operator's rule, every file's `(indent, ensure_ascii, trailing-newline)` combo was
recovered against `git show HEAD:<path>` (not the worktree) before any write, and all 97 files
round-tripped: **`gamelib.json` = `(4, False, True)`; `gamelib.mt.json` = `(2, False, True)`** —
i.e. NOT the single `(4, False, True)` combo the previous 816-string sweep found, because that
sweep did not touch the manifests. `en/gamelib.mt.json` does not exist (source locale), which is
why the count is 49 catalogs + 48 manifests.
