<objective>
Fix the QR-login → Steam-library race (v0.1 audit blocker AUTH-01 / LIB-01). After QR approval the poll returns `{status:'done', username:undefined}` synchronously while the persona name arrives asynchronously from the background CM connect. The frontend finalizes login with `username:undefined`, and `makeLibrary()` gates Steam inclusion on `steam?.username` — so the Steam library stays invisible until app reload. A secondary defect: the background connect is fire-and-forget, so a concurrent `ensureConnected()` (triggered by post-login `refreshLibrary('steam')`) starts a SECOND `connectSteamUserClient`, which logs off the first client and resolves the first with the 'Steam User' fallback, overwriting the real persona name in `userData`.

Purpose: Make the Steam library appear immediately after QR login, with the correct persona name, without regressing the 260627-vq1 hang fix.

Output: Two surgical source changes (backend connectingPromise dedupe, frontend username gating) plus unit test coverage.
</objective>
