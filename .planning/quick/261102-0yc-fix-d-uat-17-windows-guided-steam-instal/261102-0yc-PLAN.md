<objective>
Fix D-UAT-17. On Windows, consenting to the guided Steam install downloads SteamSetup.exe and then
spawns it directly. The installer needs elevation, so CreateProcess fails with EACCES and nothing
opens. The spawn is fire-and-forget, so GameLib logs "launched" and returns `{ status: 'started' }`
first, and the banner says "Installing the Steam client" with nothing behind it.

Launch it the way the repo already launches elevated Windows executables: PowerShell
`Start-Process -Verb RunAs`, which raises UAC. Await that launcher's outcome, without waiting for the
installer to exit, so a declined or failed launch reaches the frontend's existing error phase.
Then record the fix on the D-UAT-17 todo and leave it pending until the operator re-runs 4a.
