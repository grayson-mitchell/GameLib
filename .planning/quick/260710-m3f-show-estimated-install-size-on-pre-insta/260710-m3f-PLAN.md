<objective>
Show an estimated "Install Size" row on the pre-install (not-yet-installed) Steam
game page, bringing Steam closer to parity with Epic/GOG which already show
download/install size.

The backend already has `getSteamInstallSize(appId, gameInfo?)` in
`src/backend/storeManagers/steam/games.ts` (returns a formatted string like
"15.00 GiB" from the public Steam store appdetails API, with a "?? MB" fallback).
It is only consumed by the download queue today. This plan surfaces it to the
frontend via a new IPC handler and renders it in `DownloadSizeInfo.tsx`.

Purpose: Steam users can see how much space a game will take before installing.
Output: New `getSteamInstallSize` IPC handler + preload exposure; Steam branch of
`DownloadSizeInfo` renders an estimated Install Size row (Install Size ONLY — no
Download Size row for Steam).

LOCKED DESIGN DECISION (do not revisit): Steam pre-install page shows an
"Install Size" row ONLY (estimated). Do NOT render a "Download Size" row for Steam.
An "(estimate)" / "~" indicator on the size is encouraged for honesty.

OUT OF SCOPE: download size for Steam; changing installed-game size display
(InstalledInfo.tsx); InstallModal/DownloadDialog behavior; steam-user PICS depots.
</objective>
