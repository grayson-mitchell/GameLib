## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GOG login page → pristine WKWebView | Untrusted third-party page that handles credentials. It must see zero injected script (Turnstile) and must not be able to trigger shell actions. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-o1w-01 | Spoofing | single-flight latch | mitigate | GOG routes after the `if visible == true {` latch, so a second visible login cannot land in the GOG sheet (and no other sheet can land on top of GOG). The latch is cleared on Err, on resolution and on Destroyed (pinned count 6). |
| T-o1w-02 | Elevation | routing flag | mitigate | `is_gog_login`/`as_sheet` come only from the validated URL host constant `GOG_LOGIN_HOST`, never from a caller argument. |
| T-o1w-03 | Tampering | pristine page | mitigate | The cancel control is a native NSButton outside the web content. No JS evaluated or injected, so the page cannot spoof or remove the exit, and Turnstile stays unaffected. |
| T-o1w-04 | Denial of service | parent window stuck behind a sheet | mitigate | Three exits: native button, Esc monitor, programmatic close. All run dismiss → close, and a watchdog fallback shows the window if the attach is unconfirmed. |
| T-o1w-05 | Information disclosure | logs | mitigate | New log lines carry the label and booleans only, never URL, origin or title (T-34.4.2-11 discipline). |
| T-o1w-06 | Denial of service | leaked cancel target per open | accept | One tiny NSObject per GOG sign-in, the same precedent as the deliberately leaked nav delegate. |
