## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| process table -> backend | ps output is arbitrary text any local process can shape via its argv |
| on-disk ACF -> backend | appmanifest installdir is attacker-writable by anyone who can write steamapps/ |
| backend -> other processes | SIGTERM/SIGKILL can end processes the user owns |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-9b7-01 | Denial of Service | psOutputPidsInFolder | mitigate | args must START with `<folder>/` (not substring); trailing sep blocks siblings; normalizeFolder rejects ''/relative/root so the needle can never match everything |
| T-9b7-02 | Denial of Service | Steam client | mitigate | RegExp deny list for steam_osx/steamwebhelper/ipcserver/gameoverlayui/Steam Helper/Steam.AppBundle; no pkill, no name-based kill |
| T-9b7-03 | Tampering | ACF installdir | mitigate | shared sanitizeInstalldir (traversal/denylist) and blank skipped; folder confined to `<lib>/steamapps/common/<one segment>` |
| T-9b7-04 | Denial of Service | PID reuse during grace | mitigate | SIGKILL only pids in termed set AND in a fresh folder rescan |
| T-9b7-05 | Elevation of Privilege | self-kill | mitigate | selfPids (process.pid, ppid) and pid <= 1 excluded |
| T-9b7-06 | Denial of Service | sidecar exit | mitigate | ps via runner with 2000 ms timeout; grace/poll timers from injected clock, unref'd, bounded by graceMs |
