| shim -> game process IAT | the shim rewrites one IAT slot of the game exe |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-ng9-01 | Tampering | remote known-fixes feed | mitigate | shimFeatures only in TIER2_PROFILE_KEYS; tier-1/remote copies dropped (test "never takes shimFeatures from the remote layer or a tier-1 file") |
| T-ng9-02 | Tampering | gamelib_bridge.cfg line injection (`port=` smuggled via newline) | mitigate | steamShimFeatureCfgLines regex `^[A-Za-z0-9_]{1,62}\*?$`; writeBridgeConfig drops lines not starting `fix.` or containing CR/LF (tests in both suites) |
| T-ng9-03 | Denial of service / memory safety | shim cfg parser + extension filter | mitigate | fixed 16 x 64-byte pattern table with length check, 8192-byte cfg read, 16384-byte filtered buffer with bounds check and truncation; release build, no UBSan runtime (strings check in Task 2) |
