(73-18 live gate: cancelling a stale Project Zomboid queue head deleted a complete 8.2 GB install).
Three independent fix layers, each sufficient on its own to break the chain:

1. Queue-head revalidation: a persisted Steam install head that is already a current full install on
   disk is dropped, not started (`downloadqueue.ts initQueue` + new `queueHeadRevalidation.ts`).

   breadcrumb; cancel-delete refuses when the title was installed at job start, whatever finalize

   (`src-tauri/crates/gamelib-depot/src/download.rs` calls `acf::finalize` at ~line 1083; that is
   where `[depot-rust] outcome ... acf=1026 ... bytes=0` came from). Guard there, and guard the TS
   `finalizeToSteam` (zero-depot install path in `depotRust/install.ts`) the same way.
