1. **Local throwing helper (Task 1 creates it).** Create
   `src/backend/storeManagers/steam/__tests__/fixtures/indexed.ts` exporting a generic
   `at<T>(xs: ArrayLike<T>, i: number, what?: string): T` that reads `xs[i]` and throws an
   `Error` naming `what`/`i` and the length when the element is `undefined`, and (only if used) a
   `defined<T>(v: T | undefined, what: string): T` that throws when `v === undefined`. Export only
   what is used (knip ratchet). Before writing it, grep `src/backend/storeManagers/steam` and
   `src/backend/testUtils` for an existing equivalent and reuse it if present. Do NOT import a
   helper from `src/backend/humble/**` (different bucket/plan). Bridge, overlay and drm tests may
   import it by relative path (`../../__tests__/fixtures/indexed`,
   `../../../__tests__/fixtures/indexed`); dependency-cruiser exempts `__tests__` paths, but run
   `pnpm boundaries` anyway.
2. **Element then member / method call** (`fake.instances[0].emit(...)`,
   `const inst = fake.instances[0]; inst.logOn`, `deferreds[2].resolve()`,
   `sockets[0].write.mock.calls`, `plan.depots[0].files.length` in an `if`): bind with
   `at(...)`. Never use `?.` on a call or in a condition: `x?.emit()` silently does nothing and
   `if (x?.files.length > 1)` changes control flow.
3. **Inside `expect(...)`**: `?.` is allowed ONLY when the matcher fails on `undefined`
   (`toBe(<non-undefined literal/value>)`, `toEqual(<defined>)`, `toMatch`, `toContain`,
   `toHaveLength`, `toBeGreaterThan` etc., `toBe(false)`). Where the matcher passes on
   `undefined` — `toBeUndefined`, `toBeFalsy`, any `not.*` matcher (incl.
   `not.toHaveBeenCalled`), `toEqual(undefined)`. (`toBeNull` is strict and fails on undefined, so
   `?.` is fine there) — use `at(...)` so an empty array still fails
   (e.g. `expect(at(entries, 0).processes[0]?.command).toBeUndefined()` is WRONG for the inner
   index too: use `at(at(entries, 0).processes, 0).command`). Prettier may rewrap; that is fine.
4. **Mock bookkeeping**: `spy.mock.calls[0][0]` -> `at(spy.mock.calls, 0)[0]` (the inner index
   is a tuple position on typed mocks; if it still errors, `at` it too);
   `mock.invocationCallOrder[0]` passed to `toBeLessThan` -> `at(...)`;
   `callArgs = mock.calls[0]` then `callArgs[callArgs.length - 4]` -> bind `callArgs` with `at`
   and `at(callArgs, callArgs.length - 4)`; keep any existing narrowing cast on the result as is.
5. **`Record<string, Fn>` handler maps called directly** (TS2722, e.g. user.test.ts
   `sessionOnHandlers['authenticated']()`): add a small local function in that test file, e.g.
   `fire(event, ...args)`, that throws `no handler registered for <event>` when the entry is
   missing and otherwise calls it. Missing handler must fail, not no-op.
6. **`jest.requireMock<Record<string, jest.Mock>>(...)` accessors** (games.test.ts
   `adoption().probeMacSteamPid`): prefer typing the accessor from the real module,
   `jest.mocked(jest.requireMock<typeof import('../macSteamAdoption')>('../macSteamAdoption'))`,
   so each member is a typed mock; if a member is not a function export, use `defined(...)` on
   the record entry instead. Do not invent keys.
7. **Regex captures / split parts / array destructuring** (`m[1]`, `p[0].split(...)`,
   `const [a, b] = xs` TS2488 on possibly-undefined, `args[6]` into `readFileSync` TS2769):
   `at(...)`/`defined(...)`, or a filter that drops `undefined` with a type guard
   (`flatMap((m) => { const g = m[1]; return g === undefined ? [] : [g] })`) when the group is
   mandatory and a `string[]` is declared (TS2322).
8. **Index used as a key** (TS2538, `doneIndexes[0]` as an index): bind with `at`.
9. **Fixture builders** (`managedPe.ts` `nameBufs[i].length` in a loop, `stubRustScan.ts`):
   prefer iterating with `for (const [i, buf] of nameBufs.entries())` / `for...of` over indexing,
   or `at(...)`; output must be byte-identical for valid input.
10. **Anything else** (TS2339 `parent.kill` on an indexed element, TS2464, TS7006): same idea —
    bind the element with `at` and keep the expression otherwise identical.
