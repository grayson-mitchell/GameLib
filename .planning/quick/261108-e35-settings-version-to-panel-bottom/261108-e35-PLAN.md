# Quick Task 261108-e35: GameLib Version to the bottom of the Settings panel

Move the "GameLib Version" line in the Settings tier-2 (left) panel to the bottom of the
panel, and give it at least 5px left inset (it currently sits at 0px).

## Cause

`.NavShell__versionSlot` already declares `margin-top: auto`, but its parent
`.NavShell__tier2` is a block container, so the auto margin resolves to 0 and the version
sits directly under the Settings rows. The slot also has no inline padding.

## Task 1 — `src/frontend/components/UI/NavShell/index.scss`

- `.NavShell__tier2`: add `display: flex; flex-direction: column;`.
- `.NavShell__versionSlot`: add `padding: 0 var(--tier2-row-padding-inline, 8px) var(--space-sm, 8px); flex: none;`
  (`--tier2-row-padding-inline` = `--space-sm` = 0.75em, about 12px; lines up with the rows).
