| user clipboard / Finder | install path written to clipboard / revealed; path is the user's own install dir |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-r4c-01 | Tampering | nativePortCatalogue.json url | mitigate | parseNativePortCatalogue drops any row whose url does not start with `https://`; URLs are never taken from backend payloads or remote fetch (L-08), mirroring EngineNotices' constant-URL rule |
| T-r4c-02 | Elevation of Privilege | port binaries | accept | GameLib never downloads, configures or launches ports (hint-only decision); the user installs and sideloads it themselves |
| T-r4c-03 | Information Disclosure | Copy install path | accept | only the game's own local install path, copied on explicit user click |
| T-r4c-04 | Repudiation/Integrity | Steam playtime/achievements | mitigate | block always states playtime and achievements are not tracked through the port |
</threat_model>
