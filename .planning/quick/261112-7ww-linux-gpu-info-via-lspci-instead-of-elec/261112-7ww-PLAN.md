<objective>
Fix Linux system info. `getGpuInfo_linux` (src/backend/utils/systeminfo/gpu/linux.ts) still parses
`{}` with a zod schema written for Electron's `app.getGPUInfo`, which has no Tauri counterpart, so
it throws on every call. Nothing catches it (gpu/index.ts, systeminfo/index.ts `fetchSystemInfo`),
so `getSystemInfo` rejects on Linux — breaking the System Information report, the startup
system-info log and Steam Deck detection.

Replace the Electron path with a single `lspci` enumeration through the existing
`ProbeDeps`/`genericSpawnWrapper` runner, make the Linux probe never throw, and make `getGpuInfo`
tolerant of any probe failure.

Purpose: Linux users get a working System Information report, startup log and Deck detection.
Output: rewritten linux.ts, hardened gpu/index.ts, new test file.
</objective>
