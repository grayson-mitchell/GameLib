<objective>
Re-narrow the SteamGame class surface that phase 62 lift rule L4 (D-06) widened. Today every lifted
module reaches sibling helpers through `steamGame.X(...)`, which hits a one-line delegating stub on the
class (`return X(this, ...)`). That access forced each stub to lose `private`.

The fix: where no test intercepts the member, the lifted module calls the sibling free function
directly (`X(steamGame, ...)`). The class stub then either goes back to `private` (if games.ts or a
test still calls it) or is deleted (if nothing calls it). Where a test spies on the member, the call
must keep going through the class, so the member stays public and is tagged `/** @internal */`.

Purpose: the class surface matches what it was before 62, with no change at runtime.
Output: the narrowed games.ts, rerouted lifted modules, a forward-only import guard, and the todo
closed.
</objective>
