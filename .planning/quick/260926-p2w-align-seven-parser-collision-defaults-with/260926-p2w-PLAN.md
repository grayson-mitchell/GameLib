## Method — triage by cause before fixing anything

Extract every `t()` call-site default for each key and diff it against the key's English catalog
value. Do not assume the seven are one class; the remedy differs by cause, and for one class
aligning the defaults would be actively wrong.

## Locked decision

**Align a divergent default with its catalog value ONLY where the two sites mean the same thing.**
Where the two sites want genuinely different copy, aligning would silently discard an author's
wording — file it instead, because choosing the copy is a person's call and minting a key has a
real translation cost.
