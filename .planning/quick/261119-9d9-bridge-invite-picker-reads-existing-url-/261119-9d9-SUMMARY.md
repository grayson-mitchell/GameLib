# Phase quick-261119-9d9 Plan 01: Invite picker reuse URL from config Summary

Re-opening the bridge invite picker now navigates to a URL built from the app config
(`bridge_invite_app_base` + `bridge_invite_reuse_url`) instead of asking the existing webview for
its URL, so a window whose first load failed (nil `WKWebView.URL`, wry 0.55.1 unwrap) can no
longer panic the shell.
