   DECISION.

   shipped `store_embed_open` is reached through sidecar RPC and is not affected. A future Windows
   un-gating must keep it off sync commands. The spike now has async wrappers.

   ported to the app's throttle before E04(b); E01 had already been scored on the unmodified
   source.

   through the known-folder API, which ignores the env overrides, so only the Node sidecar is fully
   isolated. This is worth a line in CLAUDE.md's two-profile section. It is NOT edited here, and
   the decision is left to the operator.
5. **38-S14's "Cancel + Install" was never observable.** The component has no Cancel button;
   sitting 5 most likely restated `expected:`.
