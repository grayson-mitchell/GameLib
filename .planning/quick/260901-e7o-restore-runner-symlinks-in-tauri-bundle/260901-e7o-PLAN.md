## D-e7o-01 — Option A, sourcing from `../build/bin/...` (NOT variant A′ from `../public/`)

`260901-e7o-RESEARCH.md` left A vs A′ open. **Resolved: Option A.**

A′'s only argument was decoupling from `preserveRunnerSymlinksPlugin` / `build/bin` staleness. That
argument is already answered by an existing gate: `meta/checkBuildBinMirror.ts` (`package.json:52`,
`pnpm check:build-bin-mirror`, from quick-260901-a2w) asserts `build/bin` ≡ `public/bin` on
(a) only-in-build files, (b) only-in-public files, (c) **symlink maps equal in BOTH directions —
relPath AND `readlinkSync` target**, (d) summed apparent bytes, (e) anti-vacuity on an empty
`public/bin`. Measured now: both trees are `279 files / 12 symlinks / 100,707,073 B`, identical.

A′ would also make the darwin entries the ONLY bundle source outside `build/`. Every other thing
Tauri ships — renderer, locales, changelog, `webviewPreload.js`, `icon.png`, the win32 exes,
`legendary.LICENSE` — comes from `build/`. Two staging roots is a new drift class for no gain.

`packagingConfig.test.ts:133` hard-codes `` `../build/bin/${relPath}` ``; Option A keeps one uniform
source prefix so the reworked coverage predicate stays a single function instead of two.

Option A is also the smaller diff: the source strings are unchanged. Only the map they live in and
the target prefix change, so the live gate measures the mechanism change alone.

## D-e7o-02 — Scope boundary LIFTED by the developer

The research brief's "anything touching `bundle.resources` MAPPINGS is out of scope" is withdrawn.
8rm settled the SET of shipped trees; this task changes the COPY MECHANISM while preserving that set
byte-for-byte. The 8rm per-platform narrowing and the b8z `frontendDist` repoint both survive intact.

`tauri.conf.json5` would break `packagingConfig.test.ts`'s `JSON.parse`. The warning is instead
**enforced as a test** in Task 4 (disjointness + no-nesting) and documented in that test's docblock.
