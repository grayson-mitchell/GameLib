<objective>
Add licensed demos to the Steam library Refresh. Spike 052 showed that `getUserOwnedApps` never
returns demos, under any option and whether or not they have been played. The licenses path does
return them: `client.licenses` → PICS package info (`packageinfo.appids`) → PICS app info
(`common.type`). This plan unions those demos into the owned-apps list inside `syncOwnedLibrary`.

Purpose: a demo such as Schedule I: Free Sample (3205720, free-on-demand package 1136752) appears in
the library like any other game, and can be installed.
Output: a new pure+fail-soft module with unit tests, the wiring in `library.ts`, the corrected todo
note, and a final operator live check.
</objective>
