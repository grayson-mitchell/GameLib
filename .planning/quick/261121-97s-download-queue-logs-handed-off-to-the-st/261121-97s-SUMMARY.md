# Quick 261121-97s: Download queue logs "handed off to the Steam client"

A Steam install or update delegated to the Steam client no longer logs `Finished Installation of <appId>`. It logs `<Installation|Update> of <appId> handed off to the Steam client`.

## What changed

- `gameInstall.ts`: the macOS InstallApp `ok` return and the final steam://install return now return `{ status: 'done', handedOffToSteam: true }`. Native depot, bottle, bridge, setup-deferred and error returns are untouched.
- `utils.ts`: `installQueueElement` and `updateQueueElement` forward `handedOffToSteam` (strictly `=== true` for install). The badge `finally` logic is unchanged.
- `downloadqueue.ts`: new module-local `QueueElementOutcome` type; the call site takes the outcome object and `processNotification(element, outcome)` logs the hand-off line and returns before the `Finished` line. Toast, finished-list record and dequeue are unchanged.
- `game_manager.ts`: doc comment for `handedOffToSteam` covers both producers.
- Seven `games.test.ts` hand-off assertions updated to `{ status: 'done', handedOffToSteam: true }`; the native-depot `{ status: 'done' }` assertion is untouched, proving the flag did not leak.
- Todo closed in `.planning/todos/completed/` with `resolved`/`resolution` and a Resolution section.
