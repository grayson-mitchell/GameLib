<objective>
Close 51-REVIEW WR-03 in code (todo option (a), which the user chose, refined to PER EXACT
INTERFACE VERSION). On x64, an unserved runtime-lookup version whose Proton vtable has sret
slots gets a version-specific null object. Its sret slots zero-fill the hidden return buffer
and return it in RAX, so a caller no longer dereferences address 0.

Purpose: MSVC x64 passes the hidden sret pointer in RDX (after `this` in RCX) and expects RAX
to hold it on return. `vt_x64_null_object` returns 0 for every slot, so e.g. ELEX calling
`ISteamController::GetDigitalActionData` on its unserved `SteamController003` reads through 0.
Sret slot positions MOVE between versions (SteamController003 sret is at 9/12;
SteamController006 at 13/16/25). A family-wide table would therefore memset through RDX on a
slot where RDX is an ordinary argument, which is a new crash. So the tables are keyed by exact
version string and match exact strings only.

Output: a compact generated inventory JSON, generator support plus tests, a regenerated shim
that cross-compiles for both targets, and a progress note on the todo. The todo stays pending
because the live Wine gate on ELEX is still outstanding.
</objective>
