## Why

Quick task 260805-d62 marked the SIDLogin tile as deletion-pending on the
premise that the interactive legendary/SID login was the path being removed.
That premise was backwards. SIDLogin — real system browser, paste the auth code —
is the path that survives and becomes the single Epic device-auth sign-in in
Phase 34.7. The embedded WebKit login, the one that hits Epic's Talon anti-bot
403 (F-34.5-G6-01), is the one being deleted.

Because the F-34.5-G6-01 pivot swaps the tile roles per shell, marking the
embedded web login in both shells requires the exact inverse ternary:

| Shell | primary tile | alternative tile | marked |
|---|---|---|---|
| Tauri | SIDLogin (keep) | embedded web login | alternative |
| Electron | embedded web login | SIDLogin (keep) | primary |
