# Phase quick-261111-9p6 Plan 01: Windows Steam launch Stop Summary

Stop now ends Steam-launched games on Windows: a constant PowerShell CIM listing finds PIDs by executable path under the install folder, `taskkill /PID` (no force, no tree) asks them to close, and survivors that a fresh rescan still finds are force-ended after the grace.
