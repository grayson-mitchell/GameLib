**1. Layout files (genius, ps, nintendo, standard) — fix at the binding, not per use.** The
inputs are runtime Gamepad arrays (not static tables), so a tuple/Record type is not available;
use explicit defaults whose runtime result equals today's:
- Axes: bind `leftAxisX = axes[0] ?? NaN` (likewise every axis binding, including `dPadX`/`dPadY`
  and nintendo's `dPadAxis = axes[9] ?? NaN`). NaN gives exactly today's runtime result for an
  absent axis (`undefined < x`, `undefined * 10` and `=== -1` all behave identically with NaN),
