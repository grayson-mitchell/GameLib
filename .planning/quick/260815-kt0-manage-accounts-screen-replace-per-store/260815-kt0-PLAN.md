<objective>
On the Manage Accounts screen (`src/frontend/screens/Login`), stop rendering per-store account
usernames entirely. Every connected store tile shows the single italic word **Connected** instead.

Purpose: the displayed identity is structurally inconsistent across stores — Humble has no
retrievable username at all (its tile already falls back to a Humble-specific "Connected" string),
Amazon falls back to a literal "Unknown", and Steam/Zoom can be `undefined`. The usernames carry no
user value on this screen; the only thing the user needs is connection state. Removing them also
removes an account identifier from the rendered UI.

Output: a uniform, localised, italic connected-state indicator on all six runner tiles, with the
now-dead `user` prop and its two identity-fallback strings removed from frontend source.
</objective>
