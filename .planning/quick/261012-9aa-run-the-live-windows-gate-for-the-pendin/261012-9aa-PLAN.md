- builds an ordered hashtable of `TargetPath`, `Arguments` and `IconLocation`;
- adds `IconExtractable`, true when `$env:GATE_ICON` is non-empty and
  `[System.Drawing.Icon]::ExtractAssociatedIcon($env:GATE_ICON)` is non-null after
  `Add-Type -AssemblyName System.Drawing`;
- writes the result as `ConvertTo-Json -Compress` to `$env:GATE_OUT` with
  `[IO.File]::WriteAllText` and a BOM-less `System.Text.UTF8Encoding`.

Writing to a file instead of stdout keeps non-ASCII values clear of the console code page. Every
value reaches the script only through the environment, the same discipline as the module under
test. Always assert `existsSync(lnk)` BEFORE reading back: `CreateShortcut` on a missing path
returns an empty object, not an error.
