<decisions>
## Findings (established by the orchestrator, verified against source)

1. **The exemption is dead on EVERY OS, by construction, not just on Windows.** The enforcing rule
   flags a file only if it has a spawn call AND an object-literal assignment of one of the eight
   keys (`keyAssignmentRe`). `meta/sidecarStartupSmoke.cjs` has two `spawnSync` calls (lines ~105
   and ~122), and **neither passes an `env` key**. Its own header (lines 38-63) says this is the
   point: it inherits the real profile. So it can never match the detector, and skipping it
   suppresses nothing.
2. **The exemption hides the exact regression its file warns against.** The header says "anyone
   adding an `env` key here is removing this gate's ability to see the class of defect it exists
   for." If someone adds `env: { ...process.env, HOME: x }`, the exemption SKIPS the file on
   macOS/Linux, so the gate stays green. Today only the Windows path bug lets the gate see it.
3. **Both `ALLOWED_TO_ASSIGN` entries also suppress nothing today.** Neither
   `src/backend/testUtils/fakeHomeProfile.ts` nor `src/backend/jest.setupContainment.ts` contains a
   spawn-family call. The file's own docstring already says the setupContainment entry "documents
   intent rather than suppressing a live hit".
4. Therefore the todo's proof step, "drop the exemption and confirm the enforcing test goes RED",
   **cannot succeed and must not be attempted as a success criterion.** Nothing depends on the
   exemption.

## Implementation Decisions (locked)

### Path normalization
- Normalize once at the source: a `toRepoRel(abs)` helper returning
  `relative(REPO_ROOT, abs).split(sep).join('/')`. Use it for both `scannedRelPaths` and the `rel`
  in the enforcing loop. No other comparison site may call `relative()` directly.

### Exemption semantics: stop skipping, keep the drift check
- The `EXEMPTIONS` entry for `meta/sidecarStartupSmoke.cjs` STAYS, including its `reason` and
  `anchors`, and the "still exists on disk" and "reason still written in the file" tests stay.
  That is the machine-readable twin its header promises.
- But an exempt file is **no longer skipped by the enforcing scan**. Its exemption is from the
  *convention* (it must inherit the real profile). It is not an exemption from *this detector*,
  because the detector flags hand-rolled home/config/state env blocks, and an exempt file carrying
  one violates its own reason. Rewrite the EXEMPTIONS docstring to say this plainly.
- Add a test asserting that each exempt file **does NOT assign any of the eight keys** in its
  comment-stripped source and that it does contain a spawn call. This makes the exemption's
  contract ("passes NO env key") executable, which the current gate cannot see.
- `ALLOWED_TO_ASSIGN` keeps its skip semantics (the helper legitimately assigns the keys).

### Anti-drift for the skip list (catches this bug class on every OS)
- Add a test: every `ALLOWED_TO_ASSIGN` entry and every `EXEMPTIONS[].file` must appear in
  `scannedRelPaths`. Before normalization this goes red on Windows. That is the portable signal
  that a skip or exempt path can no longer match.

### Negative controls (the proof, run once and recorded in SUMMARY, NOT committed)
- (a) Temporarily add `env: { ...process.env, HOME: '/tmp/x' }` to one `spawnSync` in
  `meta/sidecarStartupSmoke.cjs`, then run the gate and confirm it goes RED. The enforcing scan
  should report the file, and the new "exempt file assigns no keys" test should fail too. Revert.
- (b) Temporarily revert just the normalization, confirm the new "skip list is reachable" test goes
  RED on this Windows machine, then restore.
- Record both outputs verbatim in SUMMARY. `git diff` must be clean of the injections afterwards.

### Docs
- Update CLAUDE.md, Fake-HOME section: "The one exemption, `meta/sidecarStartupSmoke.cjs`, is
  declared in that gate's `EXEMPTIONS` table with its reason, and the gate re-reads the exempt file

  the detector. The gate asserts the exempt file assigns none of the eight keys, so adding an `env`
  block there turns it red. Keep it to 1-2 sentences, matching the section's tone.
- Move the todo to `.planning/todos/completed/` with a short resolution note appended.
