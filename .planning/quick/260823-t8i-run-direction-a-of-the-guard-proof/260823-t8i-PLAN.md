# Quick task 260823-t8i — Direction A on real hardware

Direction B ran earlier today (`260823-suw`) and discharged item 16. This task runs the **failing**
direction: inject the F-34.9-01 defect, prove the guard catches it and aborts the chain before
`electron-builder`, then restore.

**No ledger item requires this.** Items 14/15/16 are all closed. This is a fresh exercise of the
contract under AMENDMENT v2 — in particular the first real use of v2 §A1's replacement PASS bar (d).

## The risk that shapes this plan

The injection mutates `public/bin/arm64/darwin/gogdl/_internal/Python.framework`, and **that tree
cannot be re-downloaded**: `download-helper-binaries` throws on the six `PENDING-CI-PUBLISH`
sentinels. `public/bin/**` is git-ignored, so git cannot restore it either.

The contract's restore depends on a single `mv`-aside copy living in `node_modules/.cache/` — the
exact directory `pnpm install` clears, and earlier today a plain `git checkout` was observed firing
this repo's post-checkout hook into `pnpm install`. **That is a single point of failure against an
irreplaceable asset.**

**Mitigation, taken before any mutation:** a tarball outside `node_modules`, archived without `-h`
so symlinks stay symlinks, and **test-extracted and diffed against the live tree to prove it
restores** before the injection begins. A backup that has never been restored is a hope, not a
backup.

to expect one; that prediction gets tested rather than assumed.
