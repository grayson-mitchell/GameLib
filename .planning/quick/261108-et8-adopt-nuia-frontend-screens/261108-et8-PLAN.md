## Fix patterns (apply everywhere; no per-line notes)

Hard rules: never a non-null `!`; never a widening, `as any` or `as unknown as` cast; never
weaken an assertion; pre-existing `!`/casts that are not ratchet sites stay as they are.

1. **Throwing helper for tests.** Task 1 (or whichever task first needs it) first greps
   `src/frontend` for an existing throwing `at`/`defined` helper in a shared test-support location
   (e.g. created by the `src/frontend/components` adoption under `src/frontend/__tests__/` or a
   `testUtils` dir). Reuse it if it exists and is not inside another bucket's component
   `__tests__` folder. Otherwise create `src/frontend/screens/__tests__/fixtures/indexed.ts`
   exporting `at<T>(xs: ArrayLike<T>, i: number, what?: string): T` (throws an Error naming
   `what`/`i`/length when the element is `undefined`) and, only if used, `defined<T>(v: T |
   undefined, what: string): T`. Export only what is used (knip). Later tasks reuse it. Record
   the choice in the SUMMARY.
2. **Element then member / call** (`calls[0][0]`, `mock.calls[0][1]()`, `rows[2].click()`,
   `screen.getAllByRole(...)[1]` passed to `fireEvent`, `match[1].trim()`): bind via `at(...)` /
   `defined(...)`, or destructure from an `at(...)` result. Never `?.` on a call or in a condition.
3. **Inside `expect(...)`**: `?.` allowed ONLY when the matcher fails on `undefined` (`toBe(<defined>)`,
   `toEqual(<defined>)`, `toMatch`, `toContain`, `toHaveLength`, `toBeGreaterThan`, `toBeNull`,
   `toBeInTheDocument`, `toHaveTextContent`). With `toBeUndefined`, `toBeFalsy`, any `not.*`,
   `toEqual(undefined)`, use `at`/`defined`.
4. **Regex/split/source-census tests** (`m[1]`, `src.split(...)[0]`, `readFileSync` + match):
   `defined(m?.[1], '...')` or an explicit `if (!m) throw`, so a non-match still fails loudly.
5. **Typed fixtures** (`tabFixtures.ts`, records keyed by literal): prefer a precise type
   (tuple, `Record<KnownUnion, T>`, `as const`) over a guard when that makes the index provably
   defined.
6. **React/TS source**: no behaviour change for valid data. Prefer precise types (tuple types,
   `Record` over string unions, `.at()` is NOT a fix since it is also `T | undefined`), or an
   explicit guard that returns the same fallback the code already uses (`?? ''`, early return of
   the existing empty state) where the index can legitimately miss. Never add, move or make
   conditional a hook; never add state or an effect; keep render output identical. If a site
   genuinely cannot be fixed without behaviour change, STOP and flag it in the SUMMARY.
7. `for (let i...)` loops over arrays: convert to `for...of` / `.entries()` only when semantics
   are identical; otherwise bind with a guard.
