## Finding 2 — Phase 34.1 human_uat test 4: the drag surface moved

`34.1-VERIFICATION.md:17-18` tells the tester to "drag the **sidebar** to move the window".

Phase 34.10 retired the left navigation. `NavShell/index.tsx:33` says so in its own comment
("Ported from the retired left navigation (`Sidebar/index.tsx:58-63`)"), and `Sidebar/index.tsx`
no longer exists — only an orphan `Sidebar/components/SidebarTour.tsx` remains.

The drag region is now resolved by `src/preload/api/tauriWindowChrome.ts:301-334`: it walks
ancestors reading `-webkit-app-region`, and when the webview does not implement that property
(the fallback's entire reason to exist) it falls back to
`start.closest('.NavShell__navbar') !== null`, minus an interactive-element/`.windowControls`
exclusion.

So the test is not stale — the behaviour it targets is live and still unobserved. Only the noun is
wrong, and a tester who goes looking for a sidebar will not find one.
