`Arguments` and `IconLocation` go through the ANSI code page (1252 here), so a title, target, icon

failure toast and no shortcut. That is the last open FAIL on

<facts_verified_by_orchestrator date="2026-10-12" box="Windows 11, ANSI code page 1252">
1. `WScript.Shell.CreateShortcut(...)` fails with `Value does not fall within the expected range.`,
   or stores `??`, when a `.lnk` path, target, argument or icon path contains `幻想`. This was
   measured through a Node `spawn` with env-passed values, the same way the product passes them.
2. An `IShellLinkW` + `IPersistFile` helper compiled with `Add-Type -TypeDefinition` writes the
   `.lnk` with UTF-16 `幻想` in its bytes. It reads back path, arguments and `icon,index`
   byte-exact. `Add-Type` costs about 150 ms, and the whole PowerShell round trip is about 500 ms
   per shortcut.
3. **`powershell.exe -Command -` reads stdin line by line and SILENTLY stops at a here-string
   opener (`@'`), with exit 0 and nothing on stderr.** A multi-line C# here-string on stdin is
   therefore a no-op that the `existsSync` contract would report only as a failure. The C# must
   travel as ONE single-quoted, single-line PowerShell string. Collapsing a readable multi-line
   constant at module load with `split(/\r?\n/).map(trim).filter(Boolean).join(' ')` was verified
   to work: exit 0, the file is present, and UTF-16 CJK is in it.
4. `-EncodedCommand` also works, but it puts CLIXML progress noise (`Preparing modules for first
   use`) on stderr, which would pollute the error the writer reports. It was rejected, and
   `POWERSHELL_ARGS` stays unchanged.
5. On failure the helper exits 1 and writes no file. Its stderr reads
   `Exception calling "Write" with "5" argument(s): "The system cannot find the path specified. ..."`.
   The existing exit-code + `existsSync` contract therefore holds.
6. The verified C# follows. Keep the member order of `IShellLinkW` exactly: it is the vtable order.

```
using System;
using System.Text;
using System.Runtime.InteropServices;
using System.Runtime.InteropServices.ComTypes;
namespace GameLibLnk {
  [ComImport, Guid("00021401-0000-0000-C000-000000000046")] public class ShellLink {}
  [ComImport, InterfaceType(ComInterfaceType.InterfaceIsIUnknown), Guid("000214F9-0000-0000-C000-000000000046")]
  public interface IShellLinkW {
    void GetPath([Out, MarshalAs(UnmanagedType.LPWStr)] StringBuilder pszFile, int cch, IntPtr pfd, int fFlags);
    void GetIDList(out IntPtr ppidl);
    void SetIDList(IntPtr pidl);
    void GetDescription([Out, MarshalAs(UnmanagedType.LPWStr)] StringBuilder pszName, int cch);
    void SetDescription([MarshalAs(UnmanagedType.LPWStr)] string pszName);
    void GetWorkingDirectory([Out, MarshalAs(UnmanagedType.LPWStr)] StringBuilder pszDir, int cch);
    void SetWorkingDirectory([MarshalAs(UnmanagedType.LPWStr)] string pszDir);
    void GetArguments([Out, MarshalAs(UnmanagedType.LPWStr)] StringBuilder pszArgs, int cch);
    void SetArguments([MarshalAs(UnmanagedType.LPWStr)] string pszArgs);
    void GetHotkey(out short pwHotkey);
    void SetHotkey(short wHotkey);
    void GetShowCmd(out int piShowCmd);
    void SetShowCmd(int iShowCmd);
    void GetIconLocation([Out, MarshalAs(UnmanagedType.LPWStr)] StringBuilder pszIconPath, int cch, out int piIcon);
    void SetIconLocation([MarshalAs(UnmanagedType.LPWStr)] string pszIconPath, int iIcon);
    void SetRelativePath([MarshalAs(UnmanagedType.LPWStr)] string pszPathRel, int dwReserved);
    void Resolve(IntPtr hwnd, int fFlags);
    void SetPath([MarshalAs(UnmanagedType.LPWStr)] string pszFile);
  }
  public static class Writer {
    public static void Write(string lnk, string target, string args, string icon, int iconIndex) {
      IShellLinkW link = (IShellLinkW)new ShellLink();
      link.SetPath(target);
      if (!string.IsNullOrEmpty(args)) link.SetArguments(args);
      if (!string.IsNullOrEmpty(icon)) link.SetIconLocation(icon, iconIndex);
      ((IPersistFile)link).Save(lnk, true);
    }
  }
}
```
