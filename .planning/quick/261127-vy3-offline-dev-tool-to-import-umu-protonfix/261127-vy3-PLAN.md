The importer translates the declarative subset of umu-protonfixes `gamefixes-steam/*.py` into candidate GameLib local fix files for Mac testing:

| protonfixes helper | GameLib key | tier |
| --- | --- | --- |
| protontricks | `winetricks` | 1 |
| set_environment | `envVariables` | 1 |
| append_argument | `launchArgs` | 1 |
| replace_command | `exeOverride` | 1 |
| winedll_override | `dllOverrides` | 2 |
| regedit_add | `registry` | 2 |

disable_esync, disable_fsync and disable_nvapi are skipped as not applicable on macOS. Every generated file keeps the BSD-2-Clause attribution.

This turns it into hand-testable candidates in GameLib's own schema: tier 1 `<appName>-<store>.json`, tier 2 `<appName>-<store>.profile.json` (notes decisions 1 and 3). It is a dev tool, not a runtime feature. Promotion stays the Phase 57 PR flow.

  - Registry `name` must be non-empty, at most 256 units and must not start with `/`.

  - `set_environment(envvar, value)`

   - `--source-url` defaults to `https://github.com/Open-Wine-Components/umu-protonfixes`.
   - **Revision.** `--source-rev` overrides it. Otherwise it is resolved from the checkout's `.git/HEAD` by reading files only: a detached 40-hex SHA, or `ref: <ref>` resolved through `.git/<ref>` and then `.git/packed-refs`. Anything that is not 40 lowercase hex is an error.

   - Take the copyright lines from lines matching `/^\s*Copyright/i`.
   - Every emitted file gets two notes:
     - `notes["umu-protonfixes"]`: "Candidate generated by meta/importProtonfixes.ts from umu-protonfixes gamefixes-steam/<id>.py at <rev> (<url>/blob/<rev>/gamefixes-steam/<id>.py). Not Mac-validated: test it as a local fix before promoting it. <copyright lines>. Used under the BSD-2-Clause licence; the full text is in notes.umu-protonfixes-license."
     - `notes["umu-protonfixes-license"]`: the licence text, trimmed.

   **Safe enumeration** of `<source>/gamefixes-steam`, sorted numerically by appId and then by name:
   - Every entry counts toward the total.
   - A name that is not `^[0-9]{1,10}\.py$` is skipped as `not-an-appid-file`.
   - Use lstat. A symlink is followed only when its realpath lies inside the realpath of `<source>`. Anything else (an escaping link, not a regular file, or larger than 256 KiB) is skipped as `unsafe-file`, with the detail in the report.
   - Output filenames come only from the matched appId digits.
   - `--only` restricts the set to the listed appIds. Their entries still count in the total; the rest are left out of the run and reported as such.

   **Python tokenizer.** Hand-written, linear, scanning character by character with no backtracking regexes. It handles:
   - a leading UTF-8 BOM and `#` comments
   - physical-to-logical line joining by backslash continuation and inside (), [] and {}
   - indentation width, with a tab advancing to the next multiple of 8
   - NAME, NUMBER (decimal, 0x, 0o and 0b forms, with underscores), OP and STRING tokens

   STRING handling:
   - Every prefix combination of r, u, b and f in any case, single and triple quotes in both quote styles.
   - Values are decoded exactly as Python 3 decodes them: `\\`, `\'`, `\"`, `\n`, `\t`, `\r`, `\a`, `\b`, `\f`, `\v`, octal `\ooo`, `\xHH`, `\uHHHH` and `\UHHHHHHHH`.
   - An unknown escape keeps its backslash verbatim, as Python does. This matters for `'HKCU\Software\Wine'`.
   - A raw string keeps its backslashes, but a backslashed quote still does not end it.
   - `\N{…}`, f-strings and byte strings are non-literal.

   An unterminated string or unbalanced brackets throws a parse error, and the file is skipped as `parse-error`. The tokenizer never hangs.

   **Statement model.**
   - **Module level:**
     - An optional docstring becomes the title source.
     - `import` and `from … import …` lines are recorded as bindings. `util` is the helper module, and bare helper names are honoured only when imported from a module path ending in `util`.
     - `def main(…)` (optionally with a `-> None` annotation) is the fix body.
     - Any other `def` is ignored on its own.
     - Any other module-level statement is unmapped `module-level-statement`, because it runs at import.
   - **main's body:**
     - It is the following logical lines indented deeper than the header, or the simple statements after the header's `:` on the same line.
     - Split simple statements on top-level `;`.
     - A line ending in `:` (if, elif, else, for, while, with, try, except, finally, def, class, match) plus all its deeper lines is ONE unmapped `non-declarative-statement`. Calls inside it are never extracted.
     - A docstring, `pass` and a bare `return` or `return None` are ignored.
   - **Recognised calls.** A simple statement that is exactly `util.<helper>(<args>)`, or `<helper>(<args>)` for a bare imported helper, is a recognised call.
     - Args are positional, then `name=` keyword.
     - A literal is one or more adjacent STRING tokens (concatenated), an integer NUMBER, `True`/`False`/`None`, or `OverrideOrder.<MEMBER>` / `util.OverrideOrder.<MEMBER>`.
     - Anything else is unmapped `non-literal-argument`.
     - A call to a non-util function is unmapped `unsupported-call`.
     - Any other expression or assignment is `non-declarative-statement`.
   - Bind arguments to the util.py signature; a wrong count or an unknown keyword is `bad-arguments`.

   **Mapping (this task: protontricks only).**
   - The verb must be a string matching `^[A-Za-z0-9][A-Za-z0-9_.=+-]*$`, else `invalid-value`.
   - Append it to `winetricks` in source order, dropping duplicates and keeping the first occurrence.
   - Every other helper is unmapped `unsupported-helper:<name>` for now.

   **Candidate assembly and classification.**
   - **Title.** Take the first line of the module docstring with a leading `Game fix for ` removed (case-insensitive). Fall back to `Steam app <appId>`.
   - **Upstream comment.** Put the comment lines directly above `def main` and main's own docstring, joined and capped at 1000 characters, into `notes["upstream-comment"]` when present.
   - When any statement is unmapped, add `notes["protonfixes-unmapped"]`: one line per unmapped statement, `line <n>: <first source line, max 200 chars> (<reason>)`.
   - **Typing.** Build the tier-1 object typed as `KnowFixesInfo` (`import type { KnowFixesInfo, KnownFixProfile } from '../src/common/types'`). Emit the keys in a fixed order: title, notes, then fix keys in TIER1 list order.
   - **Classification:**
     - `translated`: at least one fix key emitted and nothing unmapped.
     - `partial`: at least one fix key emitted and at least one statement unmapped.
     - `skipped`: no fix key emitted.
   - Skip reasons form a closed set: `not-an-appid-file`, `unsafe-file`, `parse-error`, `no-main`, `empty-main`, `only-not-applicable` (used from Task 2) and `nothing-mapped`.

   **Writing.**
   - Write each candidate as `JSON.stringify(obj, null, 2)` plus a newline to `<out>/fixes/<appId>-steam.json`.
   - Write `<out>/report.json`:
     - `tool: "importProtonfixes"`

     - `counts: { total, translated, partial, skipped }`

   - No timestamps anywhere, so a re-run over the same revision is byte-identical.
   - Print to stdout the total, the three counts, and the skip and unmapped reasons sorted by count.

   **Exports for the test:** `tokenizePython`, `translateFixSource(source, appId, attribution)` and `runImport(options)`. `main()` parses argv, calls `runImport` and exits non-zero on error. Guard it with `if (!process.env.JEST_WORKER_ID)`.
