Convert each site mechanically, in two forms:

- plain literal -> `crate::shell_diag("...")`
- interpolated -> `crate::shell_diag(&format!("..."))`

`format!` and the macro it replaces share `format_args!`, so every formatting form already in the

Drop the leading 8-character prefix from every message. `shell_diag` prepends it itself, so stderr
stays byte-identical — that is the whole reason this is safe to do to a file five previously-scored
UAT arms grep against (per D-LZ5-02).

Order of work — tracer-first, within this one task. Convert site ~1816 FIRST (the D-14
launcher-scheme block: two inline captures, one of them a const, and a `\`-continued literal — the

continuation literal still compiles. Only then convert the remaining 29. There is no separate
tracer commit because this task commits atomically and the orchestrator fixed the three-task split;
the de-risking value is in the ordering, not in a second commit.

Three shapes need care:

1. **`\`-continued literals.** Several messages are written across lines with a trailing `\`. That
   continuation strips the newline AND all leading whitespace on the next line, so re-indentation
   cannot change the concatenated text — but a hand-collapsed line can silently add or lose a
   space. Do not collapse them. Leave the continuation structure as-is and let `cargo fmt` reflow.
2. **Site ~983 has no trailing semicolon** — it is the tail expression of a `match` arm block.
   Both the old macro and `crate::shell_diag` evaluate to `()`, so this is safe either way, but do
   not "fix" it by adding a semicolon and changing the arm's shape.
3. **Do not write either of the two swapped-out tokens into this file's comments.** The file has
   **0** comment occurrences of the prefix today, and Task 1's gate greps the whole file unfiltered
   as well as comment-filtered. If you add a doc comment explaining the swap — and you should —
   refer to "the prefix `shell_diag` adds" and "the stderr-only macro" rather than reproducing
   either literal. A comment that names the token it forbids is a gate that invalidates itself.

Then run `cargo fmt --manifest-path src-tauri/Cargo.toml` in write mode and verify the concatenated
message text is unchanged apart from the dropped prefix. Do this mechanically, not by eye: compare
the literals in the working tree against `git show HEAD:src-tauri/src/macos_epic_embed.rs` with the
prefix stripped from the HEAD side. Thirty hand-edited string literals is exactly the population
