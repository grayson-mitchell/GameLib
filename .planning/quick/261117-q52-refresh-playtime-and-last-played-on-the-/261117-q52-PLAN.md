`~/Library/Application Support/Steam/userdata/<accountId>/config/localconfig.vdf`:

  never prefix match).

  without Playtime (and vice versa), so each field is independently optional.
- `userdata/` also contains a `0` directory; accountId derivation must never resolve to it for a
  real SteamID.
</facts>
