<objective>
Close the 32-bit Mac Steam orphan defect at both ends: stop NEW orphans being created
(auto-remove the unrunnable native i386 install when routing a demoted title into the
CrossOver bottle, Apple Silicon only), and give the user a single action to clean up
orphans that ALREADY exist on disk from before this ships (HOARD/63000 currently needs
three separate Uninstall clicks, one per install root).

Purpose: every 32-bit Mac Steam title currently leaves an unrunnable native install on
disk forever, because no install path in `games.ts` ever deletes anything and `install()`
has no already-installed guard.

Output: an Apple-Silicon host gate, a shared multi-root enumerate/remove primitive, a
route-time auto-cleanup call in `install()`, a `steamRemoveAllCopies` IPC channel wired
across all four mirrored seams, and a "Remove all copies" button in the Steam game submenu.
</objective>
