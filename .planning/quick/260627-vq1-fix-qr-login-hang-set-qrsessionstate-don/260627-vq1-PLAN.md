<objective>
Fix the QR login hang. When a user scans the Steam QR code and approves on their phone, the app currently does nothing because the `authenticated` handler awaits `finishAuth()`, which awaits `connectSteamUserClient()`, which waits indefinitely for the Steam CM `loggedOn` event. The frontend poll keeps seeing `waiting` forever.

Purpose: Make QR login complete the moment Steam authenticates the user, decoupling the persona-name fetch (CM connection) from the login-done signal, and add a hard timeout so no auth flow can hang.

Output: Updated `src/backend/storeManagers/steam/user.ts` and corresponding test updates.
</objective>
