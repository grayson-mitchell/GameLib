## Split spelling — read this before writing a single line

This plan, the gate, the gate's self-test and the rewritten todo all discuss an XML-style closing
tag. **The literal string is never written joined up, anywhere.** In prose it is written as two
adjacent code spans — `` `</content` `` followed by `` `>` ``. In Python it is built by
concatenation from parts.

Stated once, explicitly, so the next reader does not "helpfully" rejoin the halves. The repo has
recorded that exact impulse. Two independent reasons it matters:

1. **Self-conviction.** The gate's own source lives under `.planning/`; the moment anyone widens
   its corpus to `.py`, a joined literal in its own docstring convicts it.
2. **Grep poisoning.** Every future census of this artifact is a grep. Prose that spells the
   literal is indistinguishable from the artifact itself, and the repo has recorded both
   directions of that failure — a gate satisfied by the prose that names it, and prose that
   falsely fails a gate meant to catch exactly that defect.
</notation>
