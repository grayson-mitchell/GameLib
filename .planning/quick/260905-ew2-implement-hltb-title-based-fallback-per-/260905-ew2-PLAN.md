## Task

`getHowLongToBeat(game, hltbId)` has two working branches — GOG (scrape the store page) and
`hltbId` (fetch `/game/{id}`). `hltbId` only ever comes from `pcgamingwiki?.howLongToBeatID`, so
every non-GOG game whose PCGamingWiki article carries no HLTB ID shows no playtime, permanently.

Add a third branch that resolves by title, with a confidence threshold and an explicit
don't-guess fallback.

## Design decisions (locked)

**D1 — The matching rule is the deliverable, not the HTTP call.** A wrong match silently shows
wrong playtime and there is no UI affordance to correct it, so the acceptance rule is
conservative and lives in a pure, network-free module that can be tested exhaustively.

Accept a candidate only when ALL hold:
1. Normalized similarity ≥ `MIN_CONFIDENCE` (0.9), where an exact normalized match scores 1.0.
2. The runner-up trails by ≥ `MIN_MARGIN` (0.05). Near-ties are refused — this is what makes
   `Doom` (1993) vs `DOOM` (2016) return nothing rather than a coin flip.
3. Sequel tokens agree. A trailing arabic/roman numeral on either side must match the other
   exactly. Kills `Portal` → `Portal 2` and `Final Fantasy VII` → `Final Fantasy VIII`
   regardless of string similarity.

Refusal is a first-class outcome: log it and return `null`.

**D2 — Keep the HTTP clients separate.** This module deliberately uses bare `axios` with a
`Chrome/120` UA because HLTB sits behind Cloudflare. `utils.ts`'s shared `axiosClient` sends a
descriptive agent and its comment forbids browser impersonation (that is the PCGamingWiki UA
policy). Do not unify them; add a comment saying why.

**D3 — The search endpoint is undocumented and will break.** HLTB's search is a POST whose path
carries a per-build token scraped from the site's JS bundle. Treat every step as failure-prone:
token scrape, endpoint POST, payload shape. Any failure returns `null` — never throws, never
degrades the other wiki lookups.

**D4 — `'skipped'` stops being assignable, but the type member and the self-heal clause stay.**
With a third branch, a non-GOG game always issues an HLTB request, so the outcome is `'ok'` or
`'notfound'`. Remove `'skipped'` from the derivation. Keep it in `HowLongToBeatOutcome` and keep
the `staleWikiFetch` clause keyed on it — that clause is what makes already-cached `'skipped'`
entries re-fetch through the new path instead of sitting until their 30-day expiry.

## Out of scope

Cache self-heal and the PCGamingWiki User-Agent work — both closed and verified.
