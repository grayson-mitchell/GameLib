<objective>
Stop the Amazon boot probe reporting `healthy` when it has gathered no evidence. With zero
installed Amazon games, `nile list-updates --json` prints `[]` + `ERROR [CLI]: No games
installed` and exits 0 before any auth call (49-LIVE-GATE Run 1 item 6, F-49-R1-4; review WR-02;
re-measured 2026-10-10 against the bundled `public/bin/arm64/darwin/nile/nile` with an isolated
`NILE_CONFIG_PATH`: exit 0, stderr `ERROR [CLI]:\t No games installed`, with or without an
`installed.json`). `classifyNileOutput` falls through to `healthy`, which `signInState` maps to
`connected`, so a user with nothing installed is never told their Amazon sign-in expired.

Purpose: make the no-games shape classify `unknown` (no write, no row, P1) instead of `healthy`.
Output: the classifier change, tests pinning both stdout/stderr orders, the todo closed.
</objective>

<context>
Decision taken at planning, with the record behind it:

- **Classifier guard, not a replacement probe command.** The todo offers two routes. Probing with
  `nile library sync` is ruled out by 49-CONTEXT D-16 ("the pass never triggers library sync for
  any store"; 49-RESEARCH rejected-alternatives row, line 130). The 49-SPEC boundary row (commit
  `883ad7a6a`) further gates any replacement command on the Amazon induction live gate
  (`…amazon-expiry-strings-need-a-real-induction.md`, `ready: live-gate`) because its expired-token
  output is unmeasurable until then. The classifier guard needs neither: the no-games output has
  been observed 7x live and re-measured today.
- Rule 260822-vov holds: `expired` only on a proven auth failure; `healthy` needs positive
  evidence from the classifier's OWN spawn. A `No games installed` exit is zero evidence either
  way, so `unknown` is the correct bucket. If a refresh-failure line and the no-games line ever
  co-occur, the refresh line still decides (it is evaluated first).
- `nile/library.ts` runs the same command for its own purposes and tolerates the empty shape;
  that path is untouched (the classifier is only reached from `probeNileSession`).
</context>
