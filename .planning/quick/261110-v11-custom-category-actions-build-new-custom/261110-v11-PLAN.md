<objective>
Make the custom-category actions in `useLibraryState` build a fresh `customCategories` object (and
fresh arrays wherever an array changes) instead of mutating the held object in place. Resolves
`.planning/todos/pending/2026-11-10-custom-categories-mutated-in-place.md`.

Purpose: `setCustomCategory` currently sets the *same* reference it mutated, so an identity-comparing
subscriber (PureComponent, `useShallow`) can skip the re-render. All three mutate the store's initial
`{}` across resets, which is why tests have to seed `customCategories` themselves.

Output: fixed actions, regression tests, todo moved to `completed/` with a Resolution note.
</objective>
