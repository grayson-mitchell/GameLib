# Quick 261012-7f2 — the one-config-change test run 11 left

Run 11 (quick `261011-ws7`) refuted the IP, the UA and the jar; the embedded Tauri child webview is
the discriminator. The cheapest next measurement is the shipped pristine construction
(`open_pristine_epic_login_window`, `src-tauri/src/main.rs`) pointed at the store URL.

## Why a harness arm, not the shipped window

The shipped arm already routes ANY `www.epicgames.com` URL to the pristine window (`is_epic_login`
is a host check), so the store URL needs no code change there. But the shipped window attaches to
the process-durable `defaultDataStore()`, which on this machine holds the operator's signed-in Epic
jar. A render there would be the warm-jar confound run 11 was built to exclude, and clearing it
is a logout (`logging-out-of-epic-is-a-one-way-door-on-a-cold-jar`). The spike's own harness app
gets a port of the pristine construction on a `nonPersistentDataStore()` — cold by construction,
fresh per window, the same ephemeral shape as run 11's Private Window.
