# Quick Task 260919-u23 — BLOCKED on a credential, not on analysis

Everything except the 48-locale fill is designed, written and verified. The work was
**reverted to a clean tree on purpose** (see "Why reverted"), and is reproduced verbatim
below.

## The blocker, precisely

`meta/machineFillGamelib.ts:658` hard-codes `https://api.anthropic.com/v1/messages` with an
`x-api-key` header and **ignores `ANTHROPIC_BASE_URL`**. This environment has
`ANTHROPIC_BASE_URL` **set**, so its `ANTHROPIC_API_KEY` is scoped to that gateway, not to
the public API. Measured: the script returned `HTTP 401` for `de`, and an independent
`curl` straight to `api.anthropic.com` with the same key also returned `HTTP 401`.

This is **not** the transient `fetch failed` that `260919-9gu` hit at 15/48 and explicitly
distinguished from an auth error. It is an auth-scope mismatch, and it is not fixable from
inside this session.

**Do NOT "fix" it by teaching the script to honour `ANTHROPIC_BASE_URL`.** That would route
catalog content through a different endpoint than the proven tool was built and reviewed
for — a policy decision about where repo content is sent, not an implementation detail.

## Why reverted rather than left in the tree

`en/gamelib.json` gaining a key while 48 locales stay unfilled is exactly the
presence-baseline drift that fails CI **hard**: `comparePresenceBaseline` asserts the live
missing set equals `missing: {}`, and `missingPairs()` counts a key as missing when it is
`undefined` **or empty string**. A concurrent session committed 14 times and pushed twice
unannounced during this session, so leaving an uncommittable half-state in the shared tree
risked someone shipping a CI-red commit. Migration and fill must land as ONE commit.

## Design decision worth preserving: `{{doorLabel}}`

The English value interpolates the button name instead of hard-coding it:

    ...click the &quot;{{doorLabel}}&quot; button

fed from `tGamelib('installFlows.importDoorLabel')`. The previous defect existed *because*
the label was duplicated into 49 catalogs and then renamed. `machineFillGamelib`'s contract
preserves `{{…}}` placeholders through a fill, so a future rename updates every locale
automatically rather than rotting. `installFlows.importDoorLabel` already exists, correctly
translated, in **all 49** locales.
