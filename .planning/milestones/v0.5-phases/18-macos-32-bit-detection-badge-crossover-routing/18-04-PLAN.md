<objective>
Render an OS/arch badge beside the game logo with a "32" mark on 32-bit macOS builds, escalated to an actionable warning only on a macOS host (MAC32-04).

Purpose: Surface the arch signal so a user sees at a glance that a mac game is 32-bit-only. On macOS this is actionable (it will route to CrossOver); on Windows/Linux hosts a "mac 32" note is trivia, so it stays informational (or is omitted).
Output: `MacArchBadge.tsx` (mirrors `PlatformSupport.tsx`'s prop shape), its barrel export, a render site as a sibling of `.store-icon` in `GamePage/index.tsx`, a CSS rule, and an RTL test.
</objective>
