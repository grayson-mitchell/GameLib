<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GOG catalog API → Discounts renderer | `CatalogProduct.title` is externally-sourced text used as a lookup key |
| Renderer ownership signal → user | The pill asserts "you own this" / "you have a key" |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-01-01 | Spoofing (of ownership signal) | resolveDiscountBadge title→AppID bridge | mitigate | Exact normalized-title match only (`.trim().toLowerCase()` equality) — no fuzzy scoring, no regex/wildcard; a crafted GOG title cannot silently collide with an unrelated AppID beyond an exact string match, and a missing badge is explicitly preferred over a wrong one (D-79/D-82). |
| T-15-01-02 | Information Disclosure | Pill copy | accept | Pill text is only the fixed strings "Owned"/"Key available" — never renders key values, AppIDs, or account data. No sensitive data crosses to the UI. |
| T-15-01-03 | Tampering | Package installs | n/a | This plan installs zero npm/pip/cargo packages — no supply-chain surface this phase. |
</threat_model>
