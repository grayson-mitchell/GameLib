## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-03 | Denial of Service | library.ts fan-out | mitigate | Bounded pool (HUMBLE_SYNC_CONCURRENCY=3), abort-on-first-403/429 (429 mapped to access_denied in Plan 01), HUMBLE_COOLDOWN_MS gate (D-25/D-33) — never hammer a Humble denial |
| T-11-04 | Information Disclosure | library.ts logging | mitigate | Redacted logging: gamekey identifiers + status strings only, never a raw order/tpk/key value; caught rejections log message/status only, never the cookie |
| T-11-05 | Tampering / DoS | per-order schema_error / thrown transient | mitigate | Per-order isolation (Pattern 2) + per-order try/catch — a schema_error or a thrown network/timeout error on one order keeps its cached entry and continues; sync never crashes and never rejects unhandled |
| T-11-06 | Tampering | fail-soft abort cache integrity | mitigate | Abort only stops dispatch; no code path calls humbleLibraryStore.clear() — completed per-order writes survive (Pitfall 4) |
| T-11-08 | Denial of Service | unhandled rejection reaching the humbleSync IPC handler | mitigate | Every getGamekeys/getOrderDetail call is wrapped in try/catch (mirroring user.ts:checkHealthAndFlagExpiry); a thrown transient error becomes a fail-soft syncError='network', never an unhandled rejection to the renderer (D-31) |
| T-11-SC | Tampering | npm installs | accept | Zero new packages this phase |
