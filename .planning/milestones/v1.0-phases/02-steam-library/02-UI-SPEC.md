# Phase 2 — UI Design Contract: Steam Library

> Visual and interaction contract for Phase 2 (Steam Library). Generated by
> gsd-ui-researcher. This phase adds Steam games to the existing unified
> library view. No new screens are introduced. All Steam games appear inside
> the existing `src/frontend/screens/Library/index.tsx` alongside Epic, GOG,
> Amazon, and Zoom games.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none — custom SCSS CSS variables (`src/frontend/styles/`) |
| Preset | not applicable |

## Spacing Scale

This project uses an em-based relative scale, NOT a pixel 8-point grid. The
fixed-pixel variants (`-fixed` suffix) are provided for cases where em
relative sizing is inappropriate (e.g. fixed-height components).

| Token | Relative | Fixed-px approx. | Usage in this phase |
|-------|----------|------------------|---------------------|
| `--space-3xs` | 0.25em | 4px | Status badge inner padding, border-radius |
| `--space-2xs` | 0.375em | 6px | Dense badge padding |
| `--space-xs` | 0.5em | 8px | Icon gaps, inline spacing |
| `--space-sm` | 0.75em | 12px | Compact element padding |
| `--space-md` | 1em | 16px | Default element spacing |
| `--space-lg` | 1.5em | 24px | Section padding, card gap |
| `--space-xl` | 3em | 48px | Layout gaps |
| `--space-2xl` | 4.5em | 72px | Major section breaks |
| `--space-3xl` | 8.5em | 136px | Bottom padding of game list |
| `--space-md-fixed` | — | 16px | LibraryHeader padding, game list padding |
| `--space-xs-fixed` | — | 8px | Icons area padding |

Exceptions:
- Steam store badge on GameCard: `width: 35px; height: 35px; border-radius: 10px` —
  follows existing runner icon dimensions. Do not substitute spacing tokens here.
- Stale indicator inline icon: 16px — match `--text-md` icon size.

### New elements introduced in Phase 2

#### 1. Steam Store Logo SVG

**Asset path:** `src/frontend/assets/steam-logo.svg`

Create a single-colour SVG of the Steam "S" mark (the steam gauge icon used in
Steam's official branding). Must be SVG with `fill="currentColor"` so it
inherits `var(--text-default)` from parent. Sized to 35×35 display box via the
`.store-icon` class (existing).

**Rendered by:** `StoreLogos` component, top-right of each Steam `GameCard`.

#### 2. Steam Sync Status Spinner (background sync)

**Location:** Inline inside `LibraryHeader` `<h5>`, to the right of the game
count badge. Visible only when `steam.syncing === true`.

**Appearance:**
- Icon: `faSyncAlt` from `@fortawesome/free-solid-svg-icons`
- Size: 14px (use inline `style={{ fontSize: '14px' }}`)
- Color: `var(--text-secondary)`
- Animation: `@keyframes refreshing` (1.5s infinite rotation — already defined in
  `UpdateComponent/index.css`)
- Tooltip (`title` attribute): "Syncing Steam library…"

**Behaviour:** Hidden when sync is not in progress. Does NOT block the library
view — the cached library shows through.

#### 3. Offline Stale Indicator

**Location:** Below the `<h5 className="libraryHeader">`, inside the
`.libraryHeaderWrapper` as a second row. Visible only when
`steam.syncedAt !== null && connectivity.status !== 'online'`.

**Appearance:**
- Text: "Steam library last synced [relative time]"
  (e.g. "Steam library last synced 3 hours ago")
- Typography: `var(--text-xs)` (~11px), weight `--regular`, color
  `var(--text-secondary)`
- No icon needed

**Relative time formatting:** Use the i18n-compatible relative time pattern.
Express in the largest whole unit: minutes → hours → days. Never show seconds.
Examples: "2 minutes ago", "1 hour ago", "3 days ago".

#### 4. Manual Refresh Button

**Location:** `LibraryHeader`'s `ActionIcons` component — appears as an
additional icon button alongside the existing sort/filter/layout icons. Visible
whenever `storesFilters.steam === true` (Steam filter is included).

**Appearance:**
- Icon: `faSyncAlt` from FontAwesome
- Size: matches existing `ActionIcons` icon size
- Color: `var(--action-icon)` at rest, `var(--action-icon-hover)` on hover
- During sync: icon rotates with `@keyframes refreshing` animation, disabled state
- `title` attribute: "Refresh Steam Library"

**Click behaviour:**
1. Sends `refreshSteamLibrary` IPC call (name to be confirmed by planner)
2. Icon enters spinning/disabled state
3. Returns to rest when `libraryChange` IPC event fires for `'steam'` runner

#### 5. Playtime Display

**Locations:**

*Grid layout (`.gameCard`):*
Inside the hover title overlay (`.gameTitle` area), below the game title text,
as a separate `<span>` with class `steamPlaytime`.

*List layout (`.gameListItem`):*
Inside the `gameListInfo` column, below or replacing the status label when
no active status exists. Add class `steamPlaytime` to the span.

**Appearance:**
- Typography: `var(--text-sm)` (~13px), weight `--regular` (400), Cabin
- Color: `var(--text-secondary)`
- Format: `"{N} hours"` where N is total playtime in hours, rounded to nearest
  whole number (e.g. "47 hours", "1 hour", "0 hours")
- Zero playtime: "Never played"
- Missing playtime (data not yet available): render nothing (omit the element)

**Data source:** `GameInfo.extra.steamPlaytimeMinutes` (field name TBD by
planner based on GameInfo type extension). Phase 2 only reads and displays this
value — no in-session tracking.

## Interaction States

### Steam GameCard — state matrix

| State | Cover art | Title overlay | Status badge | Install icon | Playtime |
|-------|-----------|---------------|--------------|--------------|----------|
| Metadata loading | `img.loading` (opacity 0 → dark card bg shows) | AppID as placeholder (e.g. "730") | — | Download icon (accent) | — |
| Metadata loaded, not installed | `img.loaded`, grayscale filter | Game title | — | Download icon (accent) | "[N] hours" or "Never played" |
| Metadata loaded, installed | `img.loaded`, full colour | Game title | "Installed" in `--success` | Play icon (success) | "[N] hours" or "Never played" |
| Syncing (background) | as above | as above | — | as above | as above |

### Library loading states

| Condition | What user sees |
|-----------|---------------|
| First-ever sync (no cache, `steam.library.length === 0`, `refreshing`) | `<UpdateComponent message="Syncing your Steam library…" />` fills the library area. No game grid. |
| Background sync (cached data exists, `refreshingInTheBackground`) | Normal game grid shows. Steam sync spinner appears in LibraryHeader next to game count. |
| Offline, cached data exists | Normal game grid shows. Stale indicator appears: "Steam library last synced [X] ago". Sync spinner is hidden. |
| Steam CM sync error | Game grid shows cached data. Toast or inline error: "Steam library sync failed. Try refreshing." No retry is automatic — user must use Refresh button. |

### Metadata lazy loading

When a Steam `GameCard` enters the viewport (`visible-cards` event — existing
pattern in `GamesList`):

1. `CachedImage src` is unset or empty → `img.loading` class → opacity 0 →
   dark card background shows as cover art placeholder.
2. Title renders as AppID string (numeric) until `getGameInfo(appName, 'steam')`
   returns real `GameInfo`.
3. Metadata IPC call resolves → `title`, `art_cover`, `art_square` are populated
   → `CachedImage src` is set to Steam CDN URL → `img.loaded` class → 500ms
   fade-in to full opacity.
4. No spinner on individual cards — the opacity fade is the transition.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA (manual refresh) | "Refresh Steam Library" |
| First-sync empty state message | "Syncing your Steam library…" |
| First-sync empty state body | "Your games will appear here once the sync completes." |
| Background sync tooltip | "Syncing Steam library…" |
| Offline stale indicator | "Steam library last synced [X minutes/hours/days] ago" |
| Sync error inline | "Steam library sync failed. Try refreshing." |
| Playtime — has playtime | "[N] hours" (e.g. "47 hours", "1 hour") |
| Playtime — zero plays | "Never played" |
| Metadata loading placeholder title | "[AppID]" (e.g. "730" — the numeric Steam AppID) |
| Installed status badge | "Installed" (matches existing pattern for other runners) |

Grammar rules:
- "1 hour" (singular), "2 hours" (plural). Implement via `n === 1 ? 'hour' : 'hours'`.
- Use sentence-case for all messages, not title case.
- No ellipsis except in the active "Syncing…" message.

**Destructive actions in Phase 2:** None. Phase 2 is read-only library
browsing. Install / uninstall / launch are Phase 3.

## Implementation Constraints

1. **CSS token enforcement:** All new CSS written in this phase must reference
   semantic tokens (`var(--...)`) from `_colors.scss` and `_spacing.scss`. No
   hardcoded hex values or bare pixel values (except where existing codebase
   already uses them, e.g. the 35px store badge).

2. **No new font imports:** Rubik and Cabin are already loaded. Do not add
   Google Fonts links or font-face declarations.

3. **No new icon packages:** Use FontAwesome (`faSyncAlt` for refresh/spinning)
   or MUI Icons for any new icons. A Steam logo SVG is needed as a standalone
   asset (see "Steam Store Logo SVG" above) — it is NOT a font icon.

4. **Theme compatibility:** New elements must visually validate in at least
   midnightMirage (default), classic, and dracula themes. Use theme-variable
   tokens — do not hardcode values that only work in the dark default theme.

5. **i18n:** All user-visible strings must be wrapped in `t('key', 'fallback')`
   using `useTranslation`. Do not render raw English strings without i18n
   wrappers.

6. **Electron main process only:** `steam-user` and `steam-session` must never
   be imported in renderer/frontend code. All Steam data arrives via IPC.
