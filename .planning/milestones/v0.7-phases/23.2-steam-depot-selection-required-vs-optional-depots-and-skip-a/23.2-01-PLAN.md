<objective>
Settle the documented contradiction folded in as D-08 sub-item 1, and close D-08 sub-item 2's
size lead — both by reading the **pre-fix** source, before plan 23.2-02 changes it.

Three standing records disagree about whether a failed native install writes an
`appmanifest_*.acf`:

1. `2026-08-16-aborted-depot-residue-has-no-acf.md` — "the `.acf` is only written on a
   successful completion", and builds its whole reconciler-invisibility argument on that.
2. `23-UAT.md` Gate 2 Attempt 1 (2026-07-21) — "install failed during plan-build, before any
   `.acf` was written".
3. The 2026-08-19 KCD2 observation — a plan-build failure that downloaded **zero bytes** left a
   402-byte `StateFlags 1026` / `buildid 0` stub where a 989-byte complete manifest had been.

A fourth data point sits in the same UAT file and matters: 23-UAT.md Gate 3 (2026-08-19) records
a `kill -9` at 15,538/18,809 files leaving **no `.acf` on disk** — and that resume worked anyway.

Purpose: the D-08 fix in plan 23.2-02 must distinguish "nothing was attempted this run" from
"downloaded but unverified". That distinction is only trustworthy if the actual taxonomy of
failure-path manifest writes is established first, from source, rather than inferred from three
records that contradict each other. Establishing it also tells 23.2-02 exactly which behaviors
are load-bearing and must not change.

Output: a taxonomy document, and three corrected records.

**This plan runs no hardware and re-installs nothing.** Every conclusion is drawn from reading
`depot.ts` and the existing recorded evidence. The diagnostic is done; re-running it would cost
90 GB and regenerate identical data.
</objective>

src/backend/storeManagers/steam/depot.ts
  - `downloadSteamDepots(appId, opts): Promise<DepotDownloadOutcome>` — the orchestrator.
    Declares `attempted: FinalizeDepotEntry[]` and the `finalize()` closure at the top; the
    closure is invoked from THREE distinct sites: the zero-depot early return, the main path
    after `downloadDepotFiles` resolves, and the catch block.
  - `finalizeToSteam(appId, opts: FinalizeToSteamOpts): Promise<void>` — measures
    `sizeOnDisk` via `measureInstalledBytes(installRoot)`, runs `canWriteFullOwnership`,
    then calls `writeAppManifest` unconditionally.
  - `measureInstalledBytes(root): Promise<number>` — recursive `readdir`/`stat` walk over
    `resolve(targetSteamappsDir, 'common', installdir)`. Returns 0 when the root is missing.
    It is NOT a sum over `opts.depots`.

src/backend/storeManagers/steam/depot/manifest.ts
  - `buildAppManifestText(params)` — `InstalledDepots` is emitted UNCONDITIONALLY as a VDF
    block; an empty `depots` array yields an `"InstalledDepots" { }` block with no entries,
    not an absent key. `buildid` defaults to `'0'`, `stateFlags` defaults to `'1026'`.

taxonomy document must name all three:

  - **A — `buildDepotPlan` throws (plan-build failure, zero bytes downloaded).** The catch block
