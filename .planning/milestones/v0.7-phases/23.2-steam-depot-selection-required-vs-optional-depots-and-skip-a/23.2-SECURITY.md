# Phase 23.2 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|----------------|
| GameLib → on-disk state owned by the Steam client | `appmanifest_*.acf` files are read/trusted by a different application; GameLib writing there is a cross-application write that can destroy state it cannot reconstruct | depot ids, buildid, StateFlags, byte counts |
| Remote Steam CM → local control flow | The thrown error (including `eresult`) that reaches `downloadSteamDepots`'s catch block, and the skip decision in `buildDepotPlan`'s depot loop, both originate at a remote CM and are attacker-influenceable in principle | eresult codes, depot ids |
| Depot ids / buildid → VDF serialization | Every value interpolated into `appmanifest_*.acf` text crosses from remote PICS data into a file another application parses | depot id, manifest gid, buildid |
| Remote PICS → i18next notification body | Depot ids surviving the skip reduction flow into a user-facing OS notification via `i18next.t` interpolation | depot id (already `/^\d+$/`-validated at PICS ingestion) |
| Fail-closed → fail-open inversion | REQ-23-01 established fail-closed completeness; skip-and-warn is a deliberate, narrowly-scoped fail-open exception for exactly `eresult === 40` | depot id, eresult |
| Corrected historical records (23.2-01) | Amending a prior UAT/todo record that was factually wrong, without erasing the original claim | depot ids, appIds, EResults, byte counts — never account identifiers |
