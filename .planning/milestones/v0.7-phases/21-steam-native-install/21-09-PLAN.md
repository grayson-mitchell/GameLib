<objective>
Implement D-08/D-09 install-location targeting: resolve the native depot download's destination to an
existing Steam-registered library folder (never an arbitrary path — Steam won't adopt an unregistered
location). Default to Steam's primary library so single-library users see zero friction; when multiple
registered libraries exist, surface an override picker reusing the existing PathSelectionBox pattern,
populated from getSteamLibraries(). This fills Plan 07's resolveSteamInstallTarget seam.

Purpose: SNI-05 (D-08 registered-folder-only, D-09 default-primary + override picker).
Output: installLocation.ts (backend resolver + IPC), the override picker UI, tests.
</objective>
