<objective>
Unify the install mechanism across native and bottle (D-15): when the opt-in is ON and a game is
bottle-eligible on macOS, depot-download the WINDOWS depot directly into the CrossOver bottle's
steamapps/ filesystem path and let the bottled Windows Steam adopt the 1026 manifest — the same
mechanism as native, no Wine dispatch for the download. This replaces the old
tellBottledSteamToInstall() (steam://install-into-bottle) path for the install verb only; guided
setup/launch/uninstall Wine dispatch is untouched. The depot.ts engine (Plan 04-06) is already
parameterized on { targetSteamappsDir, os }, so this plan only routes the bottle branch.

Purpose: SNI-08 (D-15 bottle depot-download, os:'windows' selection, isBottleReady gate).
Output: games.ts bottle branch + games.test.ts cases. (Real bottle adoption is validated on real
hardware in Plan 12 — MUST-VALIDATE item 3.)
</objective>
