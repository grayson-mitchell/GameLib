<objective>
Create the depot-download orchestrator's front half: given an appId, an authenticated steam-user
connection, and a target directory + os filter, resolve all owned depots (Plan 01 select.ts), fetch
and parse each depot's raw manifest, decrypt filenames, and compute the REAL total byte count summed
across every depot (D-03). This is the enqueue-time contract the DownloadManager needs before a
single chunk is fetched. The streaming download loop is Plan 05; recovery/finalize is Plan 06 — this
plan establishes `depot.ts`'s signature, connection gate, and total-size computation.

Purpose: SNI-01 (depot engine, multi-depot from the start per D-14) + SNI-03 (real total bytes, D-03).
Output: `depot.ts` with `downloadSteamDepots(...)` returning a prepared plan of depots+files+total,
plus its test harness (mocked CM).
</objective>
