<objective>
Build the one genuinely net-new pattern in this phase: a hand-templated `.acf` writer. GameLib has
only ever READ appmanifest files (via @node-steam/vdf.parse). This module WRITES them, which is
exactly where the library's documented 64-bit rounding bug becomes fatal. The writer templates VDF
text directly, keeps every 64-bit value a string, sets StateFlags=1026 (never 4), and writes
atomically so a crash never orphans a half-written manifest.

Purpose: The `1026` manifest is the artifact Steam adopts (spike 001, StateFlags 1026→4, zero
re-download). It is also the single shared recovery artifact for cancel/failure/startup (Plan 06/08).
Output: `depot/manifest.ts` with `writeAppManifest` + a test that proves 64-bit GID preservation and
StateFlags=1026, without any @node-steam/vdf involvement.
</objective>

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-21-06 | Tampering / DoS | manifest.ts atomic write | mitigate | temp-file + fsync + atomic rename; a crash mid-write leaves the old/absent manifest, never a corrupt half-written .acf |
