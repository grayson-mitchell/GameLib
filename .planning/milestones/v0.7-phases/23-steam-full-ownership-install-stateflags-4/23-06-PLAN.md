## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Steam CM / CDN manifest → `fetchDepotPlanEntry` → `DepotPlanFile.flags` | Untrusted remote data (filenames, sizes, flag bitfields) enters the local file-writing pipeline here |
