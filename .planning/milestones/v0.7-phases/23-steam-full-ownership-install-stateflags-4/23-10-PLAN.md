## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Real Steam CM/CDN → GameLib depot writer → the operator's real Steam library | These runs perform real installs of real titles from untrusted remote manifests onto the operator's machine |
| GameLib-authored `appmanifest.acf` → the real Steam client | A `StateFlags=4` manifest instructs Steam to skip its verify pass; a wrong `4` means Steam trusts unverified content |
| Denuvo / anti-tamper runtime → the installed file set | The DRM layer inspects the GameLib-produced file set at launch |
