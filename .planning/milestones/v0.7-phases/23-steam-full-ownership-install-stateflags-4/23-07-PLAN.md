<!-- What 23-06 shipped, which this plan consumes. -->

Three log lines per install, in `~/Library/Logs/GameLib/gamelib.log`, greppable by the literal
`steam-flags-census`:
```
steam-flags-census stage=plan-build       appId=<id> depots=<n> totalFiles=<n> flagBearing=<n>
                                          executableFlagged=<n> readonlyFlagged=<n> hiddenFlagged=<n>
                                          directoryEntries=<n> symlinkEntries=<n> zeroSizeEntries=<n>
                                          distinctFlagValues=[...]
steam-flags-census stage=download-entry   <same field set>
steam-flags-census stage=download-complete <same field set> + jobCount=<n> reconciledSkipped=<n>
                                          modeCallsites=<n> chmodAttempts=<n>
```

Hypothesis → confirming census signature (full statements live in 23-TRACE.md):
| ID | Confirmed when |
|----|----------------|
| H1 | `stage=plan-build` shows `flagBearing: 0` (and therefore `chmodAttempts: 0`) — flags never populated by the steam-user parser mapping at depot.ts:524-531 |
| H2 | `flagBearing > 0` AND `executableFlagged: 0` — flags populated, but this manifest carries no executable bits |
| H3 | `chmodAttempts > 0` while the landed binary is still non-executable — modes applied then lost / applied to a different path |
| H4 | `jobCount` far below `totalFiles` on a FRESH install — the reconciler skipped the files and `healReconciledFileModes` skipped them again |
| H5 | `stage=plan-build` `flagBearing > 0` while `stage=download-entry` `flagBearing: 0` — flags dropped by a serialization boundary between the two |

Inspection helper for the written manifest:
`node .planning/spikes/003-stateflags4-full-ownership/inspect-acf.mjs <label> "<path-to-appmanifest_{appId}.acf>"`
