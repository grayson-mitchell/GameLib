<objective>
Close the MAJOR (D-UAT-24-07) badge-clobber defect that made Gates 3/4 (R6) visibly flap Play→Install→Play and revert to Install after launch, plus the small same-family uninstall-pill cosmetic gap.

**D-UAT-24-07 (24-UAT.md RETEST RUN 1):** 24-12 taught the install POLL (`pollInstallOnce`) to read the bridge bottle via the new `'bridge'` AcfSource + `getBridgeBottleSteamappsRoot()`, so the badge flips to Installed at install time. But the PERIODIC library SYNC (`refresh()`, the `fetched 378 owned games` → `Steam library sync complete` path, which fires again post-launch) re-derives install-state from ONLY the native library map (`buildInstalledMap`) and the Phase 17 bottle map (`buildBottleInstalledMap`) — it never scans the bridge bottle (`GameLibSteamBridge`). A bridge-installed Windows-only game (no native mac ACF, not in the Phase 17 bottle) therefore gets `is_installed:false` on every sync → the button flashes Play→Install→Play and ends on Install. The focus-triggered `refreshInstallState()` has the identical native+bottle-only shape and the same blind spot.

**Fix:** add a `buildBridgeInstalledMap()` (bridge-bottle sibling of the existing `buildBottleInstalledMap()`, rooted at `getBridgeBottleSteamappsRoot()`) and consult it in BOTH `refresh()` and `refreshInstallState()` — native wins, then Phase 17 bottle, then bridge — so a bridge-installed game stays installed across syncs. `installPlatformForSource` must also map the `'bridge'` source to `'Windows'` (a Windows depot under CrossOver), currently it falls through to host `'Mac'`.

**Fold-in (D-UAT-24-07 sync/status family):** a bridge uninstall succeeds on the backend but the frontend "Uninstalling" pill never clears because `markBridgeGameUninstalled()` (games.ts) emits `pushGameToLibrary` but no `gameStatusUpdate` done-status. Add the `gameStatusUpdate: 'done'` emission, mirroring `markBridgeGameInstalled()` (which already emits it).

Purpose: make a bridge-installed game's badge durable across the periodic sync + focus reconciliation, and clear the stale uninstall pill.
Output: library.ts (buildBridgeInstalledMap + bridge-aware refresh()/refreshInstallState() + installPlatformForSource 'bridge'→'Windows') + games.ts (uninstall pill clear) + tests.
</objective>
