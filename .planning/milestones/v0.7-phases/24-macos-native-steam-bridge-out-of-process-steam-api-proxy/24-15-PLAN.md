<objective>
Close the BLOCKER (D-UAT-24-06) that keeps Gates 3/4 (R6) blocked: no game has yet reached playable single-player through the bridge because the bridge launch runs under the wrong Wine runtime.

**D-UAT-24-06 (confirmed by runtime probe in 24-UAT.md RETEST RUN 1):** `launchBridgeGame` fires `runWineCommand({ gameSettings: getBridgeBottleSettings(), wait:false })`. `getBridgeBottleSettings()` (bottle.ts, currently returns `wineVersion: globalSettings.wineVersion`) inherits the GLOBAL default engine — on the test machine that is `Game-Porting-Toolkit-latest` (GPTK). GPTK ships ONLY a 64-bit `wine64` loader (`type: 'toolkit'`, no 32-bit `wine`); running the bridge games' 32-bit exes (Avernum, PE32 Intel 80386) under it aborts instantly with `Assertion failed … alloc_pages_vprot, virtual.c:1032` → empty `launch.log`, no game process, the shim never reaches `SteamAPI_Init`. The POSITIVE control in the same probe: the identical 32-bit exe under CrossOver's multi-arch `wine` (`…/CrossOver/bin/wine --bottle GameLibSteamBridge`) loads and keeps running (the bottle has `syswow64`, WoW64-capable).

The bridge bottle is CREATED by `cxbottle` — i.e. CrossOver — via `provisionBridgeBottle()` (which already REJECTS a non-CrossOver engine, D-08). But the LAUNCH getter never resolves that CrossOver runtime; it falls back to the global GPTK default. The fix: `getBridgeBottleSettings()` must resolve a CrossOver `WineInstallation` — the same runtime family that created the bottle — for its `wineVersion`, reusing bottle.ts's already-locked CrossOver root (`CXBOTTLE_BIN`, from which `WINESERVER_BIN`/`CX_ROOT` are already derived). Install/uninstall bridge paths share this getter, so fixing it fixes all three.

Purpose: make the bridge launch run the 32-bit game exe under the CrossOver runtime that created its bottle, so a bridge game can actually start and reach `SteamAPI_Init`.
Output: bottle.ts `getBridgeBottleSettings()` resolving a CrossOver WineInstallation (with a global fallback when CrossOver is absent) + tests.
</objective>
