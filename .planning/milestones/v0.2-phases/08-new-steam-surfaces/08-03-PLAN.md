CachedImage (src/frontend/components/UI/CachedImage/index.tsx):
- Props: `src: string`, `fallback?: string`, `className?`, `onLoad?`, `onError?` (spread over an <img>).
- Built-in onError chain: on first error, if it was using the imagecache:// proxy it retries the raw src; on the next error, IF a `fallback` prop is provided it switches to the fallback (`setUseFallback(true)`). WITHOUT a `fallback` prop, a broken src renders nothing (blank) — this is gap A's root cause.
- So gap A is fixed by passing a `fallback` prop; no new onError handler is needed.

getImageFormatting (src/frontend/screens/Library/components/GameCard/constants.ts):
- `getImageFormatting(cover: string, runner: Runner)` — returns the imported fallback image when `cover === 'fallback' || !cover`; otherwise the (optionally resized) cover URL. This is the BRANDED-DEFAULT path (empty art), distinct from the onError greyed path.
