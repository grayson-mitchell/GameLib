## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] pnpm i18n removed all 3 new i18n keys on execution**
- **Found during:** Task 2 (GameCard CSS + i18n keys)
- **Issue:** `pnpm i18n` (i18next-parser with `keepRemoved: false`) scans source for `t(...)` calls. It removes keys not found in source. Two keys (`library.no_hidden_games`, `library.no_non_available_games`) have no source usage yet (EmptyLibrary is plan 04). The third key (`library.delisted`) uses `t2` alias which is not detected by i18next-parser's JavascriptLexer by default. All 3 keys were removed after the script ran.
- **Fix:** Re-added all 3 keys directly to `en/translation.json` without a subsequent `pnpm i18n` run. The i18n script's sort + dead-key-removal outputs were committed (gamepage.json reorder + translation.json cleanup). When plan 04 adds EmptyLibrary source usage of the 2 remaining keys, `pnpm i18n` will find and keep them.
- **Files modified:** `public/locales/en/translation.json`
- **Verification:** `grep` confirms all 3 keys present in translation.json
- **Committed in:** `2dbac92d` (Task 2 commit)
