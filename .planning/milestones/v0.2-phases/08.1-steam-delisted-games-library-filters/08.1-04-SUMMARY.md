# Phase 08.1 Plan 04: Only-Mode Polish Summary

Context-aware empty-state messages for the 'only' filter modes and the accent active-state CSS for the 'only' button — the wave-2 polish layer completing the LIB-09 tri-state experience.

## What Was Built

**Task 1 — EmptyLibraryMessage context-aware empty states** (`d9a9b370`)

`EmptyLibraryMessage` (`src/frontend/screens/Library/components/EmptyLibrary/index.tsx`) now reads `LibraryContext` to inspect `showHidden` and `showNonAvailable`. Two override cases were added after the existing generic message logic:

- `showHidden === 'only' && showNonAvailable !== 'only'` → `"No hidden games in your library"` (`library.no_hidden_games`)
- `showNonAvailable === 'only' && showHidden !== 'only'` → `"No non-available games in your library"` (`library.no_non_available_games`)
- Both-'only' and all non-'only' combinations retain the existing `emptyLibrary.noGames` / `emptyLibrary.noResults` messages

The `t` function was added to the existing `useTranslation()` destructure alongside `i18n`, so fallback strings render even before locale propagation.

**Task 2 — Active-state CSS for the 'only' button** (`031f1d20`)

Added `.only[aria-pressed="true"] { display: block; color: var(--accent); }` inside the `.toggleWithOnly` block in `src/frontend/components/UI/Dropdown/index.scss`. This rule:
- Overrides the default `display: none` to keep the button visible when its filter is in Only state
- Applies `var(--accent)` color to signal the active state
- Pairs with the `aria-pressed` binding added to the 'only' button in Plan 03
- Does not touch the existing `.only` default or hover-reveal rules
