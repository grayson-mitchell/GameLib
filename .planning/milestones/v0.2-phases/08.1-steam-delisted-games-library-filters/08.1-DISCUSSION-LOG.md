## 'Non-available' meaning (LIB-07)

| Option | Description | Selected |
|--------|-------------|----------|
| Delisted-only | 'Non-available' = is_delisted true. Owned not-installed games stay AVAILABLE/installable. Reconcile frontend nonAvailableGames path so not-installed ≠ non-available for Steam. Matches ROADMAP intent. | ✓ |
| Keep install-state based | Leave existing not-installed = non-available; only layer greyed styling onto delisted. Simpler, but a not-installed owned game still reads as 'non-available'. | |

**User's choice:** Delisted-only
**Notes:** Availability keyed on `is_delisted` for Steam; existing `nonAvailableGames` mechanism preserved for other runners.

## Delisted default visibility

| Option | Description | Selected |
|--------|-------------|----------|
| Folded into non-available | Delisted games join the 'non-available' set: hidden by default, greyed + disabled install when revealed via Show/Only non-available. One mechanism for LIB-07/08/09. | ✓ |
| Always greyed in-place | Delisted games always visible, greyed, never hidden by the filter. More transparent but clutters the grid and decouples LIB-08 from the LIB-07 filter. | |

**User's choice:** Folded into non-available
**Notes:** Consistent with ConsoleMode hiding delisted and the existing non-available filter mechanic.

## Delisted tile behavior (LIB-08)

| Option | Description | Selected |

## 'Only' filter UX (LIB-09)

| Option | Description | Selected |
|--------|-------------|----------|
| Tri-state on existing toggles | Hidden and Non-available each cycle Off → Show → Only. Reuses existing LibraryFilters controls. Both 'Only' → union. | ✓ |
| Separate 'only' controls | Add distinct 'Only hidden' / 'Only non-available' toggles; more explicit but four controls + mutual-exclusion rules. | |

**User's choice:** Tri-state on existing toggles
**Notes:** Both-'Only' resolves to the union (hidden OR non-available), not intersection.
