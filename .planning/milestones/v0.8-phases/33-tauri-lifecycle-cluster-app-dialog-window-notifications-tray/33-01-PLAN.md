<objective>
Close the visible half of the G-30-02 install-hang: make the shared `installQueueElement()`
path settle the "installing" badge and show a failure dialog whenever a Steam install ends in
error, add a belt-and-suspenders watchdog around the real `.install()` await so no
never-settling downstream await can hang the badge again, and declare the WR-02 non-Steam DLC
boundary as a logged/guarded case.

Purpose: Phase 30-07 already bounds every pre-download PICS await, yet the live build still hung
twice — because a bounded Steam *rejection* never starts an ACF poller, and the finally-guard at
`downloadmanager/utils.ts:139` deliberately excludes `status === 'error'` for Steam, so nothing
ever clears the badge (33-RESEARCH "Why the live hang persisted"). Fixing that guard is the
actual visible-hang fix; the watchdog is defense-in-depth for any other parking await.

Output: Hardened `installQueueElement()` + extended regression test. Live proof is gated
separately in Plan 33-05 (D-13).
</objective>
