<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| sidecar showMessageBox ↔ Rust dialog plugin | a degraded/timed-out transport must not be interpretable as a destructive confirmation |
| destructive backend confirm (force-uninstall / i386 recovery) ↔ user | the button the user did NOT click must never be auto-selected |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-33-07 | Elevation of privilege / Tampering | a degraded showMessageBox auto-confirms a destructive branch (the CR-01 risk) | mitigate | Fail-safe-to-decline: ANY transport error/timeout resolves the caller's explicit `cancelId`; both destructive callers retrofitted with `cancelId`; no positional "last index" heuristic (proven wrong for askForceUninstall) |
| T-33-08 | Denial of Service | unguarded reject from showMessageBox crashes the whole sidecar | mitigate | Total-method convention: showMessageBox always resolves a safe value, never rejects (memory: sidecar-dialog-reject-crashes) |
| T-33-09 | Spoofing | attacker-supplied button labels rendered in a native dialog | accept | Labels originate from in-app backend callers, not remote input; low value |
| T-33-SC | Tampering | npm/cargo installs | mitigate | No new package installs (reuses existing tauri-plugin-dialog `"2"`); N/A |
</threat_model>
