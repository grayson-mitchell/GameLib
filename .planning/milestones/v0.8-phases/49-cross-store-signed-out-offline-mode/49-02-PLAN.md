<copy_contract>
The English strings are locked here and repeated verbatim as `defaultValue` arguments in 49-01,
49-09 and 49-10. i18next renders the catalogue value in preference to the call-site default, and
`pnpm i18n` extracts call-site defaults into `en`, so a mismatch is either a wrong UI string or a
non-no-op parser run.

| Key | English |
|---|---|
| `library.signIn.dismiss` | `Dismiss the {{store}} sign-in notice` |
| `library.signIn.expired` | `Your {{store}} sign-in expired` |
| `library.signIn.notConnected` | `{{store}} is not connected` |
| `library.signIn.reconnect` | `Reconnect` |
| `library.signIn.signIn` | `Sign in` |
| `login.amazonReconnect` | `Sign-in expired — Reconnect` |
| `login.epicReconnect` | `Sign-in expired — Reconnect` |
| `login.gogReconnect` | `Sign-in expired — Reconnect` |

Tone (D-11, P4): `notConnected` is informational — "GOG is not connected", never "failed",
"error", "missing" or "problem" in any locale. `expired` keeps the existing Steam tone ("Your Steam
sign-in expired"). The three `login.*Reconnect` keys mirror `login.steamReconnect` exactly; D-12
asks for three tile strings, so three keys exist even though English reads the same — a locale may
need the store's grammatical gender or case and cannot get it from one shared key.
</copy_contract>
