<objective>
Build the install-time family picker (Surface 1, D-10) and gate BOTH Steam install
chokepoints on it (Pitfall 7, Req 3). The picker clones `SteamInstallLocationPicker`/
`SteamInstallLocation`; its one genuine divergence is the "New family…" option, which
creates the family inline, opens the (Plan 06) guided setup for that bottleName, then
continues the install. Eligibility comes from the backend `familyStatusForApp.eligible`
flag (Open Q1 b) — no client-side predicate.

leaves an install entry point bypassing the picker; re-deriving eligibility client-side
reintroduces the drift the codebase warns against.

Output: new picker store + component; gated `InstallGameModal.ts` + `GamePage/index.tsx`.
</objective>
