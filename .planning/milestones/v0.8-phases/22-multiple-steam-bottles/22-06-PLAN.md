<objective>
Parameterize the Phase 17 guided-setup store + component by `bottleName` so it
can provision ANY family, not just the hardcoded `GameLibSteam` (Pitfall 4/5,
D-11). This is the prerequisite that both the install-time picker's "New family…"
path (Plan 07) and the Settings "Create family" path (Plan 08) reuse verbatim.

Purpose: today `useSteamBottleSetup` only knows `appName`, and the component
seeds `crossoverBottle` from the `DEFAULT_STEAM_BOTTLE_NAME` constant and polls
the removed global `steamBottleStatus` — both of which silently misprovision or
mis-report for a non-Default family. This plan makes the flow family-aware and
repoints the poll to the new family status IPC.

Output: bottleName-aware `SteamBottleSetup.ts` store + `.tsx` component.
</objective>
