<objective>
Generalize the Steam install-state reconciliation and ACF poller from one bottle
to N (D-06, Req 8). `buildBottleInstalledMap` must scan every family's steamapps
root and tag which family each installed game lives in; `readAcfState`'s bottle
branch and the targeted single-appId poller must take an explicit `bottleName`
threaded from the resolver — mirroring the native multi-root precedent already in
this file.

Purpose: without this, a game installed in a non-Default family never shows as
installed, and the D-09 delete flow has no ground truth for which family a game
belongs to. The native path (`buildInstalledMap`/`readAcfState` native branch) is
the exact multi-root template to copy.

Output: reshaped `library.ts` reconciliation, extended `library.test.ts`.
</objective>
