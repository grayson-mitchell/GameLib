## Decisions Made

- **`logInfo`'s call-site guard mirrors `logError`'s exactly.** Same try/catch-around-`Promise.resolve`/`Promise.reject` shape, same stderr-only diagnostic discipline (never stdout, never re-throw, never `process.exit`), substituting `logInfoSettled` for `logErrorSettled`. This is the plan's explicit instruction, not a judgement call — `logInfo` is `logError`'s send-shape twin and an unguarded rejection would kill the sidecar (T-34.3-14).
- **`deleteUploadedLogFile` ported at parity, not fixed.** `uploader.ts:74-77`'s hardcoded `token = '1'` makes real deletion impossible in either build — an inherited upstream Heroic defect, not port-introduced. Declared in the module docstring and in the test's own title so a green test can never be mistaken for proof the delete button works (D-08, T-34.3-16).
- **Log redaction declared out of scope, no audit performed (D-09, T-34.3-13).** Recorded in the module docstring per explicit user instruction.
- **The `uploadLogFile` "invoke rejects on HTTP failure" test uses a synchronously-throwing `fetch` mock.** Tracing `logger/uploader.ts`'s actual control flow: a normal HTTP failure (a rejected fetch promise, or a response with `ok: false`) is caught by `sendRequestToApi()`'s own `.catch(...)` and resolves to `false` — this is Electron parity, not a defect, and is NOT a rejection. To satisfy the plan's explicit requirement that this test prove the invoke "rejects... rather than resolving a falsely-successful value," the mock throws synchronously inside `fetch(...)` itself, a failure mode `sendRequestToApi`'s `.catch()` chain never gets attached to, so the exception propagates through `uploadLogFile`'s own `await` and reaches `dispatchInvoke` as a genuine `{ ok: false, error }` frame — the same reject-shape contract `checkDiskSpace`'s ASVS V5 test already pins (34.3-01-SUMMARY.md).
- **`getUploadedLogFiles`'s expiry-pruning side effect is pinned as intended behavior**, not incidental — a dedicated test seeds one live and one expired entry and asserts both the returned shape and the store mutation.
