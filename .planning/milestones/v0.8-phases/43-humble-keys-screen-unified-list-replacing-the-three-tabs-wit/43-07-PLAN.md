<objective>
Replace the three-tab route shell with one unified list: title row plus search, controls row, column
header, and rows whose per-row state now drives the KEY column.

Purpose: this is the phase's headline change. The tab predicates stop being list-membership filters
and become per-row state. Three annotation lifecycles become one. Three empty states become two —
one for "you have no keys" and a distinct one for "your filters match nothing", because with the
checkbox checked by default a user whose whole library is terminal hits the filtered state on their
very first visit and must not be told they have no keys.

Output: the unified screen, its route collapse, and one test file carrying forward the 22
behavioural assertions the two deleted tab suites pin.
</objective>
