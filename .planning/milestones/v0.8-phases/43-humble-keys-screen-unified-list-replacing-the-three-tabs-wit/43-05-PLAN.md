<objective>
Convert the Humble key row from a six-cell flex strip into the three-column CSS Grid the UI-SPEC
specifies, move the status and action content into the KEY cell, and replace the D-22 read-only
contract with D-43-17's "interactivity lives in KEY only" contract.

Purpose: this is a **behaviour-preserving structural move**. Every affordance the row renders today
(claim, gift, settle-undo, ownership override, undo-override, state badge, expiration, store logo)
still renders, with the same handlers and the same conditions — only its position in the tree
changes. The five-scenario re-model is plan 43-06's job; separating them means the 47 existing row
tests act as a real checkpoint on this move instead of being rewritten twice.

Output: the stylesheet that both the header row and every row share, a three-child row, and 47+
re-pinned tests.
</objective>
