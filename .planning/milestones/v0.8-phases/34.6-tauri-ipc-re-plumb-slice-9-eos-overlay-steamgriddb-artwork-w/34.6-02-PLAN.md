|----------|-------------|
| sidecar (Node) → Rust shell | `keyring_set`/`keyring_get` frames carrying a real credential and a slot name |
| sidecar → `config.json` on disk | the plaintext window the migration closes |
| dev machine env (`GAMELIB_DEV_SECRET_VAULT=1`) → store selection | an env var chooses which store implementation handles a real credential |
