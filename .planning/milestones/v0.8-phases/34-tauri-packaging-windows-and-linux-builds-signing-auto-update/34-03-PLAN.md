<objective>
Generate the Tauri updater minisign keypair (D-08). This is the sole trust anchor for
auto-update signature verification and cannot be deferred. The PUBLIC key is committed later
(34-05) into `tauri.conf.json`; the PRIVATE key + password are stored ONLY as GitHub Actions
secrets. This plan produces no repo file changes — it is a human-action + secret-handling gate
whose output is the captured public key recorded in the SUMMARY.

Purpose: Without this keypair, `createUpdaterArtifacts` cannot sign `latest.json` and the
updater plugin has nothing to verify against.
Output: A minisign keypair; the public key captured for 34-05; private key + password in secrets.
</objective>
