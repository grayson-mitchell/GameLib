## Behavior Change Note (WR-08 re-arm, enrichmentFlows.test.ts)

Re-arming `runOnceWhenOnline` to actually invoke its callback means that every `startSidecar()` call in this file now lets `bootstrap.ts`'s `fetchLastestReleases()` (wrapped in `runOnceWhenOnline`) actually run its async body, which (via the mocked `axios.create().get()` returning `{ data: {} }`) emits `backendEvents.emit('releasesInfoReady', {})`. This in turn drives the `releasesInfoReady` -> `downloadAntiCheatData` listener from `bootstrap.ts` with `releasesInfo.anticheatFiles` being `undefined`, which throws synchronously inside the listener body; that throw propagates up through `EventEmitter.emit()` and is caught by `releases.ts`'s own enclosing `try`/`catch` (a `logWarning` call, no crash). Verified this does not change any test's outcome: `enrichmentFlows.test.ts` still passes all 28 tests, same count as before. No assertion was weakened to accommodate this — the behavior change is real but does not intersect this suite's own assertions today, so it required no test rewrite.
