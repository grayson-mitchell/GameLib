<objective>
Close gap-cycle-3 WARNING WR-02. `src/backend/sidecar/loggerFlowRegistration.ts:56-58` calls
`logError(...)` with neither `await` nor `.catch()`. `LogWriter#logBase` is `private async`
(`src/backend/logger/log_writer.ts:131`) and performs `fsPromises.appendFile` / `mkdir`, so a
real log-write failure (EACCES, ENOSPC, deleted log directory) becomes a process-level
`unhandledRejection`. `dispatchSend`'s `try`/`catch` (`sidecarRpc.ts:137-146`) is synchronous
and cannot see it.

It survives today only because `processGuards.ts` absorbs it — which directly violates that
module's own documented invariant, stated in bold in its docstring (lines 10-14): it "is
explicitly NOT a substitute for call-site `.catch()`/`try`/`catch` handling — every `send`-kind
body and every fire-and-forget call the sidecar owns must still guard itself." Brand-new code
landed in the same gap cycle that hardened `processGuards.ts` violates the invariant its sibling
plan wrote. The net observable effect is that a real log-write failure is reported as a generic
`[sidecar] unhandled promise rejection` warning which is itself written to the log that just
failed.

Purpose: make the failure legible where it happens, and stop leaning on the defence-in-depth
guard as the primary handler.
Output: a call-site-guarded `logError` listener plus a test that proves a REJECTING log write is
caught by the call site rather than escaping to the process.
</objective>

| Boundary | Description |
|----------|-------------|
| renderer → sidecar `logError` send channel | Untrusted renderer-controlled text crosses into the sidecar and is appended verbatim to the operator log. |
| sidecar listener body → Node process | An unsettled rejected promise escaping a `send` listener reaches the process-level `unhandledRejection` handler; on Node ≥ 15 the default disposition without such a handler is process death. |
| sidecar diagnostics → stdout/stderr | stdout carries the newline-delimited JSON RPC frame protocol; any non-frame byte written there corrupts the transport. |
