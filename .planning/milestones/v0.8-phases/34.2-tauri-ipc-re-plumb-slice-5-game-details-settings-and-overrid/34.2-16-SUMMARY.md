## Decisions Made

- **Ported `logError` early, not the other five logger channels.** Only `logError` has a live
  caller under Tauri today (gap cycle 1's `onRepairYesClick` catch); the other five remain
  undeclared scope for this plan and are explicitly named as still-unported in three places so no
  reader mistakes this for "logging is ported."
- **`jest.spyOn`, never `jest.mock`, for `backend/logger` in the new test suite** — `backend/logger/
  index.ts` and `backend/logger/log_writer.ts` import each other circularly; a `jest.mock` factory
  that calls `jest.requireActual('backend/logger')` re-enters that cycle and throws inside
  `LogWriter`'s constructor (documented precedent in `sidecarRejectionGuard.test.ts`).
- **Mocked `backend/logger/paths` directly (never delegated to the real `getBaseLogPath()`)** —
  `getLogFilePath`'s real path derivation reads `process.env.LOCALAPPDATA`/`XDG_STATE_HOME` plus
  `homedir()` independently of `pathShim`, bypassing both the `os` mock and the `pathShim` mock on
  non-mac platforms. The suite reimplements the relative-path derivation (heroic/runner/game log)
  rooted at the same disposable tmp root instead.

- **Issue:** The first draft of `loggerFlowRegistration.ts`'s docstring used the literal substring

  `MUST NOT register` (uppercase), while the acceptance criteria required
  `grep -c "logger/ipc_handler" ...` to return 0 and `grep -c "must NOT register" ...` (lowercase
  "must") to return 1. Separately, `handlers.ts`'s docstring mention of `registerLoggerFlows()`

  `grep -c 'registerLoggerFlows()' handlers.ts` return 2 instead of the required exactly-1.
- **Fix:** Rephrased the docstring to describe the Electron-only file without using the literal
  path substring (e.g. "the Electron-only `ipc_handler.ts` under `src/backend/logger/`"), changed
  "MUST NOT register" to "must NOT register", and removed the trailing `()` from `handlers.ts`'s
  docstring mention of the function name.
- **Files modified:** `src/backend/sidecar/loggerFlowRegistration.ts`, `src/backend/sidecar/handlers.ts`
- **Verification:** All acceptance-criteria greps re-run and confirmed passing; `npx tsc --noEmit`
