## Issues Encountered
- The first draft of `handlers.ts`'s docstring literally quoted `cheapshark.ts`'s `import { app } from 'electron'` line and named `backend/ipc` in prose, which matched the plan's own unfiltered `grep -cE "from 'electron'|backend/ipc|from './index'"` acceptance check (3 matches instead of the required 0). Fixed by rewording to convey the identical facts without those literal substrings; re-ran the grep to confirm 0.
- One test bug in my own first draft of `handlers.test.ts`: an `await call.catch((result) => expect(result).toBeUndefined())` assertion mis-modeled a rejected promise's catch-callback argument as the resolved value rather than the rejection reason, causing a false failure. Fixed using `Promise.allSettled` to assert `status === 'rejected'` and inspect `.reason` directly — a clearer and more literal proof of the "never resolves to an empty result" requirement than the original approach.
