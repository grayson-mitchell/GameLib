<objective>
Create `backend/platform` by moving `electronStub.ts` into it, and declare the electron type surface
first-party — with zero consumers, while both shells still build.

Purpose: D-17's ordering. `backend/platform`'s exports are a pure relocation of `electronStub.ts`'s
existing exports, and nothing imports `from 'backend/platform'` until plan 35-15's 67-file string
swap. So the module can be built and fully tested in isolation before any import site changes, and
before anything irreversible happens. This is step (1) of the ordering: additive work while both
shells still run.

`electron` appears nowhere in `src/` or `package.json` — and two import shapes are invisible to the
obvious grep: 32 bare `Electron.` namespace references with no import statement at all, and lazy
`require('electron')` calls. Plans 35-15 and 35-16 rewrite those sites, but they need somewhere to
point. That target is built here.

Output: `backend/platform` with its types, the alias repointed, every existing `electronStub` test
passing against the new path, and no consumer anywhere.
</objective>
