<objective>
Delete the Flatpak and Flathub publishing path outright, and pin the Linux artifact set to AppImage.

Purpose: D-11. The path is built around `com.heroicgameslauncher.hgl.yml` and Heroic's Flathub
identity — GameLib cannot publish under it, has never used the channel, and Flatpak packaging of a
Tauri app with a bundled sidecar and helper binaries is its own project. `tauri.conf.json` already
targets exactly `["nsis","appimage","dmg"]`, so this is removal of dead machinery, not a change to
what ships.

Output: `flatpak/` and `flathub/` gone, their four scripts gone, any CI reference gone, and a test
that fails if the target list drifts or a reference comes back.
</objective>
