# Phase 34.9 Plan 30: Correct C3-02's stale pipe/argv claim; generalise + tighten the sweep tool (C3-03, D-C4-04a) Summary

**`meta/lintTranslations.ts`'s doc comment no longer claims CLI argv is mechanically unreachable through an `esbuild|node` pipe (and names no invocation mechanism at all, so it cannot go stale the same way twice), `34.9-PIPE-AUDIT.md` Section 7 retracts its own false "no stale claim to correct" conclusion about that file, and `34.9-C2-SWEEP-CHECK.cjs` is renamed and generalised to `34.9-REVIEW-SWEEP-CHECK.cjs` -- a cycle-agnostic sweep that discovers findings from every review file (proven against one that did not exist at authoring time) and rejects a FIXED-row confirmation whose own text denies the fix, RED-proven against the reviewer's verbatim counter-example.**

List A is now derived by globbing `*-REVIEW*.md` in the target directory (default: the script's own directory) and parsing every `^### <ID>` heading across all discovered files -- proven to work against a review file that did not exist at authoring time by creating a throwaway `34.9-REVIEW-CYCLE9-TEST.md` with a synthetic `### C9-01` heading, observing the tool report `C9-01` as a 4th unmapped ID, then deleting the file. The FIXED-row confirmation check now runs a case-insensitive polarity deny-list (`not fixed`, `not actually fixed`, `still has the bug`, `still broken`, `still fails`, `never landed`, `never added`, `does not exist`) BEFORE and INDEPENDENT of citation acceptance -- proven RED against the reviewer's own verbatim counter-example (`not actually fixed, meta/foo.ts still has the bug, package.json unchanged`) on a temporary copy of `deferred-items.md`, rejected with the distinct reason token `FIXED-CONFIRMATION-DENIES-FIX`; the real `deferred-items.md` was never mutated by this proof.
