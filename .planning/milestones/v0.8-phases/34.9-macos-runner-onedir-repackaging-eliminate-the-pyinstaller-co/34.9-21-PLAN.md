**This tree is git-ignored and untracked** (`public/bin/.gitignore:5`; `git ls-files
public/bin/arm64/darwin` returns 0 files). `git checkout`, `git stash` and `git clean` CANNOT restore
it. The only other recovery is rebuilding from source with `pnpm build-runners-onedir`, which
requires network and upstream sources. **Treat every mutation in this plan as irreversible except
through this plan's own recorded restore path.**

**The injection target is gogdl's framework only:**
`/Users/graysonmitchell/Projects/GameLib/public/bin/arm64/darwin/gogdl/_internal/Python.framework`.

**Which guard is expected to fire, and which is NOT.** The vite `closeBundle` plugin
(`meta/preserveRunnerSymlinks.ts`, Guard A, hardened by plan 34.9-18) collects symlinks from
`public/` and restores them into `build/`. With gogdl's framework dereferenced there are simply 9
symlinks to collect and all 9 restore, so Guard A reports **restored 9, skipped 0 and does NOT
throw**. The abort must come from **Guard B** — the `pnpm verify:runner-bundle build --arch=arm64`
step that plan 34.9-20 wires into `dist:mac` **before** `electron-builder`. Recording the
`[preserve-runner-symlinks] restored 9 symlink(s), skipped 0` line is therefore load-bearing
evidence: it discriminates "Guard B fired on the defect" from "something else aborted the build."

**The expected failure literal** comes from `meta/verifyRunnerBundle.ts:442`:
`Versions/Current exists but is not a symlink (F-34.9-01)`. A `cp -RL` of the framework also turns
the top-level `Python` stub into a real file, so `verifyRunnerBundle.ts:458`'s stub message may
appear alongside it. **The scored literal is the line-442 one**; additional F-34.9-01 failures are
recorded as corroboration, never as substitutes.

**`pnpm dist:mac` composition** (`package.json:49`, as amended by plan 34.9-20):
`export CSC_IDENTITY_AUTO_DISCOVERY=false` -> `pnpm clean:dist-mac` -> `pnpm build-steam-bridge` ->
`electron-vite build` -> `pnpm verify:runner-bundle build --arch=arm64` -> `electron-builder --mac`.
It is a `&&` chain: the first non-zero step aborts and its status propagates. `clean:dist-mac` runs
FIRST, so a failing run leaves `dist/` swept of macOS artifacts and adds none — which is exactly why
the `dist/` listing must be captured BOTH before and after each direction.

**`emptyOutDir: false`** (`electron.vite.config.ts:76`) — vite does NOT clear `build/`. A stale
well-formed `build/bin` from an earlier run would be overwritten file-by-file, leaving
`Versions/Current` as a real directory or a stale symlink depending on which run wrote it last.
**`rm -rf /Users/graysonmitchell/Projects/GameLib/build/bin` is mandatory before BOTH directions**,
for two distinct reasons: before the FAILING run, so a stale good tree cannot mask the injected
defect and yield a false PASS of the failing direction; before the PASSING run, so the injected
dereferenced tree cannot linger and yield a false FAIL of the passing direction.

**Shell state does not persist between commands in this harness.** Do not rely on an exported
`$GUARD_SESSION_DIR` surviving from one invocation to the next. The session directory path is
written once into a pointer file and re-derived from that file by every subsequent command.

**Absolute paths everywhere.** Repo-relative paths appear only inside commands explicitly stated to
run from `/Users/graysonmitchell/Projects/GameLib`, and no such command's output is fed into another
command without first being captured as an absolute path.

**Do NOT run `pnpm download-helper-binaries` at any point.** `meta/runnersOnedirDigests.json` holds
six `PENDING-CI-PUBLISH` sentinels so it throws by design — and it could delete or overwrite the only
staged local arm64 tree, which is precisely the tree this run is mutating and must restore.

**Identifier-redaction discipline.** No cookie value, gamekey, OAuth code, account id or PKCE
material in any captured artifact, the record, or the Summary. A prior session in this project
committed live PKCE material and caught it only in a post-commit audit. Audit before `git add`, not
after.
