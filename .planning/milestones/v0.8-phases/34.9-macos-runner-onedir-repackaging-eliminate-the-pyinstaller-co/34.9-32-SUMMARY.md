## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] macOS's default `bash` (3.2, GPLv2-last) has no associative arrays; the first Direction A harness attempt failed before any file mutation**
- **Found during:** Task 1 (Direction A harness authoring)
- **Issue:** The first harness script used `declare -A FILE_SCRIPTS=(...)`, which is bash-4+ only. Under macOS's shipped `bash 3.2.57`, every assignment line threw `invalid arithmetic operator`, and the script aborted with the associative-array lookup unresolved.
- **Fix:** Confirmed via `git status --porcelain` and a sentinel grep that zero file mutation had occurred (the failure happened before `inject_s1` was ever reached in the failed run's control flow), then rewrote the harness using a bash-3.2-compatible `case`-statement lookup in place of the associative array, and re-ran successfully.
- **Files modified:** none in the repo (harness script lives under the session scratchpad, not the repo tree)
- **Verification:** re-run produced all 30 Direction A rows PASS, `git status --porcelain -- meta/ package.json` clean throughout.
- **Committed in:** `7e6b56b95` (Task 1 commit; the deviation itself is documented in the RUN RECORD, not a separate code change)

**2. [Rule 1 - honestly recorded, non-blocking] Precondition 3 (`pgrep -f 'target/debug/gamelib-shell'` empty) was not satisfied at preflight**
- **Found during:** Task 1 preconditions
- **Issue:** A live Tauri dev instance (PID 97816) was running on the machine at preflight, which the contract's Section 2 precondition 3 requires to be absent, on the theory that it could hold file handles into `build/` while Direction B's `electron-vite`-adjacent scripts run.
- **Fix:** Reviewed every Direction B row in this contract (Section 5) and confirmed none of them invoke `electron-vite build` or write into the repo's `build/` tree (unlike `34.9-PIPE-PROOF.md`'s own chain proofs, which ran `pnpm dist:mac` end-to-end through `electron-vite build` and would have been affected). Recorded the precondition as NOT SATISFIED with this rationale, rather than silently marking it satisfied or halting the run. The dev instance was left running -- killing another live process was outside this plan's authorization.
- **Files modified:** none
- **Verification:** cross-checked every one of the 11 Direction-B-scored rows against the `electron-vite build` invocation string -- zero matches.
- **Committed in:** `7e6b56b95` (Task 1 commit; recorded in Section 2 and restated in the RUN RECORD's Deviations section)
