    versionsCurrentExists: boolean; versionsCurrentIsSymlink: boolean; versionsCurrentTarget: string

    boolean; codesignDisplay: string }`. `path` is absolute; `name` is the directory's basename
    (e.g. `Python.framework`).

    Add `function findFrameworks(runnerDir: string): string[]` — a recursive walk using
    `readdirSync(dir, { withFileTypes: true })` that collects directories whose name ends in

    through. Do not reuse `walkFiles`, which returns files.

    by stripping the `.framework` suffix from the basename. Use `lstatSync` (never `statSync`) for
    every symlink determination. Populate `versionsCurrentTarget` with `readlinkSync` when it is a
    symlink and `null` otherwise; set `resolvedVersionDirExists` from
    `existsSync(path.join(frameworkDir, 'Versions', target))`. Populate `codesignDisplay` by calling
    the existing `getSignatureState` against the framework DIRECTORY path — this is the artifact
    `codesign` actually classifies, and it is the specific correction the gate recorded, where a
    `--verify --deep` aimed at the inner `gogdl/gogdl` binary exited 0 against an already-malformed
    framework.

    Add `frameworks: FrameworkInspection[]` to `RunnerInspection` and populate it in
    `inspectRunner`.

    In `summarise()`, add ENFORCED failure conditions, each producing a message that names the
    runner, the framework path, and the specific malformed entry, and each citing `F-34.9-01`:
    (a) `versionsCurrentExists === false`; (b) `versionsCurrentIsSymlink === false`;
    (c) `resolvedVersionDirExists === false`; (d) `topLevelStubExists && !topLevelStubIsSymlink`.
    Leave every existing condition (presence, exec bit, Mach-O-ness, the `> 20` file-count floor)
    and the DATA-only treatment of `MachOSignature.signature` exactly as they are.

    Extend `printTable` with one line per framework showing name, whether `Versions/Current` is a
