# Phase 34.9 Plan 11: Blocking Live Gate — Run and Record

**The gate ran on real macOS hardware and returned `verdict: FAIL` — 4 of 5 items PASS. Item 4 failed on a release-blocking regression this phase itself introduced: `pnpm dist:mac` cannot complete, because vite's `copyDir` dereferences the `Python.framework` symlinks inside every onedir runner, producing a framework `codesign` refuses as `bundle format is ambiguous`. No packaged macOS build can be produced at all, and a green 235-suite / 4598-test run never saw it.**

## Root cause of F-34.9-01, proven not asserted

Same source framework, one variable, the exact codesign invocation electron-builder uses:

```
A  cp -R   (symlinks preserved)     Versions/Current = symlink    -> codesign exit 0
B  cp -RL  (dereferenced, as vite)  Versions/Current = real dir   -> codesign exit 1
                                                                     "bundle format is ambiguous"
```

Before this phase the darwin runners were flat single-file binaries with no framework and no symlinks, so the path was unreachable. All three runners are affected (3 symlinks each in source).

## Deviations, each recorded with its consequence

1. **Launch 1 predated the dual-sink capture** — no transcript exists for item 1 and none can be reconstructed; scored from the archived sidecar sink alone, which is sufficient because all of item 1's literals are sidecar-emitted. The app was deliberately not restarted to regularise this, since that would have destroyed the evidence already produced.
2. **Items 2/3 ran in their own launch** rather than sharing launch 1. Harmless — `altNileBin` was verified empty throughout.
3. **Item 5 observed without a restart**, via the component's own re-probe. The resulting one-process triple is stronger evidence than the prescribed check.
4. **The contract's own item-5 path was wrong** — it specifies a repo-relative path, but the sidecar's cwd is `<repo>/src-tauri`, so it resolved to a nonexistent file and failed with ENOENT. A contract authoring defect, not a product defect: the field is a file picker that always yields absolute paths.
