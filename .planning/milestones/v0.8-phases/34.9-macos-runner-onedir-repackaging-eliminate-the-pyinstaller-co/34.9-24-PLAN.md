never had, and the symlink-free-tree test asserts the third key of the return shape it currently

reject. That is the same class of malformation this tool exists to catch, arriving through the one
door it does not watch. Separately, `restoreSymlinks` now returns three keys and one test still
asserts two.

and runs in wave 1 alongside the census.
