**`pnpm dist:mac` after plan 34.9-14** runs, in order: `CSC_IDENTITY_AUTO_DISCOVERY=false` export →
`pnpm clean:dist-mac` → `pnpm build-steam-bridge` → `electron-vite build` → `electron-builder --mac`.
`electron-vite build` now carries plan 34.9-12's `closeBundle` plugin, which restores the twelve
`public/bin/**` symlinks into `build/bin/**`.

**Expected numbers, so a wrong reading is recognisable rather than plausible:**
- `find <darwin bin root> -type l | wc -l` → **12** (4 symlinks × 3 runners). Pre-fix `build/` was
  **0**. Both numbers are measured, so either is recognisable.
- Runner payload → **~84M** across legendary/gogdl/nile. Pre-fix dereferenced → **152M**.
- Version strings → legendary `0.20.43`, gogdl `1.2.1`, nile `1.1.2`.

**F-34.9-04, which nearly produced a false PASS on the first run:** the x64 onefile nile and the
arm64 onedir nile BOTH report `1.1.2 Will A. Zeppeli`. A version string alone discriminates nothing
about which binary ran. Only the spawned path in `gamelib.log` does.

**Sink partition — do not require the wrong sink of anything.** Rust `[shell]` → session transcript
ONLY. Sidecar `logInfo`/`logWarning`/`logError` → `~/Library/Logs/GameLib/gamelib.log` ONLY.
Per-runner output (including the actual version STRING a `--version` probe prints) →
`~/Library/Logs/GameLib/runners/{legendary,gog,nile}.log`, a THIRD sink. Sidecar STDERR →
transcript as `[sidecar:err]`. Sidecar `console.*` → nothing at all.

**Log rotation trap** (`src/backend/logger/log_writer.ts:72-74`): the next process's FIRST write
renames the live `gamelib.log` to `.old`. Archive each launch's `gamelib.log` and per-runner logs
BEFORE the next launch starts, or the earlier launch's evidence is destroyed.

**Identifier-redaction discipline.** No cookie value, gamekey, OAuth code, account id or PKCE
material (`code_verifier`, `serial`, `client_id`) in any plan, Summary, or captured artifact —
timestamps, window/launch ordinals and file paths only. `nile/user.ts:62` writes PKCE material to
`gamelib.log` in plaintext; only its TIMESTAMP is ever usable.

**A prior session already committed live PKCE material once before catching it in a post-commit
audit.** Audit every file this plan stages, before committing, not after.
