<objective>
Widen the `FOCUS ROW` section from the tracer's Views-only shape to the full pick space: every
existing collection, every connected store and every runnability value the host can compute.

Purpose: this is the half of SPEC R1 that motivated the whole phase — the old `libraryTopSection`
value space "cannot express a store, a collection or a runnability value". The tracer proved the
`{ kind, value }` path end to end for one kind; this plan makes the other three reachable, which is
pure expansion over an already-proven seam. The strip and the selector need no change at all:
`selectFocusRowGames` already handles all four kinds through `filterLibrary`.

Output: four fixed-order sub-groups inside one collapsed disclosure, each omitted wholesale when its
source list is empty, with clearable single-select across the whole section.
</objective>

executor to write a comment *explaining* why a token must not appear. An unfiltered `grep -c` counts
