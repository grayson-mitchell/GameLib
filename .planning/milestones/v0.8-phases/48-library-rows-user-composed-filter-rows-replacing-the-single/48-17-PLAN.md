## Fix decision (applies only if Task 1 confirms H1)

**Adopted: a strip-only scrollbar-allowance hold.**

- The strip already derives `C`, the track's border-box width less the list's inline padding.
- It now also reads the scroller's current vertical-scrollbar allowance: `main.content`
  `offsetWidth - clientWidth - borderLeftWidth - borderRightWidth`, clamped at 0.
- **While the grid is shown,** the sync uses `C` live and remembers that allowance as the track's
  reference.
- **While the grid is hidden,** the sync uses `C - (reference - current allowance)`. The strip keeps
  the content box the grid had, but still follows any real change of the track width, such as a
  window resize.
- **With no reference yet** (a track that has never seen the grid), it uses `C` live.
- The reference is per track element and resets with the 48-12 write history.

**Rejected, with the contract clause that rules each out:**

- *A stable gutter or `overflow-y: scroll` on `main.content` or `.listing`.* It changes the grid's
  output whenever the library does not overflow. SPEC R3: "amends the strip, never the grid", and
  the acceptance criterion "the grid's output is unchanged against a pre-phase baseline".
  `scrollbar-gutter` is also measured wrong in this repo: it reserves the platform's ~17px, not the
  10px custom bar (FocusRowStrip/index.css about line 37).
- *Always assume the scrollbar is present.* A library whose grid does not overflow would show the
  strip 10/n px narrower than the visible grid (2px at 5 columns), breaking "within 1px at every
  window width".
- *Freeze the last written width while the grid is hidden.* A window resize in the empty state would
  leave the strip stale.

**Reversibility:** reversible. The change is one optional parameter, one prop and one ref; the
default context keeps the old behaviour.

**Known, documented limit.** If the grid has never been shown on this track (for example, a launch
straight into a persisted zero-result filter), there is no reference, and the strip takes the
column over the live, scrollbar-less container. Once the grid shows, the reference exists.
