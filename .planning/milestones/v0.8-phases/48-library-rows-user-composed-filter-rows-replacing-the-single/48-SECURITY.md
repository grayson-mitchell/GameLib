## Trust Boundaries

The phase adds no network, auth, multi-tenant or transport surface (every plan says so and the
SPEC's canon referral records "must not send the selection off-device" as privacy with no network
path). The boundaries the plans name:

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| on-disk profile → renderer state | `config.json` / `store/config.json` `focusRow` and legacy `libraryTopSection` read by `GlobalConfigV0.getSettings()` and `hydrateFocusRowSelection` | a user setting, hand-editable; shape-guarded by `isValidFocusRowSelection` |
| catalogue file → rendered DOM text | `public/locales/*/gamelib.json` keys rendered as control names and `aria-label`s | localisation strings |
| user-authored collection name → DOM | collection names rendered as text children and `title` attributes in the strip header and the FOCUS ROW panel | user text, never into HTML, href, src or style |
| DOM events → input-mode class | `installKeyboardNavTracking` reads `event.key === 'Tab'` and `isTrusted`, sets a body class | no key stored, logged or forwarded |
| live-gate rig → operator profile and screen | 48-08/15/18 gates launch the dev shell, read the DOM and capture the window | the operator's real profile (backed up and hashed) and screenshots (kept in a 0700 scratchpad, never committed) |
