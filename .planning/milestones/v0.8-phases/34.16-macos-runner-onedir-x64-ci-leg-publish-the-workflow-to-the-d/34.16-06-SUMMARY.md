## F-34.16-G was measured, not inferred

Both matrix jobs were created in the same second; only one was ever served:

```
build (macos-14, arm64)  created=17:54:23  started=17:54:26  runner="GitHub Actions 1000000201"
build (macos-13, x64)    created=17:54:23  started=17:54:23  runner=""   group=""
```

An empty `runner` **and** an empty `group` after 25+ minutes is a label nothing serves. Congestion
would show a group and no runner. That distinction is what makes this a measurement rather than a
guess.

waiting on it buys no information."* **That prediction cannot have applied** — the job never

ran. Correlation read as cause, and it hid this finding for two attempts. Attempt 3 exposed it only
because arm64 went green and the queue persisted anyway.

The attempt-2 record was corrected in place rather than left to mislead the next reader.
