<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub API -> `checkRunnerInvocations` temp dir | Untrusted third-party YAML is fetched over the network and parsed. It is written to a temp dir and read by the extractor; it is never executed and never reaches a build. |
| checked-in record -> extractor/derivation under test | The record is repo content, but it originates as a verbatim copy of untrusted upstream text, so the offline layer parses attacker-influenced strings too — inside jest, with no spawn. |
| fetched text -> a command that will later be executed | Indirect: this plan executes nothing. Its whole output is a comparison. The widening of what upstream text may influence lives in plan `34.16-07` and is modelled there. |
