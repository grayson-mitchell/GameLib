<objective>
Close the prerequisite gap that blocks D-10 as literally written, and pin the two published audit
artifacts' formats so plan 05's pin script parses a contract rather than a guess.

Purpose: D-10 says `pin:runner-digests` records "the source run id from `BUILD-MANIFEST-{arch}.json`".
That file has **no run id field at all** today — no `runId`, no timestamp, no workflow-run key. Both
the researcher and the pattern mapper surfaced this independently. It is a missing prerequisite, not
an open design choice: without it the pin script reads `undefined`.

Sequencing consequence this plan exists to satisfy: the dispatch targets
`--ref fix/steam-native-install-stability`, so **that ref's** `meta/buildRunnersOnedir.ts` is the code
that runs on the macOS runners. This change must be committed on the feature branch BEFORE plan 06's
dispatch, or the first published run yields manifests with no run id and the pin script has nothing
to record.

Output: a `runId` field written from `GITHUB_RUN_ID`, two exported pure formatters, and unit tests
pinning both artifact formats.
</objective>
