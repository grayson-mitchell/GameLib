<objective>
Close the Check 3 gap from `46-LIVE-GATE.md`. A bare second launch delivered the focus sentinel and exited 0, but the MINIMIZED primary window was not restored or focused.

Root cause: tao-0.35.3 on Windows. `show()` only sets the VISIBLE flag, and it issues no `ShowWindow` call for a window that is already visible. `set_focus()` does nothing while the window is minimized. Only `set_minimized(false)` (`unminimize()`) issues `ShowWindow(SW_RESTORE)`. The claim that `show()` + `set_focus()` is enough was measured on macOS only.

Two more changes are defensive, because a live-gate round trip is expensive:
- the secondary grants foreground rights to the owner-verified primary;
- the primary logs sentinel receipt and the result of each raise call.

After that, the plan pins everything with source gates, rebuilds the debug NSIS installer for the re-gate (46-07), and closes out 46-05's record as a FAIL.

Purpose: REQ-46-10 Check 3 ("a bare second launch focuses the existing window"), which is also a stated verification of REQ-46-01. REQ-46-11 (the record matches reality) covers the corrected cross-platform comment and the 46-05 SUMMARY.
Output: the fixed main.rs, a Cargo.toml feature, new jest gates, a filed Linux todo, a rebuilt setup .exe, and 46-05-SUMMARY.md.
