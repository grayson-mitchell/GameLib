<objective>
Two halves of the same lesson.

(a) `archSpecificBinary` (`src/backend/utils.ts:499-514`) existence-checks the arch-native path and
then falls back to the x64 path **without ever checking it**. That is what converted a wrong
`publicDir` into `x64`-on-an-arm64-Mac plus a `spawn ./legendary ENOENT` from
`launcher.ts:1728-1733`, six layers away from the actual fault, with the LOGGED command
(absolute) disagreeing with the ERROR (relative). Make the fallback loud at the point of failure.

(b) The full suite was green at 3447/3447 while this defect was live, because jest runs with cwd =
the repository root, where `publicDir` accidentally resolves correctly. A test that re-asserts the
code's own arithmetic is worthless here. This plan adds coverage that forces cwd to `src-tauri/`
— the real sidecar condition — and asserts against the REAL filesystem that every asset the
sidecar resolves is actually there.

Purpose: make this failure family detectable by `npm run test:ci` instead of by a human driving a
live login.
Output: an existence-checked binary resolver and real-filesystem sidecar-conditions coverage.
</objective>

`src/backend/utils.ts:499-514`:
`function archSpecificBinary(binaryName: string)` — appends `.exe` on win32, builds
`join(publicDir, 'bin', process.arch, process.platform, binaryName)`, returns it if `existsSync`,
otherwise returns `join(publicDir, 'bin', 'x64', process.platform, binaryName)` unconditionally.

Its four callers, all memoising into a module-scope `let` and all exported at
`src/backend/utils.ts:1705-1708`:
`getLegendaryBin()`, `getGOGdlBin()`, `getCometBin()`, `getNileBin()` — each first honours a
`GlobalConfig.get().getSettings()` alt-binary override (`altLegendaryBin`, `altGogdlBin`,
`altCometBin`, `altNileBin`) and only calls `archSpecificBinary` when the override is absent. Each
returns `{ dir, bin }` via `splitPathAndName(fixAsarPath(...))`.

`src/backend/launcher.ts:1728-1733` (`callRunner`) — logs `join(runner.dir, bin)` but spawns
`'./' + bin` with `cwd: runner.dir` on non-Windows. This asymmetry is why the log and the error
disagreed; do not change it in this plan.

Real binaries on this machine: `public/bin/{arm64,x64}/darwin/{legendary,gogdl,nile,comet}`.
