## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| captured redirect URL → `authAmazon` | The first point in this project's history where a captured OAuth code is exchanged for a real Amazon credential |
| renderer → `authAmazon` payload | Untrusted at runtime despite its type contract |
| sidecar → `nile_config` CLI credential dir | Where the real token lands, written by the nile CLI, reached via `NILE_CONFIG_PATH` |
| app-wide cookie jar | Amazon cookies now share the jar with Epic, GOG and Humble (inherited T-34.4.1-47) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-34.5-34 | Spoofing | a code captured from a non-Amazon origin reaching `authAmazon` | mitigate | Hard plan dependency on REQ-34.5-02: the exact-host anchor lands first and is the ASVS V5 control. An integration test asserts a previously-matching hostile URL now yields `null` and never reaches the mint. |
| T-34.5-35 | Spoofing | a malformed payload reaching `NileUser.login` | mitigate | Shape validation at the handler boundary against `NileUser.login`'s real signature; the runner method is not invoked on rejection. |
| T-34.5-36 | Information Disclosure | logging an authorization code | mitigate | Rejection logs record a reason only; a test asserts the payload value is absent from the emitted string. |
| T-34.5-37 | Information Disclosure | Amazon cookies persisting in the shared jar after sign-out | accept | Inherited and already-accepted T-34.4.1-47. Electron's `NileUser.logout()` never cleared them either (verified: no `session` usage), so a clear here would be a behaviour change rather than a port. Declared as a residual in `34.5-PORTED-CHANNELS.md`; any future per-runner clear MUST be domain-scoped, never blanket. |
| T-34.5-38 | Repudiation | shipping a real credential path over a seam whose live gate never ran | mitigate | Live-gate precondition 1 (plan 34.5-03) blocks gate items 1-3 until 34.4.1's own gate records PASS on item 1; this plan may build but the phase may not close without it. |
| T-34.5-SC | Tampering | npm installs | accept | Zero new packages. |
