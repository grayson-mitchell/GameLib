## Decisions Made

- Implemented D-CYCLE7-A exactly as locked by the plan/routing document -- no re-litigation of the "stop presenting as a sheet" option, which the plan itself states is factually closed.
- Used `document.onreadystatechange` instead of `document.addEventListener('DOMContentLoaded', ...)` for the banner's loading-state arm. The task text requires the banner to register "NO event listener of any kind" and separately requires a test asserting `addEventListener` is absent from the script body -- a literal `document.addEventListener` call for the DOMContentLoaded-equivalent arm would have contradicted both. `onreadystatechange` achieves the identical practical effect (re-run `ensure()` once the document leaves the `loading` state) via a property assignment, not a listener registration, so the banner is provably free of `addEventListener` by construction.
