- `src/backend/sidecar/nativeImageShim.ts`: a real `nativeImage` with
  `createFromBuffer`/`createFromPath`/`createFromDataURL`/`createEmpty`, each returning a
  chainable object (lazy `resize`/`crop`, real `toPNG`/`toJPEG` via `/usr/bin/sips`, a loud

  whole `gamelib://` URL single-quoted and percent-encoded (T-34.5-C6-17) — proven RED against a
  malicious `app_name` of `x&runner=gog;touch /tmp/gamelib-pwned` before the fix, GREEN after.

  (`nativeImage.createFromBuffer: jest.fn()`, the whole `@shockpkg/icon-encoder` mock) are
  removed, not adjusted; `convertPngToICNS`'s full chain now runs real against a fixture generated
  from a macOS-shipped `.icns` via real `sips`.
- `main.rs`'s doc-comment about the (now-fixed) unquoted `run.sh` was rewritten past-tense in the
  SAME commit as the fix, keeping the runner-less URL tolerance for pre-fix `.app` bundles on
  disk (comment-only diff, `cargo build` reconfirmed clean).
- F-34.5-G6-08 discriminator: a hypothesis-by-observable matrix (H1..H5) built before any fix,
  run against two offline arms (a real RPC frame through the real `startRpcServer` loop; a
  source-text pin on `main.rs`'s `unwrap_or(Value::Null)`), both RED-proven. VERDICT: NOT
  REPRODUCED — H2/H3/H4 excluded, H1/H5 survive as live-only. No speculative fix shipped.
  `U-34.5-15` stays OPEN, its cell amended to require a `.then` console readout instead of a bare
  `await` (the discriminating observable H1 names).

  multi-line-capable pattern (10/9/4/11 per module) and classified against their declared
  `AsyncIPCFunctions` type: 27 RETURNS, 7 VOID-PARITY, **0 DROP**. New
