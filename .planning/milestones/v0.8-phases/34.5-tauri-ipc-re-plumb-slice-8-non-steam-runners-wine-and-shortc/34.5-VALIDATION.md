**Test-store containment — inherited, do not bypass.** `src/backend/jest.setupContainment.ts`
redirects HOME/APPDATA/XDG for every backend test file automatically (structurally mitigated since
the Phase 34.2 gap cycle 4). This slice writes **desktop shortcuts, macOS `.app` bundles, and Steam
shortcut VDFs** — the first slice whose code path creates files outside the app support dir by
design. Plans MUST NOT disable, bypass, or opt out of that setup file, and shortcut-writing tests
MUST assert against a redirected `desktop`/`home`, never the developer's real one.

**Rust-test CI gap (standing, inherited).** No `cargo test` / `cargo check` step exists in
`.github/workflows/*.yml`. Rust verification is a **manual, local** obligation for this slice —
record the result explicitly rather than assuming CI covered it.
