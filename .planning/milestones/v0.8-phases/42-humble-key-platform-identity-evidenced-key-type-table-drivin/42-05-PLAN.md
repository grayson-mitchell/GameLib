## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer -> OS browser | `window.api.openExternalUrl` hands a URL to the system browser. The URL embeds a live secret on the two deep-link branches. |
| Humble API -> URL selection | `humbleKey.platform` is a remote string that selects which URL template is used. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-42-17 | Information disclosure | the revealed key value leaking to a wrong destination | mitigate | This file no longer builds any URL. `getRedeemTarget` is the single resolver; it emits a code-bearing URL only for the two evidenced templates and returns the help URL with the code DROPPED for everything else. Pinned by two tests asserting the recorded `openExternalUrl` argument does not contain the secret for `uplay` and for an unrecognised platform. |
| T-42-18 | Tampering | a hostile `key_type` steering the key to an attacker URL | mitigate | Deep-link selection happens inside the closed table against the literals `'steam'` and `'gog'`; the wizard passes `redeemTarget.url` through verbatim and constructs nothing. Plan 42-01's suite pins that a URL-shaped `key_type` resolves to the help branch. |
| T-42-19 | Information disclosure | the key value in the URL path or query | mitigate | `encodeURIComponent` is applied once, inside the table; this plan removes all URL construction (and therefore all encoding) from the wizard — verified by a grep asserting zero `encodeURIComponent` occurrences remain in the file. |
| T-42-20 | Information disclosure | the key value reaching logs | mitigate | No logging is added. The wizard's existing C4/T-14-02 narrow-exposure discipline (`humbleGetRevealedKeyValue` is the only channel that transmits a raw key) is unchanged — this plan adds no new IPC call and no new channel. |
| T-42-21 | Spoofing | a fabricated store name in the button label | mitigate | The label's display name comes only from the table; the unknown branch renders the neutral 'Other' label. Pinned by the `'wibble'` case asserting the raw input string does not appear. |
| T-42-SC | Tampering | npm/pip/cargo installs | mitigate | No package-manager install in this plan. No new dependency. No `[ASSUMED]`/`[SUS]` package to gate. |
