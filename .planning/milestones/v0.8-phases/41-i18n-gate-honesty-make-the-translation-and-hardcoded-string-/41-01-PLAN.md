<objective>
Author the six `redeemKey.*` strings that are empty in **English**, and add the gate that keeps
them non-empty.

Purpose: an empty English source value is precisely what makes a key un-fillable — the
machine-fill skips any key whose English source is empty, so these six render English in all 48
non-English locales and can never be translated. This is an AUTHORING gap in `en`, not a
translation gap.

This plan must land BEFORE plan 41-05's inverted presence check (REQ-41-01). Keying that check off
`en` being non-empty is what removes the need for a carve-out list — and a carve-out list written
before this plan runs would be a list this plan then deletes.

Output: `public/locales/en/gamelib.json` at 224 keys / **0** empty values (currently 224 / 6), plus
a blocking assertion that a seventh empty English value can never appear unobserved.
</objective>

## Scope fence

`public/locales/en/gamelib.json` and `meta/` only. **No runtime code path.**
`src/frontend/components/UI/RedeemSteamKeyDialog/copy.ts` is READ as the source text for the six
strings — it is **not edited**. Its `try`/`catch` + inline-default fallback shape stays exactly as
it is; that shape is what keeps the dialog rendering if `t` throws, and it is orthogonal to this
plan.

`pnpm machine-fill-gamelib` (propagating the six strings to the other 48 locales) is **explicitly
out of this phase's scope** — it needs a working API key and has 401'd before. Do not run it and
do not plan around having run it.

## Interfaces

The six English strings live at `src/frontend/components/UI/RedeemSteamKeyDialog/copy.ts` as the
`message` binding immediately before each `t()` call:

| catalog key | copy.ts line | value |
|---|---|---|
| `redeemKey.successWithPackage` | :43 | `Key redeemed! {{packageName}} has been added to your Steam library.` |
| `redeemKey.successNoPackage` | :54 | `Key redeemed! Your Steam library has been updated.` |
| `redeemKey.alreadyOwned` | :64 | `This key has already been redeemed — you already own this on Steam.` |
| `redeemKey.invalid` | :74 | `This key doesn't look right. Double-check it and try again.` |
| `redeemKey.rateLimited` | :83 | `Too many attempts — please wait a bit before trying again.` |
| `redeemKey.error` | :94 | `Couldn't reach Steam to redeem this key. Check your connection and try again.` |

**Two of these contain U+2014 EM DASH** (`alreadyOwned`, `rateLimited`). All apostrophes are
ASCII `U+0027`, not U+2019. This project has a recorded failure where an anchor retyped from a
display copy silently no-opped because an em dash was retyped as `--`. **Extract these
programmatically from `copy.ts`; do not retype them.**

`successWithPackage` carries the i18next interpolation token `{{packageName}}`. The catalog value
must contain it verbatim — `meta/machineFillGamelib.ts`'s `validateTranslation` enforces
placeholder parity for every downstream locale against this English source.
