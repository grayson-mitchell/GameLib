- **`background: transparent` over a relational-token swap.** The plan offered a choice: prefer removing the class of defect (`transparent`, compositing onto whatever the column paints) unless a distinct raised surface is judged necessary for legibility, in which case a relational token must be justified across all three scored themes with an explicit comment. Chose `transparent` — the panel's existing `.expanded` inset hairline (`box-shadow: inset 0 0 0 1px var(--divider)`) already delimits the panel from the column visually, so there is no legibility gap a raised surface would need to fill, and `transparent` leaves nothing to mismatch in any future theme or any future surface change to `.NavShell__tier2` itself.
