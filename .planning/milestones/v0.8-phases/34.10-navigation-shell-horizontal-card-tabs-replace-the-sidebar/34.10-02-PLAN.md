Build the shell's stylesheet — layout, the three new tokens, the tier-2 collapse case — and the
`NavItem` tier-2 row primitive that every nav list in this phase renders.

(`SidebarItem/index.css:1-2`), so "reuse it verbatim" is impossible once `.Sidebar` is retired —

panel and fixes the token seam before any list is built on top of it.
