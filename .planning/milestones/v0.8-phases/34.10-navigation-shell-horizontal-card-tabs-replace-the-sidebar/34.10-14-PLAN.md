Close F-34.10-02 cause (a): the ambient Downloads ring is invisible at rest and reads as a solid
filled disc on hover. Remove the defect class rather than the symptom — the ring's centre becomes a
real transparent hole instead of an opaque patch painted in a hardcoded backdrop token.

behind the ring. The parent Link's own `&:hover { background-color: var(--navbar-active-background) }`
falsifies that guess on hover, which is precisely the "solid circle" the operator reported — and it
would be falsified again by any third background state a future phase adds.
Output: a masked donut with a genuinely visible idle track.

    **Delete the `&::after` block from `.DownloadsRing__ring`** and mask the element instead, so the

      mask: radial-gradient(farthest-side, transparent calc(100% - 3px), #000 calc(100% - 3px));

    Emit both the `-webkit-` prefixed and unprefixed forms; the target shell is WKWebView on macOS.
    With `width`/`height` at 16px (see below) `farthest-side` gives an 8px radius, so the mask is
    transparent from the centre out to 5px and opaque from 5px to 8px — a 3px ring band, matching
    today's `inset: 3px`.

    **Add a `@supports not` fallback** immediately after the rule, so a webview without mask support
    degrades to the old technique rather than to a solid disc — and so the fallback covers BOTH
    background states, which is what the original never did:

      @supports not (mask: radial-gradient(farthest-side, transparent 0, #000 0)) {
        .DownloadsRing__ring::after { content: ''; position: absolute; inset: 3px;
          border-radius: 50%; background: var(--navbar-background); }
        .DownloadsRing:hover .DownloadsRing__ring::after {
          background: var(--navbar-active-background); }
      }

    **Repaint the idle track.** In the `conic-gradient`, replace the track colour `var(--divider)`
    with `var(--navbar-inactive, var(--navbar-accent))` — the identical token chain

    confirmed visible on real hardware. Leave the progress colour `var(--primary)` and the two
    `var(--dl-progress)` stops exactly as they are. After this change `--divider` should no longer
    appear anywhere in this file.

    **Raise the idle dimming from invisible to dimmed.** Change `.DownloadsRing--idle`'s
    `opacity: 0.5` to `opacity: 0.65`. D-07 requires "dimmed, never hidden"; 0.5 against the old
    near-zero-contrast track produced hidden.

    **Grow the ring from 15px to 16px** (`width` and `height`). An even diameter makes the 3px band
    land on whole device pixels at 1x and 2x rather than on a half-pixel boundary, which is the
