<objective>
Assemble the shell root, relocate `HeroicVersion` with its mount timing preserved, and turn the
onboarding tour off.

Purpose: `HeroicVersion` is not a label. It clears the cache when the app version changes and hosts
the changelog modal that auto-shows on startup — both mount-triggered. Placing it inside a
conditionally-rendered Settings panel would silently move both behaviours from "every launch" to
"first time the user opens Settings". This plan resolves that explicitly, which no upstream decision
did.
Output: the shell root component, the relocated version block, one structural test suite.
</objective>
