<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer → external browser (`window.api.openKofiPage`) | A nav row opens an external URL outside the app |
| renderer → app lifecycle (`handleQuit`) | A nav row terminates the application |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-34.10-10 | Spoofing | Ko-fi row opening an external URL | mitigate | The external-link confirmation dialog gate (`handleExternalLink` reading `SHOW_EXTERNAL_LINK_DIALOG_STORAGE_KEY`) is ported verbatim; the destination is the fixed `window.api.openKofiPage` handler, never a URL assembled in the renderer. |
| T-34.10-11 | Denial of service | Quit row terminating the app | mitigate | The `showDialogModal` confirmation with explicit Quit/Cancel buttons is ported unchanged, so a single stray click cannot end the session. |
| T-34.10-12 | Elevation of privilege | guarded rows (Humble Keys, Redeem a Steam key, Game Defaults, Wine Manager) | mitigate | Each guard is copied verbatim from the shipped source and pinned by a test asserting both the present and absent case; a dropped guard would surface a destination for an unauthenticated or unsupported configuration. |
| T-34.10-SC | Tampering | npm/pip/cargo installs | accept | Zero new dependencies; no install task exists to audit. |
</threat_model>
