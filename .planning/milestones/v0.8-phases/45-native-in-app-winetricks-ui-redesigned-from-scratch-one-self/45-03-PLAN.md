## Planner decisions recorded here (deviations from UI-SPEC's Copywriting Contract, each with reason)

1. `everythingElse` is "Everything else" with the count rendered as a separate tabular-nums badge,
   NOT "Everything else ({{count}})": a base-only key interpolating `{{count}}` is the reserved-name
   trap, and the badge matches the task-group header idiom (UI-SPEC E4 zero-one-many: bare count, no
   plural word).
2. `applyAriaLabel` is a plural pair, not one key: it interpolates `count`, so it needs `_one`/`_other`.
3. `installingBar` names its third placeholder `{{title}}` (UI-SPEC wrote `{{family}}`): the value is
   the current row's display title — family sentences are full sentences, not labels. 45-01-PLAN.md
   already consumes `title`.
4. `environmentBannerGptk` interpolates `{{version}}` (UI-SPEC E2 said "no variable part"): the
   backend records the actual wine version (45-06), so the copy cannot go stale when GPTK's wine
   changes.
5. `curatedGroupHint` is ADDED: D-06 locks "a `Commonly needed` heading with one line explaining why";
   UI-SPEC's table omitted the line.
6. `logEmpty` is ADDED: resolves UI-SPEC unresolved row E9-empty with RESEARCH's recommended default
   (a single placeholder line); see 45-08-PLAN.md assumption A-45-02.
