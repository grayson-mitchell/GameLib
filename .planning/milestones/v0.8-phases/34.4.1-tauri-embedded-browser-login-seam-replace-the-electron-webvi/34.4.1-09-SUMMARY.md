# Phase 34.4.1 Plan 09: Wire the four OAuth runners to the login seam Summary

**Each of legendary/gog/nile/zoom now opens a real Tauri login window through the shared LoginWindowSeam, captures its own distinct redirect shape via a pure per-runner matcher, and hands the code to its still-unported auth channel inside a catch that turns the expected UNPORTED_CHANNEL_MARKER rejection into an honest "captured, but Phase 34.5" surface instead of a blank screen or a floating rejection.**

## Accomplishments

- `matchOAuthRedirect()` proves all four REQ-34.4.1-08 redirect shapes by executable test — `legendary`'s `localhost`+`?code=`, `gog`'s `embed.gog.com/on_login_success`+`?code=` (a deliberate tightening of `index.tsx`'s unanchored regex), `nile`'s `openid.oa2.authorization_code`, and `zoom`'s `li_token` (returning the full redirect url, since `authZoom` takes the url not the token) — plus their near-miss negatives, a malformed-url case, and the full 12-entry cross-runner negative matrix.
- `captureOAuthLogin()` drives the SAME `LoginWindowSeam` Humble already installed, deadline-bounded (5 min default), settles exactly once through a close-guaranteed helper, and never rejects — every failure resolves a typed outcome.
- One new `oauthCaptureLogin` handle channel reaches `window.api` (verified by importing the assembled `preload/api` default export directly and checking `typeof ... === 'function'`, not by grep alone — the 34.4 gate-item-2 lesson), boundary-validates `runner`/`url` before ever touching the seam, and is registration-kind cross-checked (handle present, listener absent).
- `useTauriOAuthLogin()` is the renderer half: it genuinely opens a login window per runner, drains navigation events, captures the redirect, and calls the real (still-unported) auth channel — the `UNPORTED_CHANNEL_MARKER` rejection is caught and surfaced as `{ phase: 'blocked', runner, channel }`, never swallowed and never left as an unhandled rejection (asserted per runner with a live `process.on('unhandledRejection')` listener).
- `TauriLoginPanel` renders the real capture phases (`awaiting`/`blocked`/`cancelled`/`timeout`/`error`) via the `state` prop plan 05 reserved for exactly this purpose, without restructuring the component.

## Decisions Made

- **`OAuthRunner`/`OAuthCaptureOutcome` moved to `common/types/oauthLogin.ts`.** The plan's interface block specified these types living in `oauthLoginCapture.ts` directly but explicitly authorized this fallback if `common/types/ipc.ts` importing from `backend/sidecar` would cross an established import-direction boundary. A repo-wide check found no existing precedent of `common/types/*` importing from `backend/sidecar/*` (the established direction is always common -> backend/frontend, e.g. `NileLoginData` in `common/types/nile.ts`), so the fallback was taken: one definition in `common/types/oauthLogin.ts`, re-exported from `oauthLoginCapture.ts` so no existing import site needed to change.
- **`TauriLoginPanel`'s state-absent default keeps plan 05's exact original wording.** Task 3's `<files>` list does not include `TauriLoginPanel.test.tsx` (plan 05's file), meaning those tests must keep passing unmodified. Since several of those tests call `TauriLoginPanel({ runner })` with no `state` at all and assert the declared-blocked copy names the channel + "Phase 34.5", the `phase === undefined` branch had to preserve that exact copy. Only the NEW `phase === 'blocked'` branch (reached only after a real capture) gets the reworded "captured, but can't finish yet" copy the plan actually asked for.
- **The hook calls `window.api.login`/`authGOG`/`authAmazon`/`authZoom` directly, not `GlobalState`'s `epicLogin`/`gogLogin`/`amazonLogin`/`zoomLogin` wrappers.** Those four `GlobalState.tsx` methods have no try/catch of their own (verified read-only, lines 596-709) and `WebView/index.tsx` calls them with `.then()` and no `.catch()`. Calling the raw channel directly lets the hook own the entire try/catch without touching `GlobalState.tsx` at all — confirmed by `git diff --stat src/frontend/state/GlobalState.tsx` returning empty.
