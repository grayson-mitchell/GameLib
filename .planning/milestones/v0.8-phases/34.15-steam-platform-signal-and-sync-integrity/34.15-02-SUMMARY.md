# Phase 34.15 Plan 02: Steam sync status channel and GlobalState tri-state Summary

**Declared the `steamSyncStatus` backend->frontend push channel end to end (ipc.ts type + preload allowlist + GlobalState consumer) and replaced the broken `refreshingInTheBackground` boolean with a real `'idle' | 'syncing' | 'failed'` tri-state, gated by a RED-proven five-touchpoint source test.**

## Performance

- **Duration:** ~35 min
- **Tasks:** 3
- **Files modified:** 5 modified, 1 created

## Accomplishments
- `steamSyncStatus` is now a fully declared, allowlisted, consumed IPC channel -- the highest-risk omission (a missing preload export failing silently on the Tauri sidecar) is closed and gated
- `GlobalState` owns a structural tri-state for the Steam sync indicator, declared in lockstep at all required sites, without touching `refreshingInTheBackground`'s own default/reset logic
- A RED-proven source gate (10 tests: 5 real-source assertions + 5 self-tests) proves every touchpoint exists and that each gate actually discriminates against a source-derived known-bad specimen

## Files Created/Modified
- `src/common/types/ipc.ts` - Added `SteamSyncStatus`/`SteamSyncFailureReason` exported type aliases and the `steamSyncStatus` `FrontendMessages` declaration, mirroring `steamMetadataSyncing`

## Decisions Made
- Reason-code vocabulary for `SteamSyncFailureReason` chosen per D-07's Claude's Discretion clause: `client-not-ready` (Steam session could not be re-established), `owned-apps-failed` (CM reached but owned-app list did not arrive, cached library served), `sync-failed` (owned-app list arrived but hydration threw)
- Did not add an explicit per-field line for `steamSyncStatus` in the `render()` provider-value object -- `GlobalState.tsx`'s `ContextProvider.Provider` value already does `{ ...this.state, ... }`, so the new state field reaches consumers automatically, exactly as `steamMetadataSyncing` does today. Verified by reading `render()` directly (`:1663-1791`) rather than assumed.
- Left `reason` out of `GlobalState` state per the plan's explicit instruction -- only `status` drives the tri-state for now
