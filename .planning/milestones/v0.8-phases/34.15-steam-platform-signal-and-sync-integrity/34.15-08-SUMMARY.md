# Phase 34.15 Plan 08: Inline Steam sync notice Summary

**A new `SteamSyncNotice` component renders the Steam sync tri-state as an inline, non-blocking row above the merged library grid -- replacing the `refreshingInTheBackground`-driven guard that hid 6 GOG games behind a centred spinner -- wired via the pure `resolveSteamSyncIndicator` resolver and locked by a RED-proven source gate with 4 string-manipulation-derived failure proofs.**

## Performance

- **Duration:** ~50 min
- **Tasks:** 3
- **Files modified:** 3 created, 2 modified

## Accomplishments
- `SteamSyncNotice` is one component with two modes (`'syncing'` | `'failed'`), always rendered in normal document flow -- no `position: absolute`/`fixed`, no full-viewport container, no early return. `'hidden'` is never a prop value; the caller decides whether to mount the component at all.
- `'failed'` mode's retry calls the existing scoped `refreshLibrary({ library: 'steam', ... })` path directly -- no new backend wiring, no new IPC.
- `Library/index.tsx`'s broken guard (`steam?.username && steam?.library?.length === 0 && refreshingInTheBackground`) is gone. The render decision is delegated wholesale to `resolveSteamSyncIndicator`, computed once and passed straight to `<SteamSyncNotice>`.
- The D-11-fenced global overlay (`{refreshing && !refreshingInTheBackground && <UpdateComponent />}` at the old `:1011`) is byte-identical, confirmed both by the `git diff` acceptance check and by a dedicated RED proof (deleting that exact line trips the same gate that guards the old guard's removal).
- Four new localised strings (`gamelib:library.steamSync.{syncing,failedTitle,failedBody,retry}`) extracted via `pnpm i18n`, with no `{{count}}` interpolation and no edited-default renames.
- `librarySyncNoticeSource.test.ts`: 12 tests -- 6 real-source gate assertions (G1-G5 plus a combined run) and 4 mandatory RED proofs, each built by manipulating captured constants of the real file's own text (never hand-authored specimens), plus a stripper-integrity pair mirroring `filterChipRowPlacement.test.ts`'s convention.
- Full suite: `npx jest` -- 282 of 283 suites pass (5871/5873 tests); the sole failure is the pre-documented, out-of-scope `genI18nGateScope.test.ts` A-17 anti-rot check, owned by the orchestrator's reconciliation pass. `npx tsc --noEmit -p tsconfig.json` exits 0.
