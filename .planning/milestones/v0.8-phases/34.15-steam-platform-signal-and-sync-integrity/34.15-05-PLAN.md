<objective>
Wire the bulk platform capture into `SteamLibraryManager.refresh()` (D-03/D-04) and give `refresh()`
a terminal failure signal on **every** exit path (D-07) — including the fourth, undocumented one.

Purpose: today `refresh()` has three obvious exits, but Steps 2-4 (`library.ts:705-847`, a ~140-line
span) are wrapped in **no try/catch at all**. An exception there propagates as an uncaught rejected
promise on exactly the unscoped mount-time path (`runOnceWhenOnline(() => this.refresh())`,
`library.ts:607`) that D-06's own rationale names as where the bug reproduces — `runOnceWhenOnline`
discards the return value with no `.catch` anywhere in the chain. A plan that only wraps the two
documented returns still ships the bug.

Output: `refresh()` gains one awaited fail-soft step and full exit-path instrumentation, plus tests
that force each path independently.
</objective>
