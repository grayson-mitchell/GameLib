## The key count is 13, not 11

`44-CONTEXT.md` D-09 locks "11 new keys" by subtracting the 5 `winetricksBrowse.category.*` keys
from the UI-SPEC's 16. That subtraction is correct and is honoured here — **no `category.*` keys are
added.** But the UI-SPEC's own 16-key copy table was already short two strings its own contract
requires, and D-09 inherited the shortfall. Both gaps were found by reading the shipped code and
the spec together. Neither is a scope expansion; each closes a string the approved design already
demands.

**Gap 1 — the search placeholder.** `SearchBar`'s `placeholder` prop is **required**
(`src/frontend/components/UI/SearchBar/index.tsx:8-18` — `placeholder: string`, no `?`). Today
`WinetricksSearch/index.tsx:111` supplies it from `t('winetricks.search', 'Search fonts or
components')` — and **D-20 deletes `winetricks.search`**. The UI-SPEC's Layout section draws
`[ ⌕ Search components… ]` but its Copywriting Contract lists no key for it. Shipping D-09's 11
keys and D-20's removal together would leave the new panel with a mandatory prop and no string.
Added as `winetricksBrowse.searchPlaceholder`.

**Gap 2 — the search-results header.** UI-SPEC Interaction Contract §2 mandates the flat results
view carry a `"{{count}} results"`-shaped header. Its Copywriting Contract lists no key for that
either. Added as `winetricksBrowse.resultsHeading`. **Its placeholder is `{{total}}`, NOT
`{{count}}`** — `count` is a reserved i18next interpolation name that switches a key into plural
resolution, which would demand per-locale `_one`/`_few`/`_many`/`_other` variants across 49 locales
(Arabic alone has six categories). `{{total}}` sidesteps pluralisation entirely for one string.

**Corrected arithmetic, superseding D-09's "11 × 48 = 528" and `44-PATTERNS.md`'s "11 × 49 = 539":**

| Figure | Value |
|---|---|
| New keys | **13** |
| Locale dirs with `gamelib.json` | **49** (verified 2026-09-16: `ls public/locales/*/gamelib.json \| wc -l` → 49) |
| Total key-values written across the phase | **13 × 49 = 637** |
| Non-English fill (plan 44-06's population) | **13 × 48 = 624** |
| Written by THIS plan | 13 (English only) |

`44-PATTERNS.md` is right that D-09's "11 × 48 = 528" was the non-English fill, not the total. Both
numbers are superseded by the table above. Any later document quoting 528 or 539 is stale.

**What is NOT added, and stays not added:** the 5 `winetricksBrowse.category.*` keys (D-09), and a
separate `installAriaLabel` key that `44-PATTERNS.md` floats as a possible 12th. The accessible name
for row buttons is composed with `aria-labelledby` pointing at the row-title node and the button's
own visible-label node (see plan 44-03), which resolves "Install Visual C++ 2019 libraries" from two
already-localised fragments at zero string cost.
</planner_correction>
