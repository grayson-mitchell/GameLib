### `src/preload/api/misc.ts` (preload, renderer-side Tauri JS — D-01)

**Analog:** `src/preload/api/misc.ts` itself (`storeGet`/`storeSet`/`storeNew`/`storeHas`/`storeDelete`, lines 62-197) — this is the ONLY existing precedent in the codebase for a channel needing a genuinely different, non-IPC body under Tauri vs. Electron, in the same exported function.


**Core `isTauri()`-branch pattern** (verbatim precedent, `misc.ts:97-108`, `storeNew`):
```typescript
export const storeNew = function (storeName: string, options: Store.Options<Record<string, unknown>>) {
  if (isTauri()) {
    registerStore(storeName, options)
    return
  }
  // Lazy, guarded `require` -- see ipc.ts's ipcRenderer comment for why: electron-store is
  // Node-only (fs-backed via `conf`) and must not be a static import value if this module
  // is ever reached from the Tauri renderer bundle (BLOCKER-1 / T-27-07).
  // eslint-disable-next-line @typescript-eslint/no-require-imports
  const ElectronStore = require('electron-store') as typeof Store
  stores[storeName] = new ElectronStore(options)
}
```
and the handler-shaped precedent (`misc.ts:178-189`, `storeGet`):
```typescript
export const storeGet = (storeName: string, key: string, defaultValue?: unknown) => {
  if (isSecretStoreKey(storeName, key)) {
    console.warn(`storeGet: blocked read of credential key "${key}" from "${storeName}"`)
    return undefined
  }
  if (isTauri()) {
    return snapshotGet(storeName, key, defaultValue)
  }
  return stores[storeName].get(key, defaultValue)
}
```

**D-01's own worked example** (from RESEARCH.md Pattern 1, already verified against the installed `@tauri-apps/api` package on disk — copy this directly rather than re-deriving):
```typescript
export const minimizeWindow = () => {
  if (isTauri()) {
    void getCurrentWindow().minimize() // Promise<void> — fire-and-forget matches
    return                              // makeListenerCaller's existing sync signature
  }
  const { ipcRenderer } = require('electron') as typeof import('electron')
  ipcRenderer.send('minimizeWindow')
}

export const isMaximized = () => {
  if (isTauri()) {
    return getCurrentWindow().isMaximized() // already Promise<boolean> — matches
  }
  const { ipcRenderer } = require('electron') as typeof import('electron')
  return ipcRenderer.invoke('isMaximized')
}

// setZoomFactor is the ONE exception — webview API, not window API (Pitfall 3):
export const setZoomFactor = (zoomFactor: string) => {
  if (isTauri()) {
    void getCurrentWebview().setZoom(parseFloat(zoomFactor))
    return
  }
  const { ipcRenderer } = require('electron') as typeof import('electron')
  ipcRenderer.send('setZoomFactor', zoomFactor)
}
```

**`isFullscreen` special case (Pitfall 1) — do NOT call `getCurrentWindow().isFullscreen()`:**
the Electron body (`main.ts:747`) is `isSteamDeckGameMode || isCLIFullscreen`, two Node-only env/CLI
signals with no Tauri renderer equivalent. `tauriAttach.ts` already hardcodes
`isSteamDeckGameMode = false` as a declared Phase 27 stub — follow that same declared-false
convention here (`Promise.resolve(false)` with a comment naming the gap), not a real window query.

**Error handling pattern:** none of the 10 exports need try/catch — the Tauri JS window methods
are `Promise`-returning and the existing generic `ipc.ts` factories they replace never wrapped
errors either. Preserve exported name + call signature exactly (Pitfall 5) so
`common/types/ipc.ts`'s `AsyncIPCFunctions`/`SyncIPCFunctions` contract keeps type-checking.

```typescript
export async function getCustomThemes(): Promise<string[]> {
  const { customThemesPath } = GlobalConfig.get().getSettings()
  if (!existsSync(customThemesPath)) {
    return []
  }
  return readdirSync(customThemesPath).filter((fileName) => fileName.endsWith('.css'))
}

// main.ts:1525-1535 (getThemeCSS)
export async function getThemeCSS(theme: string): Promise<string> {
  const { customThemesPath = '' } = GlobalConfig.get().getSettings()
  const cssPath = path.join(customThemesPath, theme)
  if (!existsSync(cssPath)) {
    return ''
  }
  return readFileSync(cssPath, 'utf-8')
}

// main.ts:1537-1539 (getCustomCSS)
export async function getCustomCSS(): Promise<string | undefined> {
  return GlobalConfig.get().getSettings().customCSS
}
```

```typescript
it('REQ-XX source gate: no file under src/backend/sidecar/ imports the real electron module', () => {
  const sidecarDir = join(__dirname, '..')
  const files = readdirSync(sidecarDir, { withFileTypes: true })
    .filter((entry) => entry.isFile() && entry.name.endsWith('.ts'))
    .map((entry) => entry.name)
  for (const file of files) {
    const stripped = stripComments(readFileSync(join(sidecarDir, file), 'utf-8'))
    expect(stripped).not.toMatch(/from\s+['"]electron['"]/)

})
```
