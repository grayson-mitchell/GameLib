<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| remote content → Tauri `main` window IPC | The store-search surface (and, from 34.4, the Humble login page) renders inside the `main` window. Tauri has no `<webview>` isolation boundary, so remote script inherits every capability granted to `main`. |
| renderer JS → Rust core commands | Every `core:window:*` / `core:webview:*` grant is a directly-invokable Rust command from any script running in `main`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-34.1-01 | Elevation of Privilege | `capabilities/default.json` `permissions` | mitigate | Grant exactly the twelve named commands; `core:window:default` / `core:webview:default` / `core:tray:default` are refused wholesale. Task 2's negative gate fails the build if any of them is added. |
| T-34.1-02 | Denial of Service | `core:window:allow-close` reachable by remote content in `main` | accept | Remote script in `main` can close the app window. Rationale: it can already do this via `window.close()` on its own document context and, more importantly, `main` is the app's own window — the user loses an unsaved-nothing session. The alternative (routing close through the sidecar) reintroduces the round-trip D-01 rejected. Re-evaluate in Phase 34.4 when a real remote login page ships. |
| T-34.1-03 | Tampering | Silent widening of the grant list in a later phase | mitigate | Task 2's exact-list + negative assertions plus the `description` rationale gate (`read-only getter set` substring) make a silent widening a red test rather than a quiet diff. |
| T-34.1-04 | Repudiation | The D-04 "verify `core:window:default` composition" mandate being satisfied from recollection | mitigate | The verified composition is recorded in the file's own `description` and pinned by Task 2 assertion 5, so the claim lives in the repo, not in a planning doc a reader may not have. |
| T-34.1-SC | Tampering | npm/pip/cargo installs | mitigate | Not applicable — this plan installs zero packages and changes no manifest. No `[ASSUMED]`/`[SUS]` package enters the tree. |
