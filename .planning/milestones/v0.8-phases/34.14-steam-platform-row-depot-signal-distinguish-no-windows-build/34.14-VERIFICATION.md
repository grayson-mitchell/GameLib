# Phase 34.14: Steam platform-row depot signal — distinguish "no Windows build" from "metadata not captured" Verification Report

**Phase Goal:** On macOS, the Steam "Install with options…" dialog stops silently withholding the
Windows/wine option from games that have a Windows build. The install-modal gating layer learns
the difference between "this game has no Windows depot" and "we have not fetched the depot signal
yet", and renders the second as a pending platform row rather than as a settled macOS-only
verdict.
