and put D-04's fail-open into one pure, testable function instead of a conditional buried in
the composition root.

captured input at all, so it cannot distinguish "never asked" from "asked and the answer is
no" — it collapses both into `readonly-macos`, which drops the Windows entry from the picker.

matrix proof expanded from 96 combinations / 8 rows to 144 / 10.
