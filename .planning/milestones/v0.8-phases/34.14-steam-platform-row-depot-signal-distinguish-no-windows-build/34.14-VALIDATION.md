### UAT forcing procedure (D-08 — verified executable)

The cold-cache window is **not reproducible on demand from a warm library**, so the gate
must force it:

1. Quit GameLib completely.
2. Edit `~/Library/Application Support/GameLib/store_cache/steam_metadata.json` and delete
   **one** appId key (targets a single game so the rest of the library stays warm; ships no
   test seam in product code). Electron and Tauri share this identical file.
3. Relaunch, open that game's **"Install with options…"**.

- **Run 1 — network UP:** expect pending row → resolves captured → Windows entry appears,
  Install enables.
- **Run 2 — network DOWN / `appdetails` blocked:** expect pending row → resolves
  uncaptured → **fail open, Windows offered anyway** (D-04).

**Note:** a single probe fires at open — **reconnecting mid-dialog does not re-probe.** Do
not author a gate step that assumes it does.

### Both runtimes

`installFormIpc.ts` is ONE shared handler body imported by both Electron (`main.ts:944`)
and the Tauri sidecar, deliberately so the two are "physically incapable of drifting."
Jest covers the shared body once. The manual gate should be exercised under **both**
runtimes, or the plan must state explicitly why one suffices.
