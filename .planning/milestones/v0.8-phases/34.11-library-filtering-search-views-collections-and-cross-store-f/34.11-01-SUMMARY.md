# Phase 34.11 Plan 01: Filter Engine Extraction Summary

**Extracted the Games library's inline filter pipeline into a pure, React-free `filterEngine.ts` module with opt-in store/runnability facets, an exclude-your-own-facet `countFor`, and 30 passing node-environment unit tests — zero behaviour change to the shipped `Library/index.tsx`.**

## Performance

- **Duration:** ~20 min
- **Tasks:** 3 completed
- **Files modified:** 3 (2 created, 1 modified)

## Accomplishments
- `filterEngine.ts` now holds the single implementation of every filter stage (view, collection, store, runnability, search, "more") as named pure functions callable without React, jsdom, or a DOM — satisfying `34.11-VALIDATION.md`'s Wave 0 prerequisite.
- `countFor` computes a facet option's count using `filterLibrary(..., { skip: kind })`, guaranteeing counts and the grid can never drift out of sync because they share one implementation (RESEARCH Anti-Patterns).
- Runnability tiers (`native` / `bottle` / `wontRun` / `notChecked`) are derived per-host with `CrossoverBadge`'s exact bucketing, correctly returning `null` (no row at all) on Windows and for any macOS game whose CrossOver rating was never looked up.
- The D-02 migration helpers (`migrateStoreFacetSelection`, `migrateRunnabilityFacetSelection`) discard every legacy `localStorage` shape — including a legacy all-`true` opt-out mask — rather than translating it into an equivalent opt-in selection, and never throw on malformed JSON.
- 30 unit tests pass under the existing `testEnvironment: 'node'` Frontend jest project, using the same direct-invocation idiom as `CrossoverBadge.test.tsx` (no `render()`, no DOM).

## Decisions Made
- Ported the runnability precedence exactly as spec'd: native build wins over rating (D-09), 32-bit mac build is always a bottle regardless of rating (D-11), medal tiers 5/4/3 collapse to `bottle` (D-10), and an app absent from the ratings map derives to `null` — distinct from `'notChecked'` (rating `null`, looked up with no data) — per the D-16 honesty invariant.
- Kept the Steam-delisted clause (`game.runner === 'steam' && game.is_delisted`) inside the non-available predicate, matching the shipped `Library/index.tsx:627-634` behaviour exactly rather than dropping it during extraction.
- `migrateStoreFacetSelection`/`migrateRunnabilityFacetSelection` take `rawLegacy` in their signature (matching the plan's required signature) but intentionally never read it for data — D-02 requires the legacy shape to be discarded, not inspected for a translatable value.

## Deviations from Plan

**1. [Rule 1 - Bug] Fixed a grep-matching false positive in the test file's own header comment**
- **Found during:** Task 3 verification (acceptance criteria check)
- **Issue:** The test file's docstring literally named `@testing-library/react` and `react-test-renderer` as libraries that are *not* used, which made the acceptance-criteria grep (`testing-library|react-test-renderer|enzyme`) match 2 lines instead of the required 0 — a false positive on prose, not on an actual import.
- **Fix:** Reworded the comment to describe the constraint without naming the package strings verbatim.
- **Files modified:** `src/frontend/screens/Library/__tests__/filterEngine.test.ts`
- **Verification:** `grep -cE "testing-library|react-test-renderer|enzyme" ...` now returns 0; test suite still passes.
- **Committed in:** `2d6bbabae` (Task 3 commit — the file was not yet committed when this was caught)

**2. [Rule 1 - Bug] Fixed a TypeScript tuple-type mismatch in the runnability `it.each` table**
- **Found during:** Task 3 verification (`npx tsc --noEmit` step)
- **Issue:** The `it.each` tuple was typed as `[boolean, string | null, ...]` but one fixture row legitimately needed `mac_arch: undefined` (no Steam `osarch` tag resolved yet) — `undefined` is not assignable to `string | null`, and jest's `it.each` overload resolution failed with `TS2769`.
- **Fix:** Retyped the tuple's second element as `GameInfo['mac_arch']` (`'32' | '64' | 'unknown' | undefined`), matching the real field's type instead of a narrower ad hoc one.
- **Files modified:** `src/frontend/screens/Library/__tests__/filterEngine.test.ts`
- **Verification:** `npx tsc --noEmit -p tsconfig.json` exits 0; the affected test (`is_mac_native=true` precedence case) still passes.
- **Committed in:** `2d6bbabae` (Task 3 commit — the file was not yet committed when this was caught)
