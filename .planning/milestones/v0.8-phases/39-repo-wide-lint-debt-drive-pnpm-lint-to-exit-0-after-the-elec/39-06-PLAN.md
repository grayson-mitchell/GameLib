<the_six_uses_of_one_local>
`watchForLogin()` declares `const seam = getLoginWindowSeam()` once (was `user.ts:274`) and a
sibling `seamLabel` local (was `:296`). SIX predicate uses read those two locals. RESEARCH.md's
census lists five of them; PATTERNS.md found the sixth and it is real. All six collapse together
because they share one declaration:

1. Was `:274-284` — the declaration itself, plus
   `let ses: ReturnType<typeof session.fromPartition> | null = null` and the
   `if (seam === null) { ses = session.fromPartition(HUMBLE_LOGIN_PARTITION) ... setUserAgent }` setup.
2. Was `:440-462`, nested `checkCookie()` — `if (seam === null) { const cookies = await ses!.cookies.get(...) } else { ... }`. The `else` arm (marked `// ── Tauri seam path ──`) survives. Note the `ses!` non-null assertion in the dead arm — it exists only because `ses` was conditionally assigned.
3. Was `:429`, nested `settle()` — `if (seam !== null && seamLabel !== null) { const labelToClose = seamLabel; seam.close(labelToClose).catch(...) }`. **This is the site RESEARCH.md's 12-site census missed.** It is an always-true guard with no Electron sibling (the Electron path closed no window here at all). Collapsing the declaration resolves it, but you must still remove the now-meaningless guard rather than leave a permanently-true `if`.
4. Was `:590` — the ternary `seam !== null ? seamLabel : null` in the notify call. Collapses to `seamLabel`.
5. Was `:640-674` — `if (seam !== null) { seam.open(HUMBLE_LOGIN_URL, {...}) ... }`, an always-true guard with no Electron sibling. Collapses by removing the wrapper and its closing brace (the block ends at 674, after the `.catch()` handler — RESEARCH.md's "640-673" is one line short), keeping the body unconditional.
6. Was `:740-762`, inside `finishLogin()` — this one declares its OWN `seam` local, so strictly it is a seventh declaration rather than a sixth use of `watchForLogin`'s. `if (seam !== null && seamLabel !== null) { ... } else { const csrfSes = session.fromPartition(HUMBLE_LOGIN_PARTITION) ... }`. The `else` arm is dead. It is grouped here because it is the last `session.fromPartition` consumer and the import cannot be dropped until it goes.

The doc comment immediately above the declaration (was `:266-273`) explicitly frames the dual build
("under Electron, `getLoginWindowSeam()` ... always returns null") and must be rewritten or deleted
with the code.
</the_six_uses_of_one_local>
