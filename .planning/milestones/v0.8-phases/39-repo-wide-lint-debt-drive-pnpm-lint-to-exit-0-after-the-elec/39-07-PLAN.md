<the_analog_to_copy>
`meta/__tests__/isTauriRemoved.test.ts` (84 lines, read it in full). Three parts of its shape are
load-bearing and must be replicated, not paraphrased:

1. The zero-match assertion is a CONJUNCTION, not an exit-code check:
```typescript
if (result.status !== 1 || result.stdout.trim() !== '') {
  throw new Error(`... expected zero matches, got:\n${result.stdout}`)
}
expect(result.status).toBe(1)
expect(result.stdout.trim()).toBe('')
```
Status alone is also satisfied by grep failing to run at all (binary not found, status 127
truncated on some shells). Empty stdout alone is satisfied by a mis-typed path grep silently walks
and finds nothing in for the wrong reason. Only the conjunction proves grep ran, walked a real
tree, and found none.

2. The failure message echoes grep's stdout back, so a red run names every offending `file:line`
rather than reporting a count.

3. The vacuity control is a separate `it` asserting a token that MUST survive is found under the
same root, with `status === 0` and non-empty stdout.

Its own header also records the un-anchored-form lesson (lines 17-23): `grep "isTauri("` anchored
to the call parenthesis undercounted by 39 references. The same lesson applies here — an anchored
`getLoginWindowSeam() === null` would miss every `const seam = getLoginWindowSeam()` /
`if (seam === null)` pair, which is how this codebase actually writes them.
</the_analog_to_copy>

<the_predicate_family>
Key the search on the predicate, not on a token. Cover at minimum:
- `seam === null`, `seam !== null`, `seam == null`, `seam != null` (loose forms included — the
  research searched for them and found none, but a gate that cannot catch a form is not a gate);
- `!seam` and `!activeSeam`-style negations of any identifier ending in `seam`/`Seam`;
- ternary and optional-chaining forms: an identifier ending in `seam`/`Seam` followed by `?`,
  excluding the optional-parameter form `seam?:` which is a type position, not a predicate;
- the direct-call forms `getLoginWindowSeam() === null` / `!== null`.

Match case-insensitively on the leading character so `activeSeam`, `loginSeam` and `Seam` are all
covered. Either one `grep -rnE` with an alternation, or one `spawnSync` per form with the results
unioned before a single zero-match assertion — the analog's per-`it` structure makes the second
easier to debug when it goes red.
</the_predicate_family>
