## Sampling Rate

- **After every task commit:** Run `npx jest --config meta/jest.config.js <relevant test file>`
- **After every plan wave:** Run `pnpm test:ci`
- **Before `/gsd-verify-work`:** Full suite green **plus** a hand-reviewed `pnpm i18n` dry run
  (filesystem side effects make this one check not purely automatable — see Manual-Only below)
- **Max feedback latency:** ~10 seconds for the per-task quick run

## Manual-Only Verifications

| Behavior | Why Manual | Test Instructions |
|----------|------------|-------------------|
| `pnpm i18n` produces only `gamelib.json` changes | The parser mutates the filesystem; running it inside a unit test would leave the working tree dirty and race concurrent sessions | Run `pnpm i18n`, then `git diff --stat public/locales/` and confirm every changed path ends in `gamelib.json`. Revert afterwards. |
| `gamelib` namespace resolves under the Tauri sidecar | `publicDir`/`getAppPath` differ under the sidecar (documented 4× recurrence in this project); only a real launch proves the fetch path | Launch the Tauri build, open a screen using `t('gamelib:…')`, confirm the string renders translated (not the raw key) and that no 404 for `gamelib.json` appears in the console/log. |
| `gamelib` namespace resolves under Electron | Same fetch-path risk on the other runtime | Launch the Electron build, same check. |
| Machine-fill proven on 1–2 locales (D-08) | Requires a live translation backend call; not hermetic | Run the script for one locale, inspect the produced `gamelib.json` + `gamelib.mt.json` by hand for interpolation/plural preservation. |
