    Extend `meta/hardcodedStringGate.ts` at the `// plan 04` hook. All three exemptions run
    BEFORE a candidate becomes a `Violation`, and each one that fires increments
    `ScanResult.exempted`.

    **Pattern 1 — t-alias detection.** Export `collectTAliases(sourceFile)`. Walk every
    `SyntaxKind.VariableDeclaration`; when its name node is an `ObjectBindingPattern`, inspect
    each `BindingElement` — take `getPropertyNameNode()?.getText()` falling back to `getName()`;
    when that resolves to `t`, add the element's own `getName()` to the alias set. Seed the set
    with the bare name `t` so `const { t } = useTranslation()` and a `TFunction` parameter named
    `t` both work. Also add any parameter whose declared type text contains `TFunction` — this
    is what makes `repairFailure.ts`'s injected-`TFunction` idiom (and plan 07's retrofit of
    `copy.ts` to the same shape) recognisable. Then: any string literal that appears as an
    argument to a `CallExpression` whose callee identifier is in the alias set is exempt. Do NOT
    inspect which namespace the key targets — D-13 is explicit that any `t()` call passes and
    the gate does not enforce namespace choice.

    **Pattern 2 — `[key, defaultText]` tuple exemption.** Exempt both string elements of any
    `ArrayLiteralExpression` with exactly two elements, both string literals, where element 0's
    text matches the dotted-key shape `/^[a-zA-Z][a-zA-Z0-9]*(\.[a-zA-Z][a-zA-Z0-9_]*)+$/`
    (at least one `.`, matching the configured `keySeparator: '.'`). This is structural, not
    dataflow: the literal and its `t()` consumption are at different source locations, so no
    per-call-site check can see the link. Add a comment recording the accepted tradeoff from
    RESEARCH.md Assumption A1 — the exemption is deliberately narrow, and a developer wrapping
    two unrelated strings in a fake key-shaped tuple to dodge the gate is visible in review.

    **Pattern 3 — single-scope dataflow fallback exemption.** For a string literal that is the
    initialiser of a `VariableDeclaration` (or the right-hand side of an assignment) to a local
    binding, use ts-morph's `findReferencesAsNodes()` on that binding. If ANY reference within
    the same source file is an argument to a call whose callee is in the t-alias set, exempt the
    literal. Bound the search to the same source file — no cross-file dataflow. This is what
    keeps `repairFailure.ts`'s `let message = 'Repair failed. See the log for details.'` (later
    `message = t('box.repair.error', message)` inside a try/catch) out of the violation list.

    Order matters: run alias collection once per source file before literal classification, and
    evaluate exemptions cheapest-first (glossary, then tuple, then t-call argument, then
    dataflow) so the reference search only runs on literals nothing else has cleared.
  </action>
