(D-02 + D-21) as a machine-readable artifact — the two prerequisites everything else in this
phase stands on.

— dynamic key construction and aliased `t`. Any later task that runs the parser before this
flip lands destroys fork data. Separately, the gate built in plans 03–05 needs the glossary to
exist before it can exempt brand and platform names.

Output: `keepRemoved: true` plus an assertion test that pins it; `meta/i18nGlossary.json` plus
a test that pins its contents.
</objective>

literal when its **trimmed text is an exact, case-sensitive member of `terms`**. Substring

even though `"Steam"` is a glossary term.
