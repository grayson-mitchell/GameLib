## Why this check exists

A missing `gamelib.json` at runtime is **invisible in English**: every string falls back to
its inline `t()` default and the UI looks correct. Only a non-English session can distinguish
"namespace loaded" from "namespace missing".

### Tauri HTTP status — NOT OBSERVED, and why that does not weaken the verdict

The developer could not surface `gamelib.json` in Tauri's DevTools Network panel. Two
contributing causes, neither of which is a load failure:

1. DevTools records only requests issued while it is open. i18next fetches a namespace
   **once**, lazily, at first use. The Tauri session inherited `de` from persisted config and
   so fetched `de/gamelib.json` at boot, before DevTools was opened.
2. Subsequent language switches did not produce visible Network entries either. Tauri's
   WKWebView DevTools is a known-unreliable instrument in this project — see also
   "Tauri DevTools console cannot be pasted into".

**The rendered string is stronger evidence than the status code would have been**, and it was
observed directly:

- `grep -rl "Anfängliche Wiederholverzögerung" src/ build/` matches **no source file and no
  bundle chunk**. The literal exists in exactly two places on disk:
  `public/locales/de/gamelib.json` and `build/locales/de/gamelib.json`.
- The call site's inline default is the English `'Gamepad input initial repeat delay'`.
- Therefore German text in the UI can only mean the runtime **fetched and parsed**
  `build/locales/de/gamelib.json`. An HTTP 200 alone would not have proven this — a 200
  serving malformed JSON still renders the English default.

### Build-copy half (automated, not human-observed)

`npx electron-vite build` was run and the copy verified independently of the UI check:

| Catalog | `public/` → `build/` |

| `en/gamelib.json` | sha256 MATCH |
| `de/gamelib.json` | sha256 MATCH |
| `fr/gamelib.json` | sha256 MATCH |

`electron.vite.config.ts` declares no `publicDir` override (its only `publicDir`-adjacent code
is `preserveRunnerSymlinksPlugin`, which restores symlinks *after* the copy);
`src-tauri/tauri.conf.json` sets `frontendDist: "../build"`. Both shells serve the same tree.
The `publicDir` / `getAppPath` divergence that has bitten this project four times is therefore
retired for the copy step; only the fetch path needed a human, and it passed.
