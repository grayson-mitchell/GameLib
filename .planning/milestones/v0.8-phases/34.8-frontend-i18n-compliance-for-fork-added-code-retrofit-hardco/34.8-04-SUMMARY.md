# Phase 34.8 Plan 04: D-14 Exemption Engine Summary

**Taught the ts-morph hardcoded-string gate the four idioms this codebase's own established i18n patterns require — aliased `t`/`t2`/`tr` calls, `[key, defaultText]` tuple tables, `repairFailure.ts`'s assign-then-`t()`-reassign fallback, and a leading-comment full-file exemption — each proven zero-violation from fixtures copied verbatim out of the real files, each paired with a negative case proving the exemption is narrow.**

## Accomplishments

- `collectTAliases()` resolves the full `t` alias inventory in a source file (bare `t`, `t2`, `tr`, and any future rename) by walking every `ObjectBindingPattern` regardless of whether its parent is a `VariableDeclaration` or a destructured function `Parameter` — the latter generalization is what makes `repairFailure.ts`'s `{ t }: ReportRepairFailureOptions` idiom resolve
- Implemented and wired three D-14 exemption checks into `scanSource`'s candidate pipeline in cheapest-first order (glossary → tuple → t-call-argument → dataflow → technical-token), so the one expensive `findReferencesAsNodes()` call only ever runs on literals nothing cheaper already cleared
- Implemented the full-file `i18n-gate-exempt:` leading-comment marker, requiring an explanatory reason on the same line — a bare marker with no reason does NOT exempt the file (proven by a dedicated negative test)
- Proved all four D-14 idioms tolerated using fixtures lifted verbatim from `CrossoverBadge.tsx`, `LibraryFilters/index.tsx`, `Humble/Keys/stateLabels.ts`, and `GameSubMenu/repairFailure.ts` — 13 new tests, all four paired with a negative counterpart proving the exemption is narrow, not a blanket hole
- Manually verified the tuple-exemption branch is load-bearing: temporarily neutered it with `if (false && isKeyDefaultTupleElement(node))`, re-ran the suite (3/4 tests in the `[key, default] tuple tables` block failed as expected, reporting real violations for every tuple site), then restored the file and confirmed a byte-identical diff against the pre-edit copy before re-running green
- Full `pnpm test:ci`: 199 suites / 3911 tests, all green (baseline was 199/3898 — this plan added exactly 13 tests, no regression)
