<objective>
Run the blocking manual verification that the automated layers structurally cannot perform.

Purpose, stated plainly so nobody treats this plan as ceremony: the frontend jest project is
`testEnvironment: 'node'` with no jsdom and no browser-automation harness anywhere in the
repo. Plans 01-06 prove that the right STRING is on the right ELEMENT'S PROPS, and that no
value is duplicated. They cannot prove that a CSS selector resolves against the live DOM, that
MUI actually forwards `data-*` from `Tab` through `NavLink` to the rendered `<a>` (RESEARCH.md
rates that claim A1 at MEDIUM confidence for exactly this reason), or that intro.js highlights
the box a user sees. A step whose selector matches nothing is silently skipped — which is
precisely the defect this phase exists to fix, and it would sail through every green suite.

Output: eighteen recorded outcomes — twelve step-by-step, six behavioural — in the SUMMARY.

highlighted". This project has been bitten repeatedly by audits coarser than the defect's
unit; a per-tour verdict cannot distinguish twelve correct highlights from eleven correct
plus one silent skip.
