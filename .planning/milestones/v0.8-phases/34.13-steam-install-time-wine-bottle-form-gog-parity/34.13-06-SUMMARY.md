## The `forceWindowsViaBottle` Expression, As Shipped (verbatim, for 34.13-08/34.13-12)

```ts
const overrideRequested = args.steamForceWindowsViaBottle === true

const forceWindowsViaBottle =
  overrideRequested &&
  isMac &&
  steamMetadataStore.get(this.appId)?.is_windows_native === true

if (overrideRequested && !forceWindowsViaBottle) {
  logWarning(
    `SteamGame: appId ${this.appId} requested a Windows-via-bottle install override but it was rejected (isMac=${isMac}) — falling through to legacy routing`,
    LogPrefix.Steam
  )
}

const routeThroughBottle = forceWindowsViaBottle || this.isBottleEligible()

if (routeThroughBottle) {
  // ...unchanged bridge / not-ready / bottle-native / bottled-dispatch body...
}
```

Note: `overrideRequested` is an internal helper const, not named in the original plan's "two consts" description — introduced so `args.steamForceWindowsViaBottle` appears on exactly one line in the whole file, satisfying the plan's own `grep -c "steamForceWindowsViaBottle"` → `1` gate while still allowing the rejection-logging branch to reuse the boolean without re-reading the raw field.
