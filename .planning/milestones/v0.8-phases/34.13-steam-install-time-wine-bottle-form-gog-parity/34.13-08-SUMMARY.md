## Gamepad-Caret Decision

**Mechanism:** document order is the entire reachability mechanism on both runtimes. Electron simulates real Tab/arrow keypresses (`gamepad.ts:236-239`), so the browser's native tab order governs. Tauri reimplements it by walking `FOCUSABLE_SELECTOR` via `document.querySelectorAll` (`tauriGamepadInput.ts:27-62`) — also document order, filtering `disabled`/`aria-hidden`/zero-area. The caret is placed immediately after the primary Install button inside the existing `.installButtons` span (proven by spec S5).

**Two hazards controlled:**
1. **Zero-area drop, Tauri-only.** `Dropdown`'s `buttonClass="button mainBtn outline"` inherits `.mainBtn { min-width: 200px }`, keeping the caret's box non-zero on both axes — a CSS comment in `GamePage/index.css` records that narrowing this class is a UI-SPEC amendment, not something to do casually.
2. **No `disabled` prop, so unmount not disable.** `Dropdown`'s `Props` type has no interaction-blocking attribute; the caret is gated `gameInfo.runner === 'steam' && !is_installed && !is.queued && !disabledInstallButtons` and fully unmounts (proven by spec S4, which asserts zero `Dropdown` nodes when `settingUpBottle` is true, and separately asserts no `disabled` prop is ever passed to `Dropdown`).

**One hazard recorded, not fixed:** `Dropdown`'s collapsed panel uses `max-height: 0` / `overflow: hidden` / `opacity: 0`, never `display: none` or `aria-hidden` — so the single "Install with options…" panel button stays in both runtimes' focus rings even while visually collapsed. This is pre-existing, app-wide `Dropdown` behavior (every existing consumer already has it) and is out of scope for this plan. Handed to 34.13-13's manual gate as an observation row (see the plan's own `<verification>` section, "The collapsed-panel focus stop").

## Caret Width Consequence

`buttonClass="button mainBtn outline"` inherits `.mainBtn`'s `min-width: 200px` — the caret renders at the same 200px width the (Steam-hidden) Import button used to occupy, containing only a chevron. Flagged to 34.13-13's manual gate for a visual judgment call; narrowing it is a UI-SPEC amendment, not something this plan changes.
