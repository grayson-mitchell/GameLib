## Methodology retained in the ledger

`34.13-UAT.md` deliberately keeps its methodology sections after closure. They are not gate
bookkeeping — each was paid for with a wrong or void attempt. The two that generalise beyond this
phase:

- **A stale stated precondition cost three attempts.** `G-D25-INDIALOG` says "cold cache (delete
  `steam_metadata.json`, relaunch)". That arms nothing: the probe short-circuits on
  `steamPlatformsCaptured`, which lives in `steam_library.json`, and the metadata file refills itself
  0 → 224 entries within ~6s of Frontend Ready. Arming it requires the fetch to **hang**, not fail.
- **`127.0.0.1` does not blackhole a host** — it REFUSES in ~1 ms, so the fetch fails instantly and
  the timeout path never runs. `198.51.100.1` (TEST-NET-2) is unrouted, so connect hangs. Verify with
  `curl --max-time 8`: exit 28 (timeout) = armed; exit 7 (refused) = not armed.
