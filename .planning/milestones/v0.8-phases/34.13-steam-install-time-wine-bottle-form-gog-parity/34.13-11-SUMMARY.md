## Both Falsified Briefs (findings for the phase record)

**1. UI-SPEC D-25 Busy State Contract: "the library dropdown / free-space line ... can render immediately alongside the loading row ... they depend only on `nativeInstallOn`/`libraryCount`, both known synchronously." FALSE.**
34.13-05's shipped formula is `libraryDropdown = !wineSection && nativeInstallOn && libraryCount > 1`, and `wineSection` depends entirely on the pending `bottleRequired`. Following the UI-SPEC literally would render a dropdown that VANISHES the instant eligibility resolves true on a macOS host with native install ON and 2+ libraries — worse than the flicker-free snap D-25 asks for. **Resolution (implemented):** `applyEligibilityPending` suppresses `libraryDropdown` and `freeSpaceLine` alongside `wineSection` while pending; `platformRow` is preserved untouched because it is genuinely synchronous (D-03/D-17/D-19), keeping the dialog from looking empty on open (the D-20 corner). This is a correction of the UI-SPEC's factually-wrong premise, not a decision reversal — an amendment is owed to `34.13-UI-SPEC.md`.

**2. 34.13-10's own truth "the footer Install button carries no `disabled` attribute at all, in any render state" is a casualty of the same inversion.**
True under the retired D-12 model, and 34.13-10 said so in its own words ("the spinner belongs on the origin control (34.13-11), never on this footer button"). D-25 inverts the premise. **Resolution:** 34.13-10 had ALREADY pre-emptively narrowed its own shipped gate (no blanket absence assertion exists in the committed `steamDialogSource.test.ts` — only a positive D-06 SIZE-gate test), so this plan did not need to rewrite an existing spec in place. This plan ADDS the D-25 positive assertion (`disabled=` exactly once, `disabled={eligibilityPending}`) as a new describe block, with a comment recording the inversion and the CONTEXT.md line reference. This is a PLANNED narrowing, explicitly flagged so a verifier does not score it as a regression against 34.13-10's `must_haves`.

## The D-25 Inversion (in this SUMMARY's own words)

2. **The zero-count on the install chokepoint**: `grep -c 'isSteamBottleEligible' src/frontend/state/InstallGameModal.ts` → `0`.
3. **The recursive `src/frontend` census** (Group A3, `steamEligibilityWiring.test.ts`) — every file whose comment-stripped source contains the literal string `isSteamBottleEligible` must be on this explicit allowlist:
