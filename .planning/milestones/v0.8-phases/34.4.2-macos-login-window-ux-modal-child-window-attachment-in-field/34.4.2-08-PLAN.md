<objective>
Give the presented login sheet the explicit close affordance the operator's binding decision of
2026-08-04 mandates, via TWO independent routes, and wire both to the existing cancelled-login
resolution.

Purpose: a sheet blocks its parent window and renders no titlebar close button — spike 021's
operator "could not dismiss it at all". Plan 34.4.2-07 shipped the presentation switch without an
affordance, which is a hard lock-out (T-34.4.2-33). This plan closes it. Two routes exist because
one of them depends on the login page rendering at all: an injected strip is invisible on a blank
page, a network error page, or a bot-management interstitial — exactly the states a login window
reaches most often when something is already wrong. The Esc route is page-independent by
construction.

**No live gate may run before this plan lands.**

Output: a visible cancel strip, an Esc backstop, one shared dismissal entry point, and source
assertions pinning every property that makes the pair safe.
</objective>

    Install ONE process-wide `NSEvent` local key-down monitor in `main()`'s `.setup()`, at the site
    plan 07's Task 2 retired the deminiaturize observer from, `#[cfg(target_os = "macos")]`.

    Use `objc2_app_kit::NSEvent::addLocalMonitorForEventsMatchingMask_handler` with
    `objc2_app_kit::NSEventMask::KeyDown` and a `block2` handler, following the idiom already in this
    file (read from the pristine arm, reimplemented here — do not refactor the pristine one into a
    shared helper; that would edit a byte-frozen region). Leak the returned monitor for the process

    monitor registered once in `.setup()`, not a per-open monitor that must be torn down.

    Handler logic, in this exact order so the common case costs almost nothing:
    1. Read `PRESENTED_LOGIN_SHEETS`. If the list is empty or the lock is poisoned, return the event
       unchanged immediately — no window resolution, no AppKit calls.
    2. Read the event's `keyCode`. If it is not 53 (Esc), return the event unchanged.
    3. Read the event's modifier flags. If Command, Option, or Control is set, return the event
       unchanged — only a bare Esc dismisses.
    4. Resolve the event's own window pointer and compare it against `login_window_ns_window(app,
       label)` for each label currently in the registry. On no match, return the event unchanged.
    5. On match: call `request_login_sheet_cancel(app, matched_label, "esc")` and return `None` to
       consume the event so the page never also sees it.

    Privacy is a hard constraint, not a style preference: the handler MUST NOT call `characters`,
    `charactersIgnoringModifiers`, or any other accessor that yields typed text, and MUST NOT log the
    event or any field derived from it. This monitor sees every keystroke the app receives, including
    the password being typed into the login sheet (T-34.4.2-35). The only line it may emit is the one
    `request_login_sheet_cancel` already logs.

    Epic non-interference is structural, not conditional: the pristine Epic login window is never
    registered in `PRESENTED_LOGIN_SHEETS` (plan 07 registers only `present_login_window_as_sheet`
