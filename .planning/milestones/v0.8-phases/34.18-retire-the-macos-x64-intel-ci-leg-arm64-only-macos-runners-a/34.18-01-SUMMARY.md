# Phase 34.18 Plan 01: README Intel-Mac disclosure + x64 non-goal survivor gate Summary

Landed the ROADMAP's named non-negotiable — the verbatim user-facing sentence that GameLib will
not support Intel Macs — and a mutation-proven survivor gate that bounds every later `x64` sweep
in this phase from the over-reach direction, before any of those sweeps run.

## What Was Built

**Task 1 — `meta/__tests__/readmeDisclosure.test.ts` (D-02/D-03 gate), RED-proven before the fix.**
Reads the repo-root `README.md` and asserts (a) the exact literal
`GameLib will not support Intel Macs on macOS` is present, and (b) no rationale token
(`macos-13`, `Fall 2027`, `F-34.16-G`) ever appears in the file. Run against HEAD before Task 2's
edit landed — see RED evidence below.

**Task 2 — `README.md` amended.** Line 82's `- macOS 14 or newer` became:

```
- macOS 14 or newer (Apple Silicon only). GameLib will not support Intel Macs on macOS.
```

No other line of `README.md` changed. `git diff --stat README.md` for this task: 1 file,
1 insertion, 1 deletion. Rationale (GitHub's `macos-13` retirement 2025-12-04, three failed
runner-assignment attempts per `F-34.16-G`, and GitHub's Fall 2027 x86_64 macOS EOL) is recorded
only in the commit body, per D-03.

**Task 3 — `meta/__tests__/x64NonGoalSurvivor.test.ts` (D-07/D-08 gate), mutation-proven.**
Pins the three explicit non-goal `x64` categories so that a later plan's macOS-arch sweep cannot
silently erode them:
1. `electron-builder.yml` — 7 total `build/bin/x64/win32/` refs, with an additional assertion
   that the `mac:` files block (sliced from the `mac:` key to the `dmg:` key) specifically still
   contains both `GalaxyCommunication.exe` and `EpicGamesLauncher.exe` under that path — the
   macOS package legitimately bundles win32 x64 GOG Galaxy / Epic helpers.
2. `meta/downloadHelperBinaries.ts` — all six linux/windows download-key literals asserted
   individually (not by regex count, which would also match the darwin keys this phase removes
   and the unrelated `comet-*` keys).
3. `src/backend/utils.ts` — the `x64Path` box64 runtime fallback for Linux ARM (identifier plus
   the `join(publicDir, 'bin', 'x64', process.platform` expression).
