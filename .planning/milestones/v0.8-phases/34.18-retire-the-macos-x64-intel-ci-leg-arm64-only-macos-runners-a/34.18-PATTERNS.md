**Source:** `.planning/phases/34.16-.../34.16-06-PLAN.md:244-286` (Task 3 — a full, real, executed

```xml
<task type="checkpoint:human-verify" gate="blocking">
  <name>Task N: HUMAN GATE — dispatch arm64 workflow, pin real digests (D-05)</name>
  <read_first>[cite the normative doc(s) the developer must follow, by section number]</read_first>
  <files>meta/runnersOnedirDigests.json, .github/workflows/build-runners-onedir-macos.yml</files>
  <action>Hand the developer the exact remote gestures (workflow dispatch on the default branch,
    then `pnpm pin:runner-digests`) as written, cited by number, and STOP. Do not paraphrase.
    After the developer reports back, record their observations and commit the pinned digests.</action>
  <what-built>
    [state what code-complete work this unblocks — e.g. "all six non-arm64 CI/build consumers are
    retired; three PENDING-CI-PUBLISH sentinels remain, blocking `pnpm download-helper-binaries`
    on darwin"]
  </what-built>
  <how-to-verify>

    independently re-deriving at least one digest locally via `shasum -a 256` rather than trusting

  </how-to-verify>
  <acceptance_criteria>
    - All three remaining digest slots are 64-char lowercase hex, `runId` is non-null.
    - `pnpm download-helper-binaries` exits 0 on darwin with no sentinel throw.
    - [any other concrete, checkable criteria]
  </acceptance_criteria>

    criterion failed.</resume-signal>
  <verify>
    <automated>[a python3/node one-liner asserting the JSON shape, mirroring 34.16-06's own
```

**Critical idiom details, verbatim from the analog — do not drop these:**
- `<action>` explicitly says "cite it, never paraphrase it" — the developer-facing gate text must

  this project's convention is to name the shortcut a rushed human would take and forbid it in
  writing, not merely list the correct steps.
- Never instructs `git checkout -- <path>` for restoring a bad edit (fires
  `.husky/post-checkout` → `download-helper-binaries` → throws on sentinel). Restore by `cp` +
  `shasum` per standing project practice.

```typescript
/**
```
