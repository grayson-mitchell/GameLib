<objective>
Remove `isIntelMac` from the codebase entirely — constant, both IPC registrations, type, preload,
frontend mirror and every comment — collapsing all eight branches it gates, while the Apple-Silicon
surfaces a keyword sweep would also reach survive and the safety proof written against it outlives

`false` in every shipped build; keeping it means the code claims a capability we do not ship.

atomically. A staged landing — backend handler removed, frontend call site still present — fails
SILENTLY under the sidecar (traced mechanism in the truths above), so a wave boundary in the middle
of this removal is exactly the failure mode the gate exists to catch. The plan is the landing unit.

Output: zero `isIntelMac` matches under `src/`, eight collapsed branches, an intact `isAppleSiliconMac`
gate, and a rewritten RED-proof that still catches the empty-CPU-model false positive.
</objective>
