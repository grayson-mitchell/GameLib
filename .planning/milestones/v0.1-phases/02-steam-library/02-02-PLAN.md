<objective>
Implement the Steam library backend sync: `SteamLibraryManager.refresh()` fetches owned games + playtime via `getUserOwnedApps()`, merges install state parsed from local ACF manifests, pushes each game to the frontend, and persists the list + sync timestamp. `init()` serves cache first then background-syncs. This is the vertical slice that makes a real Steam library available to the app (LIB-01, LIB-02, LIB-03).

Purpose: This is the data engine for the whole phase. Without it the library is empty.
Output: New `state.ts` (shared Map), implemented `library.ts`, and real assertions in `library.test.ts` (converted from the Wave 0 todos).
</objective>
