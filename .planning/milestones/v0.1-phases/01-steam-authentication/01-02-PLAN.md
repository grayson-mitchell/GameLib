<objective>
Build the main-process Steam auth core: the `SteamUser` static class (client detection, QR flow, credential + SteamGuard flow, encrypted token storage, login-state lifecycle), its electron-store, its IPC handlers in `main.ts`, and the preload bridge that exposes them to the renderer. This is the Walking Skeleton's "one real backend call" layer (`checkSteamInstalled`) plus the full auth machinery the UI slice will drive.

Purpose: Concentrate all `steam-session`/`steam-user` usage in the main process behind a tested static class, satisfying the architectural rule that these libraries never run in the renderer.
Output: A unit-tested `SteamUser`, a `steamConfigStore`, 7 registered IPC handlers, and `window.api.steam*` bridge methods.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer → main (IPC) | Untrusted username/password/code/payloads cross here into main-process handlers |
| main → Steam CM network | steam-session/steam-user open TCP/WebSocket to Steam servers |
| main → disk (steam_store) | Refresh token persisted to electron-store on disk |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-DISC-TOKEN | Information Disclosure | refresh token at rest in steam_store | mitigate | encryptToken via safeStorage.encryptString + `steam:v1:` prefix; plaintext only as logged fallback when isEncryptionAvailable() is false (secureKey.ts pattern) |
| T-01-DISC-PWD | Information Disclosure | password persistence | mitigate | Never call configStore.set with password/credentials; store only the refresh token (unit-test asserts absence). Steam ToS compliance |
| T-01-EOP | Elevation of Privilege | steam-user/steam-session in renderer | mitigate | Imports live only in src/backend/; renderer access exclusively through window.api.steam* preload bridge |
| T-01-SPOOF-TOTP | Spoofing | SteamGuard/TOTP retry loop (error 84 IP ban) | mitigate | submitSteamGuardCode returns {status:'error'} and never auto-retries with the same code; the wait is enforced in the UI (plan 03) |
| T-01-TAMPER | Tampering | malformed IPC payloads | mitigate | Handlers receive primitives only; no HTML rendering of input in the backend |
</threat_model>
