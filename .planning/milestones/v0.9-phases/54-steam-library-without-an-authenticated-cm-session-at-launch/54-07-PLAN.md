<objective>
The guided Go Offline fallback (ROADMAP: "If the LogOff is not seen, fall back to a guided 'Go
Offline' step and never log on silently"). The user chose --skip-ui, so the design is the existing
backend-pushed `SteamBridgeRouteNotice` chain copied link for link (PATTERNS "Guided Go Offline
frontend step"): IPC type (plan 01) -> preload slot -> zustand store with a standalone signal
handler -> GlobalState registration -> App mount -> dialog. Plus one new invoke for Continue.

Continue does not log on by itself. It asks the backend (`checkGuidedOfflineReady`, plan 01)
whether Mac Steam now reads `Logged Off`; only then does the renderer re-run the blocked action,
which goes back through `acquireAuthenticated` and the wrap. Because the guided flag is armed, the
wrap sets Steam back online after the logon (plan 01 decision).

Strings come from plan 02 (`steam.goOffline.*`, `steam.bridge.routeNotice.cancel`,
`steam.bridge.routeNotice.notFound`); every `t()` carries the English `defaultValue` inline as the
analog does.
</objective>
