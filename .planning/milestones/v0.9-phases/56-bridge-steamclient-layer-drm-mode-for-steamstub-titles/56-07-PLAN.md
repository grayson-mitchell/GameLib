Build `drm/valveClient.ts`, the Valve client step of DRM mode. It reads Valve's current
`steam_client_win64` manifest, selects only its `bins_win64` node, downloads that package from an
allowlisted Valve CDN base over https, checks a streamed sha256 against the manifest's own `sha2`,

`<appFolder>/steam-bridge/drm/valve-client/<manifest-version>/`. That cache is reused with no
network on every later launch.

`SteamClientDll64` slot (spikes 041/044). D-04 forbids pinning the package, D-05 makes the fetch
lazy and cached, and D-06 fixes the file set. 56-09 stages these files into the bottle, and 56-11
runs this step after the runner step with the `Steam client files` progress context.
