# Phase 56 Plan 07: Valve client step Summary

`ensureValveClient` downloads Valve's current `bins_win64` package (chosen from the live `steam_client_win64` manifest, verified against its own `sha2`, no pinned sha), extracts exactly the three D-06 DLLs with `/usr/bin/unzip` under a fake HOME, and caches them per manifest version for offline reuse.

## Exported signatures (for 56-09, 56-11, 56-12)

```ts
ensureValveClient(opts: { appFolder: string }, deps?: ValveClientDeps): Promise<DrmStepResult<ValveClientReady>>
type ValveClientReady = { clientDir: string; manifestVersion: string;
  dlls: { steamclient64: string; tier0: string; vstdlib: string }; source: 'cache' | 'download' }
type ValveClientDeps = { fetchText?; fetchToFile?; runUnzip?; manifestTimeoutMs?; packageTimeoutMs?; onFetchStart?: () => void }
```

`ValveClientReady.manifestVersion` is the value 56-12 writes into the `[bridge-drm]` anchor `client=` field. 56-11 calls `onFetchStart` for the `Steam client files` progress context (called exactly once, only when no verified cache exists).

## Cache layout

`<appFolder>/steam-bridge/drm/valve-client/<manifest-version>/` holds `steamclient64.dll`, `tier0_s64.dll`, `vstdlib_s64.dll` and `valve-client.json` (`{schema:1, manifestVersion, packageFile, packageSha2, files:{<dll>:{size,sha256}}}`). Every launch re-hashes the DLLs against the metadata with no network. Older version dirs are pruned best-effort.

## Abort ids

`drm-valve-client:manifest`, `drm-valve-client:package`. Deadlines: 30 s manifest, 600 s package, 120 s unzip.

## Fixtures

`steam_client_win64.vdf` is a LIVE capture (2026-10-28), manifest `version` 1792618285 (7379 bytes). The four zips are generated by this script (stdlib, ZIP_STORED, fixed dates):

```python
import sys, zipfile, os
out = sys.argv[1]
DT = (2026, 10, 21, 0, 0, 0)
NAMES = ['steamclient64.dll', 'tier0_s64.dll', 'vstdlib_s64.dll']
def body(n): return ('gamelib valve-client fixture %s\n' % n).encode()
def add(z, name, data, symlink=False):
    zi = zipfile.ZipInfo(name, DT); zi.compress_type = zipfile.ZIP_STORED; zi.create_system = 3
    zi.external_attr = (0o120777 << 16) if symlink else (0o100644 << 16)
    z.writestr(zi, data)
def make(fn, fill):
    with zipfile.ZipFile(os.path.join(out, fn), 'w') as z: fill(z)
def good(z):
    for n in NAMES: add(z, n, body(n))
def hostile(z):
    good(z); add(z, '../escape.txt', b'escaped\n'); add(z, 'sub/steamclient64.dll', b'nested decoy\n')
def symlink(z):
    add(z, 'steamclient64.dll', b'/etc/hosts', symlink=True)
    add(z, 'tier0_s64.dll', body('tier0_s64.dll')); add(z, 'vstdlib_s64.dll', body('vstdlib_s64.dll'))
def missing(z):
    add(z, 'steamclient64.dll', body('steamclient64.dll')); add(z, 'tier0_s64.dll', body('tier0_s64.dll'))
make('bins_win64.fixture.zip', good); make('bins_win64.hostile.fixture.zip', hostile)
make('bins_win64.symlink.fixture.zip', symlink); make('bins_win64.missing.fixture.zip', missing)
```
