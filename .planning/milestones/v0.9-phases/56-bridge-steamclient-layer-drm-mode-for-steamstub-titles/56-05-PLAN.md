Build the D-15/D-16 evidence reader for DRM mode: a zero-import trace parser (`drm/drmTrace.ts`)
and a DRM branch in `meta/bridgeCensus.ts` `classifyBridgeEvidence`.

Purpose: DRM mode has no GameLib shim, so there is no `HELLO shim attached` line. Without this
plan every DRM-mode title reads `unverified (no HELLO)` and the Phase 56 live gate (56-15) has no
tool to judge it. Research F1 makes `bridgeCensus.ts`, not `bridgeVerdict.ts`, the strict
classifier. Pitfall 10 explains the role tag: lsteamclient also initialises inside the GameLib
helper `steam.exe`, so an untagged "CreateInterface was logged" line would pass for the helper.

Output: `drmTrace.ts` + tests; census DRM branch, `.bind` row routing text, and driver wiring + tests.
56-12 consumes `parseDrmTraceFile`, `formatDrmTraceLine`, `drmRelogPrefix` and `DRM_TRACE_ENV`.

not with anything from this plan; this plan only parses that anchor. 56-15 runs
`pnpm bridge-census` against them.
