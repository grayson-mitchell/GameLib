<objective>
Close G20: an interrupted engine unpack (Cmd-Q on 'Unpacking built-in engine', re-UAT item 26)
leaves `steam-engines/.tmp-wine-*` (268 MB), and nothing sweeps it at boot because
`pruneUnpinnedEngines` runs only after a successful install (fallbackEngine.ts ~L310/392).

Design (honours the sidecar exit contract in gamelib-conventions): a synchronous, bounded sweep
called once at boot. Synchronous because it then leaves nothing in flight (half 2 of the
contract) and cannot race an install: it runs before READY, so no RPC-driven install can have
created a `.tmp-*` yet, and it also checks the in-process counters. It creates no handle (half 1).
The cost is one directory listing plus deleting whatever stale temp trees exist, which on a clean
boot is a single `readdirSync`.

Output: `sweepStaleEngineTemps()`, its boot wiring, tests.
</objective>
