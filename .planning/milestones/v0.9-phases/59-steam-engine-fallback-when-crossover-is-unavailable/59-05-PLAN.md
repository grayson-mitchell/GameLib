<objective>
Make the bridge bottle's engine switchable per launch without touching any of the 18
`getBridgeBottleSettings` call sites: add an engine registry that mirrors the existing
`drmBridgeRunners` precedent, a fallback `GameSettings` builder, and an engine-aware wineserver
kill.

Purpose: redists, known fixes, DLL-override writes, the launch and the wineserver kill must all
use the same engine and the same wineserver (RESEARCH Pattern 1, Pitfall 2). The registry is
session-scoped and rebuilt every launch, so falling back is never stored state (D-07).

Output: engine/engineRegistry.ts and the bottle.ts changes, covered by bottle.test.ts.
</objective>
