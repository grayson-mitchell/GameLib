<objective>
Give the fallback engine the ability to create a bridge bottle from nothing (no CrossOver ever,
D-01/D-02), make that bottle adoptable by CrossOver later (D-03), bound CrossOver's own bottle
creation (D-12), and switch a bottle cleanly between engines in both directions (D-07).

Purpose: a user who never had CrossOver must still be able to install and play; once they do
install CrossOver, the same prefix becomes a CrossOver bottle with saves intact.

Output: adoptBottle.ts, engineSwitch.ts, the provisionBridgeBottle fallback branch and create
cap, and a pinned-source option on DXVK.installRemove.
</objective>
