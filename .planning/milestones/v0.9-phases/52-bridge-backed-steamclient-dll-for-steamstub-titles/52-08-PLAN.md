Build the backend pieces the launch path (52-09) wires together: a SteamStub bottle-setup module
(ROADMAP Scope 3) and `.bind` detection inside `placeShimForGame` (Scope 4). Setup places
`steamclient64.dll` beside the x64 shim and registers it under
`HKCU\Software\Valve\Steam\ActiveProcess\SteamClientDll64` with `Universe=Public`. It never touches
HKLM (spike 036: `HKLM\Software\Valve\Steam` diverts the game into `steam.exe -applaunch`). Per
orchestrator decision 1 the first live run is made without a `pid` value; per decision 6 the x86
`SteamClientDll` value is not written.

</objective>
