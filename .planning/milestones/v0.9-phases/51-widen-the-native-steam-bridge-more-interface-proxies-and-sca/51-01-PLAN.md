<objective>
TRACER (lead slice of Phase 51): prove the D-51-01 architecture end-to-end on a game that already
works — Avernum 6 (206060) — before any interface widening. One bridge launch spawns one helper
inited with the game's real AppID on an ephemeral loopback port; the backend writes that port into
`gamelib_bridge.cfg` beside the exe; the regenerated shim reads it, says HELLO over CONTROL, and the
helper dies with the game. D-51-03 (concurrent helpers, no lock) falls out of the registry.

Purpose: D-51-01 is rated costly (every call site assumed one helper). Proving it on real hardware
first means an architectural dead-end costs one plan, not eighteen.
Output: per-appId helper registry, argv-driven helper, cfg handoff, shim cfg reader, lifetime via
the bottle process monitor, a compiled-helper integration test, and a live checkpoint on Avernum 6.

Spec-less probe fallback skipped: phase has no requirement IDs to probe (visible skip).
</objective>
