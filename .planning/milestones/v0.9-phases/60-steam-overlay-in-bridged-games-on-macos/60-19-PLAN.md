<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GameLib dylib -> game process | production code intercepts and defers cursor calls inside the game |
| helper -> local session | the overlay state is published under a global notification name |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-60-19-01 | Elevation of Privilege | overlay_input.dylib injection | mitigate | built from in-repo source by build-steam-bridge, ad hoc signed, gitignored artefact; 60-20 checks lstat isFile and safePath before inserting it after the Steam dylibs |
| T-60-19-02 | Spoofing | notification posted by another local process | accept | effect is limited to releasing or restoring the cursor in the user's own game for that appId; a same-user process can already move the cursor |
| T-60-19-03 | Denial of Service | missed close leaves the cursor free | accept | benign (cursor free, game still runs); the next close or game exit ends it; no timeout because the overlay may be open legitimately for long |
| T-60-19-04 | Tampering | game input stream (block branch) | mitigate | blocking goes only through the existing shim function, on open and off on close |
| T-60-19-05 | Denial of Service | stderr flood | mitigate | 64-line cap |
</threat_model>
