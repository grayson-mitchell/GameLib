<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| remote known-fix repo -> launch policy | A tier-1 file from the remote fixes repo reaches users without a release |
| per-game config file -> launch | Per-game JSON on disk is read at launch |
| filesystem/game strings -> log | Causes from fs errors flow into log lines |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-60-02-01 | Tampering | knownFixes steamGameOverlay | mitigate | The allow-list accepts only "off", so a remote file can only remove injection, never add behaviour (same precedent as drm: 'ceg') |
| T-60-02-02 | Tampering | readStoredOverlayOverride | mitigate | appId regex before any path join; parseOverlayOverride maps every unknown value to 'automatic'; parse errors return undefined |
| T-60-02-03 | Tampering / Repudiation | formatOverlayNoticeLine | mitigate | Control chars stripped, cap 160, whitespace-free token, so a crafted cause cannot forge a second log line |
| T-60-02-04 | Elevation of privilege | overlayPaths | mitigate | Absolute and control-char guard on appFolder, CROSSOVER_BUILD_RE on build, contained() check against runnersRoot |
</threat_model>
