| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-80-15 | Elevation of privilege | watchdog spawn | mitigate | the script is a fixed literal; only integer pids are passed as positional args, never interpolated into the script text |

| T-80-17 | Denial of service | huge content_log | mitigate | tail bounded at 256 KiB per read |
| T-80-18 | Information disclosure | profile leakage in tests | mitigate | no env passed; tests use temp dirs only |
