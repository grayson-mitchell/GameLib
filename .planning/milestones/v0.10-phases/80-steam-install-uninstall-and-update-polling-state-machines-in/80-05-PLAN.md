<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| on-disk ACF installdir -> remove_dir_all | a planted ACF could aim deletion anywhere |
| sidecar-supplied appId/roots -> remove_copy | via rustInvoke (plan 18) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-80-11 | Tampering | path traversal in installdir | mitigate | segment check + canonical containment in steamapps/common; tested |
| T-80-12 | Tampering | symlink / junction escape | mitigate | symlink_metadata refusal of the root and common dir; tested per OS |
| T-80-13 | Elevation of privilege | non-numeric appId into a path | mitigate | numeric-only appId before joins |
| T-80-14 | Repudiation | silent deletions | mitigate | log appId, source and outcome (no paths with user names) for every removal |
</threat_model>
