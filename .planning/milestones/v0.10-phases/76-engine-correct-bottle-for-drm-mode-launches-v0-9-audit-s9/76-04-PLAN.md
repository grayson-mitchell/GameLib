  bottle the Wine-Staging fallback creates is never marker-less when CrossOver's preflight probe later

  so a new bottle never relies on inference (checker warning 2). This install-time marker write is

  76-VERIFICATION missing item 1): install records the engine it used; the engine choice
  (`decideCreationEngine`) is unchanged.

  drmOfflinePrecheck and preflightCrossover touch the bottle, covering bottles created by earlier builds
  (marker-less) and bottles already mislabelled crossover (contradicted by DXVK-macOS). This also
  un-defeats drmOfflinePrecheck for those bottles (76-REVIEW CR-01 notes the offline refusal never
  fired for a marker-less bottle).
- Folds 76-REVIEW WR-04 (same DRM block, one line): send `done` when the DRM install root is unresolved.
