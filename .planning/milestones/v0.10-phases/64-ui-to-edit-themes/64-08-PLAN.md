  `LIVE_DERIVED_TOKENS`, minus `CORE_TOKENS` and `NON_COLOUR_TOKENS` (about 60-80 rows per theme).
- Live-derived rows are not stored on Duplicate (OD-1). Their text field is empty until the user sets a
  value; an empty derived field is valid and means "follow the source"; clearing a derived value removes it
  from the draft.
- Warning copy: line "{{a}} vs {{b}} {{ratio}}:1, needs {{min}}:1" with pair labels Border/body,
  Border/dialog, Accent/body; summary plural `contrastSummary_one` "{{count}} contrast warning",
  `contrastSummary_other` "{{count}} contrast warnings", and `contrastSummaryNone` "No contrast warnings";
  Advanced "Advanced", `advancedCount_one`/`_other` "{{count}} more token(s)", `filterPlaceholder` "Filter
  tokens", `filterEmpty` "No tokens match “{{query}}”."; chips "Derived", "Not in preview", "Set by base
  theme"; chip help "Follows {{source}} until you set a value here." and "{{base}} sets this directly, so
  editing it doesn’t change the real app."; gradient error "Enter a plain CSS gradient, for example
  linear-gradient(90deg, #000, #333). var() and url() aren’t allowed."
- Help rule (user preference, UI-SPEC): help is an icon-only (i) on the label line (`FieldLabel` `help`
  slot with `InfoIcon`); never a help paragraph or "Help" link under an input.
- Accent is reserved: the Advanced chevron is accent only when expanded; warnings use `--text-default` text
  with a `--status-warning` triangle and 3px inline-start rule.
