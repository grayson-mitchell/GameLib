<objective>
Give the renderer an awaitable configStore write that reports whether the sidecar actually persisted it,
and allow-list the new `customThemes` key with its typed shape.

Purpose: the user decided (2026-11-18, UI-SPEC "Save failure") that Save awaits the config-store write and,
on rejection, shows the failure toast and keeps the draft dirty. Today `configStore.set` is fire-and-forget
(`snapshotSet` -> `send('storeSet')`, no response frame), so no rejection is observable. Separately, a
configStore key missing from `STORE_ALLOWLIST` silently never persists (RESEARCH Pitfall 6).
Output: the `sidecar:store-set-checked` invoke channel end to end, `configStore.setChecked`, the
`CustomTheme` type, and `customThemes` in the store type and allow-list.
</objective>
