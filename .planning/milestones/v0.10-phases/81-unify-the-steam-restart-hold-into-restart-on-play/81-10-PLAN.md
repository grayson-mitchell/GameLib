<objective>
Delete the D-UAT-13 hold's behaviour (D-11): the install poll reports Installed as soon as the ACF
says so on every OS, and a native handoff no longer gets the "Restart Steam to finish" toast.
Restart-on-Play (81-06), the watch (81-01..81-05) and the page note (81-08, 81-09) now carry the
unadopted case everywhere.

Purpose: the user-visible half of D-11 — the game reads Installed, with Play, immediately.
Sequencing: 81-06 put restart-on-Play on Windows and Linux first (RESEARCH Pitfall 1, D-14), so no
OS regresses to Steam's install dialog. The boot re-arm is deleted by 81-11, the persisted store is
migrated by 81-12/81-13, and the dormant state-machine code is deleted by 81-14..81-16.

Release coupling (operator decision 2026-11-17, recorded against the pre-split numbers 81-08 and
81-09): plans 81-10, 81-11, 81-12 and 81-13 ship in the same release. After 81-11 nothing re-arms a
hold persisted by an older build, and only 81-13's boot drain carries those holds over; a release
cut inside that window would strand them (T-81-48). Do not tag or publish a build between them.
</objective>
