<objective>
Close gap G-47-12c (cosmetic): in a light theme the Store Search game rows are dark grey bands with black text.

Root cause (binding, from `.planning/debug/store-search-rows-dark-in-light-theme.md`): `.storeSearchRow`
(StoreSearch/index.css:128) uses the background shorthand with the card-art overlay gradient token, whose first stop is
a hardcoded 42% black (themes.scss:250, _colors.scss:56) that no theme can override. The shorthand paints it, so a light
theme gets a dark band under near-black text. Deals cards and Library tiles escape only because they declare the token
as a background-color, which is invalid at computed-value time and paints nothing. Phase 20's spec said to match
`.discountCard`; 20-05 wrote the shorthand. The Deals filter panel (`.discountFilters`, DiscountFilters/index.css:7) has
the same shorthand.

Choices recorded (Claude's discretion):
- Row and panel surface: `background: var(--gamecard-title-color)`, the Library tile title-plate token
  (GameCard/index.css:311). Every built-in theme sets it (measured 2026-11-19 from builtinTokens.generated.json: nord-light
  #ccdaf8cc, the dark themes 80% black or #17131cd2), the theme editor exposes it (thumbnailPalette `tileTitle`), and over
  each theme's body it keeps `--text-default` at 11.5:1 or better and `--text-secondary` at 7.3:1 or better. Dark themes
  keep almost the look they have now (the gradient ended in that same plate); Nord Light gets a light plate. Chosen over
  a transparent row because the rows keep their bar shape in every theme.
- Hover and pill tints that were white-alpha literals become `color-mix(in srgb, var(--text-default) N%, transparent)`,
  the project's existing theme-relative tint idiom (`styles/_pillChip.scss`, ConsoleMode). This is needed, not polish:
  once the Deals panel is light, its white 5% hovers (toggle, OS segment) and the white 8% count pill become invisible.
  Fallback values inside `var(--divider, ...)` and `var(--text-secondary, ...)` stay; they never paint while the token exists.
- Sketch findings rule (multi-theme survival): verify against midnightMirage, gruvbox_dark and dracula as well as the
  light theme; the per-theme contrast test covers all ten built-ins.

Purpose: Store Search and the Deals filters read correctly in light themes.
Output: two stylesheet changes and one theme-survival test.
</objective>
