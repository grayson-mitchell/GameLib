  ...)`.

  spreads `settings.defaultSettings` (config.json), so the mirror is not consulted.

  `Skipping auto-update for <title>`, `... already in the download queue`), but with an empty list
  it logs nothing.
- `steam/library/index.ts` `listAutoUpdateableGames` logs only the CR-02 per-app skip; a stale
  registered game (kind !== 'bridge') or an empty result is silent.

This plan adds two cheap diagnostic lines and no behaviour change. No refactor.
