<objective>
Move the Steam store metadata/artwork enrichment to Rust whole: the HTTP fetch, the parsing and the merge into the metadata entry and the game entry. This includes the metadata-entry model that the capture merge (79-28) and the library assembly (79-27) also use.

Purpose: D-12 as written. Rust owns the enrichment and its merge, and TS only persists the result. The same code serves two callers. The Refresh orchestration (79-30) runs `enrich_stage` for apps that have never been enriched. The lazy per-game call site (`fetchMetadataIfNeeded`, 79-32) calls `enrich_entry` through an op. reqwest replaces axios for Steam only; other stores keep axios.
Output: refresh/meta_entry.rs, refresh/store_http.rs and refresh/enrich.rs, with tests.
</objective>
