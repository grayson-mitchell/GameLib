  <action>Create gamelib_ownedapps.h, reusing gamelib_installapp.h's static helpers. Include it after gamelib_installapp.h and call `gl_ia_*` functions; do not duplicate the attach or vtable code.

Define `GL_OA_FN_BLOGGEDON 0x6585u`, `GL_OA_FN_GETSTEAMID 0xd6fcu` and `GL_OA_FN_GETSUBSCRIBEDAPPS 0x8532u`.

Implement `static int gamelib_ownedapps_main(int argc, char **argv)`:
    - Parse `--expect-steamid <decimal u64>`; missing or bad → usage 64.
    - Attach. Resolve each function by high half with a uniqueness check: zero or more than one slot → emit `{"step":"guard","ok":false,"why":"<fn> not uniquely resolved"}` and exit 3.
    - Call BLoggedOn; if not 1 → `{"ok":false,"why":"not-logged-on"}`, exit 2.
    - Call GetSteamID; compare with the expected id → `{"step":"account","match":true|false}`; mismatch → `{"ok":false,"why":"account-mismatch"}`, exit 2.
    - Call GetSubscribedApps(NULL, 0) to get the count n, allocate n (cap 100000, else exit 3), call again with the buffer, and check the second count <= n.
    - Final line `{"ok":true,"count":n,"appIds":[...]}`, exit 0.
    - Bound the whole run with the existing child-timeout pattern so a hung client call cannot hang the helper.

In bridge_helper.c, add `#include "gamelib_ownedapps.h"` and a dispatch `if (argc > 1 && strcmp(argv[1], "--steam-owned-apps") == 0) return gamelib_ownedapps_main(argc, argv);` beside the installapp dispatch. Build with `pnpm build-steam-bridge`. If Mac Steam is running and signed in, smoke it with the configStore SteamID, printing only the count and the ok flag.</action>
