<objective>
Add the credentials + Steam Guard half of Web API sign-in onto the 79-05 transport and flow registry.

Purpose: D-05 gives one HTTPS auth module for both flows, keeps sign-in off the CM and out of the wrap, and avoids logonID collisions during the fallback window.
Output: webauth/credentials.rs with mock tests.

Op shapes (registered in 79-14):
- `steamcm_signin_credentials_start { accountName, password }` → one of:
  - `{ flowId, status:'guardRequired', guardType:'email'|'device' }`
  - `{ flowId, status:'waiting' }` (app approval, or no guard)
  - `{ status:'error', reason:'eresult'|'network', eresult? }`
- `steamcm_signin_guard_submit { flowId, code }` → `{ status:'accepted' }` | `{ status:'error', reason, eresult? }`.

Completion is then read through `steamcm_signin_status`.
</objective>
