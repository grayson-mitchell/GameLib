<objective>
Expose the Rust CM layer through the crate's `dispatch` contract. This covers the global runtime, the singletons, the op table and the CLI.

Purpose: CF-01. The shell, the CLI and the parity tools all reach the CM layer through `dispatch`.
Output: runtime.rs, facade.rs, OPS registration, the CLI host and its tests.

Op table (sorted in OPS). Args are camelCase JSON. Results mirror today's TS types.

Session:
- `steamcm_configure {appFolder}` → `{}`.
- `steamcm_session_acquire {refreshToken, reason, logonId}` → `{ok:true, leaseId, steamId}` or `{ok:false, refusal, logonFailure?}`. steamId is a decimal string. logonId is 0 from TS.
- `steamcm_session_acquire_open {reason}` → `{ok:true, leaseId, steamId}` or `{ok:false}`.
- `steamcm_session_release {leaseId}`, `steamcm_session_ensure_connected {}` → `{connected}`, `steamcm_session_logout {}`.
- `steamcm_session_shutdown {boundMs}` → `{restore}`.
- `steamcm_session_status {}` → `{connected, leaseCount, logonFailure}`.

Signed-in ops, each taking `{leaseId, ...}` and returning `{ok:true, result}` or `{ok:false, kind, eresult?}`:
- `steamcm_licenses`, `steamcm_product_info {apps, packages, inclTokens}`.
- `steamcm_depot_key {appId, depotId}`, `steamcm_manifest_request_code {appId, depotId, manifestId, branch}`, `steamcm_content_servers {appId?}`.
- `steamcm_owned_apps {steamId, includeAppinfo, includePlayedFreeGames, includeFreeSub, skipUnvettedApps}`.
- `steamcm_personas {steamIds}`, `steamcm_redeem_key {key}`.

Anonymous: `steamcm_anon_product_info {apps, packages, inclTokens}` and `steamcm_anon_close {reason}`.

Sign-in: `steamcm_signin_qr_start`, `steamcm_signin_credentials_start`, `steamcm_signin_guard_submit`, `steamcm_signin_status`, `steamcm_signin_cancel`.

Wrap: `steamcm_wrap_restore_if_owed {trigger}`.

CLI-only: `steamcm_capture_anon_pics {apps}` → raw base64 buffers, used for the goldens in 79-21.
</objective>
