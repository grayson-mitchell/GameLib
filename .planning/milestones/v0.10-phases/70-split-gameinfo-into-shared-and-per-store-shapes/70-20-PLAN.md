<objective>
Close the regeneration half of gap G2 (70-REVIEW.md WR-04 item 3): the Steam refresh rebuilds every
library entry with `extra: { reqs: [], ...(cachedMeta?.extra ?? {}), ... }` from
`store_cache/steam_metadata.json` — a `kind: 'cache'` store with no strip chain (a chain on a cache
store would unlink it, discarding art metadata) — so any undeclared or null key there undoes the
library migration on every refresh. And legendary's `about.description` is taken straight from Epic
metadata with no default (`library.ts:587`), so a title without one fails the strict `about` schema.

Chosen fix (Claude's discretion between the two options WR-04 offers): sanitise at build time rather
than add a steam_metadata chain — it covers every future write into steam_metadata, not just what is
on disk today, and keeps the cache.

Output: sanitised refresh build, defaulted legendary description, regression tests in the existing
test files.
</objective>
